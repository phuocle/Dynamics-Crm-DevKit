================================================================================
                              HOWTO: RELEASE
================================================================================

FINAL RELEASE (once per year - uses 31.12.{CurrentYear} 23:59:59):
  .\Release-DynamicsCrm-DevKit.ps1

  Version and settings are loaded from DevKit.ReleaseConfig.json
  Date automatically uses Dec 31 of current year at 23:59:59

TEST RELEASE (any time for testing):
  .\Release-DynamicsCrm-DevKit-CurrentDate.ps1

  Uses current date/time for build timestamp.
  Used for development testing.

WITH CUSTOM DATE:
  .\Release-DynamicsCrm-DevKit.ps1 -BuildDate "15.12.2025 10:00:00"

TO CHANGE VERSION FOR NEW RELEASE:
  Edit DevKit.ReleaseConfig.json:
  {
    "version": "4.50.00.00",  // Change this to new version
    ...
  }

TO ADD/REMOVE FILES FROM RELEASE PROCESS:
  Edit DevKit.ReleaseConfig.json, "files" section:
  - "versionReplacement": Files where version placeholder gets replaced
  - "dateReplacement": Files where date placeholder gets replaced
  - "allModified": Combined list (used by RestoreReplacedFiles.ps1)

RESTORE MODIFIED FILES (after build error):
  .\RestoreReplacedFiles.ps1

  If the release script fails mid-way, it may leave files in a modified state
  with replaced placeholders (x.xx.xx.xx → 4.00.00.00, etc). This script
  uses git restore to revert all modified files back to original state.

  File list is automatically loaded from DevKit.ReleaseConfig.json.

================================================================================
                              TROUBLESHOOTING
================================================================================

VSIX WON'T BUILD:
  - Use MSBuild, NOT dotnet build
  - Check PFX key is imported (run ImportKey.bat)

ANALYZERS NOT WORKING IN VS:
  - Close VS completely
  - Delete bin/obj folders
  - Rebuild analyzer project
  - VS caches analyzers heavily

NUGET PACK FAILS:
  - Ensure all referenced DLLs exist in bin\Release\net48
  - Check nuspec file paths are correct
