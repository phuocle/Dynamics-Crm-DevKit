# TypeScript Modules cho Dynamics 365 / Dataverse

## Tổng quan

Đây là phiên bản TypeScript của các file JavaScript cho Dynamics 365 WebResources. Sử dụng TypeScript modules giúp:

1. **IntelliSense đầy đủ** - Không cần file `.d.ts` riêng
2. **Type safety** - Phát hiện lỗi tại compile time
3. **Không cần load phụ thuộc** - TypeScript bundler sẽ tự động bundle các dependencies
4. **Dễ bảo trì** - Code rõ ràng, có type

## Cấu trúc files

```
ts/
├── devkit.ts           # DevKit module (base library)
├── Account.form.ts     # Account Form module (generated)
├── Account.ts          # Account script (developer writes code here)
└── tsconfig.json       # TypeScript configuration
```

### devkit.ts
- **Chức năng**: Base library chứa các helper functions và interfaces
- **Nguồn gốc**: Convert từ `lib/devkit.js`
- **Export**: 
  - `LoadFormV2` - Hàm chính để load form
  - Các interfaces: `IFieldControl`, `IStringControl`, `INumberControl`, `IBooleanControl`, `IOptionSetControl`, `ILookupControl`, `IDateControl`, `IMoneyControl`, `IForm`, `ITab`, `ISection`, `IGrid`, `INavigationItem`, `IExecutionContext`

### Account.form.ts
- **Chức năng**: Module cho Account form với đầy đủ type definitions
- **Nguồn gốc**: Convert từ `entities/Account.form.js` (generated by tool)
- **Export**:
  - `AccountForm` class - Class chính để sử dụng trong Account.ts
  - `OptionSet.Account` - Các giá trị OptionSet cho Account entity
  - Các interfaces: `IAccountFormBody`, `IAccountFormHeader`, `IAccountFormTabs`, `IAccountFormGrid`, `IAccountFormNavigation`, `IAccountFormQuickForm`

### Account.ts
- **Chức năng**: File chính mà developer viết business logic
- **Nguồn gốc**: Mới viết để demo cách sử dụng
- **Đặc điểm**: Có đầy đủ IntelliSense khi code

## Cách sử dụng

### 1. Import module

```typescript
import { AccountForm, OptionSet } from './Account.form';
```

### 2. Khởi tạo form

```typescript
let form: AccountForm;

function onLoad(executionContext: any) {
    form = new AccountForm(executionContext);
}
```

### 3. Sử dụng với IntelliSense

```typescript
// Lấy giá trị - TypeScript biết kiểu dữ liệu tự động
const accountNumber = form.Body.AccountNumber.Value;  // string | null
const revenue = form.Body.Revenue.Value;               // number | null
const creditOnHold = form.Body.CreditOnHold.Value;    // boolean | null
const industryCode = form.Body.IndustryCode.Value;    // number | null
const primaryContact = form.Body.PrimaryContactId.Value; // { id, name, entityType }[] | null

// Set giá trị
form.Body.Name.Value = "New Account Name";
form.Body.CreditOnHold.Value = true;

// Control visibility và disabled state
form.Body.AccountNumber.Visible = false;
form.Body.AccountNumber.Disabled = true;

// Set required level
form.Body.Name.RequiredLevel = 'required';  // 'none' | 'required' | 'recommended'

// Tab control
form.Tab.DETAILS_TAB.Visible = false;
form.Tab.DETAILS_TAB.DisplayState = 'collapsed';

// Grid control
form.Grid.Contacts.Refresh();
const totalRecords = form.Grid.Contacts.TotalRecordCount;

// Navigation control
form.Navigation.account_parent_account.Visible = false;

// OptionSet comparison
if (form.Body.IndustryCode.Value === OptionSet.Account.IndustryCode.Consulting) {
    // Do something
}
```

## So sánh với phương pháp cũ (JavaScript + .d.ts)

### Phương pháp cũ (JavaScript + .d.ts)

```javascript
// Account.js
/// <reference path="Account.d.ts" />
"use strict";
var formAccount = (function () {
    /** @type {DevKit.FormAccount} */
    let form;
    
    function onLoad(executionContext) {
        form = new DevKit.FormAccount(executionContext);
        // IntelliSense hoạt động nhờ file Account.d.ts
    }
    
    return { OnLoad: onLoad };
})();
```

**Nhược điểm:**
- Cần duy trì 2 files: `.js` và `.d.ts`
- Dễ bị out of sync khi thay đổi
- Phải setup dependencies trong Dataverse

### Phương pháp mới (TypeScript Modules)

```typescript
// Account.ts
import { AccountForm, OptionSet } from './Account.form';

let form: AccountForm;

function onLoad(executionContext: any) {
    form = new AccountForm(executionContext);
    // IntelliSense hoạt động trực tiếp từ TypeScript types
}

export default { OnLoad: onLoad };
```

**Ưu điểm:**
- Một file nguồn duy nhất
- Types luôn sync với implementation
- Không cần setup dependencies trong Dataverse (bundler sẽ lo)
- Better refactoring support
- Compile-time error checking

## Build và Deploy

### Development
```bash
# Compile TypeScript to JavaScript
npx tsc

# Hoặc watch mode
npx tsc --watch
```

### Production (với bundler)
Sử dụng bundler như Webpack, Rollup, hoặc esbuild để bundle tất cả thành 1 file JavaScript.

```bash
# Ví dụ với esbuild
npx esbuild Account.ts --bundle --outfile=Account.bundle.js --format=iife
```

## Roadmap - Tự động generate Account.form.ts

Trong tương lai, tool generator sẽ:
1. Đọc metadata từ Dataverse
2. Tự động generate file `Account.form.ts` với đầy đủ:
   - Interfaces cho Body fields
   - Interfaces cho Header fields
   - Interfaces cho Tabs và Sections
   - Interfaces cho Grids
   - Interfaces cho Navigation items
   - Interfaces cho QuickForms
   - OptionSet values
3. Developer chỉ cần import và sử dụng trong `Account.ts`

## Notes

- File `devkit.ts` chỉ convert một phần từ `lib/devkit.js` để demo tính khả thi
- File `Account.form.ts` là ví dụ về output của generator tool
- Trong production, cần bundle các files thành 1 file JS duy nhất để deploy lên Dataverse
