# DynamicsCrm.DevKit

Visual Studio extension (VSIX) for Microsoft Dynamics 365 / Power Platform / Dataverse development.

## Features

- **Project Templates**: Create plugin, workflow, custom action, custom API, data provider, console, and web resource projects
- **Item Templates**: Generate forms, web resources, tests, and proxy types
- **T4 Templates**: Code generation for entities and forms
- **Connection Management**: Support for OAuth, Client Secret, Certificate, Managed Identity, and more
- **Wizard-based Development**: Step-by-step guidance for creating CRM components

## Project Types

| Template | Description |
|----------|-------------|
| Plugin | Dynamics 365 plugin development |
| Workflow | Custom workflow activities |
| Custom Action | Custom action implementations |
| Custom API | Custom API endpoints |
| Data Provider | Virtual entity data providers |
| WebResource | JavaScript/TypeScript web resources |
| Console | Console applications for CRM |
| ProxyTypes | Early-bound entity classes |
| Test | Unit testing projects |

## Requirements

- Visual Studio 2022 or later
- .NET Framework 4.6.2+ or .NET Standard 2.0
- Microsoft Dynamics 365 / Power Platform environment

## Getting Started

1. Install the extension from Visual Studio Marketplace
2. Create a new project using DynamicsCrm.DevKit templates
3. Configure your connection in `DynamicsCrm.DevKit.json`
4. Start developing!
