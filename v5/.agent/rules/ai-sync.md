# AI Config Sync Rules

> **Purpose**: Ensure all 3 IDEs (Claude Code, Copilot, Antigravity) stay in sync.

---

## Source of Truth

`.agent/` is the **single source of truth** for all AI configuration.

| IDE | Rules (read from) | Workflows (read from) | Skills | Entry File |
|-----|--------------------|-----------------------|--------|------------|
| **Antigravity** (Google AI Pro) | `.agent/rules/` (direct) | `.agent/workflows/` (direct) | `.agent/skills/` (direct) | `AGENTS.md` |
| **Claude Code** (VS Code) | `.claude/rules/*.md` (synced) | `.claude/commands/claude-*.md` (synced) | - | `CLAUDE.md` (@imports AGENTS.md) |
| **VS Code Copilot** (GitHub Copilot Pro) | `.github/copilot-instructions.md` + `AGENTS.md` | `.github/prompts/copilot-*.prompt.md` | - | `AGENTS.md` |

---

## Naming Convention

Workflow/command files use an **IDE prefix** to identify which IDE they belong to:

| Source (`.agent/workflows/`) | Claude | Copilot |
|-----|--------|---------|
| `build-debug.md` | `claude-build-debug.md` | `copilot-build-debug.prompt.md` |
| `commit.md` | `claude-commit.md` | `copilot-commit.prompt.md` |

Rules do NOT use prefix — they keep the original name across all IDEs.

---

## DO NOT Edit Directly

> [!CAUTION]
> **NEVER** edit these files directly. They are auto-generated by `Sync-AI-Config.ps1`:
> - `.claude/rules/*.md`
> - `.claude/commands/claude-*.md`
> - `.github/copilot-instructions.md`
> - `.github/prompts/copilot-*.prompt.md`

---

## When Editing Rules or Workflows

Regardless of which IDE you are working in:

1. **Edit** the file in `.agent/rules/` or `.agent/workflows/`
2. **Run**: `.\DynamicsCrm.DevKit.Scripts\Sync-AI-Config.ps1`
3. **Verify** output shows `"All files are in sync!"`

```powershell
# Example: after editing .agent/rules/core-rule.md
.\DynamicsCrm.DevKit.Scripts\Sync-AI-Config.ps1
```

## MCP Configuration

**Source of truth**: `.vscode/mcp.json` (VS Code format, `"servers"` key).

| Source | Target | Format | Sync |
|--------|--------|--------|------|
| `.vscode/mcp.json` | `.vscode/mcp.json` | `"servers": { ... }` | Source (Claude Code + Copilot) |
| — | Antigravity (user-level) | Per Antigravity format | Manual |

> [!IMPORTANT]
> **Antigravity** uses user-level config at `C:\Users\p\.gemini\antigravity\mcp_config.json`.
> This file is NOT auto-synced. After updating `.vscode/mcp.json`, manually update the Antigravity config.
