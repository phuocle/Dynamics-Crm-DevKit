# AI Config Sync Rules

> **Purpose**: Ensure all 4 IDEs (Claude Code, Copilot, Antigravity, Cursor) stay in sync.

---

## Source of Truth

`.agent/` is the **single source of truth** for all AI configuration.

| IDE | Rules (read from) | Workflows (read from) | Skills | Entry File |
|-----|--------------------|-----------------------|--------|------------|
| **Antigravity** (Google AI Pro) | `.agent/rules/` (direct) | `.agent/workflows/` (direct) | `.agent/skills/` (direct) | `AGENTS.md` |
| **Claude Code** (VS Code) | `.claude/rules/*.md` (synced) | `.claude/commands/claude-*.md` (synced) | ❌ Not supported | `CLAUDE.md` (@imports AGENTS.md) |
| **Cursor** (Composer) | `.cursor/rules/*.mdc` (synced) | `.cursor/commands/cursor-*.md` (synced) | ❌ Not supported | `AGENTS.md` |
| **VS Code Copilot** (GitHub Copilot Pro) | `.github/copilot-instructions.md` + `AGENTS.md` | `.github/prompts/copilot-*.prompt.md` | ❌ Not supported | `AGENTS.md` |

---

## Naming Convention

Workflow/command files use an **IDE prefix** to identify which IDE they belong to:

| Source (`.agent/workflows/`) | Claude | Cursor | Copilot |
|-----|--------|--------|---------|
| `build-debug.md` | `claude-build-debug.md` | `cursor-build-debug.md` | `copilot-build-debug.prompt.md` |
| `commit.md` | `claude-commit.md` | `cursor-commit.md` | `copilot-commit.prompt.md` |

Rules do NOT use prefix — they keep the original name across all IDEs.

---

## DO NOT Edit Directly

> [!CAUTION]
> **NEVER** edit these files directly. They are auto-generated by `Sync-AI-Config.ps1`:
> - `.claude/rules/*.md`
> - `.claude/commands/claude-*.md`
> - `.cursor/rules/*.mdc`
> - `.cursor/commands/cursor-*.md`
> - `.github/copilot-instructions.md`
> - `.github/prompts/copilot-*.prompt.md`

---

## When Editing Rules or Workflows

Regardless of which IDE you are working in:

1. **Edit** the file in `.agent/rules/` or `.agent/workflows/`
2. **Run**: `.\DynamicsCrm.DevKit.Scripts\Sync-AI-Config.ps1`
3. **Verify** output shows `"All files are in sync!"`

```powershell
# Example: after editing .agent/rules/core-rule.md
.\DynamicsCrm.DevKit.Scripts\Sync-AI-Config.ps1
```

---

## MCP Configuration

MCP config is **manually maintained** per IDE (contains credentials):

| IDE | MCP Config Location |
|-----|---------------------|
| **Antigravity** | `.agent/mcp.json` (backup) |
| **Claude Code** | `.vscode/mcp.json` (shared with Copilot) |
| **Cursor** | `.cursor/mcp.json` (workspace) |
| **VS Code Copilot** | `.vscode/mcp.json` (shared with Claude Code) |

> [!IMPORTANT]
> When updating MCP config in one IDE, manually copy the equivalent config to the other IDE locations.
