# DevKitTs-Vsix WebResourceTs

TypeScript WebResource project for Dynamics CRM DevKit - Visual Studio Extension version.

## Project Structure

```
06.DevKitTs-Vsix/
├── Dev.DevKit.WebResourceTs/
│   ├── entities/
│   │   ├── Account.ts              # Main form with all test functions
│   │   ├── Account.form.ts         # Form implementation (generated)
│   │   ├── Account.webapi.ts       # WebAPI implementation (generated)
│   │   └── OptionSet.ts            # OptionSet definitions (generated)
│   ├── lib/
│   │   ├── devkit.ts               # Core DevKit TypeScript library
│   │   └── devkit.d.ts             # TypeScript definitions
│   ├── build/                      # Build output folder
│   └── build.js                    # Build script (esbuild)
└── package.json
```

## Quick Start

```powershell
# From TestClientCode folder:
.\01.Clean-All.ps1      # Clean
.\02.Install-All.ps1    # Install npm packages
.\03.Generate-All.ps1   # Generate entity files from CRM
.\04.Sync-All.ps1       # Sync source of truth files
.\05.Build-All.ps1      # Build TypeScript projects
.\06.Test-All.ps1       # Run tests
```

## NPM Scripts

| Command | Description |
|---------|-------------|
| `npm run check` | Run TypeScript type checking |
| `npm run debug` | Build in debug mode (with sourcemaps) |
| `npm run debug Account` | Build specific entity in debug mode |
| `npm run release` | Build in release mode (minified) |
| `npm run release Account` | Build specific entity in release mode |

## Build Output

- **Debug mode**: Full code with inline sourcemaps in `build/` folder
- **Release mode**: Minified code (devkit always minified) in `build/` folder
