# DevKitJs-AICode

JavaScript testing project for Dynamics CRM DevKit controls.

## Project Structure

```
03.DevKitJs-AICode/
├── Dev.DevKit.WebResource/
│   ├── entities/
│   │   ├── Account.js              # Main form with all test functions
│   │   ├── Account.form.js         # Form implementation (generated)
│   │   ├── Account.webapi.js       # WebAPI implementation (generated)
│   │   ├── Account.d.ts            # TypeScript definitions (generated)
│   │   └── devkit.d.ts             # DevKit type definitions
│   └── lib/
│       └── devkit.js               # Core DevKit JavaScript library
└── package.json
```

## Quick Start

```powershell
# From TestClientCode folder:
.\01.Clean-All.ps1      # Clean
.\02.Install-All.ps1    # Install npm packages
.\03.Generate-All.ps1   # Generate entity files from CRM
.\04.Sync-All.ps1       # Sync source of truth files
.\05.Check-Build-Test.ps1 # Run checks, builds, and tests
```

## Architecture

Uses **class-based pattern** with `new DevKit.FormXXX(executionContext)`.

```javascript
var formAccount_DevKitV4 = (function () {
    let form;
    
    async function onLoad(executionContext) {
        form = new DevKit.FormAccount_DevKitV4(executionContext);
        registerEvents();
    }
    
    return { onLoad: onLoad };
})();
```
