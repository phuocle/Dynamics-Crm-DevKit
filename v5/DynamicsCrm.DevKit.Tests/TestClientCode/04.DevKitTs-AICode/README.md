# DevKitTs-AICode

TypeScript testing project for Dynamics CRM DevKit controls.

## Project Structure

```
04.DevKitTs-AICode/
├── Dev.DevKit.WebResourceTs/
│   ├── entities/
│   │   ├── Account.ts              # Main form with all test functions
│   │   ├── Account.form.ts         # Form implementation (generated)
│   │   ├── Account.webapi.ts       # WebAPI implementation (generated)
│   │   └── OptionSet.ts            # OptionSet definitions (generated)
│   ├── lib/
│   │   ├── devkit.ts               # Core DevKit TypeScript library
│   │   └── devkit.d.ts             # TypeScript definitions
│   └── build.js                    # Build script (esbuild)
└── package.json
```

## Quick Start

```powershell
# From TestClientCode folder:
.\01.Clean-All.ps1      # Clean
.\02.Install-All.ps1    # Install npm packages
.\03.Generate-All.ps1   # Generate entity files from CRM
.\04.Sync-All.ps1       # Sync source of truth files
.\05.Check-Build-Test.ps1 # Run checks, builds, and tests
```

## Architecture

Uses **TypeScript class-based pattern** with `new Account.Account_DevKitV4(executionContext)`.

```typescript
import { Account } from './Account.form';

export function OnLoad(executionContext: any): void {
    const form = new Account.Account_DevKitV4(executionContext);
    // Use strongly-typed form controls
    form.Body.v4_String.Value = "Hello";
}
```

## NPM Scripts
