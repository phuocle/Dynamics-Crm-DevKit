01 / Kết luận để ra quyết định

Có thể cung cấp dropdown khi người dùng gõ Context., ngay trong dialog Edit T4 hiện tại. Model đã có 41 property công khai, phần lớn là scalar hoặc helper tính toán. Completion này không cần chạy T4, kết nối Dataverse hay dùng AI. Cần thay hoặc mở rộng editor và xây một lớp hiểu vị trí con trỏ trong T4.

Giữ engineT4 của Visual Studio đã đáp ứng logic sinh mã. Điểm yếu chính nằm ở lớp tích hợp và trải nghiệm soạn thảo.
Context completionĐề xuất AvalonEdit + catalog property + bộ nhận diện block T4 cho bản đầu tiên.
Sửa độ tin cậy trướcTách output khỏi lỗi/warning, bảo vệ nội dung chưa lưu, làm rõ dữ liệu thực sự có trong Context.

“Chấm thả” được hiểu là IntelliSense/member completion sau dấu chấm. Nếu ý định còn bao gồm kéo property từ danh sách vào editor, có thể bổ sung thao tác đó; click/Enter để chèn nên có trước vì dễ dùng bằng bàn phím.

Nhận diện block và vị trí chèn

Dùng tokenizer/state machine theo dialect T4 đã chọn để phân biệt output text, directive, expression, statement và class feature. Trong code region cần hiểu comment/string, gồm escape/verbatim và các dạng C# được hỗ trợ. Parse từ checkpoint gần nhất và cập nhật theo phiên bản document; regex đơn lẻ không đủ với block nhiều dòng và template đang gõ dở. Quy tắc delimiter phải được đối chiếu host thật, nhất là chuỗi chứa ký tự T4.

Ở literal text, Explorer chèn cả expression; ở code region, chèn Context.Property; đang đứng sau Context. thì chỉ chèn member. Không tự chèn vào attribute string của directive hay comment. Nếu không xác định chắc vị trí, cho Copy expression hoặc hiện hướng dẫn thay vì sửa sai.

Nếu cần IntelliSense C# đầy đủ

Cần document C# trung gian với class/TransformText, property Context và references; ánh xạ offset qua lại giữa T4 và C#, giữ code block xuyên các đoạn output, tách class feature khỏi thân hàm, xử lý include và scope. Roslyn/VS language service mới suy ra được c., LINQ, overload và lỗi kiểu. Chạy semantic analysis nền, hủy kết quả cũ theo document version. Không transform/execute template để lấy completion.

Gắn content type “CSharp” vào toàn bộ buffer T4 không tự tạo IntelliSense đúng: phần output lẫn directive là cú pháp không hợp lệ đối với parser C#. Ngược lại, có cú pháp tô màu đẹp không chứng minh semantic completion hoạt động.

06 / Dialog đề xuất cho end-user

  1. Khởi đầu từ template có sẵn. Default ghi rõ là mẫu hệ thống; người dùng chỉnh rồi Save As. Có snippets expression, if/else, image guard, registration và test guard.
  2. Giải thích tại chỗ. Explorer có tìm kiếm/nhóm, kiểu, mô tả, giá trị thực và tình trạng thiếu dữ liệu. Tooltip ưu tiên ClassWithOrder, EntityLogicalName, RegistrationName nhưng không làm mất tên legacy.
  3. Review cùng màn hình. Preview chỉ đọc, diagnostics riêng có severity và vị trí; click chuyển caret. Đánh dấu stale khi template/context đổi; không trình bày preview cũ như kết quả hiện tại.
  4. Sample context offline. Preset Plugin Create/Update/Delete, async, order 2, global/bound Custom API, Test có/không target. Cần entrypoint Template Manager hoặc cho mở Customize trước IsValid để thật sự làm việc offline; hiện Customize nằm sau validation wizard.
  5. Validate rõ nghĩa. “Check syntax” là static analysis, không cam kết phát hiện mọi lỗi host; “Review” chạy transform; “Compile generated code” là bước riêng vì output có thể thiếu reference của project. Không gọi Review là sandbox.
  6. So sánh dễ đọc. Diff với default, reset draft, import/export UTF-8, lưu lựa chọn cuối cùng. Có thể mở rộng revision history sau, tránh lưu bản sao mọi lần gõ vào config.
  7. Bàn phím và accessibility. Ctrl+S/Ctrl+Shift+S, Ctrl+F, Ctrl+Space; focus order rõ, dropdown không giữ Tab vô hạn; hỗ trợ IME, high contrast và DPI 100–200%.

Các cải tiến nhỏ nên đi kèm: thay StackPanel + Height = windowHeight - 110 bằng Grid co giãn; splitter có MinWidth; trạng thái Save/Review inline thay message box thành công liên tục; cleanup cursor/focus ở finally. Đây là thay đổi UX đề xuất, không yêu cầu đổi public command hay key JSON.

Parameter đang được prepend vào cùng dòng đầu. Vì vậy diagnostic ở đầu file có thể lệch cột; không thể sửa bằng cách trừ 1 khỏi mọi số dòng. Cần source mapping cho phần được inject, newline, include và generated C#; lỗi trong include nên mở đúng file include. Bổ sung fixture kiểm chứng tọa độ mà callback của host thật trả về. Callback hiện không có filename parameter, nên khả năng map nguồn include cần thử API host/error session bổ sung, không hứa mapping đầy đủ chỉ từ callback hiện có. [S1]

Hiệu năng: đo trước, tối ưu đúng chỗ

  • Repo đã có ItemTemplateTelemetry đo elapsedMs qua Stopwatch/Debug.WriteLine. Tận dụng các scope GetT4Code, BuildContext và ProcessTemplate; thêm thời gian mở dialog, completion, render preview, độ dài template và cache hit. Không ghi toàn bộ template hoặc giá trị metadata vào telemetry. [S11]
  • Cache schema/reflection và embedded template text; filter 41 entry tại bộ nhớ. Snapshot Context một lần, tránh getter động làm tooltip đổi liên tục; metadata lazy theo nhu cầu, không tải schema Dataverse đầy đủ mỗi lần mở popup.
  • Debounce static diagnostics khoảng 200–400 ms là mục tiêu ban đầu; completion sau dấu chấm cần phản hồi ngay. Mục tiêu thử nghiệm: warm completion P95 dưới 50 ms cho 100 KB template, mở editor warm dưới 300 ms sau khi có context. Đây là budget đề xuất, chưa có số đo thực tế.
  • Review chạy theo nút explicit trước. Nếu sau này có live preview, gắn vào chế độ opt-in với trust/context rõ và bỏ kết quả stale. Không chạy full transform mỗi lần gõ vì T4 thực thi code tùy ý. [Microsoft: execution model]
  • Host service có mutable Session. Điều phối các request của DevKit, không chạy transform song song trên cùng instance; lưu/khôi phục session trước đó nếu host contract cho phép, cleanup trong finally. Khóa nội bộ DevKit không bảo đảm extension khác không gọi cùng service.
  • ProcessTemplate là đồng bộ. Cancellation token có thể hủy request chờ hoặc bỏ kết quả cũ, không bảo đảm dừng code đang transform. Nếu cần timeout cứng/khả năng kill, phải nghiên cứu worker process và host riêng; đây là thay đổi lớn với assembly resolution và compatibility.
  • Chỉ cache compiled template/output sau khi profiling chứng minh cần và xác định host API. Cache key còn phụ thuộc references, includes, context, engine và side effects; output có GeneratedDate càng không phù hợp cache đơn giản theo text.

Không cần đổi engine sang engine khác chỉ để có completion. Parser/editor là tầng riêng; thay engine sẽ thêm bài toán directive/assembly/AppDomain compatibility mà chưa giải quyết trải nghiệm gõ.

08 / Template dễ chia sẻ, dữ liệu rõ ràng và tương thích

Giữ các template hiện có chạy được

Giữ Type, Title, Body, IsDefault và các tên property Context hiện có. Bản đầu import/export chỉ chuyển giữa text UTF-8 và Body đang dùng; không cần đổi schema. Quy ước extension .t4/.ttinclude và Custom Tool rỗng cho file chỉ được DevKit xử lý, để không vô tình chạy transform thiếu session khi save trong VS. [S3] [Microsoft: include files]

Nếu triển khai file-backed sau: thiết kế migration đọc schema cũ, export từng template, đường dẫn relative solution, lựa chọn source of truth rõ, phát hiện file thiếu/conflict và không ghi đè từ cache cũ. Cần quyết định trước việc thêm key mới (ví dụ path/schema version); đây là thay đổi format ngoài phạm vi MVP. Không âm thầm đổi ý nghĩa Body thành đường dẫn.

Include và reuse

Template file-backed có absolute input path để include relative được xác định theo file. Template trong JSON cần virtual filename có base path quy ước hoặc thư mục materialize có vòng đời rõ. Không lấy current working directory làm contract. Diagnostics phải giữ identity nguồn; đọc dependency để biết khi nào preview stale. Assembly/import dùng trong code transform khác với using được phát ra vào mã C# đích: hướng dẫn và snippet cần giải thích sự khác nhau này.

Data Provider cần một thiết kế riêng

Bật lại panel là chưa đủ. Phải có template set với 5 operation, chọn/edit/preview từng operation, resolve custom theo operation và fallback được hiển thị rõ. Model hiện không có SubType, nên cần thiết kế lưu trữ tương thích trước khi thêm hỗ trợ. Một title + Body duy nhất không biểu diễn tự nhiên 5 body khác nhau; không tái dùng một custom body cho cả 5 replacement một cách ngầm định. Có thể bắt đầu bằng template bundle import/export có manifest sau khi thống nhất schema.

Có cần thêm property không?

41 property đủ cho scaffolding hiện tại; ưu tiên mô tả và nguồn dữ liệu trước. Khi có use case, có thể thêm ItemType, TemplateOperation, ContextSchemaVersion, timestamp cố định theo generation, và availability rõ cho metadata. Đó là API đề xuất, không phải tên đang tồn tại. Attributes/Relationships/Options collection chỉ nên bổ sung kèm lazy loading, cost indicator và snapshot serializable; không truyền ServiceClient/DTE vào model cho tiện autocomplete.

Helper escape C# string literal, identifier và comment hữu ích cho template chứa display name/user input có dấu nháy, xuống dòng, keyword. Thiết kế API output rõ loại literal/identifier, có test Unicode và */; không biến helper escaping thành sanitizer cho toàn bộ template code.

Import và completion chỉ đọc/chỉnh text. Review/Generate mới thực thi template. Nên thể hiện ranh giới này trong sản phẩm và lưu nguồn template nếu hỗ trợ chia sẻ; không mô tả parser hoặc AppDomain như một sandbox bảo mật.

Tài liệu bên ngoài đã đối chiếu ngày 21/10/2026

Các liên kết Microsoft Learn, Microsoft GitHub và upstream AvalonEdit được đặt ngay cạnh luận điểm tương ứng trong từng phần. API reference VS SDK 2022 là bằng chứng về API, không thay thế kiểm thử integration trên Visual Studio 2026. Không coi quảng cáo extension, version compiler hoặc latency chưa đo là kết quả xác nhận.

Điểm cần xác nhận bằng spike trước khi viết tính năng

  • Version engine/compiler thực tế, cú pháp C# được chấp nhận, resolution assembly chứa T4Context và include trong host VS.
  • Thread affinity, service/session lifetime và đường lấy filename diagnostic của host.
  • Khả năng screen reader/IME và phím completion của editor lựa chọn trong modal dialog.
  • Team có cần full C# semantics hay Context completion đủ đáp ứng; có cần custom Data Provider ngay đợt đầu không.
