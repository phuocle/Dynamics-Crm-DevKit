# Before optimize

## Block 1 — Tool description (hiện tại)

```text
List, get, create, update, delete, or clear Dataverse environment variables.

ACTIONS:
- action='list': List all variables (name, type, default/current value). Optional: solution_name, max_records
- action='detail': Get details for one variable. Requires variable_name
- action='create': Create variable definition. Requires variable_name + display_name + type. Optional: default_value, value, description, solution_name
- action='update': Update existing variable. Requires variable_name. Optional: display_name, default_value, value, description
- action='delete': Permanently delete definition + current value. Requires variable_name. WARNING: irreversible
- action='clear': Delete current value only (reverts to default). Requires variable_name

TIPS:
- Current value overrides default value
- Type cannot be changed after creation
- Does not require publishing in most cases
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[action] (string, required)
The action to perform: 'list', 'detail', 'create', 'update', 'delete', or 'clear'.

[variable_name] (string, default: "")
Schema name with publisher prefix (e.g., 'new_ApiEndpoint'). Required for detail, create, update, delete, and clear. Leave empty for list.

[solution_name] (string, default: "")
Solution unique name. Filters results (list only) or adds definition to solution (create only). Leave empty for all.

[max_records] (int, default: 50)
Maximum number of variables to return in list mode. Default is 50.

[display_name] (string, default: "")
Display name. Required on create.

[type] (string, default: "")
Type: 'string', 'number', 'boolean', 'json', 'datasource', 'secret'. Required on create, ignored on update.

[default_value] (string, default: "")
Default value for the definition.

[value] (string, default: "")
Current value override. Creates/updates the value record.

[description] (string, default: "")
Variable description.

[auto_publish] (bool, default: false)
Publish after changes. Default: false.
```

```text
Dataverse environment variables — list/detail/create/update/delete/clear.
- list: optional solution_name, max_records
- detail: variable_name

- update: variable_name. Optional: display_name, default_value, value, description

WHEN TO USE:
- Inspect / list env vars in a solution (config secrets, feature flags, etc.)
- Create or update a definition + current value
- Clear current value to revert to default; delete to remove definition entirely
```
