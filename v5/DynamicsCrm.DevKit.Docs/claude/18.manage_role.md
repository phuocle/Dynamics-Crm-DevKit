# Before optimize

## Block 1 — Tool description (hiện tại)

```text
Manage security roles: list, inspect, CRUD, copy, assign/unassign users.

ACTIONS:
- action='list': List root roles. Optional: role_name, business_unit_id, max_records
- action='detail': Role privileges grouped by entity. Required: role_id. Optional: entity_name
- action='user': User's roles + effective privileges. Required: user_id. Optional: entity_name
- action='assign': Assign role to user. Required: role_id + user_id
- action='unassign': Remove role from user. Required: role_id + user_id
- action='create': Create custom role. Required: role_name. Optional: business_unit_id
- action='update': Rename role. Required: role_id + role_name
- action='delete': Delete custom role (irreversible). Required: role_id
- action='copy': Clone role with all privileges. Required: role_id + role_name

WHEN TO USE:
- Debug 'access denied': action='user' + entity_name
- Audit role grants: action='detail'
- Provision access: action='assign'/'unassign', or action='create'/'copy'

TIPS:
- Depth levels: User < BU < Parent:ChildBU < Org
- Only root roles listed (not inherited BU copies)
- Managed roles cannot be deleted; use action='copy' to clone then customize
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[action] (string, required)
Action: list, detail, user, assign, unassign, create, update, delete, copy.

[user_id] (string, default: "")
Email or GUID. Required for: user, assign, unassign.

[role_id] (string, default: "")
Role GUID. Required for: detail, assign, unassign, update, delete, copy.

[role_name] (string, default: "")
Filter (contains) in list. New name for create/update/copy.

[business_unit_id] (string, default: "")
BU GUID. Filter in list. Target BU for create (empty = root BU).

[entity_name] (string, default: "")
Filter privileges by entity (e.g. 'account'). For detail and user only.

[max_records] (int, default: 50)
Max roles in list mode. Default: 50, max: 250.
```
