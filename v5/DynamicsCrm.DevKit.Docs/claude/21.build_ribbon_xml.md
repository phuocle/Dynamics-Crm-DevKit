# After optimize

## Phân tích

Source: [BuildRibbonXmlTool.cs](../../DynamicsCrm.DevKit.Cli/Mcp/Tools/BuildRibbonXmlTool.cs)

- Common required (`library, function, enable_library, enable_function`) lặp 5+ lần → định nghĩa shorthand `BTN_FN`.
- Common optional (`modern_image, tooltip_title, tooltip_description, sequence`) lặp 5+ lần → định nghĩa shorthand `BTN_OPT`.
- 3 examples: rút thành 1 example minimal, references inline.
- update_split_button / update_flyout_static syntax for items[] giống nhau — gom.
- Sequence default 85 và per-item auto 10,20,30 — giữ.

## Block 1 — Tool description (optimized)

```text
Build modified RibbonDiffXml for a Dataverse entity. Saves to temp file → apply via manage_ribbon(update). Auto-merges with existing RibbonDiffXml from solution 'devkit-ribbon'. Surfaces: form, main_grid, sub_grid. Validates webresource refs.

10 ops: add_button, update_button, hide_button, show_button, add_split_button, update_split_button, add_flyout_static, update_flyout_static, hide_flyout_item, show_flyout_item.

WHEN TO USE:
- Build classic ribbon button changes (add/update/hide/show) before applying via manage_ribbon(update)
- Create dropdown (flyout_static) or split-button menus
- For modern Power Fx command bar use manage_command + appaction tools
```

## Block 2 — Parameter descriptions (optimized)

```text
[entity_name] (string, required)
Entity logical name (e.g. 'account').

[operations] (string, required)
JSON array. Each = {action, ...}.

Shorthand:
- BTN_FN = library, function, enable_library, enable_function
- BTN_OPT = modern_image, tooltip_title, tooltip_description, sequence (default 85)

Per action:
- add_button: REQ surface, label, BTN_FN. OPT BTN_OPT.
- update_button: REQ button_id OR label. OPT label, BTN_FN, BTN_OPT. Custom buttons only — for OOB use hide/show.
- hide_button / show_button: REQ button_id. OOB + custom.
- add_split_button: REQ surface, label, BTN_FN (main click runs directly), items[](label, BTN_FN). OPT BTN_OPT. Per item OPT modern_image, tooltip_title, sequence (auto 10,20,30…).
- update_split_button: REQ split_button_id OR label. OPT label, BTN_FN, BTN_OPT. items[]: item_label REQ + any of (label, BTN_FN, modern_image, tooltip_title, sequence).
- add_flyout_static: REQ surface, label, items[](label, BTN_FN). OPT BTN_OPT. Per item OPT modern_image, tooltip_title, sequence (auto 10,20,30…).
- update_flyout_static: REQ flyout_id OR label. OPT label, modern_image, tooltip_title, tooltip_description, sequence. items[]: item_label REQ + any of (label, BTN_FN, modern_image, tooltip_title, sequence).
- hide_flyout_item / show_flyout_item: REQ (flyout_label OR flyout_id) + item_label.

Example: [{"action":"add_button","surface":"form","label":"Run","library":"new_/s.js","function":"F.run","enable_library":"new_/s.js","enable_function":"F.isEnabled"}]
```
