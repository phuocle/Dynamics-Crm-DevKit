# Tóm tắt

**Tool:** `get_business_rules`
**Mô tả:** List/inspect business rules (client-side logic) cho 1 entity Dataverse.
**Token hiện tại (description + parameters):** ~190 tokens
- Description: ~110 tokens (~440 chars)
- 4 parameters: ~80 tokens (~318 chars)

---

# Before optimize

## Block 1 — Tool description (hiện tại)

```text
List business rules (client-side logic) for a Dataverse entity.

TWO MODES:
- rule_id EMPTY: list rules with name, scope, status
- rule_id PROVIDED: full detail with conditions and actions parsed from XAML

WHEN TO USE:
- Debug form behavior (fields hiding/showing unexpectedly)
- Audit client-side logic before adding JavaScript

TIPS:
- Business rules run client-side BEFORE JavaScript form events
- Scope 'Entity' means the rule runs on ALL forms
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[entity_name] (string, required)
Entity logical name (lowercase). Use get_tables to discover names.

[rule_id] (string, default: "")
GUID of a specific business rule for full detail. Leave empty to list all.

[status] (string, default: "")
Filter by status: 'active' (activated rules), 'draft' (deactivated/not yet activated). Leave empty to return all statuses.

[max_records] (int, default: 50)
Maximum number of rules to return. Default: 50. Max: 200.
```
