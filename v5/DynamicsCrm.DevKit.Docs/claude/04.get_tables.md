# Tóm tắt

**Tool:** `get_tables`
**Mô tả:** Lấy metadata entity/table của Dataverse theo 2 chế độ: list tất cả entities (filter) hoặc detail (attributes, relationships, alternate keys).
**Token hiện tại (description + parameters):** ~250 tokens (`o200k_base`)
- Description: ~125 tokens (~496 chars)
- 5 parameters: ~80 tokens (~322 chars)

---

# Before optimize

## Block 1 — Tool description (hiện tại)

```text
Retrieve Dataverse entity/table metadata.

TWO MODES:
- entity_name EMPTY: summary table of all entities (filter by keyword, custom_only, or names list). Includes IsAuditEnabled.
- entity_name PROVIDED: full detail — attributes (type, options, required), relationships (1:N, N:1, N:N), alternate keys

COMMON NAMES: account, contact, lead, opportunity, incident (Case), systemuser (User), team, annotation (Note)

WHEN TO USE:
- Discover entity/attribute names before building FetchXML
- Find join columns, picklist options, required fields, or primary key
- Check audit settings for a set of entities (use names= with solution entity list)
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[entity_name] (string, default: "")
Entity logical name for full detail. Empty = list all entities.

[filter] (string, default: "")
LIST: keyword filter. DETAIL: prefix filter for attributes/relationships.

[custom_only] (bool, default: false)
LIST only: show only custom entities.

[include_intersect] (bool, default: false)
LIST only: include intersect (N:N) entities.

[names] (string, default: "")
LIST only: comma-separated logical names to filter (e.g. 'account,contact,lead'). Overrides filter/custom_only when provided.
```

# After optimize

## Phân tích

Source: [GetTablesTool.cs](../../DynamicsCrm.DevKit.Cli/Mcp/Tools/GetTablesTool.cs)

- "COMMON NAMES" block dài, có thể bỏ — AI tự biết các entity phổ biến.
- "WHEN TO USE" 3 bullets gom 1 dòng.
- "TWO MODES" — giữ nhưng diễn đạt ngắn gọn hơn.
- Param `names` description trùng "LIST only" với `custom_only`/`include_intersect`.

## Block 1 — Tool description (optimized)

```text
Dataverse entity metadata. entity_name empty = list (filter by keyword/custom_only/names; includes IsAuditEnabled). Set = detail (attributes, relationships, alternate keys).

WHEN TO USE:
- Discover entity/attribute names before building FetchXML
- Find join columns, picklist options, required fields, primary key
- Audit settings on a set of entities (use names= with solution entity list)

MODE/CONVENTION:
- names= filters by exact logical-name list; filter= uses contains (list) or prefix (detail).
```

> Convention: see `00.conventions.md` — tool kết thúc `s`, áp pattern list/detail by id.

## Block 2 — Parameter descriptions (optimized)

```text
[entity_name] (string, default: "")
Logical name → detail mode. Empty = list mode.

[filter] (string, default: "")
LIST: keyword filter on entity. DETAIL: prefix filter on attributes/relationships.

[custom_only] (bool, default: false)
LIST: only custom entities.

[include_intersect] (bool, default: false)
LIST: include N:N intersect entities.

[names] (string, default: "")
LIST: comma-separated logical names. Overrides filter/custom_only.
```
