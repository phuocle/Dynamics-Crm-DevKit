# Before optimize

## Block 1 — Tool description (hiện tại)

```text
List and inspect Business Process Flows (BPFs) and their stages. Each BPF auto-creates its own Dataverse entity.

TWO MODES:
- bpf_id empty (and bpf_name matches 0 or 2+): list all matching BPFs
- bpf_id provided (or bpf_name matches exactly 1): detail with all stages

TIPS:
- BPFs can span multiple entities (e.g., Lead → Opportunity); each stage has its own primaryEntity
- uniqueName is also the logical name of the BPF's auto-created entity
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[bpf_id] (string, default: "")
BPF GUID for full detail. Empty = list mode.

[bpf_name] (string, default: "")
Filter by name (contains). If exactly 1 match, returns detail.

[entity_name] (string, default: "")
Filter by primary entity (e.g., 'lead', 'opportunity').

[status] (string, default: "active")
'active' (default), 'draft', or 'all'.

[include_stages] (bool, default: false)
Include stages in list mode (default: false). Always included in detail.

[max_records] (int, default: 50)
Max BPFs (1-250). Default: 50.
```
