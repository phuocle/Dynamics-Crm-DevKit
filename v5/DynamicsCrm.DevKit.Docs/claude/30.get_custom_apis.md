# Tóm tắt

**Tool:** `get_custom_apis`
**Mô tả:** Lấy Custom API definitions từ Dataverse (modern thay thế Custom Actions).
**Token hiện tại (description + parameters):** ~210 tokens
- Description: ~120 tokens (~480 chars)
- 5 parameters: ~90 tokens (~360 chars)

---

# Before optimize

## Block 1 — Tool description (hiện tại)

```text
Retrieve Custom API definitions from Dataverse — modern replacement for Custom Actions (binding, visibility, plugin attachment, typed params).

MODES:
- api_name empty: list matching APIs (filter by entity_name, status, include_microsoft)
- api_name set: full detail — request parameters, response properties, plugin binding

TIPS:
- Managed APIs excluded by default; set include_microsoft=true to include them
- isFunction=true → GET (no side effects); isFunction=false → POST Action
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[api_name] (string, default: "")
Unique name for full detail. Empty = list all.

[entity_name] (string, default: "")
Filter by bound entity logical name (e.g., 'account'). Empty = all.

[include_microsoft] (bool, default: false)
Include managed APIs (Microsoft and third-party). Default: false.

[status] (string, default: "active")
'active' (default), 'inactive', or 'all'.

[max_records] (int, default: 100)
Max results in list mode (1-500). Default: 100.
```

# After optimize

## Phân tích

Source: [GetCustomApisTool.cs](../../DynamicsCrm.DevKit.Cli/Mcp/Tools/GetCustomApisTool.cs)

- TIPS giữ "isFunction" rule — quan trọng.
- MODES gom với description chính.

## Block 1 — Tool description (optimized)

```text
Custom API definitions — modern replacement for Custom Actions (binding, visibility, plugin attachment, typed params). api_name empty = list (filter by entity_name, status, include_microsoft). Set = detail (request params, response properties, plugin binding). Managed APIs excluded by default. isFunction=true → GET (no side effects); false → POST Action.

WHEN TO USE:
- Discover Custom APIs registered on an entity (or globally)
- Inspect input/output params + plugin binding before invoking
- For legacy Custom Actions (workflow-based) use get_messages
```

> Convention: see `00.conventions.md` — tool kết thúc `s`, áp pattern list/detail by id.
