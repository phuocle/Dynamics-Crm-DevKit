# Tóm tắt

**Tool:** `whoami`
**Mô tả:** Lấy thông tin user hiện tại (ID, tên, email, roles) và environment (org URL, version, tenant/environment IDs, language, currency, fiscal/audit settings).
**Token hiện tại (description + parameters):** ~111 tokens
- Description: ~85 tokens (~339 chars)
- Parameter `include_token`: ~26 tokens (~104 chars)

---

# Before optimize

## Block 1 — Tool description (hiện tại)

```text
Get current user identity and environment info.

Returns: user (ID, name, email, roles), org (ID, URL, version), tenant/environment IDs, language, currency, fiscal/audit settings.

WHEN TO USE:
- Confirm connected user and environment
- Check security roles for permission troubleshooting
- Get user ID for FetchXML owner filters
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[include_token] (bool, default: false)
true: include OAuth access token (~400 extra tokens). Default: false. Use only for direct Web API calls.
```
