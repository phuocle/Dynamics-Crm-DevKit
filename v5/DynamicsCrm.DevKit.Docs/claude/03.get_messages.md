# Tóm tắt

**Tool:** `get_messages`
**Mô tả:** Khám phá SDK messages và Custom Actions cho 1 entity (hoặc global). 2 chế độ: list / detail.
**Token hiện tại (description + parameters):** ~218 tokens
- Description: ~158 tokens (~635 chars)
- 3 parameters: ~60 tokens (~243 chars)

---

# Before optimize

## Block 1 — Tool description (hiện tại)

```text
Discover SDK messages and Custom Actions for a Dataverse entity.

TWO MODES (controlled by message_name):
- List (message_name empty): all SDK messages + Custom Action names for entity or globally
- Detail (message_name set): parameters, supported entities, plugin steps for a specific message

SCOPING: entity_name for entity-bound; 'none'/empty for global/unbound messages (WhoAmI, etc.).

WHEN TO USE:
- Find SDK messages available for plugin registration
- Discover Custom Actions registered on an entity
- Get input/output parameters of a legacy Custom Action (workflow category=3)

TIPS:
- For modern Custom APIs use get_custom_apis instead
- This covers legacy Custom Actions (workflow-based) that get_custom_apis does NOT
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[entity_name] (string, default: "none")
Entity logical name (lowercase). Use 'none'/empty for global/unbound messages. Use get_tables to discover names. Ignored in detail mode when message_name is set.

[message_name] (string, default: "")
Message or Custom Action name for detail mode. Empty = list mode.

[include_custom_actions] (bool, default: true)
true: include Custom Actions in list results. false: SDK messages only. Ignored when message_name is set.
```

# After optimize

Source: [GetMessagesTool.cs](../../DynamicsCrm.DevKit.Cli/Mcp/Tools/GetMessagesTool.cs)

- "TWO MODES" + "SCOPING" + "WHEN TO USE" có thể gom thành 1 đoạn ngắn.
- "TIPS" giữ thông tin quan trọng (legacy vs modern) nhưng rút gọn.
- Param `entity_name`: bỏ "Use get_tables to discover names" (đã có trong tool description khác).

```text
SDK messages + Custom Actions discovery. message_name empty = list (entity-bound or global with entity_name='none'). Set = detail (params, supported entities, plugin steps). Use for plugin registration, listing legacy Custom Actions (workflow-based). For modern Custom APIs use get_custom_apis.
```
