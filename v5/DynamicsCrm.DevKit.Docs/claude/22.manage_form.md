# Tóm tắt

**Tool:** `manage_form`
**Mô tả:** Lấy và sửa form definitions của 1 entity Dataverse (list/detail/update/rename/undo).
**Token hiện tại (description + parameters):** ~430 tokens
- Description: ~225 tokens (~890 chars)
- 10 parameters: ~205 tokens (~820 chars)

# Before optimize

## Block 1 — Tool description (hiện tại)

```text
Retrieve and modify form definitions for a Dataverse entity.

ACTIONS:
- action='list': List active forms. Optional: form_type, include_formxml
- action='detail': Full FormXML + metadata. Required: form_id (or form_name for auto-resolve)
- action='update': Replace FormXML. Required: form_id + formxml
- action='rename': Change display name. Required: form_id + form_name
- action='undo': Restore from backup. Required: form_id + formxml (= backup file path)

WORKFLOW: build_form_xml → manage_form(action='update', formxml=<result>)
SAFETY: auto-backup before update/rename, XSD validates before write, backup failure blocks update.
ALWAYS use build_form_xml to construct FormXML — never write it manually.

TIPS:
- form_type=2 for main forms only
- form_name with 1 match auto-returns detail
- Read schema://formxml for XSD. Read docs://instructions_for_formxml for rules
- Set auto_publish=false when batching, then call publish_customizations once
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[action] (string, required)
The action to perform: 'list', 'detail', 'update', 'rename', or 'undo'.

[entity_name] (string, required)
Entity logical name (e.g., 'account'). Use get_tables if unsure.

[form_id] (string, default: "")
GUID of a form. Required for detail/update/rename/undo. Empty for list.

[form_name] (string, default: "")
Filter by name (contains match). 1 match = auto-detail. Ignored if form_id set.

[form_type] (int, default: 0)
Filter by type: 2=Main, 5=Mobile, 6=QuickView, 7=QuickCreate. 0 = all.

[include_formxml] (bool, default: false)
Include FormXML in list mode (default: false). Detail mode always includes it.

[formxml] (string, default: "")
For 'update': FormXML string or file path from build_form_xml (.formxml). For 'undo': backup file path. Auto-detects file vs inline XML.

[validate] (bool, default: true)
Validate against XSD before writing (default: true). Blocks if invalid.

[backup] (bool, default: true)
Backup current FormXML before overwriting (default: true). Backup failure blocks update.

[auto_publish] (bool, default: true)
Publish after changes (default: true). Set false when batching.
```

Form definitions for a Dataverse entity.
