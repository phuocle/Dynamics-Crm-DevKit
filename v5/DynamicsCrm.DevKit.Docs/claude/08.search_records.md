# Before optimize

## Block 1 — Tool description (hiện tại)

```text
Dataverse Relevance Search (full-text) across one or more entities. Returns records ranked by relevance with highlights.

ACTIONS:
- action='search' (default): Full-text search. Required: search_term
- action='status': Relevance Search config — enabled status, indexed entities/fields, sync status, storage size, document count

WHEN TO USE:
- Find records by keyword across multiple entities
- Quick text search without knowing the exact field to filter on
- Check if Relevance Search is enabled and which entities are indexed (action='status')

IMPORTANT: Relevance Search must be enabled. Max 100 results. For larger datasets or precise filtering, use execute_fetchxml.
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[action] (string, default: "search")
'search' (default): full-text search, requires search_term. 'status': show configuration, indexed entities/fields, sync status, storage statistics.

[search_term] (string, default: "")
Text to search (1-100 chars). Required for action='search'. Syntax: + (AND), | (OR), - (NOT), * (wildcard), "quoted" (phrase), () (grouping).

[entities] (string, default: "")
Comma-separated entity logical names to scope the search (e.g., 'account,contact'). Empty = all searchable entities.

[top] (int, default: 50)
Maximum number of results to return. Default: 50. Max: 100. Use a smaller value (e.g. 10) for quick lookups.

[filter] (string, default: "")
OData-style filter (eq, ne, gt, ge, lt, le, and, or, not). E.g., 'statecode eq 0'. Empty = no filter.
```
