# Before optimize

## Block 1 — Tool description (hiện tại)

```text
List/inspect system jobs (asyncoperation): async failures, workflow errors, bulk ops, imports, solutions.

MODES:
- record_id empty: list jobs with filters (default: failed, last 24h)
- record_id provided: full detail with error message + stack trace

WHEN TO USE:
- Debug async failures: list failed jobs, then detail for full stack trace
- Monitor bulk ops: filter by operation_type ('bulk_delete', 'import', 'solution')
- Trace a request: use correlation_id to find all jobs for one operation

TIPS:
- Async plugin failures: combine with get_plugin_trace_logs for trace output
- Use entity_name to filter jobs for a specific entity
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[record_id] (string, default: "")
GUID for detail mode. Empty = list. Use parse_record_url to extract from URL.

[entity_name] (string, default: "")
Filter by entity (e.g., 'account'). Empty = all.

[status] (string, default: "failed")
'failed' (default), 'succeeded', 'waiting', 'in_progress', 'canceled', 'all'.

[operation_type] (string, default: "")
'plugin', 'workflow', 'bulk_delete', 'import', 'goal_rollup', 'solution', 'all'. Empty = all.

[name_filter] (string, default: "")
Filter by name (contains).

[correlation_id] (string, default: "")
Exact GUID. Traces a single request across jobs.

[minutes_ago] (int, default: 0)
Time range in minutes. Default: 1440 (24h). Max: 43200.

[max_records] (int, default: 50)
Max results. Default: 50. Max: 500.
```
