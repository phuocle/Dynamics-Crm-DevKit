# Tóm tắt

**Tool:** `parse_record_url`
**Mô tả:** Parse URL/string của Dynamics 365/Power Platform để lấy entity logical name + record ID.
**Token hiện tại (description + parameters):** ~140 tokens
- Description: ~115 tokens (~450 chars)
- 1 parameter: ~25 tokens (~110 chars)

# Before optimize

## Block 1 — Tool description (hiện tại)

```text
Parse a Dynamics 365/Power Platform URL or string to extract entity logical name and record ID.

Supports: main.aspx (etn/etc), Web API, Power Apps/Automate maker portal, rundialog, workflow/report/solution editor URLs, and raw GUIDs.

Returns: EntityName, RecordId, Source, EnvironmentId (maker URLs only).

TIPS:
- If EntityName is '(unknown)', ask user for entity name or a full record URL
- Auto-resolves entity type codes (etc) and entitySetNames via Dataverse
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[input] (string, required)
URL, GUID, or text to parse (Dynamics 365 record URL, Web API URL, maker portal URL, or raw GUID).
```
