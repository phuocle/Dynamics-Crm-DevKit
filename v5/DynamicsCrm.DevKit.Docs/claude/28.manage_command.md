# Tóm tắt

**Tool:** `manage_command`
**Mô tả:** Quản lý modern command bar buttons (appaction) trong Model-Driven Apps + visibility/enable rules. CHỈ dùng cho modern/Power Fx requests.
**Token hiện tại (description + parameters):** ~700 tokens
- Description: ~380 tokens (~1500 chars)
- 23 parameters: ~320 tokens (~1280 chars)

# Before optimize

## Block 1 — Tool description (hiện tại)

```text
Manage modern command bar buttons (appaction) in Model-Driven Apps. Includes visibility/enable rules (appactionrule).

TOOL SELECTION — READ BEFORE CHOOSING:
Use ONLY when user says: 'modern', 'Power Fx', 'formula', 'appaction', 'new command bar', 'command designer'.
Do NOT use for: 'button', 'ribbon button', 'custom button', 'nút', or any generic button phrase.
When in doubt → use manage_ribbon instead.

ACTIONS: list, detail, create, update, hide, show, add_flyout, update_flyout, add_flyout_item, remove_flyout_item, add_split_button, update_split_button
- list: Filter by entity, location, app, origin, action_type
- detail: Required: command_id (or label). Full details + rules + children
- create: Required: entity_name + location + label + (app_id or app_name)
- update: Required: command_id + at least one field
- hide: Required: command_id OR (label + entity_name + location + app_name). Auto-creates override for OOB buttons
- show: Required: command_id OR (label + entity_name + location). No-op if already visible
- add_flyout: Create Dropdown Button. Required: entity_name + location + label + (app_id or app_name) + items [{label, onclick_type, javascript_webresource, javascript_function}]
- update_flyout: Required: command_id (Dropdown Button id)
- add_flyout_item: Required: flyout_command_id + label. Works on Dropdown and Split Buttons
- remove_flyout_item: Required: command_id (item's appaction id)
- add_split_button: Create Split Button (left-click = direct action, arrow = dropdown). Required: entity_name + location + label + (app_id or app_name) + items
- update_split_button: Required: command_id (Split Button id)

TIPS:
- Use origin='default' to exclude auto-migrated system commands
- Commands are app-scoped — same entity can differ across apps
- Use detail + include_children=true to inspect flyout/split items
- CRITICAL: If error contains 'classic ribbon button', STOP IMMEDIATELY — report to user, do not call any other tool
- Related: manage_ribbon (classic ribbon — default fallback), manage_form (form layout)
```

```text
[action] (string, required)
Action: 'list', 'detail', 'create', 'update', 'hide', 'show', 'add_flyout', 'update_flyout', 'add_flyout_item', 'remove_flyout_item', 'add_split_button', 'update_split_button'.

[command_id] (string, default: "")
GUID of a specific appaction record. Required for detail/update.

[entity_name] (string, default: "")
Filter by entity logical name (e.g., 'account'). Required for create.

[location] (string, default: "")
Filter by location: 'form', 'main_grid', 'sub_grid', 'associated_grid', 'quick_form', 'global_header', 'dashboard'. Required for create.

[app_id] (string, default: "")
App module GUID. Required for create (or use app_name).

[label] (string, default: "")
Button label text. Required for create; optional for update.

[onclick_type] (string, default: "")
OnClick event type: 'none', 'javascript', 'formula'. Default: 'none'.

[javascript_webresource] (string, default: "")
JavaScript web resource name or GUID for onclick handler.

[javascript_function] (string, default: "")
JavaScript function name for onclick handler (e.g., 'Namespace.functionName').

[font_icon] (string, default: "")
Font icon name (e.g., 'SalesPlaybook'). Use 'none' to clear.

[icon_webresource] (string, default: "")
Icon web resource name or GUID (e.g., 'devkit_/images/icon.svg'). Sets iconwebresourceid. Use 'none' to clear.

[tooltip_title] (string, default: "")
Tooltip title text (buttontooltiptitle).

[tooltip_description] (string, default: "")
Tooltip description text (buttontooltipdescription).

[sequence] (int, default: 0)
Button sequence/order. Default: 100 for create.

[hidden] (bool, default: false)
Hide the button. Default: false.

[app_name] (string, default: "")
Filter by Model-Driven App name (contains match). Also used to resolve app for create.

[origin] (string, default: "")
'default' (custom), 'migrated' (from ribbon), 'enhanced_migrated', or 'all'. Empty = all.

[action_type] (string, default: "")
Filter by onclick event type: 'javascript', 'formula' (Power Fx), 'none'. Empty = all.

[name_filter] (string, default: "")
Filter by command name (contains match).

[include_rules] (bool, default: false)
Include associated appactionrule records with JSON definitions. Default: false.

[include_children] (bool, default: false)
Include child commands (dropdown/split button items). Default: false.

[max_records] (int, default: 50)
Max commands (1-500). Default: 50.

[items] (string, default: "")
JSON array of items for add_flyout or add_split_button. Each item: {label, onclick_type, javascript_webresource, javascript_function, sequence}.

[flyout_command_id] (string, default: "")
GUID of the flyout Dropdown Button or Split Button. Required for add_flyout_item.
```
