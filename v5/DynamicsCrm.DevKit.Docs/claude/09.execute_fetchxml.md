```text
RULES:
```

```text
[fetchxml] (string, required)
FetchXML query starting with <fetch>. Must use lowercase logical names.

[max_records] (int, default: 5000)
Max records to return (1–5000, default 5000). Use a smaller value (e.g. 10–100) for samples.

[get_all] (bool, default: false)
true: auto-page until max_records or no more rows. false: first page only (default). Use true for complete datasets.
```
