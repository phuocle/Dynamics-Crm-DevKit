# Tóm tắt

**Tool:** `get_plugins`
**Mô tả:** List/inspect plugin assemblies, types, processing steps Dataverse — 3 chế độ.
**Token hiện tại (description + parameters):** ~285 tokens
- Description: ~125 tokens (~500 chars)
- 10 parameters: ~160 tokens (~643 chars)

---

# Before optimize

## Block 1 — Tool description (hiện tại)

```text
List and inspect Dataverse plugin assemblies, types, and processing steps.

THREE MODES:
- No filters: list all assemblies with type counts
- assembly_name (single match): assembly detail with types + steps + images
- entity_name: all steps on that entity across all assemblies

TIPS:
- Stages: PreValidation, PreOperation, PostOperation, MainOperation (Custom API/DataProvider)
- include_config defaults to false — set true only when secure config inspection is needed
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[assembly_name] (string, default: "")
Filter by assembly name (contains). Empty = list all.

[entity_name] (string, default: "")
Filter steps by entity (e.g., 'account'). Shows all steps on this entity.

[message_name] (string, default: "")
Filter by SDK message (e.g., 'Create', 'Update', 'Delete').

[type_name] (string, default: "")
Filter by plugin type name (contains).

[include_images] (bool, default: true)
Include pre/post images. Default: true.

[include_config] (bool, default: false)
Include config values. Default: false (security).

[stage] (string, default: "")
'prevalidation', 'preoperation', 'postoperation', 'mainoperation'. Empty = all.

[mode] (string, default: "")
'sync' or 'async'. Empty = both.

[active_only] (bool, default: true)
Only activated steps. Default: true.

[max_records] (int, default: 100)
Max steps (1-500). Default: 100.
```
