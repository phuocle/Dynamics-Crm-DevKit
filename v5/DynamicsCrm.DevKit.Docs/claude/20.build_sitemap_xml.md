# Before optimize

## Block 1 — Tool description (hiện tại)

```text
Build modified SiteMap XML for a Model-Driven App (areas/groups/subareas). READ-ONLY — returns XML; use manage_sitemap(action='update') to apply.

12 OPERATIONS (pass as JSON array in 'operations'):
- add_area: label req. Optional: id, icon, show_groups, groups[]
- add_group: area+label req. Optional: id, is_profile, subareas[]
- add_subarea: area+group+(entity or url) req. Optional: id, label, icon, pass_params, default_dashboard, vector_icon, client
- remove_area: area req.
- remove_group: area+group req.
- remove_subarea: area+group+subarea req.
- update_area: area req. Optional: label, icon, show_groups
- update_group: area+group req. Optional: label, is_profile
- update_subarea: area+group+subarea req. Optional: label, entity, url, icon, pass_params, default_dashboard, vector_icon, client
- move_area: area+position req.
- move_group: area+group+position req.
- move_subarea: area+group+subarea+position req.

position values: 'first', 'last', 'after:<id>'. Auto-generates IDs (area_, group_, sa_). Fuzzy lookup by ID or label.
Read schema://sitemapxml for SiteMap XML structure and rules.
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[app] (string, required)
Model-Driven App name (fuzzy match) or GUID. Resolves to app_module_id and retrieves current SiteMap XML.

[operations] (string, required)
JSON array of operation objects. Each requires 'action' + operation-specific fields (see tool description for required/optional fields per action).
Example: [{"action":"add_subarea","area":"Sales","group":"Customers","entity":"account"}]
```

```text
12 ops (JSON array). Required:

position: 'first', 'last', 'after:<id>'. Auto-generates IDs (area_, group_, sa_). Fuzzy lookup by ID or label inside operations. See schema://sitemapxml.

WHEN TO USE:
- Build a SiteMap diff before applying via manage_sitemap(update)
- Add/move/remove nav nodes (areas, groups, subareas) in MDA

Fuzzy on app (display name + GUID): 0/multi → tool returns disambiguation list and stops; AI must ask user. 1 → auto-resolve.
```
