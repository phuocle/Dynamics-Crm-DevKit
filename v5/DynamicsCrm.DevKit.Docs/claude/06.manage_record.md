# Tóm tắt

**Tool:** `manage_record`
**Mô tả:** CRUD trên 1 record Dataverse (create/read/update/delete).
**Token hiện tại (description + parameters):** ~205 tokens
- Description: ~125 tokens (~497 chars)
- 5 parameters: ~80 tokens (~329 chars)

---

# Before optimize

## Block 1 — Tool description (hiện tại)

```text
Perform CRUD on a single Dataverse record.

ACTIONS:
- action='create': Requires entity_name + fields_json. Returns new GUID.
- action='read': Requires entity_name + record_id. Optional: columns.
- action='update': Requires entity_name + record_id + fields_json.
- action='delete': Requires entity_name + record_id. WARNING: irreversible.

TIPS:
- Use get_tables for field names/types; use execute_fetchxml to find lookup GUIDs.
- Partial update: include only fields to change.
- Delete may fail on dependencies; may cascade-delete children per relationship config.
```

## Block 2 — Parameter descriptions (hiện tại)

```text
[action] (string, required)
The CRUD action to perform: 'create', 'read', 'update', or 'delete'.

[entity_name] (string, required)
Entity logical name (e.g., 'account'). Required for all actions.

[record_id] (string, default: "")
Record GUID. Required for read, update, and delete. Must be empty for create.

[fields_json] (string, default: "")
JSON object of field values for create/update. Required for create and update; ignored for read and delete.

[columns] (string, default: "")
Comma-separated column logical names for 'read' only. Empty = all columns.
```

# After optimize

## Phân tích

Source: [ManageRecordTool.cs](../../DynamicsCrm.DevKit.Cli/Mcp/Tools/ManageRecordTool.cs)

- "Required: entity_name +" lặp 4 lần — entity_name luôn required, gom 1 lần.
- TIPS giữ thông tin quan trọng nhưng rút gọn.
- Param descriptions có nhiều chữ thừa ("Required for X. Must be empty for Y").

## Block 1 — Tool description (optimized)

```text
CRUD single Dataverse record. Required: entity_name. create: +fields_json (returns GUID). read: +record_id, optional columns. update: +record_id+fields_json (partial supported). delete: +record_id (irreversible, may fail on FK or cascade-delete children). Use get_tables for field names; execute_fetchxml to find lookup GUIDs.

WHEN TO USE:
- Create / read / update / delete a single record by GUID
- Partial-update specific fields without rewriting whole record
- Use create_records instead for bulk (multiple records)
```
