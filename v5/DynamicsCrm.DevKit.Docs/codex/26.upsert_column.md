# Before optimize
Tool description hiện tại:
```text
Create or update a Dataverse column (attribute). Auto-detects create vs update. Types: string, memo, integer, bigint, decimal, money, float, boolean, datetime, lookup, customer, picklist, multipicklist, image, file.

CREATE (attribute does not exist): attribute_type + display_name required.
- lookup: auto-creates 1:N relationship. Required: lookup_target
- customer: polymorphic lookup (account+contact), no lookup_target needed
- picklist/multipicklist: provide options JSON or global_optionset_name

UPDATE (attribute already exists): attribute_type ignored (immutable). Omit params to keep values.
- picklist/multipicklist: use add_options, update_options, delete_options

CREATE PREFIX CONFIRMATION FLOW:
1. First call (confirmed_prefix empty): tool resolves prefix from solution_name or attribute_name and returns [PrefixConfirmationRequired] — NOT an error.
2. Ask user to confirm the prefix shown.
3. Re-call with confirmed_prefix set to the agreed prefix to proceed.

TIPS:
- attribute_name must include publisher prefix (e.g., 'new_priority'); or provide solution_name to auto-resolve prefix.
- After create, use build_form_xml to add the column to a form
```

Params hiện tại:
```text
entity_name: string
Entity logical name (e.g., 'account').

attribute_name: string
Logical name with publisher prefix (e.g., 'new_priority'). Or just the name (e.g., 'priority') — prefix is auto-resolved from solution_name's publisher.

attribute_type: string
Column type: 'string', 'memo', 'integer', 'bigint', 'decimal', 'money', 'float' (or 'double'), 'boolean', 'datetime', 'lookup', 'customer', 'picklist', 'multipicklist', 'image', 'file'.

display_name: string
Display name (e.g., 'Priority Level'). Required for create.

solution_name: string = ""
Solution unique name. Used to auto-resolve publisher prefix when attribute_name has no prefix.

confirmed_prefix: string = ""
Confirmed publisher prefix for create. Leave empty on first call — tool returns [PrefixConfirmationRequired] with preview. Re-call with this set to the agreed prefix to proceed.

description: string = ""
Column description.

required_level: string = ""
'None', 'Recommended', or 'Required'. Omit to keep current value on update.

max_length: int = 0
For string (1-4000, default 100), memo (1-1048576, default 2000), file (KB, default 32768).

min_value: double? = null
For numeric types: minimum value.

max_value: double? = null
For numeric types: maximum value.

precision: int = -1
For decimal/money/float: decimal places (0-10, default 2; money max is 4). Omit to keep current value on update.

format: string = ""
For string: 'Text','Email','Url','Phone','TextArea','TickerSymbol','RichText'. For datetime: 'DateOnly','DateAndTime'. For integer: 'None','Duration','TimeZone','Language','Locale'.

behavior: string = ""
For datetime: 'UserLocal' (default),'DateOnly','TimeZoneIndependent'. DateOnly behavior forces DateOnly format.

precision_source: int = -1
For money: 0 (Attribute, default), 1 (Organization), 2 (Currency).

options: string = ""
For picklist (create): JSON array [{"label":"Low","value":100000000}].

global_optionset_name: string = ""
For picklist (create): existing global option set name.

lookup_target: string = ""
For lookup (create): target entity. Comma-separated for polymorphic.

lookup_relationship_name: string = ""
For lookup: relationship schema name. Auto-generated if omitted.

true_label: string = ""
For boolean: true label. Default: 'Yes'. Omit to keep current value on update.

false_label: string = ""
For boolean: false label. Default: 'No'. Omit to keep current value on update.

add_options: string = ""
For picklist (update): JSON array of options to add.

update_options: string = ""
For picklist (update): JSON array of options to rename.

delete_options: string = ""
For picklist (update): JSON array of integer values to remove.

is_audit_enabled: bool? = null
Enable/disable auditing (update only).

is_valid_for_advanced_find: bool? = null
Show/hide in Advanced Find (update only).

auto_publish: bool = true
Publish after operation. Default: true.
```
