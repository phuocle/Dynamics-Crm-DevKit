# Before optimize
Tool description hiện tại:
```text
Execute raw Dataverse Web API requests.

ALLOWED:
- GET any endpoint (always safe)
- POST/PATCH/PUT/DELETE on data records and custom actions (e.g. accounts, WhoAmI)

BLOCKED (runtime-enforced — use specialized tools):
- Schema/metadata → upsert_table, upsert_column, upsert_relationship
- Choice/OptionSet → manage_choice
- Forms/Views/SiteMaps → manage_form, manage_view, manage_sitemap
- Environment variables → manage_environment_variable
- Web resources → manage_webresource
- Security roles → manage_role
- Publish → publish_customizations
- Solutions/Plugins/Workflows/Apps → Power Apps UI or DevKit CLI

url is a relative path; SDK handles base URL. PUT/PATCH/DELETE are destructive — confirm with user first.
```

Params hiện tại:
```text
method: string
HTTP method: GET, POST, PUT, PATCH, or DELETE.

url: string
Relative URL path (SDK handles base URL). E.g., 'accounts', 'contacts(guid)', '$metadata'.

body: string = ""
JSON body for POST/PUT/PATCH. Not needed for GET/DELETE.

headers: string = ""
Extra headers as JSON. Standard headers handled by SDK.

include_headers: bool = false
Include response headers in output. Default: false.

max_response_lines: int = 200
Maximum response body lines to return. Default: 200. Use smaller values (e.g. 50) for large responses like $metadata.
```
