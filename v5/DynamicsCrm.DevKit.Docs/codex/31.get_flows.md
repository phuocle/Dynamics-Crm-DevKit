# Before optimize
Tool description hiện tại:
```text
List and inspect Power Automate cloud flows and their run history.

THREE MODES:
- No flow_id: list all flows matching filters
- flow_id + action='list': single flow detail + last 5 runs
- flow_id + action='runs': extended run history with filtering

TIPS:
- Use get_workflows for classic (category=0) workflows
```

Params hiện tại:
```text
flow_id: string = ""
Flow GUID. Empty = list mode. With action='list': detail + runs. With action='runs': run history.

action: string = "list"
'list' (default) or 'runs'. 'runs' requires flow_id.

name_filter: string = ""
Filter by name (contains). List mode only.

owner_filter: string = ""
Filter by owner name (contains). List mode only.

status: string = "active"
'active' (default), 'draft', 'suspended', or 'all'.

status_filter: string = ""
For runs: filter by status ('succeeded','failed','running','cancelled','waiting','paused','skipped','suspended'). Empty = all.

minutes_ago: int = 1440
For runs: last N minutes. Default: 1440 (24h). Max: 43200.

max_records: int = 50
Max results (1-250). Default: 50.
```
