# Before optimize
Tool description hiện tại:
```text
Create or update a Dataverse table (auto-detects create vs update by entity lookup).

CREATE (entity absent): display_name + display_collection_name + solution_name required. Auto-creates primary name attribute. Next: upsert_column → build_form_xml + manage_form.
UPDATE (entity exists): only entity_name required. Updatable: display_name, display_collection_name, description, is_audit_enabled, is_quick_create_enabled. All other props are immutable after creation.

CREATE PREFIX CONFIRMATION FLOW:
1. First call (confirmed_prefix empty): tool resolves prefix and returns [PrefixConfirmationRequired] with preview of SchemaName/LogicalName — NOT an error.
2. Ask user to confirm the prefix shown.
3. Re-call with confirmed_prefix set to the agreed prefix to proceed with creation.

TIPS:
- entity_name must include publisher prefix (e.g., 'new_project'); or provide solution_name to auto-resolve prefix.
- is_activity=true: forces User ownership, enables notes, sets Subject as primary attr.
- Use get_tables to inspect existing table metadata before updating.
```

Params hiện tại:
```text
entity_name: string
Logical name with publisher prefix (e.g., 'new_project'). Or just the name (e.g., 'project') — prefix is auto-resolved from solution_name's publisher.

display_name: string = ""
Singular display name (e.g., 'Project'). Required for create.

display_collection_name: string = ""
Plural display name (e.g., 'Projects'). Required for create.

solution_name: string = ""
Solution unique name. Required for create. Optional for update.

confirmed_prefix: string = ""
Confirmed publisher prefix for create. Leave empty on first call — tool returns [PrefixConfirmationRequired] with preview. Re-call with this set to the agreed prefix to proceed.

description: string = ""
Entity description.

primary_attribute_name: string = ""
Primary name attribute logical name. Auto-derived if omitted. Create only.

primary_attribute_display_name: string = "Name"
Display name for primary attribute. Default: 'Name'. Create only.

ownership_type: string = "User"
'User' (default) or 'Organization'. Create only — immutable.

table_type: string = "Standard"
'Standard' (default) or 'Elastic' (Azure Cosmos DB; no chart support). Create only — immutable.

is_activity: bool = false
Activity entity flag. When true: forces User ownership, enables notes, sets Subject primary attr. Create only — immutable.

has_notes: bool = false
Enable notes. Default: false. Create only — cannot be changed after creation.

is_quick_create_enabled: bool? = null
Enable quick create form. Default: false (create, update). Omit to keep current value (update).

is_audit_enabled: bool? = null
Enable/disable auditing. Default: true (create). Omit to keep current value (update).

primary_attribute_max_length: int = 850
Max length for the primary name attribute (1-850, default 850). Create only.

auto_publish: bool = true
Publish after operation. Default: true.
```
