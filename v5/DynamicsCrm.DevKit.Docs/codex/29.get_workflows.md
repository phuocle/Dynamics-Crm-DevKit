Mô tả hiện trạng: List and inspect classic workflows (background and real-time) for a Dataverse entity.

# Before optimize
Tool description hiện tại:
```text
List and inspect classic workflows (background and real-time) for a Dataverse entity.

TWO MODES:
- workflow_id EMPTY: list workflows matching filters
- workflow_id PROVIDED: full detail for a single workflow

SCOPE: Classic workflows only. Use get_business_rules, get_custom_apis, get_business_process_flows, get_flows for others.

KEY OUTPUT FIELDS:
- triggeronupdateattributelist: update-trigger fields ('statecode'=status change, 'ownerid'=assignment)
- mode: Background (async, always Post) or Realtime (sync, Pre/Post stages)
- scope: User/BU/Parent:ChildBU/Org. runas: Owner/Caller

WHEN TO USE:
- Check if a field triggers any workflow: trigger_field + entity_name
- Find synchronous workflows: mode='realtime'

TIPS:
- Realtime Pre-operation can cancel/rollback the operation
- If name_filter matches exactly 1 workflow, auto-switches to detail mode
```

Params hiện tại:
```text
workflow_id: string = ""
Workflow GUID for detail mode. Empty = list mode.

entity_name: string = ""
Entity logical name (e.g., 'account'). Empty = all entities.

mode: string = ""
'background' (async) or 'realtime' (sync). Empty = both.

active_only: bool = true
Only activated workflows. Default: true.

trigger_field: string = ""
Filter by update trigger field (contains match, e.g., 'revenue', 'statecode').

name_filter: string = ""
Filter by name (contains match). If exactly 1 match, returns detail.

max_records: int = 50
Max records. Default: 50, max: 250.
```
