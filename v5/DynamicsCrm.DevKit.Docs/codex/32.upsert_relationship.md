# Before optimize
Tool description hiện tại:
```text
Create, update, or delete Dataverse relationships (1:N, N:N) and manage polymorphic lookup targets.

ACTIONS:
- action='create_1n': Create 1:N + lookup column. Required: referenced_entity + referencing_entity + solution_name
- action='create_nn': Create N:N + intersect entity. Required: entity1 + entity2 + solution_name
- action='update': Update cascade/menu/hierarchy on existing relationship. Required: relationship_name
- action='delete': Delete relationship by schema name. Required: relationship_name
- action='add_target': Add target to polymorphic lookup. Required: entity_name + attribute_name + referenced_entity + solution_name
- action='remove_target': Remove target from polymorphic lookup. Required: entity_name + attribute_name + referenced_entity

TIPS:
- Use get_tables to find relationship_name; use build_form_xml to add lookup to a form
- WARNING: remove_target permanently deletes data in that lookup target
- is_hierarchical=true: marks this self-referential 1:N as the OOB hierarchy relationship (only one per entity; only valid when referenced_entity == referencing_entity)
- Cascade presets: Parental (all Cascade), Referential (NoCascade + RemoveLink on delete), ReferentialRestrictDelete (NoCascade + Restrict on delete)
- Cascade types: Cascade, NoCascade, RemoveLink, Restrict, Active, UserOwned
- Read docs://schema_tools_guide for cascade preset values and cascade type options
```
