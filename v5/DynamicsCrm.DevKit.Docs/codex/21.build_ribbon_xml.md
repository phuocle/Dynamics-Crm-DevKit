Build modified RibbonDiffXml for a Dataverse entity. READ-ONLY — saves to temp file; use manage_ribbon(action='update') to apply.

10 OPERATIONS: add_button, update_button, hide_button, show_button, add_split_button, update_split_button, add_flyout_static, update_flyout_static, hide_flyout_item, show_flyout_item

# After optimize

SUMMARY: Read-only classic RibbonDiffXml builder. Preserves existing devkit_ribbon customizations, validates entity/web resources/XSD, supports custom/OOB hide-show and custom button/split/flyout edits, then saves a file for manage_ribbon.

WHEN TO USE:
- Generate classic RibbonDiffXml changes.

SAFETY:
- Read-only builder; does not apply changes until manage_ribbon.
