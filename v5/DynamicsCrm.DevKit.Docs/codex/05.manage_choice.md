# Before optimize
Tool description hiện tại:
```text
List, inspect, create, or update global option sets (choices/picklists) in Dataverse.

ACTIONS:
- action='list': List all global option sets (name, displayName, type). No extra params needed.
- action='detail': Show value/label pairs. Requires optionset_name.
- action='create': Create a new global option set. Requires optionset_name + display_name + options.
- action='update': Modify options/metadata on an existing global option set. Requires optionset_name + at least one of: display_name, description, add_options, update_options, remove_option_values.

WHEN TO USE:
- Resolve integer values ↔ labels for option set fields in FetchXML or query results.
- Create a global choice for use in picklist columns via upsert_column.
- Add, rename, or remove option values from an existing global choice.

TIPS:
- GLOBAL option sets only. For entity-specific (local) picklists, use get_tables.
- After create/update, changes are auto-published unless auto_publish=false.
- Related: upsert_column (create picklist column referencing this choice).
```

Params hiện tại:
```text
action: string
The action to perform: 'list', 'detail', 'create', or 'update'.

optionset_name: string = ""
Logical name of the global option set. Required for detail, create, update; omit for list. Tip: if get_tables shows empty options for a PicklistType column, it references a global option set.

display_name: string = ""
Display name for the option set. Required for create. Optional for update.

description: string = ""
Description of the option set. Optional for create and update.

options: string = ""
Options as 'value:label' pairs separated by semicolons. Required for create. Example: '100000000:Active;100000001:Inactive'. Values must be integers ≥ 0.

add_options: string = ""
Options to add as 'value:label' pairs separated by semicolons. For update action only. Example: '100000002:Pending;100000003:Archived'.

update_options: string = ""
Options to update (rename labels) as 'value:newLabel' pairs separated by semicolons. For update action only. Example: '100000000:Active Account;100000001:Closed'.

remove_option_values: string = ""
Option values to remove, comma-separated. For update action only. Example: '100000002,100000003'. WARNING: cannot be undone.

auto_publish: bool = true
Publish after changes. Default: true.
```
