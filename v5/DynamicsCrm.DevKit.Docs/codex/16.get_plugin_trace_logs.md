# Before optimize
Tool description hiện tại:
```text
List and inspect plugin trace logs for debugging plugin/custom action execution.

MODES:
- record_id EMPTY: list recent logs with filters (default: last 60 min)
- record_id PROVIDED: full detail with complete messageblock + exceptiondetails

WHEN TO USE:
- Debug failing plugin: list first, then detail with record_id for full trace
- Trace specific request: use correlation_id for all traces of one operation

TIPS:
- Plugin Trace Log must be enabled in Dataverse (System Settings > Customization)
- Async failures: combine with get_system_jobs for error + trace output
```

Params hiện tại:
```text
record_id: string = ""
Record GUID for detail mode. Empty = list mode. Use parse_record_url to extract from a URL.

type_name: string = ""
Filter by plugin type name (contains). E.g., 'AccountPlugin'.

message_name: string = ""
Filter by SDK message: 'Create', 'Update', 'Delete', etc.

mode: string = ""
'sync' or 'async'. Empty = both.

correlation_id: string = ""
Filter by correlation ID (exact GUID). Trace a single request across logs.

minutes_ago: int = 0
Time range in minutes. Default: 60. Max: 1440.

max_records: int = 50
Max results. Default: 50. Max: 200.
```
