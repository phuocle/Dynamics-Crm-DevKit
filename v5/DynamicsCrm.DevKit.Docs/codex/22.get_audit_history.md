# Before optimize
Tool description hiện tại:
```text
Retrieve audit history for Dataverse records — who changed what, when, old/new values.

MODES:
- record_id set: field-level old/new for one record (entity_name required)
- record_id empty: summary list across records/entities (entity_name optional)

WHEN TO USE: debug unexpected changes, compliance auditing, track user/integration activity.

TIPS: Audit must be enabled at org AND entity level. Use from_date/to_date for ranges (overrides minutes_ago).
```

Params hiện tại:
```text
entity_name: string = ""
Entity logical name. Required with record_id. Optional in browse mode.

record_id: string = ""
Record GUID for detail mode. Empty = browse mode.

minutes_ago: int = 1440
Entries from last N minutes. Default: 1440 (24h). Max: 43200. Ignored with from_date.

user_filter: string = ""
Filter by user name (contains) or email (auto-resolved).

operation: string = ""
Filter by operation: Create, Update, Delete, Activate, Deactivate, Assign, Merge, SetState.

attribute_name: string = ""
Detail mode only: filter to one field's changes.

max_records: int = 50
Max entries. Default: 50, max: 500.

from_date: string = ""
ISO 8601 start date (e.g., '2026-03-01'). Overrides minutes_ago.

to_date: string = ""
ISO 8601 end date. Used with from_date. Default: now.
```
