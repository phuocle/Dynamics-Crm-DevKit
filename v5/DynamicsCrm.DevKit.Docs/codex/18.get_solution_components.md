# Before optimize
Tool description hiện tại:
```text
List all components inside a Dataverse solution by uniqueName or displayName (fuzzy/contains matching).

Returns: solution info + component summary (count per type) + full detail table (componentType, objectId, name).

BEHAVIORS:
- 1 match → components; multiple → disambiguation list; 0 → error
- Full Entity (rootComponentBehavior=0): listed as-is; use get_tables for sub-components
- include_active_layers=true: adds ActiveLayer (Yes/No) via msdyn_componentlayer
- active_layers_only=true: implies include_active_layers=true; shows only components with active layers

WHEN TO USE:
- Audit solution contents before packaging/deploying
- Find objectIds of components (plugins, web resources, workflows)
- Identify unmanaged customizations before deploying managed solutions
```

Params hiện tại:
```text
solution_name: string
Solution uniqueName (e.g. 'DevKit_Core') or displayName (e.g. 'DevKit Core'). Fuzzy (contains) matching on both fields. If multiple match, the tool returns the list — re-call with exact uniqueName.

include_active_layers: bool = false
When true, queries msdyn_componentlayer and adds an ActiveLayer (Yes/No) column. Active layer = unmanaged customization exists. Batched in groups of 200. Default: false.

active_layers_only: bool = false
When true, implies include_active_layers=true and filters to only components with an active layer. Default: false.
```
