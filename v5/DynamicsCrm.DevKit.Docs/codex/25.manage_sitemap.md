# Before optimize
Tool description hiện tại:
```text
List, create, update, or restore a Model-Driven App's SiteMap XML with auto-backup, XSD validation, and publish.

ACTIONS:
- 'list': List all Model-Driven Apps with SiteMap info. Optional: app_name filter
- 'detail': Show current SiteMap XML. Required: app
- 'update' (default): Modify SiteMap XML. Required: app + sitemapxml
- 'create': Create SiteMap for app with no existing SiteMap. Required: app + sitemapxml
- 'undo': Restore from backup. Required: app + sitemapxml (= backup file path)

SAFETY: Auto-backup before changes, XSD validates XML, backup failure blocks update.

TIPS:
- app accepts display name OR GUID (fuzzy match)
- Use build_sitemap_xml to build XML, pass result to sitemapxml for update/create
- Read schema://sitemapxml for SiteMap XML structure and rules
```

Params hiện tại:
```text
action: string = "update"
'list', 'detail', 'update' (default), 'create', or 'undo'.

app: string = ""
App display name or GUID (fuzzy match). Required for detail/update/create/undo; for list use app_name.

sitemapxml: string = ""
For 'update'/'create': SiteMap XML string or file path from build_sitemap_xml. For 'undo': backup file path. Ignored for list/detail.

app_name: string = ""
Filter apps by name (contains match). Only used with action='list'.

validate: bool = true
Validate against XSD before writing (default: true). Blocks if invalid.

backup: bool = true
Backup current SiteMap before overwriting (default: true). Backup failure blocks update.

auto_publish: bool = true
Publish after changes (default: true). Set false when batching.
```
