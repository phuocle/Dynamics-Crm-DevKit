# Before optimize
Tool description hiện tại:
```text
Retrieve and modify RibbonDiffXml for Dataverse entities via solution import.

TOOL SELECTION — READ BEFORE CHOOSING:
CLASSIC/LEGACY ribbon (RibbonDiffXml). DEFAULT FALLBACK for all button requests.
Use when: 'ribbon', 'legacy', 'classic', 'button', 'nút', 'custom button', 'action button', 'UI button', 'JavaScript button', 'sub_grid button', 'homepage grid button', or any generic button request.
Use manage_command ONLY for: 'modern', 'Power Fx', 'appaction', 'new UI', 'Model-Driven App command bar', 'command designer'.
When in doubt → always use manage_ribbon, never manage_command.

ACTIONS: list, buttons, detail, update, undo
- list: entities with ribbon customizations in solution 'devkit-ribbon'
- buttons: all ribbon buttons (OOB+custom) across form/main_grid/sub_grid. Required: entity_name
- detail: show current RibbonDiffXml. Required: entity_name
- update: apply ribbonxml from build_ribbon_xml. Required: entity_name + ribbonxml. Backup→Import→PublishAll
- undo: restore from backup file. Required: entity_name + ribbonxml (backup path)

WORKFLOW: build_ribbon_xml → manage_ribbon(action='update') [auto-publishes all by default]
Auto-backup before update; backup failure blocks update.
NOTE: Ribbon requires PublishAll (not entity-scoped publish). auto_publish=true (default) runs PublishAll synchronously. Set false when batching, then call publish_customizations once.
```

Params hiện tại:
```text
action: string
'list', 'buttons', 'detail', 'update', or 'undo'.

entity_name: string = ""
Entity logical name (e.g., 'account'). Required for detail/update/undo.

ribbonxml: string = ""
For 'update': RibbonDiffXml file path from build_ribbon_xml. For 'undo': backup file path.

auto_publish: bool = true
Publish after changes (default: true). Set false when batching.

backup: bool = true
Backup current ribbon before overwriting (default: true). Backup failure blocks update.
```
