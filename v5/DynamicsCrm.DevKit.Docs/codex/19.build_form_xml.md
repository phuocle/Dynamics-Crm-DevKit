# Before optimize
Tool description hiện tại:
```text
Build modified FormXML for an existing Dataverse form. READ-ONLY — saves to temp file; use manage_form(action='update') to apply.

5 ACTION GROUPS (use action + manage_action): manage_tab, manage_section, manage_fields, manage_library, manage_event

Valid combinations:
- manage_tab: add | update | move | remove
- manage_section: add | update | move | remove
- manage_fields: add | update | remove | add_header | update_header | remove_header
- manage_library: add | remove
- manage_event: add | remove

Each operation object requires both 'action' and 'manage_action'.

Auto-resolves classid GUIDs, validates field names against metadata.
Section columns: 1 (default), 2, 3. Tab columns: 1 (100%), 2 (50%/50%), 3 (33%/34%/33%).

TIPS:
- Fields: "createdon" or {"field":"createdon","label":"Date","disabled":true}
- Position: "first", "last" (default), "before:<name>", "after:<name>"
- Tabs/Sections: visible, show_label, hide_on_phone. Fields also: disabled
- Use manage_action='update' to modify existing tabs/sections/fields
```

Params hiện tại:
```text
entity_name: string
Entity logical name (e.g., 'account'). Used to resolve field metadata.

form_id: string
GUID of the form to modify. Use manage_form with action='list' to find valid form IDs.

operations: string
JSON array of operations. Each requires 'action' + 'manage_action'.
Actions: manage_tab, manage_section, manage_fields, manage_library, manage_event.
manage_action values depend on action (see tool description).
Common fields: tab, section, fields[], label, name, position, visible, show_label, hide_on_phone, disabled, tab_column, section_columns, library_name, event_name, function_name, target.
Read docs://instructions_for_formxml for full format and examples.
```
