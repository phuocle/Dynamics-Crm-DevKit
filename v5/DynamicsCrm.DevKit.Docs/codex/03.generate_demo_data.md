# Before optimize
Tool description hiện tại:
```text
Generate demo data for a Dataverse entity using Bogus fake data library.
Output saved to .devkit/demo_data/ as JSON — pass file path to create_records.

WORKFLOW:
  Step 1: generate_demo_data(entity_name="account", count=50, from_date="2026-01-01", to_date="2026-04-30") → file path
  Step 2: create_records(entity_name="account", records_json=<file path>)

TIPS:
- from_date + to_date REQUIRED — NEVER infer or guess these from context or current date; always ask the user explicitly if not provided
- from_date + to_date format: ISO 8601 (e.g. "2026-01-01"); count default=10, max=500; seed=0 = random
- fields empty = auto-select all creatable fields; smart mapping: emailaddress→Email, telephone→Phone, city→City etc.; overriddencreatedon always included
- Lookups: auto-fetch real GUIDs; empty targets skipped with warning; polymorphic → "field@entity" syntax auto-applied
- field_overrides: JSON array to control specific field values after Bogus generation. Operators: eq, in, startswith, endswith, contains, regex
  eq        → all records get values[0]  (use for fixed lookup GUIDs, fixed strings)
  in        → each record picks randomly from values[]  (use for rotating lookups or enums)
  startswith→ Bogus suffix appended after values[0]  e.g. 'ABC' → 'ABC_x7k2'
  endswith  → Bogus prefix prepended before values[0]  e.g. '@acme.com' → 'john.doe@acme.com'
  contains  → values[0] injected in middle  e.g. 'Manager' → 'Senior Manager II'
  regex     → simple pattern mapped to Bogus format  e.g. '\+84[0-9]{9}' → '+84912345678'
```

from_date and to_date are REQUIRED. NEVER infer or assume — ask the user if not provided. ISO 8601 format. Example: '2026-04-30'. Must be >= from_date.

count: int = 10
Number of records to generate. Default: 10. Max: 500.

Comma-separated field logical names. Empty = auto-select all creatable fields.

Random seed for reproducible data. 0 = random.

JSON array of field override rules applied after Bogus generation. Each item: {logicalname, operator, values[]}. Operators: eq, in, startswith, endswith, contains, regex. Example: [{"logicalname":"parentcustomerid","operator":"eq","values":["<guid>"]},{"logicalname":"jobtitle","operator":"in","values":["CEO","CFO","CTO"]}]
