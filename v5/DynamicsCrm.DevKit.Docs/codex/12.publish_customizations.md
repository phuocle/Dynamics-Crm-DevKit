# Before optimize

```text
Publish Dataverse customizations to make metadata changes visible. Required after changes to entities, attributes, forms, views, option sets, or relationships.

WHEN TO USE:
- After upsert_*/execute_webapi metadata changes (if auto_publish was false)
- When user reports changes not showing up

TIPS:
- Publish specific entities for faster execution than PublishAll
- PublishAll can take 30+ seconds on large environments
- Idempotent — safe to republish already-published changes
```

Params hiện tại:
```text

Comma-separated entity logical names (e.g., 'account,contact'). Empty = publish ALL customizations.

include_sitemap: bool = false
Also publish the sitemap. Only applies when entities is specified. Default: false.
```
