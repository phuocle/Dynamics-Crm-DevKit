# Before optimize
Tool description hiện tại:
```text
List, inspect, create, update, or delete web resources in Dataverse.

FIVE ACTIONS:
- action='list': List web resources filtered by name, type, solution. Optional: name, type_filter, solution_name, max_records
- action='detail': Full metadata for one web resource. Requires web_resource_id
- action='create': Create a new web resource. Requires name + content (base64) + type. Optional: display_name, description, solution_name
- action='update': Update content and/or metadata. Requires web_resource_id. Optional: content, display_name, description
- action='delete': Permanently delete a web resource. Requires web_resource_id. WARNING: cannot be undone

TIPS:
- Call this tool first to find library_name needed for build_form_xml add_event/add_library
- Names follow convention: {prefix}_/path/filename.ext (e.g., v4_/entities/Account.form.js)
- Related: build_form_xml (add events/libraries), manage_form (inspect form structure)
```

Params hiện tại:
```text
action: string
The action to perform: 'list', 'detail', 'create', 'update', or 'delete'.

web_resource_id: string = ""
GUID of the web resource. Required for detail, update, and delete. Empty for list and create.

name: string = ""
Web resource unique name (e.g., 'v4_/entities/Account.form.js'). Required for create. For list: contains filter on name.

display_name: string = ""
Display name. Optional for create/update.

description: string = ""
Description text. Optional for create/update.

content: string = ""
Base64 encoded file content. Required for create. Optional for update.

type: string = ""
Web resource type for create: 'js', 'html', 'css', 'xml', 'png', 'jpg', 'gif', 'svg', 'ico', 'resx', 'xsl', 'xap'. Required for create, ignored for other actions. For list: use type_filter instead.

solution_name: string = ""
Filter by solution unique name (list mode). Solution to add to (create mode).

type_filter: string = ""
Filter by type in list mode: 'js', 'html', 'css', 'xml', 'png', 'jpg', 'gif', 'svg', 'ico', 'resx', 'xsl', 'xap'. Empty = all.

max_records: int = 50
Max results for list mode (1-500). Default: 50.

auto_publish: bool = true
Publish after changes. Default: true.
```
