# ✅ TOOL DESCRIPTION

```text
List asynchronous system jobs or inspect one job with its diagnostic messages.

WHEN TO USE:
- Debug async failures (list failed → detail for message + friendlyMessage)
- Monitor bulk ops (operation_type='bulk_delete'/'import'/'solution')
- Trace one request (correlation_id across jobs)
- Async plugin failures: combine with get_plugin_trace_logs

RELATED TOOLS:
- get_plugin_trace_logs → plugin execution traces (sync + async)
- get_workflows → classic workflow definitions (background + realtime)
- get_flows → Power Automate cloud flows + run history
```

# PARAMETERS

```text
record_id      : string : GUID → detail. Empty = list.
entity_name    : string : Filter by entity Display Name or logical name (e.g. 'Account' or 'account').
status         : string : failed/succeeded/waiting/in_progress/canceled/all.
operation_type : string : plugin/workflow/bulk_delete/import/goal_rollup/solution/all.
name_filter    : string : Name contains.
correlation_id : string : GUID. Trace one request across jobs.
minutes_ago    : int    : 0 = 1440 (24h) default. Max 43200.
max_records    : int    : Max 500.
```

# RESULTS

- Test 1: list mode returns 5 jobs across all statuses in the last 30 days; entries carry jobId, name, operationType, status/state, startedOn/completedOn, executionTime (formatted "391ms"/"6.1s"), correlationId, owner.
- Test 2: detail mode adds createdOn, retryCount, depth; a succeeded job's text summary is a single concise line (no Error/Message noise).
- Test 3: operation_type=bulk_delete filter works and echoes operationType at the root; all 5 returned jobs are Bulk Delete.
- Test 4: default status=failed returns 3 failed async plugin jobs with errorCode and friendlyMessage — success with results, not an error.
- Test 5: invalid status returns a validation error with a hint listing valid values, IsError true.
- Test 6: non-existent record_id returns a not-found error with a hint pointing back to list mode, IsError true.
- Test 7: invalid operation_type returns a validation error with a hint listing valid values, IsError true.
- Test 8: non-GUID correlation_id returns a validation error with a hint, IsError true.
- Test 9: unresolvable entity_name returns a resolver error with a hint pointing to get_tables, IsError true.
- Test 10: non-GUID record_id returns a validation error with a hint, IsError true.
