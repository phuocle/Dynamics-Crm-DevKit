# TOOL DESCRIPTION

```text
List configured .env connection groups, aliases, startup selection and effective per-group policy without connecting or authenticating. File changes require restarting the server.

WHEN TO USE:
- Discover connection IDs and aliases before targeting another environment
- Inspect effective mutation protection and configured versus applied impersonation

RELATED TOOLS:
- whoami → verify the selected connection's live identity and runtime
- get_tables → compare metadata by passing a connection ID or alias as env
```

# PARAMETERS

```text
This tool takes no parameters.
```

# RESULTS

- Test 1: the unnumbered startup is connected while group 1 remains disconnected; effective policy and allowlisted metadata are visible.
- Test 2: listing reflects the successful lazy connection without changing canonical IDs or startup selection.
- Test 3: the numbered-startup instance identifies group 1 as startup and shows the global mutation block on both groups.
- Test 4: one startup instance advertises mcp-dev and mcp-uat with dryRun false and true respectively, leaving UAT disconnected until first use.
- Test 5: both connections become connected in the same instance while DEV remains unblocked by policy and UAT remains protected.
