# TOOL DESCRIPTION

```text
Fetch the markdown/XML content behind the docs:// and schema:// resources referenced by tool descriptions. Use this when your client cannot read MCP resources (resources/read unsupported) — it returns the same content as tool output.

name empty → returns the catalog of all instructions and schemas with the tools that reference them; name set → returns the full content of that one resource. Accepts a bare resource name ('instructions_for_manage_ribbon') or a full URI ('docs://instructions_for_manage_ribbon', 'schema://fetchxml'); case-insensitive.

WHEN TO USE:
- A tool description says 'Read docs://X' but your client has no resource reader
- Check which instructions/schemas exist before a complex operation
- Re-read a guide on demand (FetchXML syntax, FormXML rules, schema tool contracts, server-logic modes)

RELATED TOOLS:
- get_tables → entity/attribute metadata (live data, not instructions)
- every tool whose description references docs:// — see the catalog returned when name is empty
```

# PARAMETERS

```text
name : string : Resource name or URI: 'instructions_for_manage_ribbon', 'docs://instructions_for_views', 'schema://fetchxml'. Empty = return the catalog of all instructions and schemas.
```
