# TOOL DESCRIPTION

```text
Find installed field or dataset PCF controls and read their manifest properties, datasets, and property sets. Use the exact returned name with manage_form and the manage_custom_control operation.
```

# PARAMETERS

```text
name       : string : Filter by the registered PCF name. Default: "".
name_match : string : Name match: contains (default), prefix, or exact. Default: "contains".
kind       : string : Control kind: field or dataset. Default: "".
data_type  : string : Compatible bound field type, such as SingleLine.Text or Lookup.Simple. Default: "".
env        : string : Optional .env connection group: numeric id such as "1", alias such as "prod", or "default" for the unnumbered group. Omit to use the startup connection. Use connection_list to list groups. Default: null.
```
