# TOOL DESCRIPTION

```text
Find installed field or dataset PCF controls and read their manifest properties, datasets, and property sets.

WHEN TO USE:
- Find a field PCF by compatible bound column type, or a dataset PCF for a subgrid
- Look up the exact registered name and required manifest mappings before binding

RELATED TOOLS:
- manage_form → bind, update, or unbind the PCF with manage_custom_control operations
- get_tables → inspect the Dataverse columns available for property mappings
```

# PARAMETERS

```text
name       : string : Filter by the registered PCF name. Default: "".
name_match : string : Name match: contains (default), prefix, or exact. Default: "contains".
kind       : string : Control kind: field or dataset. Default: "".
data_type  : string : Compatible bound field type, such as SingleLine.Text or Lookup.Simple. Default: "".
env        : string : Optional .env connection group: numeric id such as "1", alias such as "prod", or "default" for the unnumbered group. Omit to use the startup connection. Use connection_list to list groups. Default: null.
```

# RESULTS

- Test 1: contains search with kind='field' and data_type='SingleLine.Text' returns abiz_Abiz.Controls.EntityLookup (v1.2.2) with its bound 'value' property and four optional input properties.
- Test 2: prefix search with kind='dataset' returns MscrmControls.Calendar.CalendarControl (v1.2.25) with primary dataset 'Calendar' and five bound propertySets (StartDate, Description, EndDate, Duration, Color).
- Test 3: exact lookup for MscrmControls.Grid.PCFGridControl returns its 'Items' dataset and seventeen input properties including RowStyle (Flat, Zebra) matching the manage_form dataset bindings.
- Test 4: exact lookup for MscrmControls.AutoComplete.AutoCompleteControl returns its single required bound 'value' (SingleLine.Text) property matching the manage_form replacement binding.
- Test 5: exact lookup for a non-existent PCF name returns totalCount 0 with an empty customControls array and IsError false.
