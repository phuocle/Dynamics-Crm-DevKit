# ✅ TOOL DESCRIPTION

```text
Dataverse columns: create or update is detected automatically. Create requires entity_name, attribute_type, display_name, solution_name; update identifies an existing column by logical_name. Attribute type is immutable.

For lookup/customer/choice types, autonumbers and formula cloning, use the parameter contracts and read docs://schema_tools_guide for detailed rules. Formula cloning is create-only: use the formulaDefinition reference returned by get_tables, never formula content. For statuscode use add_options/update_options/delete_options; statecode is read-only.

Names resolve Display Name first, then logical/schema name; ambiguous matches return candidates.

WHEN TO USE:
- Create a new attribute on an existing table (need attribute_type + display_name)
- Clone a PowerFx, Calculated, or Rollup column read by get_tables (CREATE only)
- Create/convert a string column to Autonumber or change its pattern/seed
- Update mutable metadata, format, required_level, and picklist options
- Add/rename/remove options on an existing picklist via add_options/update_options/delete_options

RELATED TOOLS:
- get_tables → discover entities and attribute logical names
- manage_table → create the table before its columns
- manage_relationship → 1:N / N:N relationships (lookup_target auto-creates 1:N)
- manage_choice → global option sets
- manage_record_file → file/image column data upload and download
- execute_webapi → raw Web API for endpoints not covered here
```

# PARAMETERS

```text
entity_name                : string   : Logical name (e.g. 'account'). Default: "".
logical_name               : string   : Logical name of the existing attribute to update (e.g. 'new_priority'). For CREATE: optional lowercase override of logical name; if omitted derives from schema_name/display_name. Must start with publisher prefix. Default: "".
attribute_type             : string   : string/memo/integer/bigint/decimal/money/float/boolean/datetime/lookup/customer/picklist/multipicklist/image/file. Required for CREATE. Ignored on UPDATE (immutable). Default: "".
display_name               : string   : Required for CREATE. Optional on UPDATE — pass only to rename the display label. Default: "".
solution_name              : string   : Unmanaged solution unique or display name. Required for CREATE to resolve the publisher prefix. Optional on UPDATE to add the changed column to the solution. Default: "".
description                : string   : Optional column description. Default: "".
required_level             : string   : Required level for the column. CREATE: always applied (None when omitted — NOT a Dataverse default). UPDATE: omit=keep current. Default: "".
max_length                 : int      : string 1-4000 (def 100); memo 1-1048576 (def 2000); file KB (def 32768). Default: 0.
min_value                  : double?  : Numeric types: minimum value. Default: null.
max_value                  : double?  : Numeric types: maximum value. Default: null.
precision                  : int      : decimal/money/float 0-10 (def 2; money max is 4). [update: omit=keep] Default: -1.
format                     : string   : string: Text/Email/Url/Phone/TextArea/TickerSymbol/RichText. datetime: DateOnly/DateAndTime. integer: None/Duration/TimeZone/Language/Locale. Default: "".
behavior                   : string   : datetime: UserLocal (def)/DateOnly/TimeZoneIndependent. DateOnly forces DateOnly format. Default: "".
precision_source           : int      : money: 0=Attribute (def), 1=Organization, 2=Currency. Default: -1.
options                    : string   : picklist create: JSON array [{"label":"Low","value":100000000}]. Optional 'color' field: {"label":"Low","value":100000000,"color":"#808080"}. Default: "".
global_optionset_name      : string   : picklist create: existing global option set. Default: "".
lookup_target              : string   : lookup create: target entity. Comma-separated = polymorphic. Default: "".
lookup_relationship_name   : string   : lookup: schema name. Auto if empty. Default: "".
true_label                 : string   : boolean true label (def 'Yes'). [update: omit=keep] Default: "".
false_label                : string   : boolean false label (def 'No'). [update: omit=keep] Default: "".
add_options                : string   : picklist update: JSON array — options to add. Optional 'color' field: {"label":"New","value":100000003,"color":"#FF0000"}. StatusType (statuscode): include 'state' field (statecode value, default 0): {"label":"Under Review","value":100000001,"state":0}. Default: "".
update_options             : string   : picklist update: JSON array — options to rename. Optional 'color' field: {"label":"NewLabel","value":100000000,"color":"#FF0000"}. Default: "".
delete_options             : string   : picklist update: JSON array of integer values to remove. Default: "".
is_audit_enabled           : bool?    : Enable audit on this column. CREATE: pass to override Dataverse default (true). UPDATE: omit=null keeps current. Default: null.
is_valid_for_advanced_find : bool?    : Show column in Advanced Find. CREATE: pass to override Dataverse default (true). UPDATE: omit=null keeps current.) Default: null.
is_secured                 : bool?    : Enable field-level security. CREATE: pass to override Dataverse default (false). UPDATE: omit=null keeps current. Default: null.
is_sortable                : bool?    : Make column sortable in views. CREATE: pass to override Dataverse default (true, when supported by the attribute type). UPDATE: omit=null keeps current. Default: null.
default_value              : string   : picklist/boolean create or update: default option value. Picklist: one integer matching an option. Boolean: 'true'/'false' or '1'/'0'. Omit on update to keep current; unsupported for multipicklist. Default: "".
schema_name                : string   : SchemaName for the new column (e.g. 'devkit_InvoiceLineId'). If provided, used AS-IS as SchemaName (skip auto-derive from display_name). Caller responsible for casing. Create only — ignored on update. Must start with the publisher prefix. Default: "".
formula_definition         : string   : Create-only formula clone reference returned by get_tables, exactly `source_table_logical_name:source_column_logical_name` (for example `account:new_total`). Pass it unchanged; the server retrieves and rewrites the source formula directly. Omit it and pass formula_source_type only to create an empty formula column. Default: "".
formula_source_type        : string   : Create only. Use powerfx, calculated, or rollup only when creating an empty formula column without formula_definition. Clone mode derives the kind from the referenced source column. Default: "".
can_store_full_image       : bool?    : image only. CREATE: true = store the full-sized image (default false). UPDATE: omit = keep current. Default: null.
auto_number_format         : string   : Autonumber pattern for string columns, e.g. 'TKT-{SEQNUM:5}-{RANDSTRING:3}'. Placeholders: {SEQNUM:n} (n>=1, minimum zero-padded length), {RANDSTRING:n} (1-6), {DATETIMEUTC:format}. CREATE: sets the pattern; UPDATE: changes it (omit = keep current). format must be Text. Validated client-side — Dataverse only rejects bad patterns at record-save time. Default: "".
clear_auto_number          : bool?    : string UPDATE only: true removes the autonumber pattern, turning the column back into plain text. Mutually exclusive with auto_number_format. Default: null.
auto_number_seed           : int?     : Autonumber seed (>=1; Dataverse default sequence starts at 1000). String autonumber columns only. Executed via SetAutoNumberSeed after the metadata create/update succeeds. Environment-only: NOT carried in solutions. Omit to keep the current seed. Default: null.
env                        : string   : Optional .env connection group: numeric id such as "1", alias such as "prod", or "default" for the unnumbered group. Omit to use the startup connection. Use connection_list to list groups. Default: null.
```

## Solution membership on update

Pass `logical_name` and `solution_name` with the changes. After a successful column metadata or option change, the tool adds the attribute to the solution by its metadata ID as component type 2. This covers choice and status reason option edits and required-level updates that use a Web API PUT. Check `isAddToSolution` and `addToSolutionWarning` for the add request outcome.

# RESULTS

- Test 1: string create with explicit schema_name returns the full created metadata (`status: created`, add-to-solution via SolutionUniqueName, maxLength 100, format Text) with the `[Success] Created ... column` summary trailing the structured payload.
- Test 2: update renames the display label and reports the old/new pair in `changes`.
- Test 3: picklist create renders options with values and colors in `extra.options`.
- Test 4: picklist add + rename + delete execute atomically in one call, each reported separately (`optionsAdded`/`optionsRenamed`/`optionsDeleted`).
- Test 5: boolean create applies the custom Yes/No labels.
- Test 6: lookup create commits the attribute plus its auto-created 1:N relationship (`extra.relationshipName`).
- Test 7: memo create honors max_length 5000.
- Test 8: money create applies precision 2 and the 0..1000000 min/max range.
- Test 9: image create sets canStoreFullImage.
- Test 10: entity_name alone is rejected with a hint explaining the UPDATE and CREATE parameter sets.
- Test 11: CREATE without solution_name fast-errors — the publisher prefix now comes only from the solution publisher.
- Test 12: updating a nonexistent logical_name is rejected with a hint carrying the CREATE parameter set.
- Test 13: an unknown attribute_type is rejected with the full valid type list in the hint.
- Test 14-15: dry-run create previews String and Lookup columns with derived schema/logical names, publisher prefix from all_in_one, and `status: not_executed`; nothing is created (the Lookup preview covers the branch that would also create the 1:N relationship).
- Test 16: dry-run update previews the display-label rename with the old/new value pair in `changes`; the org column is untouched.
