# TOOL DESCRIPTION

```text
Manage modern Dataverse Custom API definitions, request parameters, and response properties. Actions: 'list', 'detail' (read-only) | 'create', 'update', 'delete' (mutations — confirm first). 'create' REQUIRES solution_name (unmanaged; validates publisher prefix consistency and blocks reserved prefix 'new') and display_name (api_name is optional and auto-derived if omitted). When supplied, solution_name applies to new records. Related writes are atomic. 'update' and 'delete' are blocked for managed APIs and APIs backing Power Fx functions. 'delete' is irreversible.

WHEN TO USE:
- Inspect a Custom API's request/response parameters and plugin binding before registering or invoking it
- Discover Custom APIs bound to a specific entity
- Create, update, or delete unmanaged Custom APIs with their request parameters and response properties in a target solution

For Custom API and related server-logic inspection modes, read docs://server_logic_guide.

RELATED TOOLS:
- get_messages → legacy workflow Custom Actions (category=3) + SDK messages
- get_plugins → plugin assemblies/types/steps registered on these APIs
- manage_function → Power Fx functions backed by Custom APIs
- get_solution_components → verify Custom API solution membership
```

# PARAMETERS

```text
action                              : string : 'list', 'detail', 'create', 'update', 'delete'. Required.
api_name                            : string : Display Name, unique name, or GUID. Required: detail/update/delete. Optional on create (auto-derived from solution prefix + display_name if omitted; must start with publisher prefix if provided). Default: "".
entity_name                         : string : Bound entity Display/logical name. 'list': filter. 'create': required when binding_type is 'Entity' or 'EntityCollection'. Default: "".
solution_name                       : string : Unmanaged solution unique/display name. Required: create. Optional: update (adds new parameters/properties to this solution). Default: "".
display_name                        : string : Human-readable label. Required: create. Optional: update. Default: "".
description                         : string : Optional description for create/update. Default: "".
binding_type                        : string : Create only (immutable): 'Global' (default), 'Entity', or 'EntityCollection'. Default: "".
is_function                         : bool   : Create only (immutable): false = Action (default), true = Function. Default: null.
is_private                          : bool   : Optional: create/update. Default false on create. Default: null.
allowed_custom_processing_step_type : string : Create only. 'None' (default), 'AsyncOnly', or 'SyncAndAsync'. Default: "".
workflow_sdk_step_enabled           : bool   : Create only. Enable workflow SDK step (default false). Default: null.
execute_privilege_name              : string : Optional: create/update. Execute privilege name required to invoke this API. Default: "".
request_parameters                  : string : Optional JSON array string of request parameters for create/update: [{"name":"ntf_To","type":"String","is_optional":true,"display_name":"To","description":"...","logical_entity_name":"..."}]. On update, each item accepts optional "action": "add"|"update"|"remove". Existing items allow changes to display_name and description. Default: "".
response_properties                 : string : Optional JSON array string of response properties for create/update: [{"name":"ntf_IsSuccess","type":"Boolean","display_name":"Is Success","description":"...","logical_entity_name":"..."}]. On update, each item accepts optional "action": "add"|"update"|"remove". Existing items allow changes to display_name and description. Default: "".
include_microsoft                   : bool   : List only: include managed APIs. Default false. Default: false.
status                              : string : List only: 'active' / 'inactive' / 'all'. Default: "active".
max_records                         : int    : List only: 1-500. Default 100. Default: 100.
env                                 : string : Optional .env connection group: numeric id such as "1", alias such as "prod", or "default" for the unnumbered group. Omit to use the startup connection. Use connection_list to list groups. Default: null.
```
