# ✅ TOOL DESCRIPTION

```text
Manage form definitions (systemform) for a Dataverse entity. Actions: 'list', 'detail' (read-only) | 'update', 'rename', 'undo' (mutations — require System Administrator).

WHEN TO USE:
- List or inspect forms of an entity (list, detail) before editing
- Apply form operations via action=update (recommended: operations JSON) or raw formxml (advanced/undo)
- Rename a form, or restore a form from a .formxml backup (undo) — the result's backupPath points to the pre-change backup; pass it as formxml to action='undo' to restore

RELATED TOOLS:
- get_tables → entity logical names; manage_view → entity views; publish_customizations → batch publish
- See schema://formxml + docs://instructions_for_formxml for FormXML structure and operation examples
```

# PARAMETERS

```text
action           : string : 'list', 'detail', 'update', 'rename', 'undo'.
entity_name      : string : Entity Display Name or logical name (Display Name is resolved first; e.g. 'Account' or 'account').
form_id          : string : GUID. Required for detail/update/rename/undo.
form_name        : string : Name contains filter. 1 match → auto-detail. Ignored if form_id is set.
form_type        : int    : 2=Main, 5=Mobile, 6=QuickView, 7=QuickCreate. 0 or omit = all types.
include_formxml  : bool   : List mode only — include formxml in each entry. Detail always includes formxml.
formxml          : string : update (advanced) / undo: raw FormXML string or backup file path (.formxml). Auto-detects. Use 'operations' for the recommended flow.
operations       : string : update (recommended): JSON array of form operations. Read docs://instructions_for_formxml for format and examples.
```
