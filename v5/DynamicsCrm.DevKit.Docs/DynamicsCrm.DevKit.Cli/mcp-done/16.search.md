# MCP Tool: search

## Tool #16 — Query & Read

## Status: IMPLEMENTED

## Purpose

Perform a Dataverse Relevance Search (full-text search) across one or more entities. Returns matching records ranked by relevance score with highlights.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| search_term | string | Yes | — | The text to search for (1-100 characters) |
| entities | string | No | `""` | Comma-separated entity logical names to limit scope |
| top | int | No | `50` | Maximum number of results (max 100) |
| filter | string | No | `""` | OData-style filter to narrow results (e.g., `'statecode eq 0'`) |

## Returns

- Total count of matching records
- Markdown table with entity type, record ID, score, and attribute values
- Highlights showing which parts of the text matched the search term

## When to Use

- When the user asks to "find" or "search for" something by name or keyword
- When you need to search across multiple entities at once (e.g., find "Contoso" in accounts, contacts, and leads)
- When you don't know the exact field to filter on — Relevance Search searches across all indexed fields
- As a quick alternative to FetchXML when you just need to find records by text

## Tips

- Relevance Search must be enabled in the Dataverse environment
- Only entities and columns configured for Relevance Search will be searched
- Max 100 results per call — for larger datasets, use `execute_fetchxml` instead
- Search syntax: `+` (AND), `|` (OR), `-` (NOT), trailing `*` wildcard, `"exact phrase"`
- Real data: searching "Fourth Coffee" returns account "Fourth Coffee 4"; searching "Adventure" returns "Adventure Works (sample)"
