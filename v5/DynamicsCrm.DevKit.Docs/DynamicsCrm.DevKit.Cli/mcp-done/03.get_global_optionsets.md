# MCP Tool: get_global_optionsets

## Tool #3 — Metadata Discovery

## Status: IMPLEMENTED

## Purpose

Retrieve global option sets (choices/picklists) from Dataverse metadata.

Two modes:
- **Summary mode** (optionset_name empty): returns a markdown table of ALL global option sets (name, displayName, type, isGlobal)
- **Detail mode** (optionset_name provided): returns detailed options for that specific option set (value, label, description)

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| optionset_name | string | No | `""` | The logical name of the global option set (leave empty to list all) |

## When to Use

- When you need to know the valid values for a global choice/picklist column
- When building FetchXML filters on option set fields and need the integer values
- When you see an integer value in query results and need to map it to a label
- When get_entity_metadata shows a column is PicklistType but the options are empty (references a global option set)

## Note

This retrieves GLOBAL option sets only. For entity-specific (local) picklists, use `get_entity_metadata` which includes options in the attribute definition.
