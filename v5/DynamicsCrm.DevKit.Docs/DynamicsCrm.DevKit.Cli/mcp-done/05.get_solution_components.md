# MCP Tool: get_solution_components

## Tool #5 — Metadata Discovery

## Status: IMPLEMENTED

## Purpose

List all components inside a Dataverse solution. Accepts either the solution unique name (logical name) or display name — uses fuzzy (contains) matching to find the correct solution.

## Returns

- **Solution info**: uniqueName, displayName, version, publisher, isManaged
- **Component summary table**: count per component type
- **Full component detail table**: componentType, typeId, objectId, name

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| solution_name | string | Yes | — | The solution unique name or display name (supports fuzzy matching) |

## Fuzzy Match Behavior

- Matches against both uniqueName and displayName using a 'contains' search
- If exactly 1 solution matches → proceeds and returns components
- If multiple solutions match → returns a list of all matching solutions for disambiguation
- If no solution matches → returns an error message

## When to Use

- Before packaging or deploying a solution, to audit its contents
- To find objectIds of specific components (plugin assemblies, web resources, workflows)
- To count entities, attributes, forms, or other component types in a solution
- As a prerequisite step before operating on specific solution components
