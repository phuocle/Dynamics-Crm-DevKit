# MCP Tool: create_attribute

## Tool #17 — Schema Management

## Status: IMPLEMENTED

## Purpose

Add a new column (attribute) to an existing Dataverse entity. Supports all common types with guided parameters and automatic type resolution.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| entity_name | string | Yes | — | Entity logical name (e.g., `account`) |
| attribute_name | string | Yes | — | Logical name with publisher prefix (e.g., `v4_priority`) |
| attribute_type | string | Yes | — | Type: `string`, `memo`, `integer`, `bigint`, `decimal`, `money`, `float`, `boolean`, `datetime`, `lookup`, `customer`, `picklist`, `multipicklist`, `image`, `file` |
| display_name | string | Yes | — | Display name shown in forms |
| description | string | No | `""` | Column description |
| required_level | string | No | `"None"` | `None`, `Recommended`, or `Required` |
| max_length | int | No | `100` | For string: max chars (1-4000). For memo: (1-1048576). |
| min_value | number | No | — | For numeric types: minimum value |
| max_value | number | No | — | For numeric types: maximum value |
| precision | int | No | `2` | For decimal/money/float: decimal places (0-10) |
| format | string | No | — | For string: `Text`, `Email`, `Url`, `Phone`, `RichText`. For datetime: `DateOnly`, `DateAndTime`. |
| options | string | No | — | For picklist: JSON array `[{"label":"Low","value":100000000}]` |
| global_optionset_name | string | No | — | For picklist: reuse existing global option set (e.g., `v4_v4_category`) |
| lookup_target | string | No | — | For lookup: target entity (e.g., `contact`) |
| lookup_relationship_name | string | No | auto | For lookup: relationship schema name |
| true_label | string | No | `"Yes"` | For boolean: true label |
| false_label | string | No | `"No"` | For boolean: false label |
| solution_name | string | No | `""` | Add column to this solution |
| auto_publish | bool | No | `true` | Publish after creation |

## Returns

- Created attribute details: name, type, MetadataId
- Options (for picklist), target (for lookup)
- Solution and publish status

## When to Use

- To add a new field to an entity
- After creating a new entity with `create_entity`
- When extending an existing entity's data model

## Tips

- Attribute name MUST include publisher prefix (e.g., `v4_`, `new_`)
- Use `get_entity_metadata` to verify the attribute doesn't already exist
- For lookups, the 1:N relationship is created automatically
- For picklist with existing choices, use `global_optionset_name` (e.g., `v4_v4_category`) instead of `options`
- After creation, use `build_form_xml` to add the new field to a form
