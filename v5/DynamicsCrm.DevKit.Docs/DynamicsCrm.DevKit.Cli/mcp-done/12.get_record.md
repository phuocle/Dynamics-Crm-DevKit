# MCP Tool: get_record

## Tool #12 — Query & Read

## Status: IMPLEMENTED

## Purpose

Retrieve a single Dataverse record by entity name and record ID. Returns the record's fields as a markdown table with formatted values for lookups, option sets, money, dates, etc.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| entity_name | string | Yes | — | The logical name of the entity (always lowercase) |
| record_id | string | Yes | — | The GUID of the record to retrieve |
| columns | string | No | `""` | Comma-separated list of column logical names (empty = all columns) |

## When to Use

- When you have a record ID from a previous query and need to see its full details
- When you need to inspect a specific record without writing FetchXML
- When you need to verify a record exists before performing operations on it
- After execute_fetchxml returns IDs, use this to get complete field values for a specific record

## Tip

Use `get_entity_metadata` first to discover available columns for the entity.
