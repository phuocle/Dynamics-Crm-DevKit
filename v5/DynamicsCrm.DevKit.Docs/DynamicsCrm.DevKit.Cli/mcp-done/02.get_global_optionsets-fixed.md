# MCP Tool: get_global_optionsets

## Tool #3 — Metadata Discovery

## Status: IMPLEMENTED

## Purpose

Retrieve global option sets (choices/picklists) from Dataverse metadata. Summary mode lists all 150+ global option sets; detail mode shows options for a specific one.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| optionset_name | string | No | `""` | Logical name of the global option set (leave empty to list all) |

## Returns

- Summary mode (empty name): table of all global option sets with name, displayName, type, isGlobal
- Detail mode (name provided): option set properties + options table with value, label, description

## When to Use

- When you need to know the valid values for a global choice/picklist column
- When building FetchXML filters on option set fields and need the integer values
- When you see an integer value in query results and need to map it to a label
- When `get_metadata_entities` shows a column is PicklistType but the options are empty (references a global option set)

## Tips

- This retrieves GLOBAL option sets only — for local picklists, use `get_metadata_entities` instead
- The environment has 150 global option sets — use `optionset_name` to get details for a specific one
- Custom global option sets have publisher prefixes (e.g., `v4_v4_category`)
- Boolean types show as global option sets too (e.g., `activitypointer_isregularactivity`)
