# MCP Tool: create_entity

## Tool #18 — Schema Management

## Status: IMPLEMENTED

## Purpose

Create a new custom Dataverse entity (table) with guided parameters. Automatically creates the primary name attribute and configures common properties.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| entity_name | string | Yes | — | Logical name with publisher prefix (e.g., `v4_project`) |
| display_name | string | Yes | — | Singular display name (e.g., `Project`) |
| display_collection_name | string | Yes | — | Plural display name (e.g., `Projects`) |
| solution_name | string | Yes | — | Solution unique name (e.g., `devkitv4`) |
| description | string | No | `""` | Entity description |
| primary_attribute_name | string | No | auto | Primary name attribute logical name |
| primary_attribute_display_name | string | No | `"Name"` | Display name for primary attribute |
| primary_attribute_max_length | int | No | `100` | Max length of primary attribute (max 850) |
| ownership_type | string | No | `"User"` | `User` (user/team owned) or `Organization` |
| is_activity | bool | No | `false` | Create as activity entity |
| has_notes | bool | No | `true` | Enable notes/annotations |
| has_activities | bool | No | `true` | Enable activities |
| has_feedback | bool | No | `false` | Enable feedback/ratings |
| is_quick_create_enabled | bool | No | `false` | Enable quick create form |
| is_duplicate_detection_enabled | bool | No | `true` | Enable duplicate detection |
| change_tracking_enabled | bool | No | `true` | Enable change tracking |
| entity_color | string | No | `""` | Hex color code (e.g., `#4A90D9`) |
| auto_publish | bool | No | `true` | Publish after creation |

## Returns

- Created entity details: logical name, MetadataId, EntitySetName
- Primary attribute details
- Solution and publish status

## When to Use

- To create a new custom table in Dataverse
- At the start of a new feature or module development
- When the data model requires a new entity

## Tips

- Entity name MUST include a publisher prefix (e.g., `v4_` for the DevKit solution publisher)
- Existing custom entities: `v4_devkit`, `v4_test_mcp`, `v4_accountbpf`, `v4_packagesqlite`
- After creation, use `create_attribute` to add columns, then `build_formxml` + `update_form` for the UI
- UserOwned entities support sharing, assigning, and team ownership
- OrgOwned entities are visible to all, no row-level security
