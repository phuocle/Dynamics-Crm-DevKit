# MCP Tool: build_form_xml

## Tool #7 — UI Customization

## Status: IMPLEMENTED

## Purpose

Build modified FormXML by adding fields, sections, or tabs to an existing Dataverse form. Automatically resolves classid GUIDs, generates proper XML structure, and creates unique IDs.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| entity_name | string | Yes | — | Entity logical name (e.g., `account`) |
| form_id | string | Yes | — | GUID of the form to modify |
| operations | string | Yes | — | JSON array of operations: `add_fields`, `add_section`, `add_tab` |

## Returns

- Complete modified FormXML string ready to pass to `update_form`
- Validated field metadata with resolved classid GUIDs

## When to Use

- When adding fields to an existing section on a form
- When adding a new section (with fields) to an existing tab
- When adding a new tab (with sections and fields) to a form
- Instead of manually editing FormXML (error-prone classid resolution)

## Tips

- Always call `get_forms` first to find the form_id
- Use `get_entity_metadata` to verify field names exist before adding them
- Fields can be strings (`"createdon"`) or objects (`{"field":"createdon","label":"Date Created","disabled":true}`)
- section_columns: 1 (one field per row), 2 (two per row), 3 (three per row)
- After building, pass the returned FormXML to `update_form` to write it
