# MCP Tool: parse_record_url

## Tool #15 — Utility

## Status: IMPLEMENTED

## Purpose

Parse a Dynamics 365 / Power Platform URL or string to extract the entity logical name and record ID (GUID).

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| input | string | Yes | — | URL, GUID, or text to parse. Accepts Dynamics 365 record URLs, Web API URLs, maker portal URLs, or raw GUIDs. |

## Returns

- EntityName: the entity logical name (e.g., `account`, `plugintracelog`)
- RecordId: the record GUID
- Source: what type of input was parsed (main.aspx, Web API, maker portal, raw GUID)
- EnvironmentId: (if present in maker portal URLs)

## When to Use

- When a user pastes a Dynamics 365 URL and you need to extract entity name and record ID
- Before calling `get_record`, `get_logs`, or other tools that need entity_name + record_id
- When a user references a record by URL instead of by entity name + GUID

## Tips

- Supports: `main.aspx?etn=...&id=...`, Web API URLs, Power Apps maker URLs, Power Automate URLs, raw GUIDs
- For `etc` (entity type code) URLs, the tool resolves the code to entity logical name via Dataverse
- If entity name is `unknown` (raw GUID), ask the user for context
- GUID formats with braces `{guid}` or URL-encoded `%7Bguid%7D` are handled automatically
