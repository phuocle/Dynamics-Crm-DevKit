# Proposal: upsert_variable MCP Tool

## Priority: 35 (Configuration Management — Environment Variables)

## Phase: 3 — Configuration & DevOps

## Why This Tool Is Needed

Environment variables in Dataverse consist of two tables: `environmentvariabledefinition` (schema: name, type, default value) and `environmentvariablevalue` (the current override value). Creating or updating a variable requires coordinating writes across both tables, resolving whether a value record already exists, and optionally adding the definition to a solution.

### Current Pain (execute_webapi)

```
# Step 1: Check if definition exists
method: GET
url: environmentvariabledefinitions?$filter=schemaname eq 'new_ApiEndpoint'&$select=environmentvariabledefinitionid

# Step 2a: Create definition (if not exists)
method: POST
url: environmentvariabledefinitions
body: {"schemaname":"new_ApiEndpoint","displayname":"API Endpoint","type":100000000,"defaultvalue":"https://api.example.com"}

# Step 2b: Update definition (if exists)
method: PATCH
url: environmentvariabledefinitions(guid)
body: {"defaultvalue":"https://api-v2.example.com"}

# Step 3: Check if value record exists
method: GET
url: environmentvariablevalues?$filter=_environmentvariabledefinitionid_value eq guid&$select=environmentvariablevalueid

# Step 4: Create or update value record
method: POST (or PATCH)
url: environmentvariablevalues (or environmentvariablevalues(guid))
body: {"value":"https://api-prod.example.com","environmentvariabledefinitionid@odata.bind":"environmentvariabledefinitions(guid)"}
```

Must know: (1) two-table structure, (2) value record may or may not exist, (3) type is an integer optionset, (4) solution component registration is separate.

### Proposed (upsert_variable)

```
variable_name: new_ApiEndpoint
display_name: API Endpoint
type: string
value: https://api-prod.example.com
```

Tool auto-resolves definition existence, creates or updates both tables, and optionally adds to solution.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `variable_name` | string | Yes | — | Schema name with publisher prefix (e.g., `new_ApiEndpoint`). Used to find or create the definition. |
| `display_name` | string | Cond. | — | Display name. Required when creating a new variable. Ignored on update if not provided. |
| `type` | string | Cond. | — | Variable type: `string`, `number`, `boolean`, `json`, `datasource`, `secret`. Required on create, ignored on update (type cannot change). |
| `default_value` | string | No | `""` | Default value for the definition. |
| `value` | string | No | `""` | Current value override. If provided, creates or updates the `environmentvariablevalue` record. If empty, leaves the current value unchanged (does NOT clear it). |
| `clear_value` | bool | No | false | Set to `true` to delete the current value record, reverting to the default value. Mutually exclusive with `value`. |
| `description` | string | No | `""` | Variable description. |
| `solution_name` | string | No | `""` | Solution to add the definition to (create only). |
| `auto_publish` | bool | No | false | Publish after changes. Environment variables typically do not require publishing, but some integrations check published state. |

---

## Behavior

### Upsert Logic

1. **Query** `environmentvariabledefinition` by `schemaname`
2. **If not found** → CREATE definition (requires `display_name` and `type`)
3. **If found** → UPDATE definition with provided fields (`display_name`, `default_value`, `description` — only non-empty values are patched)
4. **If `value` is provided** → query `environmentvariablevalue` for this definition
   - If value record exists → UPDATE it
   - If value record does not exist → CREATE it with link to definition
5. **If `clear_value = true`** → DELETE the value record (if it exists)
6. **If `solution_name` is provided** (create only) → add definition as solution component

### Type Mapping

| Parameter Value | OptionSet Value | Dataverse Type |
|---|---|---|
| `string` | 100000000 | String |
| `number` | 100000001 | Number |
| `boolean` | 100000002 | Boolean |
| `json` | 100000003 | JSON |
| `datasource` | 100000004 | Data Source |
| `secret` | 100000005 | Secret |

## Dataverse API

```csharp
// Step 1: Check if definition exists
var def = RetrieveDefinition(variableName);

if (def == null)
{
    // Step 2a: Create
    if (string.IsNullOrEmpty(displayName))
        return Error("display_name is required when creating a new variable.");
    if (string.IsNullOrEmpty(type))
        return Error("type is required when creating a new variable.");

    var newDef = new Entity("environmentvariabledefinition")
    {
        ["schemaname"] = variableName,
        ["displayname"] = displayName,
        ["type"] = new OptionSetValue(MapType(type)),
        ["defaultvalue"] = defaultValue,
        ["description"] = description
    };
    var defId = _serviceClient.Create(newDef);

    // Add to solution if specified
    if (!string.IsNullOrWhiteSpace(solutionName))
        AddToSolution(defId, solutionName);
}
else
{
    // Step 2b: Update existing definition (only non-empty fields)
    var update = new Entity("environmentvariabledefinition", def.Id);
    if (!string.IsNullOrEmpty(displayName)) update["displayname"] = displayName;
    if (!string.IsNullOrEmpty(defaultValue)) update["defaultvalue"] = defaultValue;
    if (!string.IsNullOrEmpty(description)) update["description"] = description;
    if (update.Attributes.Count > 0)
        _serviceClient.Update(update);
}

// Step 3: Handle current value
if (clearValue)
{
    DeleteCurrentValue(defId);
}
else if (!string.IsNullOrEmpty(value))
{
    UpsertCurrentValue(defId, value);
}
```

## Response Format (Compact)

### Create

```
[EnvironmentVariable] Created: new_ApiEndpoint
DisplayName: API Endpoint
Type: String
DefaultValue: https://api.example.com
CurrentValue: https://api-prod.example.com
Solution: MySolution
```

### Update

```
[EnvironmentVariable] Updated: new_ApiEndpoint
DefaultValue: https://api-v2.example.com (changed)
CurrentValue: https://api-prod.example.com (unchanged)
```

### Clear Value

```
[EnvironmentVariable] Updated: new_ApiEndpoint
CurrentValue: (cleared — reverted to default)
DefaultValue: https://api.example.com
```

### Error — Missing Required Fields

```
[Error] Cannot create environment variable 'new_ApiEndpoint':
  display_name is required when creating a new variable.
  type is required when creating a new variable.
Tip: Use get_variables to check if the variable already exists.
```
