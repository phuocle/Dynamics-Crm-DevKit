# MCP Tool: execute_webapi

## Tool #26 — Query & Read

## Status: IMPLEMENTED

## Purpose

Execute any Dataverse Web API request (GET/POST/PUT/PATCH/DELETE). This is a fallback "escape hatch" tool when specialized tools (`execute_fetchxml`, `get_metadata_entities`, `upsert_record`) don't cover a specific use case.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| method | string | Yes | — | HTTP method: `GET`, `POST`, `PUT`, `PATCH`, `DELETE` |
| url | string | Yes | — | Relative URL path — SDK handles base URL automatically |
| body | string | No | `""` | Request body for POST/PUT/PATCH (valid JSON string) |
| headers | string | No | `""` | Additional custom headers as JSON string (e.g., `{"MSCRM.MergeLabels": "true"}`) |
| include_headers | bool | No | `false` | Include response headers in output |
| max_response_lines | int | No | `200` | Maximum response body lines to return |

## Returns

- HTTP status code and status text
- Response headers (if include_headers=true)
- Response body (JSON, truncated if exceeding max_response_lines)

## When to Use

- Query metadata endpoints: `RelationshipDefinitions`, `EntityDefinitions` subpaths
- PUT/PATCH metadata (relationship, entity, attribute metadata)
- Call custom Actions or Functions
- Read `$metadata` CSDL schema
- Any Dataverse Web API operation not covered by other tools

## Tips

- Pass relative URL only — SDK handles base URL and auth automatically
- Standard headers (Authorization, OData-Version) are handled by SDK — only provide extra headers
- **BLOCKED endpoints** (use dedicated tools instead): PATCH/PUT/DELETE on `systemforms` → use `upsert_form`; on `savedqueries`/`userqueries` → use `upsert_view`; on `sitemaps` → use `upsert_sitemap`; on `environmentvariable*` → use `upsert_variable`; POST `PublishXml`/`PublishAllXml` → use `publish_customizations`
- PUT/PATCH/DELETE operations are destructive and irreversible — confirm with user before executing write operations on metadata
- Real data: `EntityDefinitions(LogicalName='account')` returns account metadata; `$metadata` returns CSDL schema
