# MCP Tool: delete_record

## Tool #19 — Data Operations

## Status: IMPLEMENTED

## Purpose

Delete a record from a Dataverse table by its GUID. This operation is PERMANENT and cannot be undone.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| entity_name | string | Yes | — | Logical name of the entity/table (lowercase) |
| record_id | string | Yes | — | GUID of the record to delete |

## Returns

- Confirmation of deletion or error message

## When to Use

- When the user explicitly asks to delete a specific record
- For cleanup of test data
- When removing orphaned records

## Tips

- Use `execute_fetchxml` or `get_record` to verify the record exists before deleting
- Some records may fail to delete due to dependencies (child records, required lookups)
- Deleting a parent record may cascade-delete child records depending on relationship config
- Real test data: accounts like "Fourth Coffee 4", "Litware, Inc. (sample)" — be careful with sample data
