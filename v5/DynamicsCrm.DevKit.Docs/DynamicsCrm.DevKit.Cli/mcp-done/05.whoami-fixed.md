# MCP Tool: whoami

## Tool #6 — Utility

## Status: IMPLEMENTED

## Purpose

Get the identity of the currently authenticated user, environment info, and optionally the access token.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| include_token | bool | No | `false` | Include OAuth access token (adds ~400 tokens) |

## Returns

- UserId, FullName, DomainName, Email (the authenticated user)
- BusinessUnitId, OrganizationId
- Security Roles assigned to the user
- Environment URL, version, friendly name, unique name
- TenantId, EnvironmentId
- Base language, base currency, fiscal settings, audit status
- AccessToken (only when include_token=true)

## When to Use

- At the start of a session to confirm which user and environment you are connected to
- When troubleshooting permission errors to check which security roles the user has
- When you need the current user's ID for FetchXML filters (e.g., records owned by me)
- To verify the connection is working before running other tools
- When you need the access token for direct Web API calls

## Tips

- The current environment is DEVKITV4 at `dynamics-crm-devkit-v4.crm.dynamics.com`
- Current user has the `System Administrator` role
- Use include_token=true only when you need to make direct API calls outside MCP
