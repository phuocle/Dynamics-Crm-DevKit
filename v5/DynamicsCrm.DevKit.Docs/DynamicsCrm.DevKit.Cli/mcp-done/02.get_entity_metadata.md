# MCP Tool: get_entity_metadata

## Tool #2 — Metadata Discovery

## Status: IMPLEMENTED

## Purpose

Retrieve full metadata for a single Dataverse entity/table. Call this BEFORE writing FetchXML to discover correct attribute names and relationships. Call this AFTER a failed execute_fetchxml to find the correct column names.

## Returns

1. **Entity info**: logicalName, displayName, displayCollectionName, entitySetName, primaryIdAttribute, primaryNameAttribute, schemaName, ownershipType, isActivity, isCustomEntity, isAuditEnabled, changeTrackingEnabled, objectTypeCode, totalAttributes
2. **Attributes table**: logicalName, type, requiredLevel, isValidForCreate, isValidForUpdate, constraints, displayName
3. **Relationships**: 1:N, N:1, N:N with schema names and join columns
4. **Alternate Keys**: schemaName, displayName, keyAttributes

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| entity_name | string | Yes | — | The logical name of the entity (always lowercase) |
| attribute_prefix | string | No | `""` | Optional prefix filter for attributes and relationships (e.g., 'ab_', 'msdyn_', 'new_') |

## When to Use

- Before building any FetchXML query to ensure correct attribute names
- When you need to join entities and need the correct from/to columns
- When you need to know what picklist/choice options are available for filtering
- When you need to find the primary key or primary name field of an entity
