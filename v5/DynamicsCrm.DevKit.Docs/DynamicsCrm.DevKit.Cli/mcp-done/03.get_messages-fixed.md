# MCP Tool: get_messages

## Tool #4 — Metadata Discovery

## Status: IMPLEMENTED

## Purpose

Discover SDK messages, Custom Actions, and Custom APIs available for a Dataverse entity. Returns counts and categorized message lists.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| entity_name | string | No | `"none"` | Entity logical name or `"none"` for global (unbound) messages |
| include_custom_actions | bool | No | `true` | Include Custom Action messages |
| include_custom_apis | bool | No | `true` | Include Custom API messages |

## Returns

- Summary table: category (SDK Messages, Custom Actions, Custom APIs) with counts
- SDK Messages list: standard platform messages (Create, Update, Delete, Retrieve, etc.)
- Custom Actions list: organization-defined actions registered for this entity
- Custom APIs list: custom API messages registered for this entity

## When to Use

- When building plugins and you need to know which messages are available for an entity
- When you need to discover Custom Actions or Custom APIs in the environment
- When registering plugin steps and need to verify message availability
- When exploring what operations can be performed on a specific entity

## Tips

- Use `"none"` for global messages like `WhoAmI`, `RetrieveCurrentOrganization`
- The account entity has 23 SDK Messages, 1 Custom Action (`v4_AccountCustomAction`), and 1 Custom API (`v4_AccountCustomApi`)
- Custom Actions/APIs with `v4_` prefix are project-specific; `msdyn_` are Microsoft-provided
