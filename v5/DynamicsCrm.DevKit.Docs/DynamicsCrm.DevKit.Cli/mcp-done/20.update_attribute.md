# MCP Tool: update_attribute

## Tool #21 — Schema Management

## Status: IMPLEMENTED

## Purpose

Update an existing column (attribute) on a Dataverse entity. Supports modifying display properties (name, description, required level) and type-specific properties (max length, value ranges, precision, format, boolean labels, picklist options).

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| entity_name | string | Yes | — | Entity logical name (e.g., `account`) |
| attribute_name | string | Yes | — | Logical name of the column to update (e.g., `v4_priority`) |
| display_name | string | No | `""` | New display name. Leave empty to keep current. |
| description | string | No | `""` | New description. Leave empty to keep current. |
| required_level | string | No | `""` | `None`, `Recommended`, or `Required`. Leave empty to keep current. |
| max_length | int | No | `0` | For string/memo: new max chars (1-4000). 0 = keep current. |
| min_value | number | No | `null` | For integer/decimal/float/money: new minimum value |
| max_value | number | No | `null` | For integer/decimal/float/money: new maximum value |
| precision | int | No | `-1` | For decimal/money/float: new decimal places (0-10). -1 = keep current. |
| format | string | No | `""` | For string: `Text`, `Email`, `Url`, `Phone`. For datetime: `DateOnly`, `DateAndTime`. |
| true_label | string | No | `""` | For boolean: new label for true value |
| false_label | string | No | `""` | For boolean: new label for false value |
| add_options | string | No | `""` | For picklist: JSON array `[{"label":"Critical","value":100000003}]` to add |
| update_options | string | No | `""` | For picklist: JSON array `[{"label":"New Label","value":100000000}]` to rename |
| delete_options | string | No | `""` | For picklist: JSON array `[100000002, 100000003]` integer values to remove |
| is_audit_enabled | bool | No | `null` | Enable/disable auditing on this column |
| is_valid_for_advanced_find | bool | No | `null` | Show/hide in Advanced Find |
| auto_publish | bool | No | `true` | Publish the entity after update |

## Returns

- Updated attribute details with before/after values for changed properties
- Picklist option changes (added/renamed/deleted)
- Publish status

## When to Use

- To rename a column's display name
- To change required level (None -> Required)
- To expand a string field's max length
- To add/rename/remove picklist options
- To change boolean Yes/No labels
- To adjust numeric range or precision

## Tips

- Only provide parameters you want to change — omitted params keep current values
- Use `get_metadata_entities` first to see current attribute properties
- For picklist options: `add_options`, `update_options`, `delete_options` can be combined in one call
- Cannot change attribute type (e.g., string to integer) — this is a Dataverse limitation
- Cannot update system attributes (e.g., `createdon`, `modifiedby`)
- Real data: account has 16 custom v4_* attributes including `v4_category` (Picklist), `v4_isdevkit` (Boolean), `v4_name` (String)
