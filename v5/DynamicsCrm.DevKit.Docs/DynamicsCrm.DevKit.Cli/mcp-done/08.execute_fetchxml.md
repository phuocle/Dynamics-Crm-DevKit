# MCP Tool: execute_fetchxml

## Tool #8 — Query & Read

## Status: IMPLEMENTED

## Purpose

Execute a FetchXML query against Microsoft Dataverse and return results as a markdown table. Supports auto-paging to retrieve large datasets. Max 5000 records per call.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| fetchxml | string | Yes | — | The FetchXML query string (valid XML starting with `<fetch>`) |
| max_records | int | No | `5000` | Maximum records to return (capped at 5000) |
| get_all | bool | No | `false` | Automatically page through all results until max_records is reached |

## FetchXML Structure

- Root: `<fetch [distinct='true'] [aggregate='true']>`
- Entity: `<entity name='logical_name'>`
- Columns: `<attribute name='col'/>` (omit all for all columns)
- Order: `<order attribute='col' [descending='true']/>`
- Filter: `<filter [type='and|or']>` with `<condition>` elements
- Joins: `<link-entity>` for related entities
- Aggregation: `aggregate='true'` on `<fetch>` with aggregate functions

## Important Rules

- Do NOT use `top='N'` in FetchXML — use the `max_records` parameter instead
- Always use entity/attribute logical names (lowercase)
- Use `get_entity_metadata` first to discover correct attribute names

## When to Use

- For querying data with complex filters, joins, or aggregations
- When you need more than what `search` provides
- For reporting and analytics queries
- When you need precise filtering by date range, status, numeric values
