# MCP Tool: get_variables

## Tool #20 — Solution Management

## Status: IMPLEMENTED

## Purpose

List or get Dataverse environment variables (read-only). Environment variables store configuration values that change between environments (Dev/Test/Prod), used by Power Automate flows, plugins, and custom code.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| variable_name | string | No | `""` | Schema name of the variable. Empty = list mode, provided = detail mode |
| solution_name | string | No | `""` | Filter by solution (list mode only) |
| max_records | int | No | `50` | Max variables for list mode (capped at 5000) |

## Returns

- List mode: TSV table of variables with name, type, default value, current value
- Detail mode: Key-value details of a single variable

## When to Use

- To check environment-specific configuration
- To verify connection strings or API endpoints between environments
- When debugging flows or plugins that use environment variables
- To audit configuration before a deployment

## Tips

- Environment variables have a default value and an optional current value — the current value overrides the default
- This tool is read-only — to update a variable value, use the `upsert_variable` tool
- Real data: the DEVKITV4 environment has 5 environment variables (all `msdyn_*` prefixed), including `msdyn_AllowSelectLeafOnly` (Boolean) and `msdyn_SLAWebClientDeprecationAcknowledge` (Number)
- Variables are defined in `environmentvariabledefinition` and values in `environmentvariablevalue`
