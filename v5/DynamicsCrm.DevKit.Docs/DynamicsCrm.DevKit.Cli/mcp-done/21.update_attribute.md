## Why This Tool Is Needed

After creating columns with `create_attribute`, modifying them is the **next most common schema operation**. Currently, AI must:

1. Know the exact OData type annotation for the attribute being updated
2. GET the full attribute metadata first, then PATCH/PUT it back
3. Use `execute_webapi` with raw requests — easy to corrupt metadata
4. Handle `MSCRM.MergeLabels: true` header to preserve localized labels
5. Manually call `publish_customizations` afterward

A guided tool ensures safe updates with automatic type resolution and label preservation.

### DevKit Advantage Over mwhesse

mwhesse's `update_dataverse_column` only supports generic properties. Our tool will also support **type-specific properties**: maxLength, min/max values, precision, format, boolean labels, and picklist option management — making it significantly more capable.

## Purpose

Update an existing column (attribute) on a Dataverse entity. Supports modifying display properties (name, description, required level) and type-specific properties (max length, value ranges, precision, format, boolean labels). Can also add/remove picklist options.

## Dataverse API

### Update Generic Properties (all types)

```csharp
var retrieveRequest = new RetrieveAttributeRequest
{
    EntityLogicalName = entityName,
    LogicalName = attributeName,
    RetrieveAsIfPublished = true
};
var response = (RetrieveAttributeResponse)_serviceClient.Execute(retrieveRequest);
var metadata = response.AttributeMetadata;

// Update properties
if (!string.IsNullOrEmpty(displayName))
    metadata.DisplayName = new Label(displayName, 1033);
if (!string.IsNullOrEmpty(description))
    metadata.Description = new Label(description, 1033);
if (requiredLevel != null)
    metadata.RequiredLevel = new AttributeRequiredLevelManagedProperty(requiredLevel);

var updateRequest = new UpdateAttributeRequest
{
    EntityName = entityName,
    Attribute = metadata,
    MergeLabels = true,
    SolutionUniqueName = solutionName
};
_serviceClient.Execute(updateRequest);
```

### Update Type-Specific Properties

```csharp
// String: update max length
if (metadata is StringAttributeMetadata stringMeta && maxLength.HasValue)
{
    stringMeta.MaxLength = maxLength.Value;
}

// Integer: update range
if (metadata is IntegerAttributeMetadata intMeta)
{
    if (minValue.HasValue) intMeta.MinValue = (int)minValue.Value;
    if (maxValue.HasValue) intMeta.MaxValue = (int)maxValue.Value;
}

// Decimal: update range and precision
if (metadata is DecimalAttributeMetadata decMeta)
{
    if (minValue.HasValue) decMeta.MinValue = minValue.Value;
    if (maxValue.HasValue) decMeta.MaxValue = maxValue.Value;
    if (precision.HasValue) decMeta.Precision = precision.Value;
}

// Money: update range and precision
if (metadata is MoneyAttributeMetadata moneyMeta)
{
    if (minValue.HasValue) moneyMeta.MinValue = (double)minValue.Value;
    if (maxValue.HasValue) moneyMeta.MaxValue = (double)maxValue.Value;
    if (precision.HasValue) moneyMeta.Precision = precision.Value;
}

// Boolean: update labels
if (metadata is BooleanAttributeMetadata boolMeta)
{
    if (!string.IsNullOrEmpty(trueLabel))
        boolMeta.OptionSet.TrueOption.Label = new Label(trueLabel, 1033);
    if (!string.IsNullOrEmpty(falseLabel))
        boolMeta.OptionSet.FalseOption.Label = new Label(falseLabel, 1033);
}
```

### Manage Picklist Options

```csharp
// Add new option
var insertRequest = new InsertOptionValueRequest
{
    EntityLogicalName = entityName,
    AttributeLogicalName = attributeName,
    Label = new Label(optionLabel, 1033),
    Value = optionValue // null for auto-assign
};
_serviceClient.Execute(insertRequest);

// Update option label
var updateOptionRequest = new UpdateOptionValueRequest
{
    EntityLogicalName = entityName,
    AttributeLogicalName = attributeName,
    Value = optionValue,
    Label = new Label(newLabel, 1033),
    MergeLabels = true
};
_serviceClient.Execute(updateOptionRequest);

// Delete option
var deleteOptionRequest = new DeleteOptionValueRequest
{
    EntityLogicalName = entityName,
    AttributeLogicalName = attributeName,
    Value = optionValue
};
_serviceClient.Execute(deleteOptionRequest);
```

## Response Format (Compact)

### Success — Generic Update
```
[AttributeUpdated] account.new_priority
Changes:
  DisplayName: "Priority" -> "Priority Level"
  RequiredLevel: "None" -> "Recommended"
Published: yes
```

### Success — Picklist Options Modified
```
[AttributeUpdated] account.new_priority
OptionsAdded: Critical (100000003)
OptionsRenamed: Low (100000000) -> "Low Priority"
OptionsDeleted: 100000002
Published: yes
```

### Error — Attribute not found
```
[Error] Attribute 'new_priorityy' not found on entity 'account'
Tip: Use get_entity_metadata to find the correct attribute logical name
```

### Error — Invalid property for type
```
[Error] Cannot update 'max_length' on attribute 'new_priority' (type: Picklist)
Tip: max_length is only valid for String and Memo types
```

## Tool Description for AI

```
Update an existing column (attribute) on a Dataverse entity.
Supports modifying display properties and type-specific properties.

TWO SCOPES OF CHANGES:
- Generic (all types): display_name, description, required_level, audit, advanced_find
- Type-specific: max_length (string/memo), min/max_value (numeric), precision (decimal/money),
  format (string/datetime), true/false_label (boolean), options (picklist)

PARAMETERS:
- entity_name (required): Entity logical name (e.g., 'account').
- attribute_name (required): Logical name of the column to update (e.g., 'new_priority').
- display_name: New display name. Leave empty to keep current.
- description: New description. Leave empty to keep current.
- required_level: 'None', 'Recommended', or 'Required'. Leave empty to keep current.
- max_length: For string/memo: new max length (1-4000).
- min_value/max_value: For numeric types: new value range.
- precision: For decimal/money: new decimal places (0-10).
- format: For string: 'Text','Email','Url','Phone'. For datetime: 'DateOnly','DateAndTime'.
- true_label/false_label: For boolean: new labels.
- add_options: For picklist: JSON [{label,value}] to add new options.
- update_options: For picklist: JSON [{label,value}] to rename existing options.
- delete_options: For picklist: JSON [value1, value2] integer values to remove.
- is_audit_enabled: Enable/disable auditing.
- is_valid_for_advanced_find: Show/hide in Advanced Find.
- auto_publish: Publish after update (default: true).

RETURNS:
- Updated attribute details with before/after values for changed properties
- Publish status

WHEN TO USE:
- To rename a column's display name
- To change required level (None -> Required)
- To expand a string field's max length
- To add/rename/remove picklist options
- To change boolean Yes/No labels
- To adjust numeric range or precision

TIPS:
- Only provide parameters you want to change — omitted params keep current values
- Use get_entity_metadata first to see current attribute properties
- For picklist options: add_options, update_options, delete_options can be combined in one call
- MergeLabels is always true to preserve existing translations
- Cannot change attribute type (e.g., string to integer) — this is a Dataverse limitation
```

## Implementation Notes

- Always retrieve current metadata first via `RetrieveAttributeRequest` with `RetrieveAsIfPublished = true`
- Set `MergeLabels = true` on `UpdateAttributeRequest` to preserve localized labels
- Validate type-specific parameters against actual attribute type (e.g., reject max_length for Picklist)
- For picklist option management, use separate SDK requests: `InsertOptionValueRequest`, `UpdateOptionValueRequest`, `DeleteOptionValueRequest`
- Handle `FaultException` for invalid values (e.g., max_length < current data length)
- Cannot change: attribute type, logical name, or schema name — these are immutable after creation
- Cannot update system attributes (e.g., `createdon`, `modifiedby`)
