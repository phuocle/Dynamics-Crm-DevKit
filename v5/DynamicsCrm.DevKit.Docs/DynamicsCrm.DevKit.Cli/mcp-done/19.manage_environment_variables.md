# MCP Tool: manage_environment_variables

## Tool #20 — Solution Management

## Status: IMPLEMENTED

## Purpose

List, get, and set Dataverse environment variables. Environment variables store configuration values that change between environments (Dev/Test/Prod), used by Power Automate flows, plugins, and custom code.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| action | string | Yes | — | `"list"`, `"get"`, or `"set"` |
| variable_name | string | Cond. | — | For get/set: schema name of the variable |
| value | string | Cond. | — | For set: new value |
| solution_name | string | No | `""` | Filter by solution (list mode) |
| max_records | int | No | `50` | Max variables for list mode |

## Returns

- List mode: TSV table of variables with name, type, default value, current value
- Get mode: Key-value details of a single variable
- Set mode: Confirmation with old and new values

## When to Use

- To check environment-specific configuration
- To update connection strings or API endpoints between environments
- When debugging flows or plugins that use environment variables
- To audit configuration before a deployment

## Tips

- Environment variables have a default value and an optional current value — the current value overrides the default
- Use `get` to check both default and current values before using `set`
- Real data: the DEVKITV4 environment has 5 environment variables including `v4_devkit_ConnectionString` (String type) and `v4_devkit_JsonData` (JSON type)
- Variables are defined in `environmentvariabledefinition` and values in `environmentvariablevalue`
