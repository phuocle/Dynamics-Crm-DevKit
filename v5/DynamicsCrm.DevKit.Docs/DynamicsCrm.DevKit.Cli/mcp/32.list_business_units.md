# Proposal: list_business_units MCP Tool

## Priority: 19 (Admin & Governance — BU Hierarchy)

## Phase: 4 — Admin & Governance

## Why This Tool Is Needed

Business units form the security hierarchy in Dataverse. Understanding the BU tree is essential for debugging security role inheritance, record visibility, and team ownership. Currently requires FetchXML with self-referential join to build the hierarchy.

### Current Pain (execute_fetchxml)

```xml
<fetch>
  <entity name="businessunit">
    <attribute name="name"/>
    <attribute name="parentbusinessunitid"/>
    <attribute name="isdisabled"/>
    <order attribute="name"/>
  </entity>
</fetch>
```

Returns flat rows — AI must reconstruct the tree hierarchy from `parentbusinessunitid` references.

### Proposed (list_business_units)

```
format: tree
include_user_count: true
```

Returns a pre-formatted hierarchy with user counts per BU.

---

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `format` | string | No | `tree` | `tree` (indented hierarchy) or `flat` (table). |
| `include_user_count` | bool | No | false | Include count of active users per BU. |
| `include_team_count` | bool | No | false | Include count of teams per BU. |
| `filter` | string | No | `active` | `active`, `disabled`, `all`. |

---

## Dataverse API

```csharp
var fetchXml = @"
<fetch>
  <entity name='businessunit'>
    <attribute name='businessunitid'/>
    <attribute name='name'/>
    <attribute name='parentbusinessunitid'/>
    <attribute name='isdisabled'/>
    <attribute name='createdon'/>
    <order attribute='name'/>
  </entity>
</fetch>";

var allBUs = ExecuteFetchXml(fetchXml);

// Build tree structure
var root = allBUs.First(bu => bu.ParentBUId == null);
BuildTree(root, allBUs);

// If include_user_count, aggregate:
// <fetch aggregate='true'><entity name='systemuser'>
//   <attribute name='businessunitid' groupby='true' alias='bu'/>
//   <attribute name='systemuserid' aggregate='count' alias='count'/>
//   <filter><condition attribute='isdisabled' operator='eq' value='0'/></filter>
// </entity></fetch>
```

## Response Format

### Tree Format
```
[BusinessUnits] 8 active business units

Contoso Ltd (root)                    [45 users, 3 teams]
├── Sales                             [12 users, 2 teams]
│   ├── Sales - North America         [5 users, 1 team]
│   └── Sales - EMEA                  [4 users, 1 team]
├── Support                           [18 users, 2 teams]
│   └── Support - Tier 2              [3 users, 1 team]
└── Engineering                       [10 users, 1 team]
```

### Flat Format
```
[BusinessUnits] 8 active business units

| # | Name | Parent | Users | Teams | Status |
|---|------|--------|-------|-------|--------|
| 1 | Contoso Ltd | (root) | 45 | 3 | Active |
| 2 | Sales | Contoso Ltd | 12 | 2 | Active |
| 3 | Sales - North America | Sales | 5 | 1 | Active |
| ... |
```

## Structured Output Model

```csharp
internal sealed class ListBusinessUnitsResult
{
    [JsonPropertyName("totalCount")]
    public int TotalCount { get; set; }

    [JsonPropertyName("format")]
    public string Format { get; set; }

    [JsonPropertyName("businessUnits")]
    public List<BusinessUnitEntry> BusinessUnits { get; set; }
}

internal sealed class BusinessUnitEntry
{
    [JsonPropertyName("businessUnitId")]
    public string BusinessUnitId { get; set; }

    [JsonPropertyName("name")]
    public string Name { get; set; }

    [JsonPropertyName("parentBusinessUnitId")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public string ParentBusinessUnitId { get; set; }

    [JsonPropertyName("parentName")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public string ParentName { get; set; }

    [JsonPropertyName("isDisabled")]
    public bool IsDisabled { get; set; }

    [JsonPropertyName("depth")]
    public int Depth { get; set; }

    [JsonPropertyName("userCount")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public int? UserCount { get; set; }

    [JsonPropertyName("teamCount")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public int? TeamCount { get; set; }

    [JsonPropertyName("children")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public List<BusinessUnitEntry> Children { get; set; }
}
```
