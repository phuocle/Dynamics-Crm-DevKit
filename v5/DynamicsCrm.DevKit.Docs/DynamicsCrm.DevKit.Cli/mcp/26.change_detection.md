# Proposal: change_detection MCP Tool

## Priority: 13 (Advanced Features — Track Data Changes)

## Phase: 3 — Advanced Features

## Why This Tool Is Needed

Change tracking enables incremental data sync — instead of querying ALL records, only retrieve records that changed since the last sync. This uses the Dataverse `RetrieveEntityChanges` message or OData `$deltatoken` pattern. Critical for integration scenarios, data pipelines, and ETL processes.

### Current Pain

No way to do incremental sync via MCP. Must either:
1. Query all records every time (expensive for large datasets)
2. Use `modifiedon` filter (misses deletions, unreliable for high-volume)
3. Build custom change tracking outside MCP

### Proposed (change_detection)

```
entity_name: account
columns: name,revenue,primarycontactid
delta_token: (empty for first sync)
```

Returns changed records + a new `delta_token` for the next call.

---

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `entity_name` | string | Yes | — | Entity logical name (must have change tracking enabled). |
| `columns` | string | No | All | Comma-separated column names to track. |
| `delta_token` | string | No | — | Token from previous call. Empty = initial full sync. |
| `max_records` | int | No | 5000 | Max records per page (1–5000). |

---

## Dataverse API

```csharp
// Check entity has change tracking enabled
var metadata = GetEntityMetadata(entity_name);
if (!metadata.ChangeTrackingEnabled)
    throw new InvalidOperationException($"Change tracking is not enabled on '{entity_name}'. Enable it in entity settings.");

// Build OData request with prefer header
var entitySetName = ResolveEntitySetName(entity_name);
var selectClause = string.IsNullOrEmpty(columns) ? "" : $"$select={columns}";

string url;
if (string.IsNullOrEmpty(delta_token))
    url = $"{entitySetName}?{selectClause}"; // Initial sync
else
    url = $"{entitySetName}?{selectClause}&$deltatoken={delta_token}";

var headers = new Dictionary<string, string>
{
    ["Prefer"] = $"odata.track-changes,odata.maxpagesize={max_records}"
};

var response = _serviceClient.ExecuteWebRequest(HttpMethod.Get, url, null, headers);
// Parse @odata.deltaLink from response for next token
```

## Response Format

### Initial Sync
```
[ChangeDetection] Initial sync for account — 1,234 records
  Columns tracked: name, revenue, primarycontactid
  Delta token: 8015163!03/15/2026 10:30:00

Use this delta_token in the next call to get only changes.
```

### Incremental Sync
```
[ChangeDetection] Changes since last sync for account
  Created: 5 records
  Updated: 12 records
  Deleted: 2 records
  Delta token: 8015163!03/16/2026 14:00:00

| Change | ID | name | revenue |
|--------|----|------|---------|
| Created | a1b2... | New Corp | 50000 |
| Updated | c3d4... | Contoso | 1000000 |
| Deleted | e5f6... | — | — |
```

### Error — Change Tracking Not Enabled
```
[Error] Change tracking is not enabled on entity 'lead'.
Tip: Enable change tracking via entity settings or use update_entity metadata.
```

## Structured Output Model

```csharp
internal sealed class ChangeDetectionResult
{
    [JsonPropertyName("entityName")]
    public string EntityName { get; set; }

    [JsonPropertyName("isInitialSync")]
    public bool IsInitialSync { get; set; }

    [JsonPropertyName("deltaToken")]
    public string DeltaToken { get; set; }

    [JsonPropertyName("created")]
    public int Created { get; set; }

    [JsonPropertyName("updated")]
    public int Updated { get; set; }

    [JsonPropertyName("deleted")]
    public int Deleted { get; set; }

    [JsonPropertyName("totalChanges")]
    public int TotalChanges { get; set; }

    [JsonPropertyName("records")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public List<Dictionary<string, object>> Records { get; set; }
}
```

## Implementation Notes

- Entity MUST have `ChangeTrackingEnabled = true` (check with `get_entity_metadata`)
- First call (no delta_token) returns ALL records — this is the baseline
- Subsequent calls return only created/updated/deleted since last token
- Delta tokens expire after ~90 days (Dataverse retention policy)
- Deleted records return only the ID (no field values)
- The `@odata.deltaLink` in the response contains the new delta token
