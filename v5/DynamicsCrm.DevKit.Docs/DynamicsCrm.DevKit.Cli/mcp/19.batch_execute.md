# Proposal: batch_execute MCP Tool

## Priority: 6 (Core Operations — Bulk Performance)

## Phase: 1 — Core Operations

## Why This Tool Is Needed

Batch operations send up to 1000 requests in a single HTTP `$batch` call — critical for bulk imports, mass updates, and transactional operations. Without this tool, AI must call `upsert_record` or `delete_record` one at a time (1000 HTTP calls vs 1).

### Performance Comparison

| Scenario | Without Batch | With Batch |
|----------|--------------|------------|
| Create 100 contacts | ~100 HTTP calls (~60s) | 1 HTTP call (~3s) |
| Update 500 records | ~500 HTTP calls (~300s) | 1 HTTP call (~10s) |
| Delete 200 records | ~200 HTTP calls (~120s) | 1 HTTP call (~5s) |

### Changeset (Atomic Transactions)

When `use_changeset=true`, all mutating operations (POST/PATCH/DELETE) are wrapped in an atomic changeset — if one fails, ALL roll back. Essential for data consistency.

---

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `requests` | string | Yes | — | JSON array of request objects: `[{"method":"POST","url":"accounts","body":{...}}, ...]` |
| `use_changeset` | bool | No | false | Wrap mutating ops in an atomic changeset. Failure rolls back ALL. |

### Request Object Schema

```json
{
  "method": "GET|POST|PATCH|DELETE",
  "url": "accounts(guid)",
  "body": { "name": "Contoso" }
}
```

- `method`: HTTP method (required)
- `url`: Relative OData URL (required) — uses entitySetName (plural)
- `body`: Request body for POST/PATCH (optional)

## Dataverse API

```csharp
// Build multipart/mixed MIME batch request
var batchId = $"batch_{Guid.NewGuid():N}";
var changesetId = use_changeset ? $"changeset_{Guid.NewGuid():N}" : null;

var sb = new StringBuilder();

if (use_changeset)
    sb.AppendLine($"--{batchId}\r\nContent-Type: multipart/mixed; boundary={changesetId}\r\n");

int contentId = 1;
foreach (var req in requests)
{
    if (use_changeset && req.Method != "GET")
    {
        sb.AppendLine($"--{changesetId}");
        sb.AppendLine($"Content-Type: application/http\r\nContent-Transfer-Encoding: binary\r\nContent-ID: {contentId++}\r\n");
    }
    else
    {
        sb.AppendLine($"--{batchId}");
        sb.AppendLine("Content-Type: application/http\r\nContent-Transfer-Encoding: binary\r\n");
    }
    sb.AppendLine($"{req.Method} {req.Url} HTTP/1.1");
    // ... headers and body
}

// POST /$batch
var response = _serviceClient.ExecuteWebRequest(
    HttpMethod.Post, "$batch", sb.ToString(),
    new Dictionary<string, string> {
        ["Content-Type"] = $"multipart/mixed; boundary={batchId}"
    }
);
```

---

## Response Format

### Success
```
[BatchExecuted] 100/100 operations succeeded
  POST: 100 created
Changeset: no (individual operations)
```

### Success — With Changeset
```
[BatchExecuted] 50/50 operations succeeded (atomic changeset)
  PATCH: 50 updated
Changeset: yes — all-or-nothing
```

### Partial Failure
```
[BatchExecuted] 98/100 operations succeeded, 2 failed
  POST: 98 created, 2 failed
Failed operations:
  #23: 400 Bad Request — Required field 'name' is missing
  #67: 409 Conflict — Duplicate alternate key value
```

## Structured Output Model

```csharp
internal sealed class BatchExecuteResult
{
    [JsonPropertyName("totalRequests")]
    public int TotalRequests { get; set; }

    [JsonPropertyName("succeeded")]
    public int Succeeded { get; set; }

    [JsonPropertyName("failed")]
    public int Failed { get; set; }

    [JsonPropertyName("usedChangeset")]
    public bool UsedChangeset { get; set; }

    [JsonPropertyName("failures")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public List<BatchFailure> Failures { get; set; }
}

internal sealed class BatchFailure
{
    [JsonPropertyName("index")]
    public int Index { get; set; }

    [JsonPropertyName("statusCode")]
    public int StatusCode { get; set; }

    [JsonPropertyName("message")]
    public string Message { get; set; }
}
```

## Implementation Notes

- MIME multipart boundary must use `\r\n` (RFC 2046) — `\n` alone may fail
- Changeset wraps only mutating operations (POST/PATCH/DELETE); GET requests go outside
- Max 1000 requests per batch (Dataverse limit)
- For `$ref` operations (N:N associations), `@odata.id` in body must use **absolute URL**
- Parse multipart response to extract individual status codes per operation
