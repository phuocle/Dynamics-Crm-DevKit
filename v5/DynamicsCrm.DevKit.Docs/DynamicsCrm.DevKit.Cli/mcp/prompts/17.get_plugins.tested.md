> **Observation:** All 20 prompts mapped cleanly to `get_plugins` with a single MCP call each. The tool's filter parameters (entity_name, assembly_name, message_name, stage, mode, active_only) covered all prompt variations effectively. The one limitation discovered is the `assembly_name` contains-matching: when one assembly name is a prefix of another (e.g., "Dev.DevKit.Legacy.Server" vs "Dev.DevKit.Legacy.Server2"), the tool cannot return detail mode for the shorter-named assembly. This affected prompts 10 and 19, which returned list mode instead of type-level detail. A potential improvement would be to support exact-match or regex-based filtering. Average of 1.0 MCP calls per prompt demonstrates the tool's comprehensive filtering capabilities.
