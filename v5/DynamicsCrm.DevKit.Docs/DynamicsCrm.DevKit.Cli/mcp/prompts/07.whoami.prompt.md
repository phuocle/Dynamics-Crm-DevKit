# 07. whoami

> MCP Tool: `whoami`
> Environment: DEVKITV4 (dynamics-crm-devkit-v4.crm.dynamics.com)

---

## Prompts

1. "Who am I connected as?"
2. "What environment is this and what version of Dataverse is it running?"
3. "Check my security roles — I need to know if I have System Administrator"
4. "I need my user ID to filter FetchXML by owner. What is it?"
5. "Get me an access token so I can call the Web API directly from Postman"
6. "Before I start making changes, verify the connection to this org is working"
7. "What roles does my account have?"
8. "Show me the environment URL and org unique name for this Dataverse instance"
9. "I'm about to register a plugin. First, confirm which user and environment I'm working with"
10. "Is audit enabled on this environment? Also show me the org currency"
11. "Which user am I connected to right now? I need UserId, FullName, and Email"
12. "Show me the full environment details — OrganizationId, URL, version, friendly name"
13. "What security roles are assigned to my current user account?"
14. "I need the current user's ID so I can use it as an owner filter in FetchXML"
15. "Show me the BusinessUnitId for my user and the TenantId for this org"
16. "I'm getting permission errors. Can you check which security roles my user has?"
17. "What Dataverse version is this environment running? I need to check feature compatibility"
18. "Can you get my OAuth access token? I need it for a direct Web API call"
19. "Show me the base language, base currency, and fiscal settings for this org"
20. "Verify the connection is working and show me the org friendly name"
