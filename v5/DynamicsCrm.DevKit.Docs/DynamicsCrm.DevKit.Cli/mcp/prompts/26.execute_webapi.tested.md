#### Prompt 6: "Fetch the $metadata CSDL document — show me the first 50 lines"

**Step 1:** Call `mcp__devkit__execute_webapi` with `{method: "GET", url: "$metadata", max_response_lines: 50}`
**Step 1 Result:** ERROR — 415 UnsupportedMediaType: "A supported MIME type could not be found"

**Step 2:** Call `mcp__devkit__execute_webapi` with `{method: "GET", url: "$metadata", headers: "{\"Accept\":\"application/xml\"}", max_response_lines: 50}`
**Step 2 Result:** ERROR — Same 415 UnsupportedMediaType error

**Verdict:** ERROR
**Total MCP Calls:** 2
**Error:** $metadata returns CSDL XML but the tool's SDK-based HTTP handler forces JSON Accept headers internally
**Root Cause:** The tool uses Dataverse SDK HttpClient which sets Accept: application/json. The $metadata endpoint only serves application/xml (CSDL). Custom headers parameter doesn't override the SDK's internal Accept header
**Fix:** No fix applied — this is a known SDK limitation. The $metadata endpoint requires raw HTTP with XML Accept header, which the SDK-based tool cannot provide

#### Prompt 7: "Is updating a system form via execute_webapi blocked? I need to know the safety rules"

**Step 1 Result:** Yes, updating system forms is blocked. The tool hard-blocks PATCH/PUT/DELETE on systemforms to prevent malformed FormXML from breaking UI for all users. Use manage_form instead (auto-handles backup → validate XSD → update → publish)

**Total MCP Calls:** 0
