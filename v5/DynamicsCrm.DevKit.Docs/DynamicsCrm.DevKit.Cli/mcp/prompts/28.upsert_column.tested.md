#### Prompt 20: "What parameters are needed to create a new lookup column? I want to understand the options"

**Step 1:** This is an informational prompt. The answer is derived from the `upsert_column` tool description without needing an MCP call.

**Answer:** To create a lookup column, you need:
- `entity_name` (required): The entity to add the lookup to (e.g., 'account')
- `attribute_name` (required): Logical name with publisher prefix (e.g., 'new_managerid')
- `attribute_type` (required): Set to 'lookup' (or 'customer' for polymorphic account+contact)
- `display_name` (required): User-visible name (e.g., 'Manager')
- `lookup_target` (required for lookup): Target entity logical name (e.g., 'systemuser'). Comma-separated for polymorphic (e.g., 'account,contact,lead')
- `lookup_relationship_name` (optional): Custom relationship schema name. Auto-generated if omitted as `{prefix}_{target}_{entity}_{attribute}`
- `required_level` (optional): 'None' (default), 'Recommended', or 'Required'
- `description` (optional): Column description
- `solution_name` (optional): Add to a specific solution
- `auto_publish` (optional): Publish after creation (default: true)
