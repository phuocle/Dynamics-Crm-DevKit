# 06. search_records — NO DATA

> MCP Tool: `search_records`
> Environment: DEVKITV4 (dynamics-crm-devkit-v4.crm.dynamics.com)
> Status: Relevance Search not enabled — error "Expected non-empty Guid" caught and user-friendly message returned

---

## Root Cause

Relevance Search (Dataverse Search) is **not enabled** in the DEVKITV4 environment. The raw API error `"Expected non-empty Guid"` is unhelpful — the tool now catches this and returns a clear message with instructions.

## Error Patterns Caught

| Error Pattern | Meaning |
|---|---|
| `0x80060203` | Search not enabled error code |
| `SearchNotEnabled` | Explicit search disabled |
| `not provisioned` | Search index not provisioned |
| `not enabled` | Generic not enabled |
| `non-empty Guid` | S2S app user / search not configured |
| `Expected non-empty` | Variant of Guid error |

## How to Enable

1. Go to [Power Platform admin center](https://admin.powerplatform.microsoft.com)
2. Select environment → Settings → Product → Features
3. Turn ON **Dataverse Search** (formerly Relevance Search)
4. Wait for indexing to complete (minutes to hours)

## Known Limitation

S2S app users (Client Credentials) may not support Relevance Search even when enabled. Use an interactive user if needed.

## Workaround

Use `execute_fetchxml` with `like` operator filters instead of Relevance Search.
