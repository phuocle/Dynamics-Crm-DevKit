# Proposal: execute_bound_action MCP Tool

## Priority: 3 (Core Operations — Record-Scoped Actions)

## Phase: 1 — Core Operations

## Why This Tool Is Needed

Bound actions are scoped to a specific record instance. The URL pattern differs from unbound actions — requires `{entitySetName}({id})/Microsoft.Dynamics.CRM.{actionName}`. Using `execute_webapi` requires knowing the exact OData entity set name, the `Microsoft.Dynamics.CRM.` namespace prefix, and correct parameter formatting.

### Current Pain (execute_webapi)

```
method: POST
url: leads(a1b2c3d4-...)/Microsoft.Dynamics.CRM.QualifyLead
body: {"CreateAccount":true,"CreateContact":true,"CreateOpportunity":true,"Status":-1}
```

### Proposed (execute_bound_action)

```
entity_name: lead
record_id: a1b2c3d4-...
action_name: QualifyLead
parameters: {"CreateAccount":true,"CreateContact":true,"CreateOpportunity":true,"Status":-1}
```

Tool auto-resolves entity set name and adds namespace prefix.

---

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `entity_name` | string | Yes | — | Entity logical name (e.g., `lead`). Auto-resolves to entitySetName. |
| `record_id` | string | Yes | — | GUID of the record. |
| `action_name` | string | Yes | — | Action name WITHOUT `Microsoft.Dynamics.CRM.` prefix. |
| `parameters` | string | No | `{}` | JSON object of action parameters. |

---

## Dataverse API

```csharp
// Resolve entity name → entitySetName
var entitySetName = ResolveEntitySetName(entity_name); // lead → leads

// Bound action: POST /{entitySetName}({id})/Microsoft.Dynamics.CRM.{actionName}
var url = $"{entitySetName}({record_id})/Microsoft.Dynamics.CRM.{action_name}";

var response = _serviceClient.ExecuteWebRequest(
    HttpMethod.Post, url, body, headers
);
```

---

## Response Format

### Success
```
[BoundActionExecuted] QualifyLead on lead(a1b2c3d4-...)
Status: 200 OK
Response: { "CreatedEntities": [...] }
```

---

## Common Bound Actions

| Action | Entity | Purpose |
|--------|--------|---------|
| `QualifyLead` | lead | Qualify to contact + opportunity + account |
| `CalculatePrice` | quote/order/invoice | Recalculate pricing |
| `GenerateInvoiceFromOpportunity` | opportunity | Create invoice |
| `Reschedule` | appointment | Reschedule an appointment |
| `Cancel` | contract/salesorder | Cancel the record |
| Custom actions | any | Organization-defined custom actions |

## McpServerTool Attribute

```csharp
[McpServerTool(

    Title = "Execute a Dataverse action bound to a specific record",
    ReadOnly = false, Destructive = false)]
```
