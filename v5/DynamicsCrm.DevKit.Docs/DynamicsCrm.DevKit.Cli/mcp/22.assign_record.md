# Proposal: assign_record MCP Tool

## Priority: 9 (Data Management — Record Ownership)

## Phase: 2 — Data Management

## Why This Tool Is Needed

Assigning a record to a different user or team is a fundamental CRM operation, but OData requires a specific `PATCH` with `ownerid@odata.bind` using the correct entity set name (`systemusers` or `teams`). A guided tool handles this automatically and validates the target owner exists.

### Current Pain (execute_webapi)

```
method: PATCH
url: accounts(a1b2c3d4-...)
body: {"ownerid@odata.bind":"/systemusers(e5f6g7h8-...)"}
```

Must know: (1) `ownerid` is a polymorphic lookup (user or team), (2) entity set names are `systemusers` and `teams` (not `users`), (3) org-owned entities cannot be assigned.

### Proposed (assign_record)

```
entity_name: account
record_id: a1b2c3d4-...
owner_type: user
owner_id: e5f6g7h8-...
```

---

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `entity_name` | string | Yes | — | Entity logical name (e.g., `account`). |
| `record_id` | string | Yes | — | Record GUID to reassign. |
| `owner_type` | string | Yes | — | `user` or `team`. |
| `owner_id` | string | Yes | — | GUID of the new owner (systemuser or team). |

---

## Dataverse API

```csharp
// Validate entity supports ownership
var metadata = GetEntityMetadata(entity_name);
if (metadata.OwnershipType != OwnershipTypes.UserOwned)
    throw new InvalidOperationException($"Entity '{entity_name}' is organization-owned and cannot be assigned.");

var ownerEntitySet = owner_type.ToLower() == "team" ? "teams" : "systemusers";
var entitySetName = ResolveEntitySetName(entity_name);

var body = JsonSerializer.Serialize(new Dictionary<string, string>
{
    ["ownerid@odata.bind"] = $"/{ownerEntitySet}({owner_id})"
});

_serviceClient.ExecuteWebRequest(
    HttpMethod.Patch, $"{entitySetName}({record_id})", body, headers
);
```

---

## Response Format

### Success
```
[Assigned] account(a1b2c3d4) → user(e5f6g7h8)
  Owner: John Smith (john@contoso.com)
  Previous owner: Jane Doe (jane@contoso.com)
```

### Error — Org-Owned Entity
```
[Error] Cannot assign 'organization' records — entity is organization-owned.
Tip: Only user-owned entities (ownershipType=UserOwned) support assignment.
```

### Error — User Not Found
```
[Error] User e5f6g7h8 not found.
Tip: Use execute_fetchxml on systemuser to find valid user IDs.
```

## Structured Output Model

```csharp

{
    [JsonPropertyName("entityName")]
    public string EntityName { get; set; }

    public string RecordId { get; set; }

    [JsonPropertyName("ownerType")]
    public string OwnerType { get; set; }

    [JsonPropertyName("ownerId")]
    public string OwnerId { get; set; }

    [JsonPropertyName("ownerName")]
    public string OwnerName { get; set; }

    [JsonPropertyName("previousOwnerId")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public string PreviousOwnerId { get; set; }

    [JsonPropertyName("previousOwnerName")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public string PreviousOwnerName { get; set; }
}
```
