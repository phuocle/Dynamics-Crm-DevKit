# Proposal: associate_records MCP Tool

## Priority: 4 (Core Operations — N:N Relationship Management)

## Phase: 1 — Core Operations

## Why This Tool Is Needed

N:N relationships (roles↔privileges, contacts↔campaigns, users↔teams) require `$ref` POST/DELETE operations with absolute URLs. This is the most error-prone OData pattern — even experienced developers get the URL format wrong. A guided tool eliminates all URL construction.

### Current Pain (execute_webapi)

```
method: POST
url: roles(a1b2c3d4-...)/roleprivileges_association/$ref
body: {"@odata.id":"https://org.crm.dynamics.com/api/data/v9.2/privileges(e5f6g7h8-...)"}
headers: {"Content-Type":"application/json"}
```

**3 common mistakes**: (1) relative URL in `@odata.id` (must be absolute), (2) wrong navigation property name, (3) wrong entity set name in the body URL.

### Proposed (associate_records)

```
entity_name: role
record_id: a1b2c3d4-...
relationship_name: roleprivileges_association
related_entity_name: privilege
related_record_id: e5f6g7h8-...
```

Tool auto-constructs the absolute URL and correct `$ref` payload.

---

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `entity_name` | string | Yes | — | Source entity logical name (e.g., `role`). |
| `record_id` | string | Yes | — | Source record GUID. |
| `relationship_name` | string | Yes | — | Navigation property / relationship schema name. Use `get_entity_metadata` to find. |
| `related_entity_name` | string | Yes | — | Related entity logical name (e.g., `privilege`). |
| `related_record_id` | string | Yes | — | Related record GUID. |

---

## Dataverse API

```csharp
var sourceSetName = ResolveEntitySetName(entity_name);
var relatedSetName = ResolveEntitySetName(related_entity_name);
var baseUrl = _serviceClient.ConnectedOrgUriActual.AbsoluteUri.TrimEnd('/');
// Ensure we use the Web API base URL
var apiUrl = $"{baseUrl}/api/data/v9.2";

// POST /{sourceSetName}({id})/{relationship_name}/$ref
var url = $"{sourceSetName}({record_id})/{relationship_name}/$ref";
var body = JsonSerializer.Serialize(new
{
    @odata_id = $"{apiUrl}/{relatedSetName}({related_record_id})"
});
// Note: @odata.id key requires special serialization handling

_serviceClient.ExecuteWebRequest(HttpMethod.Post, url, body, headers);
```

---

## Response Format

### Success
```
[Associated] role(a1b2c3d4) ↔ privilege(e5f6g7h8) via roleprivileges_association
```

### Error — Already Associated
```
[Warning] Association already exists. Dataverse returns 204 for duplicate associations.
Tip: Use execute_fetchxml to verify current associations.
```

### Error — Wrong Relationship Name
```
[Error] Navigation property 'roleprivilege_association' not found on entity 'role'
Tip: Use get_entity_metadata to find correct N:N relationship names.
```
