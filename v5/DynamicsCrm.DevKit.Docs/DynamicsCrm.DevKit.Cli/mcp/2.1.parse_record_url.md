# Proposal: parse_record_url MCP Tool

## Priority: 2.5 (Utility — enables AI to extract entity + record ID from any Dynamics 365 URL/string)

## Why This Tool Is Needed

When users paste a Dynamics 365 URL or reference a record by pasting text containing a GUID, the AI must extract the **entity logical name** and **record ID** to call other tools (`get_record`, `get_plugin_trace_logs`, `execute_fetchxml`, etc.).

While AI can often regex a GUID from text, there are cases that require Dataverse access:
- URLs with `etc=N` (entity type code integer) instead of `etn=entityname` — need to resolve code to logical name
- Web API URLs with `entitySetName` — need to resolve entity set name to logical name
- Ambiguous URLs with multiple GUIDs (which one is the record ID?)

A dedicated tool ensures **reliable, consistent parsing** across all URL formats.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| input | string | Yes | — | The URL, GUID, or text to parse. Accepts any string containing a Dynamics 365 URL or a raw GUID. |

## Supported Input Formats

### Priority 1: Model-Driven App URLs (main.aspx)

| Pattern | Entity Source | GUID Source |
|---------|--------------|-------------|
| `main.aspx?etn={entity}&pagetype=entityrecord&id={guid}` | `etn` param | `id` param |
| `main.aspx?etc={code}&pagetype=entityrecord&id={guid}` | `etc` param → Dataverse lookup | `id` param |
| `main.aspx?appid={guid}&pagetype=entityrecord&etn={entity}&id={guid}` | `etn` param | `id` param |
| `main.aspx?etn={entity}&pagetype=entitylist&viewid={guid}` | `etn` param | `viewid` param (savedquery) |

### Priority 2: Dataverse Web API URLs

| Pattern | Entity Source | GUID Source |
|---------|--------------|-------------|
| `api/data/v9.X/{entitySetName}({guid})` | entitySetName → Dataverse lookup | parenthesized GUID |
| `api/data/v9.X/{entitySetName}({guid})?$select=...` | entitySetName | parenthesized GUID |
| `api/data/v9.X/{entitySetName}({guid})/{navProperty}` | entitySetName | parenthesized GUID |

### Priority 3: Power Platform Maker Portal URLs

| Pattern | Entity Source | GUID Source |
|---------|--------------|-------------|
| `make.powerapps.com/environments/{envGuid}/solutions/{solGuid}` | solution | path segment |
| `make.powerapps.com/environments/{envGuid}/flows/{flowGuid}` | workflow | path segment |
| `make.powerautomate.com/environments/{envGuid}/flows/{flowGuid}` | workflow | path segment |
| `make.powerautomate.com/environments/{envGuid}/flows/{flowGuid}/runs/{runGuid}` | flowsession | last path segment |

### Priority 4: Legacy / Specialized URLs

| Pattern | Entity Source | GUID Source |
|---------|--------------|-------------|
| `sfa/workflow/edit.aspx?id={guid}` | workflow | `id` param |
| `crmreports/viewer/viewer.aspx?id={guid}` | report | `id` param |
| `cs/dialog/rundialog.aspx?DialogId={guid}&EntityName={entity}&ObjectId={guid}` | `EntityName` param | `ObjectId` param |
| `tools/solution/edit.aspx?id={guid}` | solution | `id` param |

### Priority 5: Raw GUID

| Pattern | Entity Source | GUID Source |
|---------|--------------|-------------|
| `{guid}` or `{guid}` with braces/url-encoding | **unknown** — not determinable | the GUID itself |

### GUID Format Variants (all must be recognized)

| Format | Example |
|--------|---------|
| Raw | `91330924-802a-4b0d-a900-34fd9d790829` |
| Braces | `{91330924-802A-4B0D-A900-34FD9D790829}` |
| URL-encoded braces | `%7B91330924-802A-4B0D-A900-34FD9D790829%7D` |

## Dataverse Resolution (requires ServiceClient)

These cases require a Dataverse call to resolve entity info:

### 1. Entity Type Code (`etc`) → Logical Name

```csharp
var request = new RetrieveEntityRequest { EntityFilters = EntityFilters.Entity, MetadataId = Guid.Empty };
// Or query: EntityDefinitions?$filter=ObjectTypeCode eq {etc}&$select=LogicalName
```

### 2. Entity Set Name → Logical Name

```csharp
// Query: EntityDefinitions?$filter=EntitySetName eq '{entitySetName}'&$select=LogicalName
```

## Response Format (Compact)

### Success — entity name known

```
[ParsedUrl]
EntityName: plugintracelog
RecordId: 1d27ebbc-afca-4fd7-b1ef-7ab01646490d
Source: main.aspx (etn+id)
```

### Success — entity name unknown (raw GUID)

```
[ParsedUrl]
EntityName: (unknown)
RecordId: 1d27ebbc-afca-4fd7-b1ef-7ab01646490d
Source: raw GUID
Tip: Provide entity name or use a Dynamics 365 URL for automatic detection
```

### Success — multiple GUIDs found (e.g., Power Platform URLs)

```
[ParsedUrl]
EntityName: workflow
RecordId: abc-123-def
EnvironmentId: xyz-456-ghi
Source: make.powerautomate.com (flow URL)
```

### Error — no GUID found

```
[ParsedUrl] No GUID found in input
Tip: Paste a Dynamics 365 record URL or a raw GUID
```

## Tool Description for AI

```
Parse a Dynamics 365 / Power Platform URL or string to extract the entity logical name and record ID (GUID).

PARAMETERS:
- input: The URL, GUID, or text to parse. Accepts Dynamics 365 record URLs, Web API URLs, Power Platform maker portal URLs, or raw GUIDs.

RETURNS:
- EntityName: the entity logical name (e.g., 'account', 'plugintracelog', 'workflow')
- RecordId: the record GUID
- Source: what type of input was parsed (main.aspx, Web API, maker portal, raw GUID)
- EnvironmentId: (if present in maker portal URLs)

WHEN TO USE:
- When a user pastes a Dynamics 365 URL and you need to extract the entity name and record ID
- Before calling get_record, get_plugin_trace_logs, or other tools that need entity_name + record_id
- When a user references a record by URL instead of by entity name + GUID

SUPPORTED URL FORMATS:
- Model-driven app: main.aspx?etn=account&pagetype=entityrecord&id={guid}
- Model-driven app (legacy): main.aspx?etc=1&pagetype=entityrecord&id={guid}
- Web API: api/data/v9.2/accounts({guid})
- Power Apps maker: make.powerapps.com/environments/{env}/solutions/{sol}
- Power Automate: make.powerautomate.com/environments/{env}/flows/{flow}
- Workflow editor: sfa/workflow/edit.aspx?id={guid}
- Report viewer: crmreports/viewer/viewer.aspx?id={guid}
- Raw GUID: 1d27ebbc-afca-4fd7-b1ef-7ab01646490d

TIPS:
- If entity name is 'unknown' (raw GUID), ask the user for the entity name or URL
- For etc (entity type code) URLs, the tool resolves the code to entity logical name via Dataverse
- For Web API URLs, the tool resolves entitySetName to entity logical name via Dataverse
- GUID formats with braces {guid} or URL-encoded %7Bguid%7D are automatically handled
```

## Implementation Notes

- Pure string parsing for most URL formats — fast, no Dataverse call needed
- Only call Dataverse for `etc` code resolution and `entitySetName` resolution
- Use `Uri.TryCreate` + `HttpUtility.ParseQueryString` for URL parsing
- Use regex for Web API path parsing: `api/data/v\d+\.\d+/(\w+)\(([0-9a-f-]+)\)`
- Use regex for Power Platform path parsing: `environments/([0-9a-f-]+)/(flows|solutions)/([0-9a-f-]+)`
- GUID regex: `\{?[0-9a-fA-F]{8}-?[0-9a-fA-F]{4}-?[0-9a-fA-F]{4}-?[0-9a-fA-F]{4}-?[0-9a-fA-F]{12}\}?`
- URL-decode `%7B` / `%7D` before GUID extraction
- Return type: `string` (read-only, compact format)
