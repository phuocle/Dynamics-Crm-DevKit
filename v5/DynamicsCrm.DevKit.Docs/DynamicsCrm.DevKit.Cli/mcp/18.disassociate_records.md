# Proposal: disassociate_records MCP Tool

## Priority: 5 (Core Operations — Remove N:N Links)

## Phase: 1 — Core Operations

## Why This Tool Is Needed

Natural complement to `associate_records`. Removing N:N associations requires a `DELETE` request with a specific URL format that differs from the associate pattern. Destructive operation — requires confirmation.

### Current Pain (execute_webapi)

```
method: DELETE
url: roles(a1b2c3d4-...)/roleprivileges_association(e5f6g7h8-)
```

Must know: (1) the delete URL uses `({relatedId})` not `/$ref`, (2) for some relationships it's `/$ref?$id=...`.

### Proposed (disassociate_records)

```
entity_name: role
record_id: a1b2c3d4-...
relationship_name: roleprivileges_association
related_entity_name: privilege
related_record_id: e5f6g7h8-...
```

---

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `entity_name` | string | Yes | — | Source entity logical name. |
| `record_id` | string | Yes | — | Source record GUID. |
| `relationship_name` | string | Yes | — | Relationship/navigation property name. |
| `related_entity_name` | string | No | — | Related entity logical name (required for N:N). |
| `related_record_id` | string | No | — | Related record GUID (required for N:N). |

---

## Dataverse API

```csharp
var sourceSetName = ResolveEntitySetName(entity_name);

// For N:N: DELETE /{sourceSetName}({id})/{relationship_name}({relatedId})
// For 1:N single-valued: DELETE /{sourceSetName}({id})/{relationship_name}/$ref
string url;
if (!string.IsNullOrEmpty(related_record_id))
    url = $"{sourceSetName}({record_id})/{relationship_name}({related_record_id})/$ref";
else
    url = $"{sourceSetName}({record_id})/{relationship_name}/$ref";

_serviceClient.ExecuteWebRequest(HttpMethod.Delete, url, null, null);
```

---

## Response Format

### Success
```
[Disassociated] role(a1b2c3d4) ✕ privilege(e5f6g7h8) via roleprivileges_association
Note: This removes the link only — neither record is deleted.
```
