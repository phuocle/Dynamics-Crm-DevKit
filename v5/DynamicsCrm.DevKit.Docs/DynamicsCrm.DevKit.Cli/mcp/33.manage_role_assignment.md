# Proposal: manage_role_assignment MCP Tool

## Priority: 20 (Admin & Governance — Role Assignment)

## Phase: 4 — Admin & Governance

## Why This Tool Is Needed

Assigning/removing security roles to/from users and teams is a core admin operation. It requires N:N association via `systemuserroles_association` or `teamroles_association` with the correct navigation property names and absolute URL format. The existing `get_security_roles` tool is read-only — this tool adds the write capability.

### Current Pain (execute_webapi)

```
# Assign role to user
method: POST
url: systemusers(userId)/systemuserroles_association/$ref
body: {"@odata.id":"https://org.crm.dynamics.com/api/data/v9.2/roles(roleId)"}

# Remove role from user
method: DELETE
url: systemusers(userId)/systemuserroles_association(roleId)/$ref
```

Must know: (1) navigation property names differ for users vs teams, (2) `@odata.id` must be absolute URL, (3) role GUID must be the BU-specific copy (not root role).

### Proposed (manage_role_assignment)

```
action: assign
target_type: user
target_id: e5f6g7h8-...
role_name: Salesperson
```

Tool auto-resolves role GUID (including BU-specific copy), constructs absolute URL.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `action` | string | Yes | — | `assign` or `remove`. |
| `target_type` | string | Yes | — | `user` or `team`. |
| `target_id` | string | Yes | — | User/team GUID or email (for users). |
| `role_name` | string | No | — | Role display name. One of `role_name` or `role_id` required. |
| `role_id` | string | No | — | Role GUID. One of `role_name` or `role_id` required. |

## Dataverse API

```csharp
// Resolve target
var targetEntitySet = target_type == "team" ? "teams" : "systemusers";
var targetId = IsGuid(target_id) ? target_id : ResolveUserByEmail(target_id);

// Resolve role (get BU-specific copy)
Guid roleId;
if (!string.IsNullOrEmpty(role_name))
{
    // Get target's business unit
    var targetBU = GetTargetBusinessUnit(target_type, targetId);

    // Find role for that BU
    var roleFetch = $@"
    <fetch count='1'>
      <entity name='role'>
        <attribute name='roleid'/>
        <attribute name='name'/>
        <filter>
          <condition attribute='name' operator='eq' value='{role_name}'/>
          <condition attribute='businessunitid' operator='eq' value='{targetBU}'/>
        </filter>
      </entity>
    </fetch>";
    roleId = ExecuteAndGetId(roleFetch);
}
else
{
    roleId = Guid.Parse(role_id);
}

// Navigation property
var navProperty = target_type == "team"
    ? "teamroles_association"
    : "systemuserroles_association";

if (action == "assign")
{
    var baseUrl = GetWebApiBaseUrl();
    var body = $"{{\"@odata.id\":\"{baseUrl}/roles({roleId})\"}}";
    _serviceClient.ExecuteWebRequest(
        HttpMethod.Post,
        $"{targetEntitySet}({targetId})/{navProperty}/$ref",
        body, headers
    );
}
else // remove
{
    _serviceClient.ExecuteWebRequest(
        HttpMethod.Delete,
        $"{targetEntitySet}({targetId})/{navProperty}({roleId})/$ref",
        null, null
    );
}
```

## Response Format

### Assign
```
[RoleAssigned] Salesperson → user John Smith (john@contoso.com)
  Role ID: a1b2c3d4-...
  Business Unit: Sales
```

### Remove
```
[RoleRemoved] Salesperson ✕ user John Smith (john@contoso.com)
  Role ID: a1b2c3d4-...
  Note: User may still have this role via team membership.
```

### Error — Role Not Found
```
[Error] Role 'SalesPerson' not found in business unit 'Sales'.
Tip: Use get_security_roles to find exact role names. Role names are case-sensitive.
```

### Error — Already Assigned
```
[Warning] Role 'Salesperson' is already assigned to user John Smith.
```
