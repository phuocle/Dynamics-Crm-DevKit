## How to Use These Specs

Each spec file is a complete tool proposal compatible with the `/create-mcp-tool` command:

```
/create-mcp-tool "<tool name>" "DynamicsCrm.DevKit.Docs\DynamicsCrm.DevKit.Cli\mcp2\<N>.<filename>.md"
```

Each spec includes: Purpose, Parameters, Dataverse API, Response Format, McpServerTool Attribute, Tool Description, Implementation Notes, and the exact command to create.

## Example Prompts

> Natural-language prompts a user or AI agent might use that would trigger one or more of these tools.

| # | Prompt | Tool(s) Involved |
|---|--------|-----------------|
| 1 | "Add the new_project entity to the Sales Hub app navigation under the Service area" | `update_sitemap` |
| 2 | "Create a custom entity called 'new_project' with fields for name, budget, and a lookup to account, then add it to the main form" | `create_entity` → `create_attribute` → `manage_relationship` → `build_formxml` |
| 3 | "Who changed the revenue field on the Contoso account in the last 7 days?" | `get_audit_history` |
| 4 | "Show me all business rules on the opportunity entity and explain what they do" | `get_business_rules` |
| 5 | "Create a global option set called 'new_priority' with Low, Medium, High, Critical values and add it as a column to the case entity" | `manage_global_optionset` → `create_attribute` |
| 6 | "Export the 'DevKitCore' solution as unmanaged and save it to my local backups folder" | `manage_solution` |
| 7 | "Generate an ERD diagram showing relationships between account, contact, opportunity, and quote" | `generate_erd` |
| 8 | "Check if any Power Automate flows failed in the last 24 hours and show me the error details" | `get_flow_runs` |
| 9 | "Import the test-contacts.csv file into the contact table, mapping 'Company' column to 'parentcustomerid'" | `manage_data` |
| 10 | "Set the environment variable 'new_ApiEndpoint' to 'https://api.prod.contoso.com'" | `manage_environment_variables` |
