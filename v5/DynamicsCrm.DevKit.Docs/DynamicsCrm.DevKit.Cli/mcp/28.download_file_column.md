# Proposal: download_file_column MCP Tool

## Priority: 15 (Advanced Features — File Column Download)

## Phase: 3 — Advanced Features

## Why This Tool Is Needed

Downloading files from Dataverse File columns requires a `GET` request to a specific URL pattern with chunked download support for large files. The response is binary data that needs base64 encoding for transport via MCP. Natural complement to `upload_file_column`.

### Current Pain (execute_webapi)

```
method: GET
url: accounts(guid)/new_document/$value
```

Simple URL, but: (1) response is binary (can't display in text), (2) large files need range headers, (3) no file metadata (name, size, MIME) returned in the body.

### Proposed (download_file_column)

```
entity_name: account
record_id: a1b2c3d4-...
attribute_name: new_document
```

Returns file metadata + base64 content (or just metadata if `include_content=false`).

---

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `entity_name` | string | Yes | — | Entity logical name. |
| `record_id` | string | Yes | — | Record GUID. |
| `attribute_name` | string | Yes | — | File column logical name. |
| `include_content` | bool | No | true | Include base64 file content. Set false for metadata only. |

---

## Dataverse API

```csharp
var entitySetName = ResolveEntitySetName(entity_name);

// Get file metadata first
var metadataUrl = $"{entitySetName}({record_id})?$select={attribute_name}";
var metadataResponse = _serviceClient.ExecuteWebRequest(HttpMethod.Get, metadataUrl, null, null);

// Download file content
if (include_content)
{
    var downloadUrl = $"{entitySetName}({record_id})/{attribute_name}/$value";
    var headers = new Dictionary<string, string>
    {
        ["Accept"] = "application/octet-stream"
    };
    var fileBytes = _serviceClient.ExecuteWebRequest(HttpMethod.Get, downloadUrl, null, headers);
    // Parse Content-Disposition header for filename
    // Parse Content-Type for MIME type
    var base64Content = Convert.ToBase64String(fileBytes);
}
```

---

## Response Format

### Success — With Content
```
[FileDownloaded] account(a1b2c3d4).new_document
  File: report.pdf
  Size: 245 KB
  MIME: application/pdf
  Content: (base64 encoded, 327,680 chars)
```

### Success — Metadata Only
```
[FileInfo] account(a1b2c3d4).new_document
  File: report.pdf
  Size: 245 KB
  MIME: application/pdf
  Content: (not included — set include_content=true to download)
```

### Error — No File
```
[Info] No file stored in account(a1b2c3d4).new_document
Tip: Use upload_file_column to upload a file first.
```

## Structured Output Model

```csharp
internal sealed class DownloadFileResult
{
    [JsonPropertyName("entityName")]
    public string EntityName { get; set; }

    [JsonPropertyName("recordId")]
    public string RecordId { get; set; }

    [JsonPropertyName("attributeName")]
    public string AttributeName { get; set; }

    [JsonPropertyName("fileName")]
    public string FileName { get; set; }

    [JsonPropertyName("fileSize")]
    public long FileSize { get; set; }

    [JsonPropertyName("mimeType")]
    public string MimeType { get; set; }

    [JsonPropertyName("contentBase64")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public string ContentBase64 { get; set; }

    [JsonPropertyName("hasContent")]
    public bool HasContent { get; set; }
}
```
