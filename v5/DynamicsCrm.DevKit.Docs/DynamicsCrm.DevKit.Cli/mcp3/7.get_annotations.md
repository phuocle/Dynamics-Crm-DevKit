# Proposal: get_annotations MCP Tool

## Priority: 7 (Data Management — Read Notes/Attachments)

## Phase: 2 — Data Management

## Why This Tool Is Needed

Notes (annotations) are one of the most-used features in Dynamics 365 — every entity with `has_notes=true` can have notes with file attachments. Currently, retrieving notes requires writing FetchXML with base64 `documentbody` handling, MIME type mapping, and join to the parent record. A dedicated tool simplifies this to a single call.

### Current Pain (execute_fetchxml)

```xml
<fetch>
  <entity name="annotation">
    <attribute name="subject"/>
    <attribute name="notetext"/>
    <attribute name="filename"/>
    <attribute name="mimetype"/>
    <attribute name="filesize"/>
    <attribute name="createdon"/>
    <attribute name="modifiedby"/>
    <filter>
      <condition attribute="objectid" operator="eq" value="a1b2c3d4-..." />
    </filter>
    <order attribute="createdon" descending="true"/>
  </entity>
</fetch>
```

Must know: (1) entity is `annotation` not `note`, (2) parent link is `objectid`, (3) `documentbody` is base64, (4) `objecttypecode` for filtering by parent entity type.

### Proposed (get_annotations)

```
entity_name: account
record_id: a1b2c3d4-...
include_body: false
max_records: 20
```

---

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `entity_name` | string | Yes | — | Parent entity logical name (e.g., `account`). |
| `record_id` | string | Yes | — | Parent record GUID. |
| `include_body` | bool | No | false | Include base64 `documentbody` (attachments). Default false to save tokens. |
| `max_records` | int | No | 50 | Max annotations to return (1–500). |
| `subject_filter` | string | No | — | Filter by subject (contains match). |

---

## Dataverse API

```csharp
var fetchXml = $@"
<fetch count='{max_records}'>
  <entity name='annotation'>
    <attribute name='subject'/>
    <attribute name='notetext'/>
    <attribute name='filename'/>
    <attribute name='mimetype'/>
    <attribute name='filesize'/>
    <attribute name='createdon'/>
    <attribute name='modifiedby'/>
    {(include_body ? "<attribute name='documentbody'/>" : "")}
    <filter>
      <condition attribute='objectid' operator='eq' value='{record_id}'/>
      <condition attribute='objecttypecode' operator='eq' value='{objectTypeCode}'/>
      {(subject_filter != null ? $"<condition attribute='subject' operator='like' value='%{subject_filter}%'/>" : "")}
    </filter>
    <order attribute='createdon' descending='true'/>
  </entity>
</fetch>";
```

## Response Format

### Success
```
[Annotations] 3 notes found for account(a1b2c3d4)

| # | Subject | Text | File | Size | Created | Modified By |
|---|---------|------|------|------|---------|-------------|
| 1 | Follow-up call | Called customer... | — | — | 2026-03-15 | John Smith |
| 2 | Contract | See attached | contract.pdf | 245 KB | 2026-03-10 | Jane Doe |
| 3 | Meeting notes | Discussed Q2... | — | — | 2026-03-01 | John Smith |
```

### No Notes
```
[Annotations] No notes found for account(a1b2c3d4)
Tip: Ensure the entity has notes enabled (has_notes=true in entity definition).
```

## Structured Output Model

```csharp
internal sealed class GetAnnotationsResult
{
    [JsonPropertyName("totalCount")]
    public int TotalCount { get; set; }

    [JsonPropertyName("entityName")]
    public string EntityName { get; set; }

    [JsonPropertyName("recordId")]
    public string RecordId { get; set; }

    [JsonPropertyName("annotations")]
    public List<AnnotationEntry> Annotations { get; set; }
}

internal sealed class AnnotationEntry
{
    [JsonPropertyName("annotationId")]
    public string AnnotationId { get; set; }

    [JsonPropertyName("subject")]
    public string Subject { get; set; }

    [JsonPropertyName("noteText")]
    public string NoteText { get; set; }

    [JsonPropertyName("fileName")]
    public string FileName { get; set; }

    [JsonPropertyName("mimeType")]
    public string MimeType { get; set; }

    [JsonPropertyName("fileSize")]
    public int? FileSize { get; set; }

    [JsonPropertyName("createdOn")]
    public string CreatedOn { get; set; }

    [JsonPropertyName("modifiedBy")]
    public string ModifiedBy { get; set; }

    [JsonPropertyName("documentBody")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public string DocumentBody { get; set; }
}
```
