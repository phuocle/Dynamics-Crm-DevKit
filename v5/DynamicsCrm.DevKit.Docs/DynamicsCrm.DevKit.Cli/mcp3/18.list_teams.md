# Proposal: list_teams MCP Tool

## Priority: 18 (Admin & Governance — Team Management)

## Phase: 4 — Admin & Governance

## Why This Tool Is Needed

Teams in Dataverse control record ownership and sharing. Querying teams requires knowing the `team` entity attributes, team types (Owner, Access, AAD Security Group, AAD Office Group), and how to join team members. A dedicated tool simplifies common team queries.

### Current Pain (execute_fetchxml)

```xml
<fetch>
  <entity name="team">
    <attribute name="name"/>
    <attribute name="teamtype"/>
    <attribute name="businessunitid"/>
    <attribute name="isdefault"/>
    <filter>
      <condition attribute="teamtype" operator="eq" value="0"/>
    </filter>
    <link-entity name="teammembership" from="teamid" to="teamid" link-type="outer">
      <link-entity name="systemuser" from="systemuserid" to="systemuserid">
        <attribute name="fullname"/>
      </link-entity>
    </link-entity>
  </entity>
</fetch>
```

Must know: (1) team types are integers (0=Owner, 1=Access, 2=AADSecurityGroup, 3=AADOfficeGroup), (2) `teammembership` is N:N intersect, (3) default team per BU can't be deleted.

### Proposed (list_teams)

```
team_type: owner
include_members: true
business_unit: Sales
```

---

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `team_type` | string | No | `all` | `owner`, `access`, `aad_security`, `aad_office`, `all`. |
| `name_filter` | string | No | — | Filter by team name (contains match). |
| `business_unit` | string | No | — | Filter by business unit name or GUID. |
| `include_members` | bool | No | false | Include team member list. |
| `max_records` | int | No | 100 | Max teams to return (1–500). |

---

## Dataverse API

```csharp
var teamTypeValue = team_type switch
{
    "owner" => "0",
    "access" => "1",
    "aad_security" => "2",
    "aad_office" => "3",
    _ => null
};

var fetchXml = $@"
<fetch count='{max_records}'>
  <entity name='team'>
    <attribute name='teamid'/>
    <attribute name='name'/>
    <attribute name='teamtype'/>
    <attribute name='businessunitid'/>
    <attribute name='isdefault'/>
    <attribute name='administratorid'/>
    <filter>
      {(teamTypeValue != null ? $"<condition attribute='teamtype' operator='eq' value='{teamTypeValue}'/>" : "")}
      {(name_filter != null ? $"<condition attribute='name' operator='like' value='%{name_filter}%'/>" : "")}
    </filter>
    <order attribute='name'/>
  </entity>
</fetch>";
```

## Structured Output Model

```csharp
internal sealed class ListTeamsResult
{
    [JsonPropertyName("totalCount")]
    public int TotalCount { get; set; }

    [JsonPropertyName("teamType")]
    public string TeamType { get; set; }

    [JsonPropertyName("teams")]
    public List<TeamEntry> Teams { get; set; }
}

internal sealed class TeamEntry
{
    [JsonPropertyName("teamId")]
    public string TeamId { get; set; }

    [JsonPropertyName("name")]
    public string Name { get; set; }

    [JsonPropertyName("teamType")]
    public string TeamType { get; set; }

    [JsonPropertyName("businessUnit")]
    public string BusinessUnit { get; set; }

    [JsonPropertyName("isDefault")]
    public bool IsDefault { get; set; }

    [JsonPropertyName("memberCount")]
    public int MemberCount { get; set; }

    [JsonPropertyName("members")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public List<TeamMember> Members { get; set; }
}

internal sealed class TeamMember
{
    [JsonPropertyName("userId")]
    public string UserId { get; set; }

    [JsonPropertyName("fullName")]
    public string FullName { get; set; }

    [JsonPropertyName("email")]
    public string Email { get; set; }
}
```

## Team Type Reference

| Value | Type | Description |
|-------|------|-------------|
| 0 | Owner | Can own records. Created manually. |
| 1 | Access | Cannot own records. Auto-created for sharing. |
| 2 | AAD Security Group | Synced from Azure AD security group. |
| 3 | AAD Office Group | Synced from Microsoft 365 group. |
