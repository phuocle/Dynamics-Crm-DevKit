# Proposal: list_users MCP Tool

## Priority: 17 (Admin & Governance — User Management)

## Phase: 4 — Admin & Governance

## Why This Tool Is Needed

Querying system users requires knowing the `systemuser` entity name, its specific attributes (`fullname`, `internalemailaddress`, `isdisabled`, `businessunitid`), and the correct FetchXML for filtering by business unit, security role, or enabled status. A dedicated tool provides a clean interface for the most common user queries.

### Current Pain (execute_fetchxml)

```xml
<fetch>
  <entity name="systemuser">
    <attribute name="fullname"/>
    <attribute name="internalemailaddress"/>
    <attribute name="isdisabled"/>
    <attribute name="businessunitid"/>
    <filter>
      <condition attribute="isdisabled" operator="eq" value="0"/>
      <condition attribute="accessmode" operator="ne" value="3"/>
    </filter>
    <order attribute="fullname"/>
  </entity>
</fetch>
```

Must know: (1) entity is `systemuser` not `user`, (2) `accessmode=3` is non-interactive/system, (3) `isdisabled` is boolean but stored as int, (4) email is `internalemailaddress` not `emailaddress1`.

### Proposed (list_users)

```
filter: active
business_unit: Sales
include_roles: true
```

---

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `filter` | string | No | `active` | `active`, `disabled`, `all`. |
| `name_filter` | string | No | — | Filter by name (contains match). |
| `business_unit` | string | No | — | Filter by business unit name or GUID. |
| `include_roles` | bool | No | false | Include security roles for each user. |
| `include_teams` | bool | No | false | Include team memberships for each user. |
| `max_records` | int | No | 100 | Max users to return (1–500). |

---

## Dataverse API

```csharp
var fetchXml = $@"
<fetch count='{max_records}'>
  <entity name='systemuser'>
    <attribute name='systemuserid'/>
    <attribute name='fullname'/>
    <attribute name='internalemailaddress'/>
    <attribute name='isdisabled'/>
    <attribute name='businessunitid'/>
    <attribute name='accessmode'/>
    <attribute name='createdon'/>
    <filter>
      {(filter == "active" ? "<condition attribute='isdisabled' operator='eq' value='0'/>" : "")}
      {(filter == "disabled" ? "<condition attribute='isdisabled' operator='eq' value='1'/>" : "")}
      <condition attribute='accessmode' operator='ne' value='3'/>
      {(name_filter != null ? $"<condition attribute='fullname' operator='like' value='%{name_filter}%'/>" : "")}
    </filter>
    <order attribute='fullname'/>
  </entity>
</fetch>";

// If include_roles, also query systemuserroles_association
// If include_teams, also query teammembership_association
```

## Response Format

### Success
```
[Users] 45 active users found

| # | Name | Email | Business Unit | Status | Roles |
|---|------|-------|---------------|--------|-------|
| 1 | Jane Doe | jane@contoso.com | Sales | Active | Salesperson, Custom Role |
| 2 | John Smith | john@contoso.com | Support | Active | CSR Manager |
| 3 | Admin User | admin@contoso.com | Root BU | Active | System Administrator |
```

### No Users Found
```
[Users] No users found matching filter: name='xyz', status=active
```

## Structured Output Model

```csharp
internal sealed class ListUsersResult
{
    [JsonPropertyName("totalCount")]
    public int TotalCount { get; set; }

    [JsonPropertyName("filter")]
    public string Filter { get; set; }

    [JsonPropertyName("users")]
    public List<UserEntry> Users { get; set; }
}

internal sealed class UserEntry
{
    [JsonPropertyName("userId")]
    public string UserId { get; set; }

    [JsonPropertyName("fullName")]
    public string FullName { get; set; }

    [JsonPropertyName("email")]
    public string Email { get; set; }

    [JsonPropertyName("businessUnit")]
    public string BusinessUnit { get; set; }

    [JsonPropertyName("isDisabled")]
    public bool IsDisabled { get; set; }

    [JsonPropertyName("roles")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public List<string> Roles { get; set; }

    [JsonPropertyName("teams")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public List<string> Teams { get; set; }
}
```
