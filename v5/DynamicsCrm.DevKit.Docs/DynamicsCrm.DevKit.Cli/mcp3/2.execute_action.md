# Proposal: execute_action MCP Tool

## Priority: 2 (Core Operations — Unbound Dataverse Actions)

## Phase: 1 — Core Operations

## Why This Tool Is Needed

Dataverse actions (WinOpportunity, SendEmail, AddToQueue, custom process actions) are the primary way to trigger business logic. Currently, AI must use `execute_webapi` with manual URL construction and payload formatting — error-prone and verbose.

### Current Pain (execute_webapi)

```
method: POST
url: WinOpportunity
body: {"Status":3,"OpportunityClose":{"@odata.type":"Microsoft.Dynamics.CRM.opportunityclose","subject":"Won via AI","opportunityid@odata.bind":"opportunities(a1b2c3d4-...)"}}
```

AI must know: (1) exact action name casing, (2) full `@odata.type` annotation, (3) `@odata.bind` syntax for entity references, (4) which parameters are required.

### Proposed (execute_action)

```
action_name: WinOpportunity
parameters: {"Status":3,"OpportunityClose":{"subject":"Won via AI","opportunityid":"a1b2c3d4-..."}}
```

Tool auto-adds `@odata.type` and `@odata.bind` where possible.

### Competitor Analysis

| Server | Unbound Actions | Bound Actions | Notes |
|--------|----------------|---------------|-------|
| **DevKit CLI** | No (only raw `execute_webapi`) | No | — |
| **codeurali** | Yes (`dataverse_execute_action`) | Yes (`dataverse_execute_bound_action`) | Full support |

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `action_name` | string | Yes | — | Action logical name (e.g., `WinOpportunity`, `SendEmail`, `QualifyLead`). |
| `parameters` | string | No | `{}` | JSON object of action parameters. |

---

## Dataverse API

```csharp
// Unbound action: POST /{actionName}
var url = action_name.Trim();
var body = string.IsNullOrWhiteSpace(parameters) ? "{}" : parameters;

var response = _serviceClient.ExecuteWebRequest(
    HttpMethod.Post, url, body,
    new Dictionary<string, string> { ["Content-Type"] = "application/json" }
);
```

---

## Response Format

### Success
```
[ActionExecuted] WinOpportunity
Status: 204 No Content
```

### Success — With Response Body
```
[ActionExecuted] QualifyLead
Status: 200 OK
Response:
  CreatedEntities: [{ entityType: "contact", id: "..." }, { entityType: "opportunity", id: "..." }]
```

### Error
```
[Error] Action 'WinOpportnity' not found (HTTP 404)
Tip: Check the action name spelling. Use get_messages to discover available actions for an entity.
```

## Common Actions

| Action | Purpose | Bound? |
|--------|---------|--------|
| `WinOpportunity` | Close opportunity as won | Unbound |
| `LoseOpportunity` | Close opportunity as lost | Unbound |
| `QualifyLead` | Qualify lead → contact + opportunity | Unbound |
| `SendEmail` | Send email activity | Unbound |
| `AddToQueue` | Add record to a queue | Unbound |
| `RouteTo` | Route record to user/team | Unbound |
| `Merge` | Merge two records | Unbound |
| `CalculateRollupField` | Recalculate rollup field | Bound (function) |
| `PublishXml` | Publish specific customizations | Unbound |
