# Proposal: list_workflows MCP Tool

## Priority: 21 (Admin & Governance — Process Management)

## Phase: 4 — Admin & Governance

## Why This Tool Is Needed

Workflows, Power Automate flows (modern flows), and business rules are stored in the `workflow` and `process` entities. Understanding what automation exists for an entity is critical before making schema changes, debugging unexpected behavior, or auditing business logic. A dedicated tool consolidates all process types into one query.

### Current Pain (execute_fetchxml)

```xml
<fetch>
  <entity name="workflow">
    <attribute name="name"/>
    <attribute name="category"/>
    <attribute name="primaryentity"/>
    <attribute name="statecode"/>
    <attribute name="type"/>
    <filter>
      <condition attribute="primaryentity" operator="eq" value="account"/>
      <condition attribute="statecode" operator="eq" value="1"/>
      <condition attribute="type" operator="eq" value="1"/>
    </filter>
  </entity>
</fetch>
```

Must know: (1) `category` values (0=Workflow, 1=Dialog, 2=BusinessRule, 3=Action, 4=BPF, 5=ModernFlow, 6=DesktopFlow), (2) `type` values (1=Definition, 2=Activation, 3=Template), (3) `statecode` (0=Draft, 1=Activated), (4) `primaryentity` uses logical name.

### Proposed (list_workflows)

```
entity_name: account
category: all
status: active
```

---

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `entity_name` | string | No | — | Filter by primary entity logical name. Empty = all entities. |
| `category` | string | No | `all` | `workflow`, `business_rule`, `action`, `bpf`, `modern_flow`, `desktop_flow`, `dialog`, `all`. |
| `status` | string | No | `active` | `active`, `draft`, `all`. |
| `name_filter` | string | No | — | Filter by name (contains match). |
| `max_records` | int | No | 100 | Max results (1–500). |

## Dataverse API

```csharp
var categoryValue = category switch
{
    "workflow" => "0",
    "dialog" => "1",
    "business_rule" => "2",
    "action" => "3",
    "bpf" => "4",
    "modern_flow" => "5",
    "desktop_flow" => "6",
    _ => null
};

var stateValue = status switch
{
    "active" => "1",
    "draft" => "0",
    _ => null
};

var fetchXml = $@"
<fetch count='{max_records}'>
  <entity name='workflow'>
    <attribute name='workflowid'/>
    <attribute name='name'/>
    <attribute name='category'/>
    <attribute name='primaryentity'/>
    <attribute name='statecode'/>
    <attribute name='type'/>
    <attribute name='createdon'/>
    <attribute name='modifiedon'/>
    <attribute name='createdby'/>
    <attribute name='mode'/>
    <attribute name='triggeroncreate'/>
    <attribute name='triggeronupdateattributelist'/>
    <attribute name='triggerondelete'/>
    <filter>
      <condition attribute='type' operator='eq' value='1'/>
      {(categoryValue != null ? $"<condition attribute='category' operator='eq' value='{categoryValue}'/>" : "")}
      {(stateValue != null ? $"<condition attribute='statecode' operator='eq' value='{stateValue}'/>" : "")}
      {(entity_name != null ? $"<condition attribute='primaryentity' operator='eq' value='{entity_name}'/>" : "")}
      {(name_filter != null ? $"<condition attribute='name' operator='like' value='%{name_filter}%'/>" : "")}
    </filter>
    <order attribute='name'/>
  </entity>
</fetch>";
```

## Structured Output Model

```csharp
internal sealed class ListWorkflowsResult
{
    [JsonPropertyName("totalCount")]
    public int TotalCount { get; set; }

    [JsonPropertyName("entityName")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public string EntityName { get; set; }

    [JsonPropertyName("categorySummary")]
    public Dictionary<string, int> CategorySummary { get; set; }

    [JsonPropertyName("workflows")]
    public List<WorkflowEntry> Workflows { get; set; }
}

internal sealed class WorkflowEntry
{
    [JsonPropertyName("workflowId")]
    public string WorkflowId { get; set; }

    [JsonPropertyName("name")]
    public string Name { get; set; }

    [JsonPropertyName("category")]
    public string Category { get; set; }

    [JsonPropertyName("primaryEntity")]
    public string PrimaryEntity { get; set; }

    [JsonPropertyName("status")]
    public string Status { get; set; }

    [JsonPropertyName("mode")]
    public string Mode { get; set; }

    [JsonPropertyName("triggerOnCreate")]
    public bool TriggerOnCreate { get; set; }

    [JsonPropertyName("triggerOnUpdate")]
    public bool TriggerOnUpdate { get; set; }

    [JsonPropertyName("triggerOnDelete")]
    public bool TriggerOnDelete { get; set; }

    [JsonPropertyName("updateAttributes")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public string UpdateAttributes { get; set; }

    [JsonPropertyName("modifiedOn")]
    public string ModifiedOn { get; set; }

    [JsonPropertyName("createdBy")]
    public string CreatedBy { get; set; }
}
```

## Category Reference

| Value | Category | Description |
|-------|----------|-------------|
| 0 | Workflow | Classic background/real-time workflow |
| 1 | Dialog | Interactive dialog (deprecated) |
| 2 | Business Rule | Client-side or server-side rules |
| 3 | Action | Custom action (global or entity-bound) |
| 4 | BPF | Business Process Flow |
| 5 | Modern Flow | Power Automate cloud flow |
| 6 | Desktop Flow | Power Automate desktop flow (RPA) |
