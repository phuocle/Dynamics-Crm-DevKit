# Proposal: create_annotation MCP Tool

## Priority: 8 (Data Management — Create Notes/Attachments)

## Phase: 2 — Data Management

## Why This Tool Is Needed

Creating notes with file attachments requires constructing a JSON payload with base64-encoded `documentbody`, correct `objectid@odata.bind` syntax, `objecttypecode`, and MIME type detection. A guided tool handles all of this automatically — the AI just provides parent record, text, and optional file content.

### Current Pain (execute_webapi / upsert_record)

```json
{
  "subject": "Meeting notes",
  "notetext": "Discussed Q2 targets",
  "objectid_account@odata.bind": "/accounts(a1b2c3d4-...)",
  "filename": "notes.pdf",
  "mimetype": "application/pdf",
  "documentbody": "JVBERi0xLjQK..."
}
```

Must know: (1) `objectid_ENTITY@odata.bind` format varies by parent entity, (2) `documentbody` must be base64, (3) MIME type must match file extension, (4) `objecttypecode` is needed for some operations.

### Proposed (create_annotation)

```
entity_name: account
record_id: a1b2c3d4-...
subject: Meeting notes
note_text: Discussed Q2 targets
file_name: notes.pdf
file_content_base64: JVBERi0xLjQK...
```

Tool auto-resolves `@odata.bind`, detects MIME type from extension, validates base64.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `entity_name` | string | Yes | — | Parent entity logical name (e.g., `account`). |
| `record_id` | string | Yes | — | Parent record GUID. |
| `subject` | string | No | — | Note subject line. |
| `note_text` | string | No | — | Note body text (plain text or HTML). |
| `file_name` | string | No | — | Attachment file name with extension (e.g., `report.pdf`). |
| `file_content_base64` | string | No | — | Base64-encoded file content. Required if `file_name` is provided. |

## Dataverse API

```csharp
var entitySetName = ResolveEntitySetName(entity_name);

var payload = new Dictionary<string, object>
{
    [$"objectid_{entity_name}@odata.bind"] = $"/{entitySetName}({record_id})"
};

if (!string.IsNullOrEmpty(subject))
    payload["subject"] = subject;

if (!string.IsNullOrEmpty(note_text))
    payload["notetext"] = note_text;

if (!string.IsNullOrEmpty(file_name))
{
    payload["filename"] = file_name;
    payload["mimetype"] = ResolveMimeType(file_name); // .pdf → application/pdf
    payload["documentbody"] = file_content_base64;
}

var body = JsonSerializer.Serialize(payload);
var response = _serviceClient.ExecuteWebRequest(
    HttpMethod.Post, "annotations", body, headers
);
```

---

## Response Format

### Success — Text Only
```
[AnnotationCreated] Note added to account(a1b2c3d4)
  ID: f1e2d3c4-...
  Subject: Meeting notes
  Text: Discussed Q2 targets (22 chars)
```

### Success — With Attachment
```
[AnnotationCreated] Note with attachment added to account(a1b2c3d4)
  ID: f1e2d3c4-...
  Subject: Contract
  File: contract.pdf (245 KB, application/pdf)
```

### Error
```
[Error] Parent record not found: account(a1b2c3d4)
Tip: Verify the record exists with get_record.
```

## Structured Output Model

```csharp
internal sealed class CreateAnnotationResult
{
    [JsonPropertyName("annotationId")]
    public string AnnotationId { get; set; }

    [JsonPropertyName("entityName")]
    public string EntityName { get; set; }

    [JsonPropertyName("recordId")]
    public string RecordId { get; set; }

    [JsonPropertyName("subject")]
    public string Subject { get; set; }

    [JsonPropertyName("fileName")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public string FileName { get; set; }

    [JsonPropertyName("fileSize")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public int? FileSize { get; set; }

    [JsonPropertyName("mimeType")]
    [JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]
    public string MimeType { get; set; }
}
```

## MIME Type Resolution

| Extension | MIME Type |
|-----------|----------|
| `.pdf` | `application/pdf` |
| `.docx` | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` |
| `.xlsx` | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` |
| `.png` | `image/png` |
| `.jpg` / `.jpeg` | `image/jpeg` |
| `.txt` | `text/plain` |
| `.csv` | `text/csv` |
| `.zip` | `application/zip` |
| Other | `application/octet-stream` |
