# Proposal: upload_file_column MCP Tool

## Priority: 14 (Advanced Features — File Column Upload)

## Phase: 3 — Advanced Features

## Why This Tool Is Needed

Dataverse File columns (introduced in 2020) store files directly on records without using the annotation (notes) entity. Uploading requires a chunked upload protocol — `InitializeFileBlocksUpload` → `UploadBlock` (1 or more) → `CommitFileBlocksUpload`. This 3-step process is complex and error-prone via raw `execute_webapi`.

### Current Pain (execute_webapi)

```
# Step 1: Initialize
POST /accounts(guid)/new_document/InitializeFileBlocksUpload
Body: {}

# Step 2: Upload chunk(s)
PATCH /accounts(guid)/new_document/UploadBlock
Headers: {"x-ms-file-name":"doc.pdf","Content-Type":"application/octet-stream"}
Body: <binary chunk>

# Step 3: Commit
POST /accounts(guid)/new_document/CommitFileBlocksUpload
Body: {"FileName":"doc.pdf","MimeType":"application/pdf","BlockList":["block1"]}
```

3 separate calls with binary handling, chunking logic, block IDs, and MIME detection.

### Proposed (upload_file_column)

```
entity_name: account
record_id: a1b2c3d4-...
attribute_name: new_document
file_name: report.pdf
file_content_base64: JVBERi0xLjQK...
```

Tool handles the full 3-step protocol automatically.

## Dataverse API

```csharp
var entitySetName = ResolveEntitySetName(entity_name);
var bytes = Convert.FromBase64String(file_content_base64);
var mimeType = ResolveMimeType(file_name);

// Step 1: Initialize
var initUrl = $"{entitySetName}({record_id})/{attribute_name}";
var initResponse = _serviceClient.ExecuteWebRequest(
    HttpMethod.Post, $"{initUrl}/InitializeFileBlocksUpload", "{}", headers
);
var fileContinuationToken = ParseToken(initResponse);

// Step 2: Upload in chunks (4MB each)
var blockIds = new List<string>();
var chunkSize = 4 * 1024 * 1024;
for (int offset = 0; offset < bytes.Length; offset += chunkSize)
{
    var chunk = bytes.Skip(offset).Take(chunkSize).ToArray();
    var blockId = Convert.ToBase64String(Encoding.UTF8.GetBytes($"block{blockIds.Count}"));
    blockIds.Add(blockId);

    var uploadHeaders = new Dictionary<string, string>
    {
        ["x-ms-file-name"] = file_name,
        ["Content-Type"] = "application/octet-stream",
        ["x-ms-file-continuation-token"] = fileContinuationToken
    };
    _serviceClient.ExecuteWebRequest(HttpMethod.Patch, initUrl, chunk, uploadHeaders);
}

// Step 3: Commit
var commitBody = JsonSerializer.Serialize(new
{
    FileName = file_name,
    MimeType = mimeType,
    BlockList = blockIds
});
_serviceClient.ExecuteWebRequest(
    HttpMethod.Post, $"{initUrl}/CommitFileBlocksUpload", commitBody, headers
);
```

## Response Format

### Success
```
[FileUploaded] report.pdf → account(a1b2c3d4).new_document
  Size: 2.4 MB
  MIME: application/pdf
  Chunks: 1
```

### Error — Column Not File Type
```
[Error] Attribute 'name' on entity 'account' is not a File column.
Tip: Use get_entity_metadata to find File-type columns.
```

### Error — File Too Large
```
[Error] File size (135 MB) exceeds column max (128 MB).
Tip: Check the column's MaxSizeInKB setting.
```

## Structured Output Model

```csharp
internal sealed class UploadFileResult
{
    [JsonPropertyName("entityName")]
    public string EntityName { get; set; }

    [JsonPropertyName("recordId")]
    public string RecordId { get; set; }

    [JsonPropertyName("attributeName")]
    public string AttributeName { get; set; }

    [JsonPropertyName("fileName")]
    public string FileName { get; set; }

    [JsonPropertyName("fileSize")]
    public long FileSize { get; set; }

    [JsonPropertyName("mimeType")]
    public string MimeType { get; set; }

    [JsonPropertyName("chunks")]
    public int Chunks { get; set; }
}
```
