# Proposal: manage_environment_variables MCP Tool

## Priority: 11 (ALM — Environment-specific configuration)

## Phase: 3 — ALM & Operations (Long Term)

## Analysis Reference

- **Gap #8** in MCP-Analysis-2026.md
- **Impact**: 🟡 Medium
- **Effort**: Low

## Why This Tool Is Needed

Environment variables store configuration values that change between environments (Dev/Test/Prod). They're used by Power Automate flows, plugins, and custom code. Currently AI must query `environmentvariabledefinition` and `environmentvariablevalue` tables manually via FetchXML.

## Purpose

List, get, and set environment variables in Dataverse.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| action | string | Yes | - | `"list"`, `"get"`, or `"set"`. |
| variable_name | string | Cond. | - | For get/set: schema name of the variable. |
| value | string | Cond. | - | For set: new value. |
| solution_name | string | No | `""` | Filter by solution (list mode). |
| max_records | int | No | 50 | Max variables for list mode. |

## Dataverse Tables

| Table | Purpose |
|-------|---------|
| `environmentvariabledefinition` | Variable definitions (name, type, default) |
| `environmentvariablevalue` | Current override values |

## Response Format (Compact)

### List mode
```
[EnvironmentVariables] 5 total

name	type	defaultValue	currentValue
new_ApiEndpoint	String	https://api.dev.contoso.com	https://api.prod.contoso.com
new_MaxRetries	Integer	3	5
new_EnableFeatureX	Boolean	false	true
```

### Set success
```
[EnvironmentVariable] Updated
Name: new_ApiEndpoint
Type: String
OldValue: https://api.dev.contoso.com
NewValue: https://api.prod.contoso.com
```

## McpServerTool Attribute

```csharp
[McpServerTool(

    ReadOnly = false)]
```

## Tool Description for AI

```
List, get, and set Dataverse environment variables.

PARAMETERS:
- action (required): 'list', 'get', or 'set'.
- variable_name: For get/set: variable schema name.
- value: For set: new value.
- solution_name: Filter by solution (list mode).

WHEN TO USE:
- To check environment-specific configuration
- To update connection strings or API endpoints between environments
- When debugging flows or plugins that use environment variables

TIPS:
- Environment variables have a default value and an optional current value
- The current value overrides the default value
- Use get to check both default and current values before setting
```
