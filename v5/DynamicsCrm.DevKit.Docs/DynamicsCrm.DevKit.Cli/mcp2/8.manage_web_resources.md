# Proposal: manage_web_resources MCP Tool

## Priority: 8 (Developer Experience — Expose existing CLI capability)

## Phase: 2 — Enhance Developer Experience (Mid Term)

## Analysis Reference

- **Gap #6** in MCP-Analysis-2026.md (Web Resource Management)
- **Impact**: 🟡 Medium
- **Effort**: Low (CLI already has `TaskWebResource` and `TaskDownloadWebResource`)

## Why This Tool Is Needed

Web resources (JS, HTML, CSS, images) are core development artifacts. DevKit CLI already has `TaskWebResource` and `TaskDownloadWebResource` commands — this tool would expose a subset of that capability via MCP.

## Purpose

List, upload, and download web resources in Dataverse.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| action | string | Yes | - | `"list"`, `"upload"`, `"download"`, `"get"`. |
| name_filter | string | No | `""` | Filter by name (contains match). For list/download. |
| solution_name | string | No | `""` | Filter by solution. |
| type_filter | string | No | `""` | Filter by type: `"js"`, `"html"`, `"css"`, `"xml"`, `"png"`, `"jpg"`, `"gif"`, `"svg"`, `"resx"`. |
| web_resource_id | string | No | `""` | GUID for get/download. |
| file_path | string | No | `""` | For upload: local file path. For download: target directory. |
| display_name | string | No | `""` | For upload: display name. |
| description | string | No | `""` | For upload: description. |
| max_records | int | No | 50 | Max results for list. |

## Response Format (Compact)

### List mode
```
[WebResources] 12 found (filter: "account")

id	name	type	size	modifiedOn
abc-123	new_/js/account.form.js	JS (3)	4.2KB	2026-03-15
def-456	new_/js/account.webapi.js	JS (3)	2.1KB	2026-03-10
```

### Upload success
```
[WebResource] Uploaded
Name: new_/js/account.form.js
Type: JS (3)
Size: 4.2KB
Solution: MySolution
Published: yes
```

## McpServerTool Attribute

```csharp
[McpServerTool(
    Name = "manage_web_resources",
    Title = "List, upload, and download web resources",
    ReadOnly = false)]
```

## Tool Description for AI

```
List, upload, download, and inspect web resources in Dataverse.

PARAMETERS:
- action (required): 'list', 'upload', 'download', or 'get'.
- name_filter: Filter by name (contains match).
- solution_name: Filter by solution.
- type_filter: Filter by type: 'js', 'html', 'css', 'xml', 'png', 'svg'.
- web_resource_id: GUID for get/download actions.
- file_path: Upload source or download target path.

WHEN TO USE:
- To find web resources by name or type
- To upload new JavaScript/CSS/HTML files
- To download web resource content for editing
- After generating form/webapi code with DevKit CLI

TIPS:
- Web resource names follow convention: {prefix}/path/filename.ext
- Use with DevKit CLI 'webresource' command for bulk operations
- JavaScript web resources must be published before they take effect
```
