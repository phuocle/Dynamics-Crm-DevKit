# Proposal: manage_data MCP Tool

## Priority: 14 (Operations — Bulk data import/export)

## Phase: 3 — ALM & Operations (Long Term)

## Analysis Reference

- **Gap #13** in MCP-Analysis-2026.md (Data Import/Export)
- **Impact**: 🟢 Low
- **Effort**: Medium

## Why This Tool Is Needed

AI agents frequently need to seed test data, export records for analysis, or migrate data between environments. Currently this requires multiple `upsert_record` calls or external tools.

## Purpose

Import records from CSV/JSON into a Dataverse table, or export records to CSV/JSON.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| action | string | Yes | - | `"import"` or `"export"`. |
| entity_name | string | Yes | - | Target entity logical name. |
| file_path | string | Yes | - | For import: source CSV/JSON. For export: target file path. |
| file_format | string | No | auto | `"csv"` or `"json"`. Auto-detected from file extension. |
| fetchxml | string | No | `""` | For export: FetchXML query to filter records. Empty = all records. |
| max_records | int | No | 1000 | For export: max records. Default: 1000. Max: 5000. |
| batch_size | int | No | 50 | For import: records per batch. Default: 50. |
| upsert_mode | bool | No | false | For import: use upsert (match by primary key). Default: false (create only). |
| column_mapping | string | No | `""` | For import: JSON mapping `{"csv_column": "crm_attribute"}`. |

## Tool Description for AI

```
Import records from CSV/JSON into Dataverse or export records to a file.

PARAMETERS:
- action (required): 'import' or 'export'.
- entity_name (required): Target entity logical name.
- file_path (required): Source file (import) or target path (export).
- file_format: 'csv' or 'json'. Auto-detected from extension.
- fetchxml: For export: filter query. Empty = all records.
- max_records: For export: max records (default: 1000).
- batch_size: For import: records per batch (default: 50).
- upsert_mode: For import: upsert by primary key (default: false = create only).
- column_mapping: For import: JSON mapping of file columns to CRM attributes.

WHEN TO USE:
- To seed test data from a CSV file
- To export records for analysis or reporting
- To migrate data between environments
- To bulk-create records from structured data

TIPS:
- Use get_entity_metadata to verify column names before import
- CSV files must have a header row matching attribute logical names
- Use column_mapping when CSV headers don't match attribute names
- Failed rows are reported individually — fix and re-import
- For large datasets, adjust batch_size (smaller = safer, larger = faster)
```
