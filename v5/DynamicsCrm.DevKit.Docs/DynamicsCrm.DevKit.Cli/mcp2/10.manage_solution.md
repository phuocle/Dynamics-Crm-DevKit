# Proposal: manage_solution MCP Tool

## Priority: 10 (ALM — Solution export/import for deployment)

## Phase: 3 — ALM & Operations (Long Term)

## Analysis Reference

- **Gap #7** in MCP-Analysis-2026.md (Solution Import/Export)
- **Impact**: 🟡 Medium
- **Effort**: Medium

## Why This Tool Is Needed

Solution export/import is core ALM workflow. DevKit CLI already has `TaskPacSolutionPackager`. Lightweight MCP wrappers would enable AI to export/import solutions without leaving the AI conversation context.

## Purpose

Export or import Dataverse solutions.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| action | string | Yes | - | `"export"` or `"import"`. |
| solution_name | string | Cond. | - | For export: solution unique name. |
| managed | bool | No | false | For export: export as managed (true) or unmanaged (false). |
| output_path | string | No | auto | For export: local file path for the .zip file. |
| import_path | string | Cond. | - | For import: path to the solution .zip file. |
| overwrite_unmanaged | bool | No | true | For import: overwrite existing unmanaged customizations. |
| publish_workflows | bool | No | true | For import: activate workflows/processes after import. |
| async_import | bool | No | true | For import: use async import (recommended for large solutions). |

## Dataverse API

### Export Solution

```csharp
var request = new ExportSolutionRequest
{
    SolutionName = solutionName,
    Managed = managed
};
var response = (ExportSolutionResponse)serviceClient.Execute(request);
File.WriteAllBytes(outputPath, response.ExportSolutionFile);
```

### Import Solution

```csharp
var solutionBytes = File.ReadAllBytes(importPath);
var request = new ImportSolutionRequest
{
    CustomizationFile = solutionBytes,
    OverwriteUnmanagedCustomizations = overwriteUnmanaged,
    PublishWorkflows = publishWorkflows
};
serviceClient.Execute(request);
```

## Response Format (Compact)

### Export success
```
[SolutionExport] MySolution v1.0.0.1
Type: Unmanaged

```

### Import success
```
[SolutionImport] MySolution v1.0.0.1
Status: Imported successfully
Duration: 45 seconds
OverwriteUnmanaged: yes
PublishWorkflows: yes
```

## Tool Description for AI

```
Export or import Dataverse solutions for ALM workflows.

PARAMETERS:
- action (required): 'export' or 'import'.
- solution_name: For export: solution unique name.
- managed: For export: managed (true) or unmanaged (false). Default: false.
- output_path: For export: target file path.
- import_path: For import: path to .zip file.
- overwrite_unmanaged: For import: overwrite existing (default: true).
- async_import: For import: use async (default: true).

WHEN TO USE:
- Before deploying changes to another environment
- To create a solution backup before major changes
- To import solutions from other environments
- As part of CI/CD pipeline operations

TIPS:
- Use get_solution_components to verify contents before export
- Managed solutions cannot be customized in target environment
- Large solutions should use async_import=true
- Export path defaults to .devkit/solutions/ directory
```
