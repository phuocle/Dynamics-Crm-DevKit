# Proposal: get_business_process_flows MCP Tool

## Priority: 7 (Developer Experience — Understand guided data entry)

## Phase: 2 — Enhance Developer Experience (Mid Term)

## Analysis Reference

- **Gap #5** in MCP-Analysis-2026.md
- **Impact**: 🟡 Medium
- **Effort**: Low

## Why This Tool Is Needed

Business Process Flows (BPFs) guide users through a multi-stage data entry process. They define stages, steps, and branching logic. Developers need to understand BPFs when building plugins that interact with process stages, customizing forms, or migrating processes.

## Purpose

List Business Process Flows with their stages, steps, and entity bindings.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| entity_name | string | No | `""` | Filter by primary entity. Leave empty for all BPFs. |
| bpf_id | string | No | `""` | GUID of a specific BPF for full detail. |
| status | string | No | `""` | `"active"`, `"draft"`, or empty for all. |
| max_records | int | No | 50 | Max BPFs to return. |

## Dataverse Tables

| Table | Purpose |
|-------|---------|
| `workflow` | BPFs with `category = 4` |
| `processstage` | Stages within a BPF |
| `processstep` | Steps within stages |

## Response Format (Compact)

### List mode
```
[BusinessProcessFlows] 3 total

bpfId	name	primaryEntity	stages	status
abc-123	Lead to Opportunity	lead	4	Active
def-456	Phone to Case	phonecall	3	Active
```

### Detail mode
```
[BPF] Lead to Opportunity
BpfId: abc-123
PrimaryEntity: lead
Status: Active

[Stages]
1. Qualify (lead) → Budget Amount, Decision Maker, Need
2. Develop (opportunity) → Customer Need, Proposed Solution
3. Propose (opportunity) → Proposal, Quote
4. Close (opportunity) → Final Decision Date, Revenue
```

## Tool Description for AI

```
List Business Process Flows (BPFs) with stages, steps, and entity bindings.

PARAMETERS:
- entity_name: Filter by primary entity. Leave empty for all BPFs.
- bpf_id: GUID for full detail (stages + steps). Leave empty to list all.
- status: Filter by 'active' or 'draft'.
- max_records: Maximum BPFs (default: 50).

RETURNS:
- List mode: Table of BPFs with name, entity, stage count, status
- Detail mode: Full BPF with ordered stages and required steps

WHEN TO USE:
- Understanding guided data entry flows
- Building plugins that interact with process stages
- Auditing business processes
- Before customizing entity forms that have BPFs

TIPS:
- BPFs can span multiple entities (cross-entity processes)
- Each BPF creates a hidden entity (e.g., 'new_bpf_xxx') to track instances
- Active BPFs are visible on entity forms
```
