## Why This Tool Is Needed

Creating custom tables (entities) is the **foundation** of every Dynamics 365 project. Currently, AI must:

1. Construct complex JSON payloads for `EntityDefinitions` via WebAPI
2. Know the exact `@odata.type`, `EntityMetadata` properties, and primary attribute requirements
3. Handle solution association manually
4. Call `publish_customizations` separately

This is the most complex schema operation and the most error-prone when done via raw WebAPI.

## Purpose

Create a new custom Dataverse entity (table) with guided parameters. Automatically creates the primary name attribute and configures common entity properties.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| entity_name | string | Yes | - | Logical name with publisher prefix (e.g., `"new_project"`). |
| display_name | string | Yes | - | Singular display name (e.g., `"Project"`). |
| display_collection_name | string | Yes | - | Plural display name (e.g., `"Projects"`). |
| description | string | No | `""` | Entity description. |
| primary_attribute_name | string | No | `"{prefix}_name"` | Logical name of the primary name attribute. Auto-derived if omitted. |
| primary_attribute_display_name | string | No | `"Name"` | Display name of the primary name attribute. |
| primary_attribute_max_length | int | No | 100 | Max length of the primary name attribute (1–4000). |
| ownership_type | string | No | `"User"` | `"User"` (user/team owned) or `"Organization"` (org-owned). |
| is_activity | bool | No | false | Create as an activity entity (inherits activitypointer). |
| has_notes | bool | No | true | Enable notes (annotations) on the entity. |
| has_activities | bool | No | true | Enable activities on the entity. |
| has_feedback | bool | No | false | Enable feedback/ratings. |
| is_quick_create_enabled | bool | No | false | Enable quick create form. |
| is_duplicate_detection_enabled | bool | No | true | Enable duplicate detection. |
| change_tracking_enabled | bool | No | true | Enable change tracking (for data sync scenarios). |
| entity_color | string | No | `""` | Hex color code (e.g., `"#4A90D9"`). Auto-assigned if empty. |
| solution_name | string | Yes | - | Solution unique name to add the entity to. |
| auto_publish | bool | No | true | Publish after creation. |

## Dataverse API

### Create Entity

```csharp
var entity = new EntityMetadata
{
    SchemaName = schemaName,       // e.g., "new_Project"
    LogicalName = entityName,      // e.g., "new_project"
    DisplayName = new Label(displayName, 1033),
    DisplayCollectionName = new Label(displayCollectionName, 1033),
    Description = new Label(description, 1033),
    OwnershipType = ownershipType, // OwnershipTypes.UserOwned or .OrganizationOwned
    IsActivity = isActivity,
    HasNotes = hasNotes,
    HasActivities = hasActivities,
    HasFeedback = hasFeedback,
    IsQuickCreateEnabled = isQuickCreateEnabled,
    IsDuplicateDetectionEnabled = new BooleanManagedProperty(isDuplicateDetectionEnabled),
    ChangeTrackingEnabled = changeTrackingEnabled,
    EntityColor = entityColor
};

var primaryAttribute = new StringAttributeMetadata
{
    SchemaName = primarySchemaName,   // e.g., "new_Name"
    LogicalName = primaryAttributeName,
    DisplayName = new Label(primaryAttributeDisplayName, 1033),
    MaxLength = primaryAttributeMaxLength,
    RequiredLevel = new AttributeRequiredLevelManagedProperty(AttributeRequiredLevel.ApplicationRequired),
    FormatName = StringFormatName.Text
};

var request = new CreateEntityRequest
{
    Entity = entity,
    PrimaryAttribute = primaryAttribute,
    SolutionUniqueName = solutionName,
    HasNotes = hasNotes,
    HasActivities = hasActivities
};

var response = (CreateEntityResponse)serviceClient.Execute(request);
var entityId = response.EntityId;
```

## Response Format (Compact)

### Success
```
[EntityCreated] new_project
DisplayName: Project
PluralName: Projects
Ownership: UserOwned
PrimaryAttribute: new_name (Name)
HasNotes: yes
HasActivities: yes
Solution: MySolution
Published: yes
MetadataId: abc-123-def-456
EntitySetName: new_projects
```

### Error — Missing prefix
```
[Error] Cannot create entity
EntityName: project
Message: Entity name must include a publisher prefix (e.g., 'new_project', 'cr_project')
Tip: Check solution publisher prefix. Use get_solution_components to find solution details.
```

### Error — Duplicate
```
[Error] Entity 'new_project' already exists
Tip: Use get_entity_metadata to inspect the existing entity, or choose a different name
```

## Tool Description for AI

```
Create a new custom Dataverse entity (table) with guided parameters.
Automatically creates the primary name attribute and configures common properties.

PARAMETERS:
- entity_name (required): Logical name with publisher prefix (e.g., 'new_project').
- display_name (required): Singular display name (e.g., 'Project').
- display_collection_name (required): Plural display name (e.g., 'Projects').
- description: Entity description.
- primary_attribute_name: Primary name attribute logical name. Auto-derived if omitted.
- primary_attribute_display_name: Display name for primary attribute (default: 'Name').
- primary_attribute_max_length: Max length of primary attribute (default: 100).
- ownership_type: 'User' (default, user/team owned) or 'Organization'.
- is_activity: Create as activity entity (default: false).
- has_notes: Enable notes/annotations (default: true).
- has_activities: Enable activities (default: true).
- has_feedback: Enable feedback/ratings (default: false).
- is_quick_create_enabled: Enable quick create form (default: false).
- change_tracking_enabled: Enable change tracking (default: true).
- entity_color: Hex color code (e.g., '#4A90D9').
- solution_name (required): Solution to add the entity to.
- auto_publish: Publish after creation (default: true).

RETURNS:
- Created entity details (name, MetadataId, EntitySetName)
- Primary attribute details
- Solution and publish status

WHEN TO USE:
- To create a new custom table in Dataverse
- At the start of a new feature or module development
- When the data model requires a new entity

TIPS:
- Entity name MUST include publisher prefix (e.g., 'new_', 'cr_')
- After creation, use create_attribute to add columns
- Then use build_form_xml + update_form to customize the default form
- Use create_relationship to link to other entities
- Activity entities inherit from activitypointer and have special behavior
- UserOwned entities support sharing, assigning, and team ownership
- OrgOwned entities are visible to all users (no row-level security)
```

## Implementation Notes

- Use SDK `CreateEntityRequest` (not WebAPI) for proper handling of all properties
- Validate entity_name includes a publisher prefix (contains `_`)
- Auto-derive SchemaName from logical name (capitalize after prefix: `new_project` → `new_Project`)
- Auto-derive primary attribute name if not provided: `{prefix}_name`
- Default entity color if not provided: use a neutral color like `#0078D4`
- Handle `FaultException` for duplicate entity names
- Activity entities have additional constraints (must have subject, regardingobjectid, etc.)

## Pre-requisite

- `publish_customizations` must exist ✅
- `get_entities_metadata` must exist ✅ (to verify entity doesn't already exist)
