## Why This Tool Is Needed

Adding columns (attributes) to entities is the **single most frequent schema operation** in any Dynamics 365 project. Currently, AI must:

1. Know the exact JSON payload structure for `EntityDefinitions(LogicalName='xxx')/Attributes`
2. Include correct `@odata.type` annotations for each attribute type
3. Use `execute_webapi` with raw POST — error-prone and un-guided
4. Manually call `publish_customizations` afterward

A guided tool with parameter validation would dramatically reduce errors and accelerate development.

## Purpose

Add a new column (attribute) to an existing Dataverse entity. Supports all common attribute types with guided parameters and automatic resolution of `@odata.type` and schema properties.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| entity_name | string | Yes | - | Entity logical name (e.g., `"account"`). |
| attribute_name | string | Yes | - | Logical name for the new column (e.g., `"new_priority"`). Must include publisher prefix. |
| attribute_type | string | Yes | - | Column type: `"string"`, `"memo"`, `"integer"`, `"decimal"`, `"money"`, `"float"`, `"boolean"`, `"datetime"`, `"lookup"`, `"picklist"`, `"multipicklist"`, `"image"`, `"file"`. |
| display_name | string | Yes | - | Display name shown in forms (e.g., `"Priority Level"`). |
| description | string | No | `""` | Column description. |
| required_level | string | No | `"None"` | `"None"`, `"Recommended"`, or `"Required"`. |
| max_length | int | No | 100 | For `string` type: max character length (1–4000). Default: 100. |
| min_value | number | No | varies | For `integer`/`decimal`/`float`/`money`: minimum value. |
| max_value | number | No | varies | For `integer`/`decimal`/`float`/`money`: maximum value. |
| precision | int | No | 2 | For `decimal`/`money`: decimal places (0–10). |
| format | string | No | `"Text"` | For `string`: `"Text"`, `"Email"`, `"Url"`, `"Phone"`, `"TextArea"`. For `datetime`: `"DateOnly"`, `"DateAndTime"`. |
| options | string | No | - | For `picklist`/`multipicklist`: JSON array of `{label, value}` objects. E.g., `[{"label":"Low","value":100000000},{"label":"High","value":100000001}]`. |
| global_optionset_name | string | No | - | For `picklist`/`multipicklist`: use existing global option set instead of local options. |
| lookup_target | string | No | - | For `lookup`: target entity logical name (e.g., `"contact"`). |
| lookup_relationship_name | string | No | auto | For `lookup`: relationship schema name. Auto-generated if omitted. |
| true_label | string | No | `"Yes"` | For `boolean`: label for true value. |
| false_label | string | No | `"No"` | For `boolean`: label for false value. |
| solution_name | string | No | `""` | Add the column to this solution. Leave empty for default solution. |
| auto_publish | bool | No | true | Publish the entity after creation. |

## Dataverse API

### Create String Attribute

```csharp
var request = new CreateAttributeRequest
{
    EntityName = entityName,
    Attribute = new StringAttributeMetadata
    {
        SchemaName = attributeName,
        LogicalName = attributeName,
        DisplayName = new Label(displayName, 1033),
        Description = new Label(description, 1033),
        RequiredLevel = new AttributeRequiredLevelManagedProperty(requiredLevel),
        MaxLength = maxLength,
        FormatName = StringFormatName.Text
    },
    SolutionUniqueName = solutionName
};
serviceClient.Execute(request);
```

### Create Lookup Attribute

```csharp
var request = new CreateOneToManyRequest
{
    OneToManyRelationship = new OneToManyRelationshipMetadata
    {
        SchemaName = relationshipName,
        ReferencedEntity = lookupTarget,
        ReferencingEntity = entityName,
        AssociatedMenuConfiguration = new AssociatedMenuConfiguration
        {
            Behavior = AssociatedMenuBehavior.UseCollectionName,
            Group = AssociatedMenuGroup.Details,
            Order = 10000
        },
        CascadeConfiguration = new CascadeConfiguration
        {
            Assign = CascadeType.NoCascade,
            Delete = CascadeType.RemoveLink,
            Merge = CascadeType.NoCascade,
            Reparent = CascadeType.NoCascade,
            Share = CascadeType.NoCascade,
            Unshare = CascadeType.NoCascade
        }
    },
    Lookup = new LookupAttributeMetadata
    {
        SchemaName = attributeName,
        LogicalName = attributeName,
        DisplayName = new Label(displayName, 1033),
        RequiredLevel = new AttributeRequiredLevelManagedProperty(requiredLevel)
    },
    SolutionUniqueName = solutionName
};
serviceClient.Execute(request);
```

### Create Picklist Attribute

```csharp
var optionMetadata = options.Select(o => new OptionMetadata(new Label(o.Label, 1033), o.Value)).ToArray();

var request = new CreateAttributeRequest
{
    EntityName = entityName,
    Attribute = new PicklistAttributeMetadata
    {
        SchemaName = attributeName,
        LogicalName = attributeName,
        DisplayName = new Label(displayName, 1033),
        RequiredLevel = new AttributeRequiredLevelManagedProperty(requiredLevel),
        OptionSet = new OptionSetMetadata
        {
            IsGlobal = false,
            OptionSetType = OptionSetType.Picklist,
            Options = { /* add optionMetadata */ }
        }
    },
    SolutionUniqueName = solutionName
};
serviceClient.Execute(request);
```

## Response Format (Compact)

### Success
```
[AttributeCreated] account.new_priority
Type: Picklist
DisplayName: Priority Level
RequiredLevel: Recommended
Options: Low (100000000), Medium (100000001), High (100000002)
Solution: MySolution
Published: yes
MetadataId: abc-123-def-456
```

### Error — Invalid attribute name
```
[Error] Cannot create attribute
Entity: account
AttributeName: priority
Message: Attribute name must include a publisher prefix (e.g., 'new_priority', 'cr_priority')
Tip: Check solution publisher prefix and use it as attribute name prefix
```

### Error — Entity not found
```
[Error] Entity 'accccount' not found
Tip: Use get_entities_metadata to find the correct entity logical name
```

## Tool Description for AI

```
Add a new column (attribute) to an existing Dataverse entity.
Supports all common types: string, memo, integer, decimal, money, boolean,
datetime, lookup, picklist, multipicklist, and more.

PARAMETERS:
- entity_name (required): Entity logical name (e.g., 'account').
- attribute_name (required): Logical name with publisher prefix (e.g., 'new_priority').
- attribute_type (required): Column type: 'string', 'memo', 'integer', 'decimal',
  'money', 'float', 'boolean', 'datetime', 'lookup', 'picklist', 'multipicklist'.
- display_name (required): Display name shown in forms.
- description: Column description.
- required_level: 'None' (default), 'Recommended', or 'Required'.
- max_length: For string: max characters (1-4000). Default: 100.
- min_value/max_value: For numeric types: value range.
- precision: For decimal/money: decimal places (0-10). Default: 2.
- format: For string: 'Text','Email','Url','Phone'. For datetime: 'DateOnly','DateAndTime'.
- options: For picklist: JSON array [{label,value}] for local options.
- global_optionset_name: For picklist: reuse an existing global option set.
- lookup_target: For lookup: target entity (e.g., 'contact').
- solution_name: Add column to this solution.
- auto_publish: Publish after creation (default: true).

RETURNS:
- Created attribute details (name, type, MetadataId)
- Solution and publish status

WHEN TO USE:
- To add a new field to an entity
- After creating a new entity with create_entity
- When extending an existing entity's data model

TIPS:
- Attribute name MUST include publisher prefix (e.g., 'new_', 'cr_')
- Use get_entity_metadata to verify the attribute doesn't already exist
- For lookups: also creates the 1:N relationship automatically
- For picklist with existing choices: use global_optionset_name instead of options
- After creation, use build_form_xml to add the new field to a form
```

## Implementation Notes

- Use SDK `CreateAttributeRequest` for most types, `CreateOneToManyRequest` for lookups
- Validate attribute_name includes a publisher prefix (contains `_`)
- Validate entity exists before attempting creation
- Auto-generate relationship schema name for lookups if not provided: `{entity}_{target}_{attribute}`
- Handle `FaultException` for duplicate attribute names
- Default min/max values per type: integer (-2B to 2B), decimal (-100B to 100B), money (0 to 922T)
