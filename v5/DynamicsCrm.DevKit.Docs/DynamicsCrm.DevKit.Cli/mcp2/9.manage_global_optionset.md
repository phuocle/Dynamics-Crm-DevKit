# Proposal: create_global_optionset MCP Tool

## Priority: 9 (Schema Management — Complete choice/picklist CRUD)

## Phase: 2 — Enhance Developer Experience (Mid Term)

## Analysis Reference

- **Gap #1** in MCP-Analysis-2026.md (Schema Management)
- **Impact**: 🟡 Medium
- **Effort**: Low

## Why This Tool Is Needed

Global option sets (choices) are reusable picklists shared across entities. Currently, `get_global_optionsets` is read-only. Creating or updating global option sets requires raw WebAPI calls.

## Purpose

Create a new global option set or add/remove options from an existing one.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| action | string | Yes | - | `"create"`, `"add_option"`, `"remove_option"`. |
| optionset_name | string | Yes | - | Logical name (e.g., `"new_priority"`). |
| display_name | string | Cond. | - | For create: display name. |
| description | string | No | `""` | Description. |
| options | string | Cond. | - | For create: JSON array `[{label, value}]`. |
| option_label | string | Cond. | - | For add_option: label of the new option. |
| option_value | int | No | auto | For add_option: integer value. Auto-generated if omitted. |
| remove_value | int | Cond. | - | For remove_option: integer value of option to remove. |
| solution_name | string | No | `""` | Solution to add to. |
| auto_publish | bool | No | true | Publish after changes. |

## Dataverse API

### Create Global OptionSet

```csharp
var request = new CreateOptionSetRequest
{
    OptionSet = new OptionSetMetadata
    {
        Name = optionsetName,
        DisplayName = new Label(displayName, 1033),
        IsGlobal = true,
        OptionSetType = OptionSetType.Picklist,
        Options = { /* populated from options JSON */ }
    },
    SolutionUniqueName = solutionName
};
serviceClient.Execute(request);
```

### Add Option

```csharp
var request = new InsertOptionValueRequest
{
    OptionSetName = optionsetName,
    Label = new Label(optionLabel, 1033),
    Value = optionValue // null for auto-assign
};
var response = (InsertOptionValueResponse)serviceClient.Execute(request);
```

### Remove Option

```csharp
var request = new DeleteOptionValueRequest
{
    OptionSetName = optionsetName,
    Value = removeValue
};
serviceClient.Execute(request);
```

## Response Format (Compact)

```
[GlobalOptionSet] Created: new_priority
DisplayName: Priority
Options: Low (100000000), Medium (100000001), High (100000002)
Solution: MySolution
Published: yes
```

## Tool Description for AI

```
Create or modify global option sets (choices/picklists) in Dataverse.

PARAMETERS:
- action (required): 'create', 'add_option', or 'remove_option'.
- optionset_name (required): Logical name with prefix (e.g., 'new_priority').
- display_name: For create: display name.
- options: For create: JSON array [{label, value}].
- option_label: For add_option: new option label.
- option_value: For add_option: integer value (auto if omitted).
- remove_value: For remove_option: value to remove.
- solution_name: Solution to add to.
- auto_publish: Publish after changes (default: true).

WHEN TO USE:
- Creating reusable picklists shared across multiple entities
- Adding new options to existing global choices
- Before using create_attribute with global_optionset_name parameter

TIPS:
- Use get_global_optionsets to verify existing option sets first
- Option values should follow convention: 100000000, 100000001, etc.
- Global option sets can be reused by multiple entity attributes
```
