### Các lệch so với thiết kế gốc của file này (đã được user thông báo khi bàn giao)

1. **`MonoTextTransformer` đặt trong CLI (`DynamicsCrm.DevKit.Cli/Templates/`), không nằm trong Shared** như mục 3.4 viết — vì VSIX không tham chiếu package `Mono.TextTemplating`; nếu đặt trong Shared thì VSIX net48 vỡ build. Interface `ITextTransformer` + `T4ContextFactory` + `T4TemplateResolver` vẫn nằm Shared nên hợp đồng dùng chung đúng tinh thần source of truth. VSIX sau này cắm impl VS T4 COM vào cùng interface.
2. **`TaskNew` là static class, không implements `ITask`** — interface `ITask` đòi `OrgServiceAsync`/`SolutionId`… không phù hợp scaffolding offline.
3. **Alias `devkit new list`** được chuẩn hóa trong `Program.cs` (`new list` → `new --kind list`) vì Spectre.Console.Cli coi `list` là subcommand lạ của leaf command.
4. **Resource naming**: 3.2 gốc viết quy ước `templates.project...`; thực tế dùng **`Resources.templates.project...`** (có prefix `Resources.`) để nhất quán với pattern đọc EndsWith của các resource cũ.

### Bài học kỹ thuật — các file P.*/I.* PHẢI đọc trước khi làm

- **`ProcessTemplateAsync(inputFile, inputContent, outputFile)` của Mono.TextTemplating trả tuple `(outputFile, outputContent, success)` — content là Item2**, không phải Item1 (Item1 là tên file output).
- **Blob `.snk` (CSP PRIVATEKEYBLOB): field pubexp trong RSAPUBKEY là GIÁ TRỊ exponent dạng DWORD little-endian** (65537 → `01 00 01 00`), không phải độ dài; các field modulus/D = keySize/8 bytes, P/Q/DP/DQ/IQ = keySize/16 bytes, **fixed-width left-pad 0**. Tìm ra bằng diff với `RSACryptoServiceProvider.ExportCspBlob`. Kiểm chứng bằng `ImportCspBlob` + `ExportParameters(true)`; bằng chứng cuối (SignAssembly build) thuộc về smoke P.3/P.4.
- **`Path.GetRelativePath` không tồn tại trên net48** → `SolutionMutator` có helper `GetRelativePath` riêng. Quy tắc chung: **code trong Shared chỉ dùng API mức netstandard2.0**; mỗi lần nghi ngờ hãy build cả CLI lẫn VSIX.
- **Mono.TextTemplating 3.0.0: class feature block `<#+ #>` bị lỗi cú pháp khi compile** (đã tái lập độc lập, bất kể template). May là **không `.tt` nào của DevKit dùng `<#+`** — chỉ `<#=` và `<#if`. Nếu sau này cần feature block phải nâng cấp/khác giải pháp.
- **RSACryptoServiceProvider.ImportCspBlob(CALG_RSA_SIGN blob) import OK nhưng `SignData` ngay sau đó dính "Keyset does not exist"** (nuance CAPI AT_SIGNATURE) — nên test dùng import + export-params, đừng sign trực tiếp.
- **Tên resource giữa các host khác RootNamespace** (VSIX: `DynamicsCrm.DevKit.Resources.*`, CLI: `DynamicsCrm.DevKit.Cli.Resources.*`) → luôn đọc qua `TemplatePayload` (EndsWith match), đừng ghép tên tuyệt đối.
- **`devkit new` không flag trong terminal tương tác** mới vào flow hỏi–đáp (Spectre prompt); trong shell không TTY (AI/CI) sẽ báo `--kind: required` exit 1 — đúng thiết kế.

MCP host nằm trong CLI nên tự động có. Sửa 1 chỗ → cả 3 nền tảng cập nhật.

**Ràng buộc khi viết code trong Shared:** phải biên dịch được cho **cả net48 và net10** (tránh API chỉ có ở .NET hiện đại; nếu bắt buộc dùng `#if` theo TFV `NET48` / `NET10_0_OR_GREATER` — nhưng CLI/VSIX import shproj không khai báo TFV riêng, nên ưu tiên dùng API chung của netstandard2.0).
