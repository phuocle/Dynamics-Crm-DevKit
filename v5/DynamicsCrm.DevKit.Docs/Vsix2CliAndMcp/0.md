## 0. Mục tiêu của bước 0

Xây **một khung scaffolding trung lập nền tảng** đặt trong `DynamicsCrm.DevKit.Shared` (shared project `.shproj`) để cả 3 nền tảng **VSIX (net48), CLI (net10), MCP (trong CLI)** cùng gọi. **Không clone/copy code** — logic tồn tại đúng 1 lần.

Việc cần làm ở bước 0 là **khung + hạ tầng**, chưa scaffold bất kỳ template cụ thể nào (13 project + 17 item template sẽ làm ở các file `P.*` / `I.*`).

**Cách VS chạy template hiện nay** (phải hiểu trước khi port):
1. User chọn template trong VS → VS copy các file payload được khai báo trong `.vstemplate` (mục `<ProjectItem ReplaceParameters="true|false">`) tới thư mục đích, thay `$token$` bằng giá trị trong `replacementsDictionary`.
2. Trước khi copy, VS gọi `IWizard.RunStarted(...)` với `replacementsDictionary` — wizard mở WPF form thu thập input, sinh code (T4), điền token vào dictionary.
3. Sau khi copy, VS gọi `RunFinished()` — wizard chỉnh sửa tiếp (đổi tên project, sinh `.snk`, nest file `.generated.cs` dưới `.cs`…).

## 2. Kiến trúc đích — Source of Truth 3 lớp

```
┌─────────────────────────────────────────────────────────────────┐
│ LỚP 3 — PAYLOAD (vật lý duy nhất, KHÔNG copy)                   │
│ ProjectTemplates/CSharp/NN.*  +  ItemTemplates/CSharp/NN.*      │
│ (VSIX zip build vẫn đọc ở đây; Shared embed làm resource)       │
└──────────────────────────────┬──────────────────────────────────┘
                               │ embed qua .projitems
┌──────────────────────────────▼──────────────────────────────────┐
│ LỚP 2 — TEMPLATE CORE (mới, trong DynamicsCrm.DevKit.Shared)    │
│ DynamicsCrm.DevKit.Shared/Templates/                            │
│  • TemplateCatalog    — danh mục 13 P + 17 I (id, kind, params)  │
│  • TemplateManifest   — mỗi template: file payload + token      │
│  • TokenEngine        — thay $token$ (port Replacement.cs)      │
│  • ScaffoldingEngine  — orchestrate: input → render → ghi file  │
│  • T4/ (ITextTransformer + MonoTextTransformer + T4ContextFactory) │
│  • SigningService     — .snk bằng RSA thuần (thay mscoree)      │
│  • SolutionMutator    — sửa .sln/.slnx/.projitems thuần text/XML │
│  • WorkspaceScanner   — tìm .sln, shared project, root namespace │
│  • Models/            — ProjectTemplateInput, ItemTemplateInput, │
│                         ScaffoldResult (thay FormProject/…)     │
└──────────────────────────────┬──────────────────────────────────┘
                               │ gọi chung
   ┌───────────────────────────┼───────────────────────────────┐
   │ VSIX adapter (mỏng)       │ CLI adapter (mới)             │ MCP adapter (phase 2)
   │ Wizard + WPF form →       │ devkit new + Spectre prompt → │ Mcp/Tools/… →
   │ TemplateInput → Core      │ TemplateInput → Core          │ TemplateInput → Core
   └───────────────────────────┴───────────────────────────────┘
```

**Vì sao Shared là đúng:** `.shproj` đã được cả VSIX (`DynamicsCrm.DevKit.Vsix.csproj` dòng 519) và CLI (`DynamicsCrm.DevKit.Cli.csproj` dòng 84) import qua `.projitems` — code trong Shared biên dịch chung cho net48 lẫn net10. MCP host nằm trong CLI nên tự động có. Sửa 1 chỗ → cả 3 nền tảng cập nhật.

**Ràng buộc khi viết code trong Shared:** phải biên dịch được cho **cả net48 và net10** (tránh API chỉ có ở .NET hiện đại; nếu bắt buộc dùng `#if` theo TFV `NET48` / `NET10_0_OR_GREATER` — nhưng CLI/VSIX import shproj không khai báo TFV riêng, nên ưu tiên dùng API chung của netstandard2.0).
