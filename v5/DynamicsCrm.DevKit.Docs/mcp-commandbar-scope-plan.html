DevKit MCP Command Bar (manage_command / appaction) — Thiết kế theo chuẩn 3 Command Scopes của Microsoft: app | table | global

TL;DR — Thiết kế tối giản, chuẩn 100% theo tài liệu Microsoft Learn:

Theo tài liệu chính thức của Microsoft (Modern commanding overview — Command scope), Modern Command Bar có đúng 3 tầm vực (Command Scopes):
  1. "app" (Mặc định khi không truyền scope): Gắn với 1 App + 1 Table + 1 Location (context = 1, có contextentity/contextvalue, có appmoduleid). Nút chỉ xuất hiện trên bảng đó bên trong App đó. (Đã có — giữ nguyên 100% hành vi mặc định).
  2. "table" (Table Scope — Mọi App): Gắn với 1 Table + 1 Location, không gắn App (context = 1, có contextentity/contextvalue, appmoduleid = null). Nút xuất hiện trên bảng đó ở tất cả các Model-Driven Apps trong Environment.
  3. "global" (Global Scope — Mọi Table & Mọi App): Chỉ gắn với 1 Location, không gắn Table và không gắn App (context = 0, contextentity = null, contextvalue = null, appmoduleid = null). Nút xuất hiện ở vị trí đó trên tất cả các bảng và tất cả các Apps trong Environment.
Các nguyên tắc đã chốt:
  • Chỉ áp dụng cho Standard Button (create, update, hide, show, list, detail). Không mở rộng cho Flyout Dropdown & Split Button.
  • Giữ nguyên 12 action hiện tại (không thêm delete).
  • Publisher Prefix khi không có entity_name (ở scope = "global") sẽ dùng "devkit" (tương ứng devkit_).
  • Auto-Publish: khi có entity_name (app, table) → PublishHelper.PublishEntity; khi là global (không có entity_name) → PublishHelper.PublishRibbon.

1. Tài liệu Microsoft Learn: 3 Command Scopes trên bảng appaction

Trong tài liệu chính thức của Microsoft Learn (Modern commanding overview — Command scope), Microsoft định nghĩa đúng 3 mức tầm vực từ hẹp nhất đến rộng nhất:

Command scope (Microsoft Learn):
  • App (Narrowest / Default): Bound to a specific model-driven app, table, and command bar location. When you create a command in the modern command designer, the default scope is the App.
  • Table: Bound to a table and a command bar location. Table-scoped commands render in all apps that utilize that table.
  • Global (Broadest): Bound only to a command bar location, not a specific app or table. For example, a command bound to the main form location with global scope renders in all apps and for all tables.

2. Bảng so sánh 3 giá trị scope: "app" (default) vs "table" vs "global"

Tại sao mô hình 3 giá trị của Microsoft hoàn toàn không gây confuse cho Dev và AI?
Mỗi giá trị của scope tương ứng giảm dần đúng 1 tham số bắt buộc:
  • scope = "app" (hoặc không truyền): Cần cả 3 (app_name/app_id + entity_name + location).
  • scope = "table": Cần 2 (entity_name + location) — bỏ app vì áp dụng cho mọi App.
  • scope = "global": Cần 1 (location) — bỏ cả app lẫn entity_name vì áp dụng cho mọi Table ở mọi App.

3. Quy tắc sinh name, uniquename, Prefix & Auto-Publish

3.1 Quy tắc lấy Publisher Prefix (ResolvePublisherPrefix)

  • Khi có entityLogicalName (ở scope = "app" hoặc scope = "table") và tên bảng có dấu _ (vd: all_testform) → tách lấy phần trước dấu _ ("all").
  • Khi không có entityLogicalName (ở scope = "global") hoặc bảng hệ thống không có dấu _ (vd: account) → dùng fallback "devkit".
private string ResolvePublisherPrefix(string entityLogicalName)
{
    if (!string.IsNullOrWhiteSpace(entityLogicalName))
    {
        var idx = entityLogicalName.IndexOf('_');
        if (idx > 0) return entityLogicalName.Substring(0, idx);
    }
    return "devkit";
}

3.2 Quy tắc sinh name và uniquename cho Standard Button

3.3 Quy tắc Auto-Publish (PublishCommandTarget)

private string PublishCommandTarget(string entityLogicalName, Guid? appModuleId = null)
{
    if (!string.IsNullOrWhiteSpace(entityLogicalName))
    {
        PublishHelper.PublishEntity(_context, _orgService, entityLogicalName.Trim().ToLowerInvariant());
        return "Entity published.";
    }
    if (appModuleId.HasValue && appModuleId.Value != Guid.Empty)
    {
        PublishHelper.PublishAppModule(_context, _orgService, appModuleId.Value);
        return "App published.";
    }
    PublishHelper.PublishRibbon(_context, _orgService);
    return "Global command bar published.";
}

4. Đặc tả hành vi từng Action (create, update, hide, show, list, detail)

4.1 action = "create"

  • Chuẩn hóa scope: nếu rỗng/null → "app". Nếu khác "app", "table", "global" → trả lỗi Invalid scope '{scope}'. (Hint: Valid values: 'app' (default), 'table', 'global'.).
  • Khi scope == "app" (mặc định):
    • Giữ nguyên 100% validation hiện tại: yêu cầu entity_name, location, label, và app_id/app_name.
    • Gán context = OptionSetValue(1), contextvalue = entityLogical, contextentity = entityId, appmoduleid = resolvedAppId.
    • Publish entity qua PublishCommandTarget(entityLogical, resolvedAppId).
  • Khi scope == "table":
    • Nếu truyền app_id hoặc app_name → trả lỗi app_id and app_name must not be specified when scope='table'. (Hint: Use scope='app' (default) to target a specific app, or omit app_id/app_name for table-scoped commands across all apps.).
    • Yêu cầu entity_name, location, label.
    • Gán context = OptionSetValue(1), contextvalue = entityLogical, contextentity = entityId, không gán appmoduleid (để null).
    • Publish entity qua PublishCommandTarget(entityLogical).
  • Khi scope == "global":
    • Nếu truyền entity_name, app_id, hoặc app_name → trả lỗi entity_name, app_id, and app_name must not be specified when scope='global'. (Hint: Global commands apply to all tables and all apps. Use scope='table' for a specific table or scope='app' for a specific app and table.).
    • Yêu cầu location, label.
    • Gán context = OptionSetValue(0), không gán contextvalue, contextentity, và appmoduleid.
    • Publish qua PublishCommandTarget(null) (gọi PublishHelper.PublishRibbon).

4.2 action = "update"

  • Truy vấn RetrieveAppActionOrNull(cmdGuid, "name", "buttonlabeltext", "contextvalue", "appmoduleid").
  • Sau khi Update, gọi PublishCommandTarget(existing.GetAttributeValue<string>("contextvalue"), existing.GetAttributeValue<EntityReference>("appmoduleid")?.Id) để không bao giờ bị NullReferenceException khi update một nút Global (contextvalue == null).

4.3 action = "hide" & action = "show"

  • Path 1 (Theo command_id): Truy vấn thêm appmoduleid và dùng PublishCommandTarget sau khi cập nhật hidden hoặc xóa override.
  • Path 2 (Theo label):
    • Chuẩn hóa scope (mặc định "app").
    • Nếu scope == "app": giữ nguyên 100% logic hiện tại (yêu cầu label + entity_name + location, và app_id/app_name khi hide; hỗ trợ tạo/xóa OOB override).
    • Nếu scope == "table": yêu cầu label + entity_name + location. Tìm bản ghi appaction có context = 1, contextvalue = entityName, appmoduleid null, location = locationValue, buttonlabeltext = label. Cập nhật hidden = wantHidden và publish entity.
    • Nếu scope == "global": yêu cầu label + location. Tìm bản ghi appaction có context = 0, appmoduleid null, location = locationValue, buttonlabeltext = label. Cập nhật hidden = wantHidden và publish global command bar.

4.4 action = "list" & action = "detail"

  • Trong CommandEntry:
    • Thêm Context ("Entity" khi context = 1, "All" khi context = 0).
    • Thêm Scope:
      • context == 0 → "Global" (hoặc "App" nếu có appmoduleid).
      • context == 1 và có appmoduleid → "App".
      • context == 1 và appmoduleid == null → "Table".
  • Trong HandleList / GetList:
    • Khi truyền scope ("app", "table", "global"):
      • scope = "app": lọc appmoduleid not-null.
      • scope = "table": lọc context = 1 và appmoduleid null.
      • scope = "global": lọc context = 0 và appmoduleid null.
  • Trong GetDetailByLabel:
    • Khi scope = "global": tìm theo label + location + context = 0 (không bắt buộc entity_name).
    • Khi scope = "table": tìm theo label + entity_name + location + appmoduleid null.
