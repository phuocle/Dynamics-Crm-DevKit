# TOOL DESCRIPTION

```text
Manage Dataverse 1:N, N:N relationships and polymorphic lookup targets.
create_1n auto-creates the lookup column; create_nn auto-creates the intersect entity; update adjusts cascade/menu/hierarchy; add_target/remove_target manage polymorphic lookup targets (remove_target deletes the target's data).
is_hierarchical: self-referential 1:N only (referenced=referencing), max 1/entity. Cascade presets: Parental (all Cascade) | Referential (NoCascade + RemoveLink) | ReferentialRestrictDelete (NoCascade + Restrict). Cascade types: Cascade | NoCascade | RemoveLink | Restrict | Active | UserOwned.
WHEN TO USE:
- Create a 1:N relationship (with auto lookup) or an N:N relationship (with auto intersect).
- Adjust cascade behaviors, relationship menu display, or hierarchy.
- Add or remove a polymorphic lookup target.
RELATED TOOLS:
- get_tables → discover relationships
- manage_column → lookup columns
- publish_customizations → batch publish after multiple relationship changes
```

# PARAMETERS

```text
action                  : string : create_1n / create_nn / update / delete / add_target / remove_target.
relationship_name       : string : Schema name. Required for update/delete. Auto-generated on create.
referenced_entity       : string : Parent (1:N create, add/remove target).
referencing_entity      : string : Child (1:N create).
entity1                 : string : First entity for N:N.
entity2                 : string : Second entity for N:N.
cascade_preset          : string : Parental / Referential / ReferentialRestrictDelete.
cascade_assign          : string : Override cascade Assign behavior.
cascade_delete          : string : Override cascade Delete behavior.
cascade_merge           : string : Override cascade Merge behavior.
cascade_reparent        : string : Override cascade Reparent behavior.
cascade_share           : string : Override cascade Share behavior.
cascade_unshare         : string : Override cascade Unshare behavior.
menu_behavior           : string : UseCollectionName / UseLabel / DoNotDisplay.
menu_group              : string : Details / Sales / Service / Marketing.
menu_order              : int    : Order. Default 10000.
lookup_display_name     : string : 1:N create only.
solution_name           : string : Required: create_1n, create_nn, add_target.
is_hierarchical         : bool   : Self-referential 1:N (create_1n/update). 1 per entity.
entity_name             : string : Entity with polymorphic lookup (add/remove target).
attribute_name          : string : Polymorphic lookup logical name.
intersect_entity_name   : string : N:N intersect entity. Auto if empty.
```

- Test 4: Deleted the 1:N relationship created in Test 1.
- Test 5: Created the N:N relationship all_account_contact between account and contact with auto intersect entity all_account_contact, published.
- Test 6: Deleted the N:N relationship created in Test 5; the delete succeeded after a publish settled pending metadata (an immediate delete failed on a SQL reference constraint).
- Test 7: Updating cascade_preset to Parental fails with a friendly rewrite of Dataverse fault 0x80047007.
- Test 8: Updating menu_behavior to UseLabel without custom labels fails with a friendly rewrite of Dataverse fault 0x80044328.
- Test 9: create_1n without solution_name returns a tool-side error with a hint to provide solution_name.
- Test 10: Deleting a nonexistent relationship fails with a friendly rewrite of Dataverse fault 0x80040217.
- Test 11: is_hierarchical=true on two different entities returns a tool-side validation error.
- Test 12: Self-referential hierarchical create account -> account fails with a friendly rewrite of Dataverse fault 0x80072550 (navigation property name cannot be the same on both sides).
- Test 13: An invalid action returns the tool-side error listing all six valid actions.
- Test 14: add_target on the OOB regardingobjectid lookup fails with a friendly rewrite of Dataverse fault 0x80044366.
- Test 15: remove_target for a target that was never added fails with a friendly rewrite of Dataverse fault 0x80040217 on the convention relationship name.
- Test 16: Added Poly Table as a target of the polymorphic lookup all_testmcpfinal.all_relatedrecord, creating relationship all_all_polytable_all_testmcpfinal_all_relatedrecord, published.
- Test 17: Removed the Poly Table target added in Test 16, deleting the relationship with a data-loss warning.
- Test 18: remove_target on the OOB regardingobjectid lookup fails with a relationship-not-found rewrite because the OOB relationship name does not follow the prefix convention.
