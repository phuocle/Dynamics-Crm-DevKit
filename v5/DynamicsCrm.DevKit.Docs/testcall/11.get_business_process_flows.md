# get_business_process_flows

# Tool description

```text
List Business Process Flow definitions or inspect one BPF and its stage definitions.

WHEN TO USE:
- Inspect stage categories and primary entities for a BPF
- Find BPFs bound to an entity (entity_name filter)
- Resolve BPF unique/logical name for the auto-created entity

RELATED TOOLS:
- get_workflows -> classic workflow definitions (background async + realtime sync)
- get_business_rules -> client-side business rules
- get_flows -> Power Automate cloud flows
```

# Input tool call

**Test 1 — List mode: tất cả active BPFs**

```json
{
  "max_records": 50
}
```

**Test 2 — List mode + entity_name filter (regression phase 4: full paging + server filter)**

```json
{
  "entity_name": "contact",
  "max_records": 50
}
```

**Test 3 — Detail qua bpf_name (1 match → auto-detail) + include_stages (regression phase 4: stage order từ workflow.clientdata)**

```json
{
  "bpf_name": "AccountBPF",
  "include_stages": true
}
```

**Test 4 — bpf_name không khớp → list 0 found (không phải error)**

```json
{
  "bpf_name": "nonexistent-bpf-zzz"
}
```

# Kết quả

- **Regression phase 4 (stage order):** Test 3 chứng minh stages lấy đúng sequence từ `workflow.clientdata` (Stage 1 → Stage 2, category Qualify → Develop map qua StageCategoryMap), không còn sắp xếp sai.
- **Regression phase 4 (entity filter paging):** Test 2 filter `contact` qua paging loop trả đúng 1 BPF, có `entityName` echo trong structured output.
- `bpf_name` 1 match → auto-detail (Test 3); không khớp → list 0 found là Success, không phải error (Test 4).
- List entries có đủ `uniqueName`, `primaryEntity`, `businessProcessType`, `isManaged`, `stageCount`.
- Output ghi nguyên văn; description khớp source hiện tại (`GetBusinessProcessFlowsTool.cs`).
