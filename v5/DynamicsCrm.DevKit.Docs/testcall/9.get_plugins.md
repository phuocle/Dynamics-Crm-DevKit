# 9. get_plugins

# Tool description

```text
Plugin assemblies, types, steps. No filters = assembly list. assembly_name (1 match) = detail (types+steps+images). entity_name = steps on entity (wins over assembly_name). Stages: PreValidation/PreOperation/PostOperation/MainOperation (Custom API/DataProvider). include_config=true only for secure config inspection.

WHEN TO USE:
- Inspect a plugin assembly's types+steps before refactoring/disabling
- Find steps registered on an entity (entity_name wins over assembly_name)
- Check if a field triggers any plugin (trigger_field + entity_name)
- Find synchronous plugins (mode='sync'; Pre-op can cancel/rollback)

RELATED TOOLS:
- get_plugin_trace_logs → execution traces
- get_system_jobs → async failures
- get_messages → SDK messages + legacy Custom Actions
- get_custom_apis → modern Custom API definitions
```


```json

}
```

**Test 3 — entity_name steps (wins over assembly_name) + message filter**

```json
{
  "entity_name": "account",
  "message_name": "Create",
  "max_records": 10
}
```

**Test 4 — Detail 1 assembly + type_name filter + include_config=true (regression: config behavior an toàn)**

```json
{
  "assembly_name": "AccountPlugin",
  "type_name": "PostDeleteAccount",
  "include_config": true
}
```

```json

}
```

**Test 6 — Error: assembly_name 0 matches**

```json

  "assembly_name": "nonexistent_assembly_zzz"
}
```

# Kết quả

- **Disambiguation contract:** assembly_name 2+ matches → list mode, không auto-detail (Test 2). 1 match → detail (Test 4).
- **entity_name wins over assembly_name** + trả `mode: "steps"` với `summary` (preValidation/preOperation/postOperation/sync/async/disabled counts) — Test 3.
- **Regression (config an toàn):** `include_config=true` mới trả `unsecureConfig` (Test 4); các call khác (Test 1-3) không có field config nào — secure config không bao giờ lộ trong output mặc định.
- Steps có đầy đủ images (name/entityAlias/imageType/attributes) khi `include_images=true` (default).
- Error paths (Test 5, 6) `IsError: true` với hint đúng.
- Description khớp source hiện tại (`GetPluginsTool.cs`).
