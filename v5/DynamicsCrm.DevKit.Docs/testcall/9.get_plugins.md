# TOOL DESCRIPTION

```text
Plugin assemblies, types, steps. No filters = assembly list. assembly_name (1 match) = detail (types+steps+images). entity_name = steps on entity (wins over assembly_name). Stages: PreValidation/PreOperation/PostOperation/MainOperation (Custom API/DataProvider). include_config=true only for secure config inspection.

WHEN TO USE:
- Inspect a plugin assembly's types+steps before refactoring/disabling
- Find steps registered on an entity (entity_name wins over assembly_name)
- Check if a field triggers any plugin (trigger_field + entity_name)
- Find synchronous plugins (mode='sync'; Pre-op can cancel/rollback)

RELATED TOOLS:
- get_plugin_trace_logs → execution traces
- get_system_jobs → async failures
- get_messages → SDK messages + legacy Custom Actions
- get_custom_apis → modern Custom API definitions
```

# PARAMETERS

```text
assembly_name  : string : Assembly name contains. 1 match → detail; 0/2+ → disambiguation. Empty = list all.
entity_name    : string : Steps for entity Display/logical name. Wins over assembly_name.
message_name   : string : SDK message name (Create, Update, …). Empty = all.
type_name      : string : Plugin type typename contains. Empty = all.
include_images : bool   : Include pre/post images. Default true.
include_config : bool   : Include unsecure/secure config (security-sensitive). Default false.
stage          : string : 'prevalidation'/'preoperation'/'postoperation'/'mainoperation'. Empty = all.
mode           : string : 'sync' / 'async'. Empty = both.
active_only    : bool   : Only activated steps. Default true.
max_records    : int    : 1-500. Default 100.
```

# RESULTS

- Test 1: list mode returns all 20 assemblies with isolationMode, sourceType, typeCount, and a packages section for FileStore plugin packages.
- Test 2: assembly_name with 2+ matches returns a list (no auto-detail), honoring the "1 match → detail; 0/2+ → disambiguation" contract.
- Test 3: entity_name returns mode="steps" with a stage/sync/async/disabled summary; entity_name wins over assembly_name.
- Test 4: single-match detail returns types and steps; unsecureConfig appears only because include_config=true — config fields never leak in other calls.
- Test 5: invalid stage returns a validation error, IsError true.
- Test 6: unmatched assembly_name returns a not-found error with a hint pointing to list mode, IsError true.
