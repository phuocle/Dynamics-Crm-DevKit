# 31. manage_ribbon

# Tool description

```text
Classic RibbonDiffXml for Dataverse entities via 'devkit-ribbon' solution import.

WHEN TO USE: classic/legacy ribbon & button customization — 'ribbon', 'classic', 'legacy', 'button', 'nút', 'custom button', 'action button', 'JavaScript button', 'sub_grid/homepage grid button', or generic button. NOT for modern Power Fx command bar (appaction) → use manage_command.

Actions (modes): list | buttons | detail | update | undo.
- list: entities with ribbon customizations in 'devkit-ribbon'
- buttons: OOB+custom buttons across form/main_grid/sub_grid (entity_name)
- detail: current RibbonDiffXml (entity_name)
- update: entity_name + operations (or ribbonxml patch) → validate → backup → import → PublishAll async
- undo: restore from backup (entity_name + ribbonxml path)

Operations (update): add_button, update_button, hide_button, show_button, add_split_button, update_split_button, add_flyout_static, update_flyout_static, hide_flyout_item, show_flyout_item. entity_name and web-resource fields resolve Display Name contains first, then logical/unique/schema.

RELATED TOOLS: manage_command (modern Power Fx command bar / appaction), get_system_jobs (poll PublishAll async job), publish_customizations (manual publish if async publish did not finish). Pass workspace_folder so backups land in the user's project.
```

## update_button label contract (Option A — đã fix)

`update_button` xác định nút bằng `button_id` HOẶC `label`:
- **Có `button_id`** → `label` = new value (backward compat). Vd: `{"action":"update_button","button_id":"devkit...Button","label":"New Label"}`.
- **Không `button_id`, có `label`** (lookup) → `new_label` = new value. Vd: `{"action":"update_button","label":"Old","new_label":"New"}`. Không có `new_label` → không đổi label, vẫn update được `tooltip_title`/`tooltip_description`/`library`/`function`/`sequence` khác.
