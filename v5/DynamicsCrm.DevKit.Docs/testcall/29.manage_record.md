# ✅ TOOL DESCRIPTION

```text
CRUD a single Dataverse record. Actions: 'read' (read-only) | 'create', 'update', 'delete' (IRREVERSIBLE), 'associate', 'disassociate' (mutations). Record changes are live immediately — no publish needed.

WHEN TO USE:
- Create / read / update / delete a single record by GUID
- Partial-update specific fields without rewriting whole record
- Associate/disassociate two records via an N:N relationship
- Verify a record before destructive changes

RELATED TOOLS:
- get_tables → entity/attribute names before building fields_json
- execute_fetchxml → find lookup GUIDs and record_id
- create_records → bulk create multiple records
- execute_webapi → raw OData JSON/annotations
```

# PARAMETERS

```text
action              : string : 'create', 'read', 'update', 'delete', 'associate', 'disassociate'.
entity_name         : string : Entity logical name (e.g., 'account').
record_id           : string : GUID. Required: read/update/delete. Empty: create.
fields_json         : string : JSON object of field values. Required: create/update. Polymorphic lookup: 'fieldname@targetentity' key. Activity party fields (to/from/cc/bcc/requiredattendees/optionalattendees): JSON array of {"id":"<guid>","type":"<entity>"}. Single party auto-wrapped: {"id":"<guid>","type":"<entity>"}. Optional: "addressused":"email". Regular lookup: {"fieldname": "guid"}.
columns             : string : Read only. Comma-separated columns. Empty = all.
related_entity_name : string : Related Entity Name for associate/disassociate.
related_record_id   : string : Related Record GUID for associate/disassociate.
relationship_name   : string : N:N Relationship Name for associate/disassociate.
```
