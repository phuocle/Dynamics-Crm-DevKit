# TOOL DESCRIPTION

```text
Return the connected Dataverse identity, organization, direct roles, and DevKit runtime evidence.

WHEN TO USE:
- Verify the active environment and user before reading or changing data
- Verify MCP process version, build timestamp, assembly path, and SHA after reinstall

RELATED TOOLS:
- execute_fetchxml → query records with the returned userId
- manage_role → inspect role definitions and assignments
```

