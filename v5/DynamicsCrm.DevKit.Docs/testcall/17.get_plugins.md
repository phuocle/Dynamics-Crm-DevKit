# 17. get_plugins

# Tool description AI đọc được

```
Name:        get_plugins
Title:        List plugin registrations and steps
Idempotent:  true
Destructive: false
ReadOnly:    true

Description:
Plugin assemblies, types, steps. No filters = assembly list. assembly_name (1 match) = detail (types+steps+images). entity_name = steps on entity (wins over assembly_name). Stages: PreValidation/PreOperation/PostOperation/MainOperation (Custom API/DataProvider). include_config=true only for secure config inspection.
WHEN TO USE:
- Inspect a plugin assembly's types+steps before refactoring/disabling
- Find steps registered on an entity (entity_name wins over assembly_name)
- Check if a field triggers any plugin (trigger_field + entity_name)
- Find synchronous plugins (mode='sync'; Pre-op can cancel/rollback)
RELATED TOOLS:
- get_plugin_trace_logs → execution traces
- get_system_jobs → async failures
- get_messages → SDK messages + legacy Custom Actions
- get_custom_apis → modern Custom API definitions

Parameters:
  assembly_name    (string, default: "")
    Assembly name contains. 1 match → detail; 0/2+ → disambiguation. Empty = list all.
  entity_name      (string, default: "")
    Steps for entity Display/logical name. Wins over assembly_name.
  message_name     (string, default: "")
    SDK message name (Create, Update, …). Empty = all.
  type_name         (string, default: "")
    Plugin type typename contains. Empty = all.
  include_images   (bool, default: true)
    Include pre/post images. Default true.
  include_config   (bool, default: false)
    Include unsecure/secure config (security-sensitive). Default false.
  stage            (string, default: "")
    'prevalidation'/'preoperation'/'postoperation'/'mainoperation'. Empty = all.
  mode             (string, default: "")
    'sync' / 'async'. Empty = both.
  active_only      (bool, default: true)
    Only activated steps. Default true.
  max_records      (int, default: 100)
    1-500. Default 100.
```

### Kết quả AI tổng hợp lại

- **Trạng thái:** Thành công. 73 plugin assemblies trên org 🟢DEVKITV4.
- **mode:** `assemblies` — chế độ danh sách.
- **totalCount:** 73 — tổng số assembly.
- **assemblies[i]:** mỗi entry có:
  - `assemblyId` — GUID của plugin assembly.
  - `name` / `version` — tên và phiên bản.
  - `isolationMode` — `Sandbox` / `None` / `External`.
  - `sourceType` — `Database` / `Disk` / `Normal` / `AzureWebApp` / `FileStore`.
  - `isManaged` — `true` nếu solution-managed.
  - `hasManagedIdentity` — `true` nếu gắn Managed Identity (cho Azure Web App isolation).
  - `managedIdentity` — chi tiết (ẩn khi `hasManagedIdentity=false`): `applicationId`, `tenantId`, `credentialSource`.
  - `packageName` — tên plugin package (ẩn khi không thuộc package nào).
  - `typeCount` — số plugin types trong assembly.
  - `types` — ẩn trong list mode (chỉ có trong detail mode).
- **packages:** danh sách plugin packages (ẩn khi không có package nào). Mỗi package có `assemblies` = list tên assembly thuộc package.
- **Token tiết kiệm:** `types`/`steps`/`summary`/`entityName` ẩn trong assemblies mode; `managedIdentity` ẩn khi không có.
- **Cách dùng tiếp theo:** Dùng `assembly_name` với 1 match để xem detail (types + steps + images).
