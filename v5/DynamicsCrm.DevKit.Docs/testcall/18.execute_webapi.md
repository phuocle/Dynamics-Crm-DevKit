# 18. execute_webapi

# Tool description

```text
Execute a raw Dataverse Web API request (GET/POST/PUT/PATCH/DELETE). Relative URL only.

WHEN TO USE:
- Call Web API endpoints not covered by a dedicated tool (custom actions, WhoAmI, $metadata CSDL)
- Read $metadata schema (GET $metadata, returns XML)
- Invoke custom/custom API actions (POST {actionName})

RELATED TOOLS:
- execute_fetchxml → deterministic FetchXML queries
- get_tables → entity/attribute metadata (use instead of GET EntityDefinitions)
- manage_record_file → file/image column binary data (use instead of /$value endpoints)
- manage_form / manage_app / manage_view / manage_chart → metadata mutations
- publish_customizations → publish after metadata changes
```
