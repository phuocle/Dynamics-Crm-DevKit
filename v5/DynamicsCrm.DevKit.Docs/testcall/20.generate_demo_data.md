# ✅ TOOL DESCRIPTION

```text
Bogus-generated demo data for an entity → JSON file at {workspace}/.devkit/generate_demo_data/{entity}/ (workspace auto-resolved from MCP roots or server cwd) → pipe to create_records. from_date/to_date REQUIRED (ISO 8601, ask user, never infer). Auto-selects creatable fields with smart mapping (email→Email, telephone→Phone…) and overriddencreatedon. Lookups: real GUIDs auto-fetched; polymorphic uses 'field@entity'.

WHEN TO USE:
- Generate demo/test data for an entity → pipe to create_records
- Reproducible runs (fix seed); rotate lookups/enums via field_overrides 'in'
- Pin specific FK values across all rows via field_overrides 'eq'

RELATED TOOLS:
- create_records → import generated JSON into Dataverse
- get_tables → discover entity fields before generating
```

# PARAMETERS

```text
entity_name      : string : Entity logical name (e.g., 'account').
from_date        : string : ISO 8601, e.g. '2026-01-01'. NEVER infer — ask user.
to_date          : string : ISO 8601, e.g. '2026-04-30'. Must be >= from_date.
count            : int    : 1-500.
fields           : string : Comma-separated logical names. Empty = auto-select creatable.
seed             : int    : 0 = random; non-zero = reproducible.
field_overrides  : string : JSON array of {logicalname, operator, values[]}. Operators (see description). Example: [{"logicalname":"jobtitle","operator":"in","values":["CEO","CFO","CTO"]}].
```

# RESULTS
- Test 1: auto-select generates 65 creatable account fields and reports the lookup pools sampled (account, systemuser, team, contact, transactioncurrency); the payload goes to the timestamped file only — no inline records.
- Test 2: all three shape overrides applied (`eq`, `endswith`, `contains`); two lookup warnings for solution entities with no active records still yield a success with `warnings` listed.
- Test 3: the remaining three operators (`startswith`, `regex`, `in` on an option set) applied with seed 99.
- Test 4: explicit `fields` restricts generation to exactly those 6 columns (no lookups sampled) — the clean shape piped into Test 2 of `18.create_records.md`.
- Tests 5-8: name-only batches 500+500+500+223 = 1723 records on the custom table `all_testpushrecord`; the `all_fullname` logical name makes the smart mapping emit Bogus full names (no dedicated full-name option exists); the four files feed the bulk push in Test 7 of `18.create_records.md`. File names are minute-precision (`yyyyMMddHHmm.demo.json`); parallel calls in the same minute get `-2`, `-3`, … suffixes via a create-new retry loop, so no call overwrites another.
- Test 9: unknown entity returns a not-found error with a get_tables hint.
- Test 10: ambiguous Display Name `Product` returns the first-line error plus hint, with the three candidates in `[Detail]` `entityMatches`.
- Test 11: to_date before from_date is rejected with a hint.
- Test 12: unparseable from_date is rejected with an ISO 8601 hint.
- Test 13: omitted dates are rejected; the hint restates the never-infer contract.
- Test 14: unknown override operator is rejected with the valid-operator list.
- Test 15: count 501 is rejected at the 500 maximum with a multi-call hint.
- Test 16: a field_override without `logicalname` is rejected with an example hint.
- Test 17: a field_override with an empty `values` array is rejected with an example hint.
