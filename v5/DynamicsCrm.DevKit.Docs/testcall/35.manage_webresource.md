# 35. manage_webresource

# Tool description AI đọc được

```
Manage Dataverse web resources — list / detail / create / update / delete.
Required: detail/update/delete need web_resource_id (GUID, Display Name, or unique name); create needs name + file_path + type + solution_name.
On create the prefix in name must match the solution's publisher prefix; on mismatch the tool errors with the suggested name — re-call with it. Create adds the web resource to the solution and publishes; update also publishes; delete is irreversible.
Types: js, html, css, xml, png, jpg, gif, svg, ico, resx, xsl, xap. Naming: {prefix}_/path/filename.ext (e.g. 'v4_/entities/Account.form.js').
WHEN TO USE: upload/update/inspect a web resource; find library_name for build_form_xml add_event/add_library (run list first); combine with build_form_xml + manage_form to wire JS into a form.
RELATED TOOLS: get_solution_components, manage_form, publish_customizations.
```

Input schema params: `action` (required), `web_resource_id`, `name`, `display_name`, `description`, `file_path`, `type`, `solution_name`, `type_filter`, `max_records` (default 50).
