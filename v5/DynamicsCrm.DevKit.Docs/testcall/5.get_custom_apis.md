# 5. get_custom_apis

# Tool description

```text
List modern Custom API definitions or inspect one API's parameters and plugin binding.

WHEN TO USE:
- Inspect a Custom API's request/response parameters and plugin binding before registering or invoking it
- Discover Custom APIs bound to a specific entity
- Distinguish modern Custom APIs from legacy workflow Custom Actions

RELATED TOOLS:
- get_messages → legacy workflow Custom Actions (category=3) + SDK messages
- get_plugins → plugin assemblies/types/steps registered on these APIs
- get_workflows → classic workflow definitions
```

# Input tool call

**Test 1 — List mode: active custom APIs**

```json
{
  "max_records": 20
}
```

**Test 2 — Detail qua api_name (parameters + plugin binding)**

```json
{
  "api_name": "v4_AccountCustomApi"
}
```

**Test 3 — Validation error: status không hợp lệ**

```json
{
  "status": "disabled"
}
```

**Test 4 — Error: api_name không khớp**

```json
{
  "api_name": "nonexistent_api_zzz"
}
```

**Test 5 — List mode + entity_name filter**

```json
{
  "entity_name": "account"
}
```

# Kết quả

- List (Test 1) gọn: không có requestParameters/responseProperties; detail (Test 2) có đầy đủ parameters (type map String, isOptional) + plugin binding (pluginTypeFullName, assembly name/version, solution).
- `entity_name` filter (Test 5) hoạt động, structured output có `entityFilter` echo.
- Validation: status sai → error rõ (Test 3); api_name không khớp → error kèm Tip (Test 4). Cả 2 `IsError: true`.
- Không output nào bị rút gọn; description khớp source hiện tại (`GetCustomApisTool.cs`).
