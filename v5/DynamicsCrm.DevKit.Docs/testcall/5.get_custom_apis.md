# TOOL DESCRIPTION

```text
List modern Custom API definitions or inspect one API's parameters and plugin binding.

WHEN TO USE:
- Inspect a Custom API's request/response parameters and plugin binding before registering or invoking it
- Discover Custom APIs bound to a specific entity
- Distinguish modern Custom APIs from legacy workflow Custom Actions

RELATED TOOLS:
- get_messages → legacy workflow Custom Actions (category=3) + SDK messages
- get_plugins → plugin assemblies/types/steps registered on these APIs
- get_workflows → classic workflow definitions
```

# PARAMETERS

```text
api_name          : string : Display Name or unique name → detail. Empty = list.
entity_name       : string : Bound entity Display/logical name. Empty = all.
include_microsoft : bool   : Include managed APIs. Default false.
status            : string : 'active' / 'inactive' / 'all'.
max_records       : int    : 1-500. Default 100.
```

- Test 2: detail mode via api_name returns full parameters (type, isOptional) and plugin binding (pluginTypeFullName, assembly name/version, solution).
