# ✅ TOOL DESCRIPTION

```text
Run a SQL SELECT query against Dataverse in single-page or auto-paging mode.

WHEN TO USE:
- Query Dataverse records with standard SQL SELECT syntax (JOINs, aggregates, WHERE, ORDER BY)
- Read-only analytical queries, multi-table joins, or summaries after validating logical names

RELATED TOOLS:
- get_tables → discover entity and attribute logical names before querying
- execute_fetchxml → alternative for FetchXML-specific conditions or deep hierarchies
- execute_webapi → raw REST calls (non-SQL; the ?sql= query option is redirected here)
- docs://instructions_for_sql → Dataverse SQL syntax rules and conversion cheat sheet
```

# PARAMETERS

```text
sql         : string : SQL SELECT query. Lowercase logical names. No SELECT *.
max_records : int    : 1-50000. Default 5000. Use 10-100 for samples.
get_all     : bool   : true = auto-page until max_records. false = first page only.
```
