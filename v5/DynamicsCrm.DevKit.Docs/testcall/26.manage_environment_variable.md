# TOOL DESCRIPTION

```text
Manage Dataverse environment variables (definition + current value). Actions: 'list', 'detail' (read-only) | 'create', 'update', 'delete', 'clear' (mutations — confirm first). CREATE uses the publisher prefix from solution_name directly. 'create' REQUIRES solution_name+display_name+type; schema name = publisher prefix of solution_name + display name (blocks reserved prefix 'new'; rejects if display/schema name exists → use update). confirmed_prefix = optional safety check. Type immutable after create — delete+recreate to change. 'update' with empty value leaves the current value untouched — use 'clear' to remove it. 'clear' removes current value only (definition+default remain). 'delete' is irreversible (no backup). Secret-type values are masked as '(secret)' in all outputs.

WHEN TO USE:
- Create or update env vars used by apps, flows, or integrations
- Inspect default/current values; move config between environments via solutions

RELATED TOOLS:
- execute_webapi → environmentvariable* endpoints are blocked; use this tool
- get_solution_components → verify a variable's solution membership
```

# PARAMETERS

```text
action           : string : 'list', 'detail', 'create', 'update', 'delete', 'clear'.
variable_name    : string : Display/schema name with prefix (e.g. 'v4_ApiEndpoint'). Required: detail/update/delete/clear. Omit for create (derived from solution).
solution_name    : string : Display/unique name or GUID. 'list': filter. 'create': REQUIRED (resolves publisher prefix).
max_records      : int    : List only. Default 50. Max 5000.
display_name     : string : Human-readable label. Required: create.
type             : string : 'string'/'number'/'boolean'/'json'/'datasource'/'secret'. Required: create. Immutable after.
default_value    : string : Default value. Optional: create/update.
value            : string : Current value (overrides default). Optional: create/update. On update, omit/empty = keep existing — use action='clear' to remove.
description      : string : Description. Optional: create/update.
confirmed_prefix : string : Optional prefix check for 'create'. Must match solution publisher prefix.
```

# RESULTS

- Test 1: list without filter returns 11 environment variables with name, type, default, and current values.
- Test 2: list with a solution filter returns an empty result as a success when the solution has no variables.
- Test 3: create derives the schema name from the solution publisher prefix (all_DevKitRefactor3Test), sets both default and current values, and adds the variable to solution all_in_one.
- Test 4: detail returns the full definition including description and both values.
- Test 5: update changes the current value and description; the structured result echoes the updated current value.
- Test 6: clear removes only the current value (valueCleared=true, definition and default remain).
- Test 7: create with an existing display_name fails with a redirect to action='update'.
- Test 8: detail on a non-existent variable fails with a not-found error plus a redirect hint to action='list'.
- Test 9: update with no change fields fails with a hint listing the changeable fields and the clear action for removing the current value.
- Test 10: an invalid action fails with the list of valid values.
- Test 11: create with an invalid type fails with the valid type list in the hint.
- Test 12: the solution-filtered list confirms the created variable is a member of all_in_one.
- Test 13: delete removes the variable definition irreversibly.
- Test 14: the solution-filtered list returns to zero after the delete.
