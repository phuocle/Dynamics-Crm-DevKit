# Tool description AI đọc được

```
Manage environment variables
Manage Dataverse environment variables (definition + current value). Actions: 'list', 'detail' (read-only) | 'create', 'update', 'delete', 'clear' (mutations — confirm first).
WHEN TO USE:
- Create or update env vars used by apps, flows, or integrations
- Inspect default/current values; move config between environments via solutions
RELATED TOOLS:
- execute_webapi → environmentvariable* endpoints are blocked; use this tool
- get_solution_components → verify a variable's solution membership

'create' REQUIRES solution_name+display_name+type; schema name = publisher prefix of solution_name + display name (blocks reserved prefix 'new'; rejects if display/schema name exists → use update). confirmed_prefix = optional safety check. Type immutable after create — delete+recreate to change.
'update' with empty value leaves the current value untouched — use 'clear' to remove it. 'clear' removes current value only (definition+default remain). 'delete' is irreversible (no backup).
Secret-type values are masked as '(secret)' in all outputs.
```
