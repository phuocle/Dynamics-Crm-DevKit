# ✅ TOOL DESCRIPTION

```text
Manage soft-deleted (recycle bin) records. Actions: 'list', 'detail', 'status' (read-only) | 'restore', 'turn' (mutations). Soft-deleted records stay recoverable up to the retention period (1-30 days, default 30), then are auto-purged. Bin exposes record attributes only (no deletedon/deletedby; use modifiedOn as delete-time proxy).

WHEN TO USE:
- List or inspect records in the recycle bin before restoring
- Restore one or many deleted records back to the live table (restore prepends name_prefix, default '[RESTORE] ', to the primary name)
- Check (status) or toggle (turn on/off) the org-level 'Keep deleted Dataverse records' setting

RELATED TOOLS:
- manage_record → live CRUD; delete becomes soft-delete when the bin is ON
- get_audit_history → who deleted a record and when
- execute_webapi → raw access (Restore action is redirected here)
```

# PARAMETERS

```text
action          : string   : Action: 'list' (default) | 'detail' | 'restore' | 'status' | 'turn'.
entity_name     : string   : Entity Display/logical name. list: required. detail: required. restore: required if record_ids span multiple entities. status: not used. turn: not used.
record_id       : string   : Single GUID. detail: required. list: not used. restore: optional if record_ids set.
record_ids      : string[] : Array of GUIDs (preferred for restore). detail/list: not used. restore: alternative to record_id.
name_filter     : string   : Search by primary attribute value (contains, case-insensitive). list only. Empty = all deleted records of entity.
max_records     : int      : Max records. list: default 100, max 5000. detail/restore/status/turn: not used.
turn            : string   : Toggle direction for action='turn': 'on' to enable soft-delete, 'off' to disable. Required when action='turn'.
retention_days  : int      : Retention days for action='turn' turn='on'. Integer 1..30 inclusive. Default 30. Ignored for turn='off' or other actions.
name_prefix     : string   : restore only. Prefix prepended to the primary name of each restored record. Default '[RESTORE] '. Pass '' (empty string) to restore names unchanged.
```

# RESULTS

- Test 1: status reports soft-delete ON with 397 enabled tables and retention 21 days.
- Test 2: list with a non-matching name_filter is a success with 0 deleted records.
- Test 3: detail of a well-formed GUID not in the bin is a success with notFound=true and a notFoundHint pointing to manage_record read.
- Test 4: list with a name_filter returns the soft-deleted account created and deleted during setup, with modifiedOn, expiresOn, and canRestore=true.
- Test 5: list with max_records 20 returns the full bin (2 records at run time).
- Test 6: detail returns all 32 attributes of the soft-deleted record from the bin, including statecode, ownerid, and custom columns.
- Test 7-8: list validation errors — missing entity_name returns [Error]+[Hint]; unknown entity_name returns the resolver's [Error] with a [Hint] redirecting to get_tables.
- Test 9-11: detail validation errors — missing entity_name, missing record_id, and invalid GUID each return [Error]+[Hint].
- Test 12-15: restore validation errors — missing IDs, invalid GUID in record_ids, missing entity_name, and unknown entity_name each return [Error]+[Hint].
- Test 16-17: restore of a real record and a 2-GUID batch both fail at the Dataverse platform level (generic SQL error / Entity Id must be specified); the tool reports bulk [Failed] results with per-record reasons.
- Test 18-19: turn with an invalid value is rejected with valid values in the hint; turn on while already ON is rejected as a no-op with the current org state in the hint.
