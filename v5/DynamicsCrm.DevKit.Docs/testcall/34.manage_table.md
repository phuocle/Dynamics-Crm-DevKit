# ✅ TOOL DESCRIPTION

```text
Create or update a Dataverse table. Auto-detects create vs update from the inputs (no entity_name param).
- UPDATE (entity exists): logical_name + optional display_name, display_collection_name, description, is_audit_enabled, is_quick_create_enabled, is_search_enabled.
- CREATE (new table): display_name + display_collection_name + solution_name (resolves publisher prefix). Auto-creates primary name attribute.
Technical names come from logical_name / schema_name or are auto-derived from display_name.

WHEN TO USE:
- Create a new custom table, or update mutable metadata of an existing one

RELATED TOOLS:
- get_tables → discover entities
- manage_column → add columns
- manage_relationship → 1:N / N:N
- manage_form → forms
- publish_customizations → batch publish after multiple metadata changes
```

# PARAMETERS

```text
display_name                  : string : Singular display name (e.g. 'Project'). Required for CREATE.
display_collection_name       : string : Plural (e.g. 'Projects'). Required: create.
solution_name                 : string : Required: create.
description                   : string : Optional table description.
primary_attribute_name        : string : Auto-derived if omitted. [create-only]
primary_attribute_display_name: string : [create-only]
ownership_type                : string : 'User' or 'Organization'. [create-only, immutable]
table_type                    : string : 'Standard' or 'Elastic' (Cosmos DB, no charts). [create-only, immutable]
is_activity                   : bool   : Activity entity. [create-only, immutable]
has_notes                     : bool   : Enable notes. [create-only]
is_quick_create_enabled       : bool   : null = keep current (update).
is_audit_enabled              : bool   : null = keep current (update). Default true on create.
is_search_enabled             : bool   : Enable this table for Dataverse Search/Relevance Search (SyncToExternalSearchIndex). null = keep current on update; false by default on create unless specified.
primary_attribute_max_length  : int    : 1-850. [create-only]
schema_name                   : string : SchemaName for the new table (e.g. 'all_InOne' or 'all_In_One'). If provided, used AS-IS as SchemaName (skip auto-derive). Caller responsible for casing. Create only — ignored on update. Must start with the publisher prefix.
logical_name                  : string : Logical name for the new table (e.g. 'all_inone' or 'all_in_one'). If provided, used AS-IS as the lowercase logical name. Create only — ignored on update. Must start with the publisher prefix and be the lowercase form of schema_name.
```

# RESULTS

- Test 1: create auto-derives `all_TestMcpTable7`/`all_testmcptable7` from display_name, commits to solution all_in_one, and returns the full metadata block with `status: created`, `published: true`.
- Test 2: update changes DisplayName and IsAuditEnabled (2 changes) and returns the full metadata block plus 2 immutable-parameter warnings.
- Test 3: update with only logical_name returns `status: not_executed`, `published: false`.
- Test 4: is_search_enabled=false toggles SyncToExternalSearchIndex true → false and reports the change.
- Test 5: setting is_search_enabled to its current value is a no-change success (`status: not_executed`).
- Test 6: is_search_enabled=true toggles SyncToExternalSearchIndex false → true and reports the change.
- Test 7: a create-shaped input whose explicit schema_name/logical_name resolve to an existing table takes the UPDATE path and skips the anti-collision check.
- Test 8: updating label fields + is_audit_enabled applies only the 2 effective changes; fields that already match are not tracked.
- Test 9: re-creating a display_name whose derived logical name exists is blocked with a clear error and hint — no silent overwrite.
- Test 10-16: seven validation errors (unknown solution, invalid ownership_type, missing identifier, missing solution_name, unknown logical_name, wrong schema_name prefix, wrong logical_name prefix) all return `IsError: true` with message + hint.
- Test 17: dry-run preview of a create returns `metadataId: null`, `status: not_executed`, auto-derived `schemaName`/`logicalName`, and a `[DryRun] Would CREATE` summary; nothing is created or published.
- Test 18: dry-run preview of an update returns `status: not_executed`, the tracked `changes`, 2 immutable-parameter warnings, and a `[DryRun] Would UPDATE ... 1 change(s)` summary; nothing is changed or published.
