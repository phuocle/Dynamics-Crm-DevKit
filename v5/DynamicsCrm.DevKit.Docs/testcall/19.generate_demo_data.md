# TOOL DESCRIPTION

```text
Bogus-generated demo data for an entity → JSON file at .devkit/demo_data/ → pipe to create_records. from_date/to_date REQUIRED (ISO 8601, ask user, never infer). Auto-selects creatable fields with smart mapping (email→Email, telephone→Phone…) and overriddencreatedon. Lookups: real GUIDs auto-fetched; polymorphic uses 'field@entity'.

WHEN TO USE:
- Generate demo/test data for an entity → pipe to create_records
- Reproducible runs (fix seed); rotate lookups/enums via field_overrides 'in'
- Pin specific FK values across all rows via field_overrides 'eq'

RELATED TOOLS:
- create_records → import generated JSON into Dataverse
- get_tables → discover entity fields before generating
```

# PARAMETERS

```text
entity_name      : string : Entity logical name (e.g., 'account').
from_date        : string : ISO 8601, e.g. '2026-01-01'. NEVER infer — ask user.
to_date          : string : ISO 8601, e.g. '2026-04-30'. Must be >= from_date.
count            : int    : 1-500.
fields           : string : Comma-separated logical names. Empty = auto-select creatable.
seed             : int    : 0 = random; non-zero = reproducible.
field_overrides  : string : JSON array of {logicalname, operator, values[]}. Operators (see description). Example: [{"logicalname":"jobtitle","operator":"in","values":["CEO","CFO","CTO"]}].
```

# RESULTS

- Test 1: auto-select generates 65 creatable account fields and reports the lookup pools sampled (account, systemuser, team, contact, transactioncurrency).
- Test 2: all three shape overrides applied (`eq`, `endswith`, `contains`); two lookup warnings for solution entities with no active records still yield a success with `warnings` listed.
- Test 3: the remaining three operators (`startswith`, `regex`, `in` on an option set) applied with seed 99.
- Test 4: explicit `fields` restricts generation to exactly those 6 columns (no lookups sampled) — the clean shape for piping into create_records.
- Test 5: unknown entity returns a 3-part not-found error with a get_tables hint.
- Test 6: ambiguous Display Name `Product` returns the first-line error only, with the three candidates in `[Detail]` `entityMatches`.
- Test 7: to_date before from_date is rejected.
- Test 8: unparseable from_date returns an error with an ISO 8601 format hint.
- Test 9: missing dates return an error whose hint restates the never-infer, ask-the-user contract.
- Test 10: unknown override operator returns an error listing the six valid operators in the hint.
- Test 11: count above 500 is rejected.
