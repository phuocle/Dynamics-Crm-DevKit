# 21. manage_chart

# Tool description AI đọc được

```text
Name:        manage_chart
Title:       Manage Dataverse system charts
Idempotent:  false
Destructive: true
ReadOnly:    false

Description:
Manage Dataverse system charts (savedqueryvisualization). Actions: 'list', 'detail' (read-only) | 'create', 'update', 'rename', 'set_default', 'undo' (mutations). datadescription FetchXML is built from entity metadata — no view binding.

WHEN TO USE:
- List or inspect system charts of an entity
- Create a chart from group-by/aggregate columns, update chart type or columns, rename, set the entity default chart
- Restore a chart from a .chart.json backup written by update (undo)

RELATED TOOLS:
- get_tables → column logical names for group_by_column/aggregate_column
- publish_customizations → batch publish after multiple metadata changes
- manage_view → views; execute_webapi → raw savedqueryvisualization access

Omitted chart_type on create defaults to Pie (category=statecode, legend=importsequencenumber/count). Pie create first returns needs_confirmation without creating; re-call with confirmed=true after user approval. Multi-series: measures='col:agg[:label]; ...' (agg: count/countcolumn/sum/avg/min/max) defaults chart_type to Column and is mutually exclusive with aggregate_column. filter='field op value; ...' (ops: =, !=, >, >=, <, <=, like, in, null, not-null) filters chart data. Create with measures or filter also requires confirmed=true.

Parameters:
  action (string, required)
    'list', 'detail', 'create', 'update', 'rename', 'set_default', 'undo'.
  entity_name (string, default: "")
    Entity Display Name or logical name (e.g. 'Account' or 'account'). Required for list/create.
  chart_id (string, default: "")
    Chart GUID. Required for detail/update/rename/set_default/undo (unless chart_name uniquely identifies chart).
  chart_name (string, default: "")
    Chart name. Used for detail/update/rename lookup or create. Required for create.
  chart_type (string, default: "")
    OOB Chart Type: Column, Bar, Line, Pie, Doughnut, Funnel, Area, Bubble, Radar. Default: Pie when omitted on create.
  group_by_column (string, default: "")
    Category / group-by attribute logical name or display name. Pie default: statecode.
  aggregate_column (string, default: "")
    Legend / measure attribute logical name or display name. Pie default: importsequencenumber.
  aggregate_type (string, default: "count")
    Aggregation type: 'count' (default), 'sum', 'avg', 'min', 'max'.
  measures (string, default: "")
    Multi-measure series: 'column:aggregate_type[:label]; ...'. Mutually exclusive with aggregate_column/aggregate_type.
  filter (string, default: "")
    Structured datadescription filter: 'field op value; ...'. Operators: =, !=, >, >=, <, <=, like, in, null, not-null.
  presentationdescription (string, default: "")
    Custom presentation Chart XML override (create/update). For undo: path to the .chart.json backup file.
  description (string, default: "")
    Chart description text.
  solution_name (string, default: "")
    Optional solution unique/display name. When provided, chart is added to the solution after create/update.
  validate (bool, default: true)
    Validate XML syntax and chart types before saving.
  backup (bool, default: true)
    Backup before overwrite.
  publish (bool, default: true)
    Publish entity after create/update/rename/set_default/undo. Set false to batch-publish later.
  confirmed (bool, default: false)
    Pie create only: set true only after user approved the confirmation summary.
  workspace_folder (string, default: "")
    Optional project/workspace folder path to save backups in.
```

## Key behaviors observed

- **Needs-confirmation gate** hoạt động đúng cho Pie chart lần đầu (Test 2); defaults `chart_type=Pie`, `category=statecode`, `legend=importsequencenumber` được điền tự động, `defaultsApplied` list populated cho AI biết đã default gì.
- **Confirm gate** chỉ cần `confirmed=true` cho Pie create đơn giản (không có measures/filter). Khi có measures hoặc filter thì vẫn yêu cầu `confirmed=true` (per tool comment).
- **datadescription** XML cho Pie OOB ordering: aggregate attribute trước, groupby attribute sau; categorycollection không có `alias="groupby_column"` (đồng OOB pie samples).
- **presentationdescription** XML load từ Pie chart template + dynamic binding Series.Name = aggregate alias. Custom colors Palette giữ nguyên.
- **publish=true** (default) → tool gọi `PublishHelper.PublishEntity` + `MetadataOperationWaitHelper.WaitAfterFormView()` (5s) — visible vì Test 3 trả status `published: true` ngay.
- **publish=false** (Test 7) → không publish, backup file vẫn tạo (vì `backup=true` default), không có metadata fetch delay.
- **Soft-delete cleanup** cần ~5s async trước khi FetchXML return 0 (đồng gotcha đã lưu trong user memory).
- **Error paths**:
  - Pre-flight validation (`chart_name is required`, invalid GUID) → trả trước khi call Dataverse.
  - Dataverse fault (`0x80040217` "Does Not Exist") → bubble qua entry-point catch → `ThrowException` → `McpErrorResult` với `errorCode` đầy đủ, `stackTrace`, `kind: DataverseFault`.
