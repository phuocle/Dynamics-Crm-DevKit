# ✅ TOOL DESCRIPTION

```text
Manage Dataverse File and Image column data. Actions: 'info' (read-only) | 'upload', 'download', 'delete' (upload/delete are mutations).
- Upload always uses the SDK block protocol (4 MB blocks) — works for any size up to the column limit
- Image columns: only gif/jpeg/tiff/bmp/png; download returns the thumbnail by default, use full_size=true for the full-sized image (requires CanStoreFullImage)
- execute_webapi BLOCKS file/image endpoints (/$value, block-protocol actions, chunked PATCH) — always use this tool instead

WHEN TO USE:
- Inspect a file/image column value (file id, name, size, column limits)
- Upload a file from a local path, an http(s) URL (auto-downloaded), or base64 (< 1 MB)
- Download a file or image to local disk (.devkit/manage_record_file/{entity}/{record}/)
- Clear a file/image column value without deleting the record

RELATED TOOLS:
- get_tables → find File/Image columns of a table
- manage_record / search_records → find record_id
- manage_column → create file/image columns or raise MaxSizeInKB
```

# PARAMETERS

```text
action         : string : 'info', 'upload', 'download', 'delete'.
entity_name    : string : Table Display or logical name (Display Name resolved first). Required.
column_name    : string : File/Image column Display or logical name (Display Name resolved first). Required.
record_id      : string : GUID of the record. Required.
file_path      : string : upload: local file path or http(s) URL (auto-downloaded). Relative paths resolve against the workspace folder (auto-resolved from MCP roots or server cwd).
content_base64 : string : upload alternative: base64 content, files < 1 MB only. Requires file_name.
file_name      : string : upload: override file name. Required with content_base64; default = name from path/URL.
full_size      : bool   : download: image columns only. true = full-sized image (requires CanStoreFullImage); false = thumbnail. Default false.
```
