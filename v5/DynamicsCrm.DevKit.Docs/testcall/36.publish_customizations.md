# Tool description AI đọc được

```text
Name:        publish_customizations
Title:       Publish customizations to make changes visible
Idempotent:  true
Destructive: true
ReadOnly:    false

Description:
Publish Dataverse customizations. Pass at least one target (entities/optionset_names/dashboards/webresources/appmodules/include_ribbons/include_sitemap/include_global_optionset) for targeted PublishXml; pass nothing for PublishAll (async, org-wide lock).

WHEN TO USE:
- After metadata mutations with auto_publish=false, or when changes are not showing up
- Batch many changes then publish once at the end

RELATED TOOLS:
- get_system_jobs → track PublishAll async operation status
- get_tables / manage_app / manage_webresource → discover valid target identifiers
```
