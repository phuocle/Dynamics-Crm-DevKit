# 6. get_flows

# Tool description

```text
Power Automate cloud flows + run history. Modes: no flow_id = list (filtered); flow_id + action='list' = detail + last 5 runs; flow_id + action='runs' = extended run history. For classic (category=0) workflows use get_workflows.

WHEN TO USE:
- List flows by name/owner/status
- Inspect a specific flow + recent runs
- Drill into run history with status_filter (debug failures)

RELATED TOOLS:
- get_workflows → classic workflows (category=0)
- get_business_process_flows → BPF definitions + stages
- get_business_rules → client-side business rules
```

# Input tool call

**Test 1 — List mode: status=all (org không có active flow nào)**

```json
{
  "status": "all",
  "max_records": 20
}
```



# Kết quả

- **Regression phase 4:** `name_filter` (Test 3: "search" → đúng 2/3 flows) và `owner_filter` (Test 4: paging đầy đủ, không rơi record — trả đủ 3 flows owner SYSTEM).
- List mặc định `status='active'` trả 0 trong org này (tất cả flows là Draft, managed, owner SYSTEM) — `status='all'` trả đủ 3.
- Detail mode (Test 2) trả metadata đầy đủ hơn (createdOn/modifiedBy); flow Draft chưa chạy nên không có `runs` field (absent khi rỗng).
- Runs mode (Test 5) trả `runSummary` đủ 9 trạng thái kể cả khi 0 runs — Success, không phải error.
- Validation/error paths (Test 6, 7) đúng, `IsError: true`, có hint.
- Description khớp source hiện tại (`GetFlowsTool.cs`).
