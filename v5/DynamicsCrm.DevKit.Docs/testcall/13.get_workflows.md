# 13. get_workflows

# Tool description

```text
Classic workflows (background async + realtime sync) for a Dataverse entity. workflow_id empty = list; set = detail. Classic only — see RELATED TOOLS for modern alternatives.

WHEN TO USE:
- Check if a field triggers any workflow (trigger_field + entity_name)
- Find synchronous workflows (mode='realtime'; Pre-op can cancel/rollback)
- Inspect workflow triggers and execution metadata before refactoring/disabling

RELATED TOOLS:
- get_business_process_flows → BPF definitions + stages
- get_business_rules → client-side business rules
- get_flows → Power Automate cloud flows + run history
- get_system_jobs → workflow execution results (asyncoperation)
```

# Kết quả

- **Regression (trigger_field):** Test 3 filter `statecode` match đúng workflow có `triggerOnUpdateFields: "statecode,name"`; echo `triggerField` trong structured.
- List entry đủ: trigger flags (onCreate/onDelete/onUpdateFields), mode, scope, runAs, onDemand, subprocess, isTransacted, asyncAutoDelete, status/state, owner, modifiedBy/On; `summary` đếm background/onDemand/draft.
- Detail (Test 2) thêm `workflowIdUnique`, `isCustomizable`, `businessProcessType`, createdBy/createdOn.
- name_filter 1 match → auto-detail (Test 6), đúng mô tả "1 match → auto-detail".
- Workflow duy nhất trong org là Draft — list mặc định `status='active'` sẽ trả 0; phải dùng status='all'/'draft'.
- Error paths (Test 4, 5) `IsError: true`; message Test 5 nhắc đúng giới hạn category=0 (classic only).
- Description khớp source hiện tại (`GetWorkflowsTool.cs`).
