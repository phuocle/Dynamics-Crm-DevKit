# 5. manage_choice

# Tool description AI đọc được

```text
Name:        manage_choice
Title:       Manage global option sets (choices)
Idempotent:  false
Destructive: true
ReadOnly:    false

Description:
Manage GLOBAL option sets (choices). Actions: 'list', 'detail' (read-only) | 'create', 'update' (mutations). For local picklists → manage_column.

WHEN TO USE:
- Create a global choice with options, or update options (add/rename/remove/recolor), display name, description
- Inspect a global choice before binding it to a column

RELATED TOOLS:
- manage_column → local picklists; bind a global choice to a column
- get_tables → see which columns use a choice
- publish_customizations → batch publish after multiple metadata changes

solution_name is REQUIRED for create and label-only add_options — ask the user if missing, never guess. If needsWait=true, wait pollAfterSeconds before detail.

Parameters:
  action (string, required)
    'list', 'detail', 'create', 'update'.
  optionset_name (string, default: "")
    Logical or display name. Required: detail/update. Optional: create (auto-derived). Display Name matched first.
  display_name (string, default: "")
    Required: create. Optional: update (rename). For list, prefer filter=.
  filter (string, default: "")
    'list' only. Contains filter on logical+display name.
  description (string, default: "")
    Optional: create/update. Localized description.
  options (string, default: "")
    'create' only. 'Draft;Confirmed' (auto-value) or 'value:label'. solution_name required.
  add_options (string, default: "")
    'update' only. 'NewLabel' (needs solution_name) or 'value:label'. Existing labels skipped.
  update_options (string, default: "")
    'update' only. 'OldLabel:NewLabel;...' pairs.
  remove_options (string, default: "")
    'update' only. 'Label1,Label2'. IRREVERSIBLE.
  solution_name (string, default: "")
    Required: create + label-only add_options. Solution unique/display name.
  option_colors (string, default: "")
    Optional: create/update. 'Label:#RRGGBB;...' or 'value:#RRGGBB;...'.
```

## Key behaviors verified

- **Auto-derived optionset name:** `display_name="Test Choice Phase3"` → `all_testchoicephase3` (prefix `all_` + compacted name)
- **Auto-assigned option values:** label-only options get values starting at `prefix * 10000` (999990000, 999990001, ...)
- **Add existing label skipped:** if `add_options` contains a label that already exists, it's reported in `optionsAlreadyExisted` and skipped (no error)
- **Remove does not require publish:** Dataverse auto-publishes removed options (`needsWait=false`, `published=false`)
- **Metadata verification:** after every mutation, `VerifyChoiceUpdate()` reads back metadata to confirm changes propagated
- **needsWait + pollAfterSeconds:** after publish, tool returns `needsWait=true` with `pollAfterSeconds=15` and `nextAllowedActions=["manage_choice detail"]`
- **option_colors:** supports both label-keyed and value-keyed color assignment; colors applied during create or update
- **Prefix validation:** `optionset_name` must start with solution publisher prefix; otherwise error with auto-derived suggestion
- **solution_name required for create:** enforced at code level, not just description
