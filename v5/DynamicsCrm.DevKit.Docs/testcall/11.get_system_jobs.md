# 11. get_system_jobs

# Tool description

```text
List asynchronous system jobs or inspect one job with its diagnostic messages.

WHEN TO USE:
- Debug async failures (list failed → detail for message + friendlyMessage)
- Monitor bulk ops (operation_type='bulk_delete'/'import'/'solution')
- Trace one request (correlation_id across jobs)
- Async plugin failures: combine with get_plugin_trace_logs

RELATED TOOLS:
- get_plugin_trace_logs → plugin execution traces (sync + async)
- get_workflows → classic workflow definitions (background + realtime)
- get_flows → Power Automate cloud flows + run history
```

# Input tool call

**Test 1 — List mode: status=all trong 30 ngày (org không có failed job)**

```json
{
  "status": "all",
  "minutes_ago": 43200,
  "max_records": 5
}
```

**Test 2 — Detail mode: record_id**

```json
{
  "record_id": "9373f20b-a6fb-484d-8b6a-aad14d4453a0"
}
```

**Test 3 — List + operation_type=bulk_delete**

```json
{
  "status": "all",
  "operation_type": "bulk_delete",
  "minutes_ago": 43200,
  "max_records": 5
}
```

**Test 4 — Validation error: status không hợp lệ**

```json
{
  "status": "broken"
}
```

**Test 5 — Error: record_id không tồn tại**

```json
{
  "record_id": "00000000-0000-0000-0000-000000000001"
}
```

**Test 6 — Default status=failed, 0 kết quả (Success, không phải error)**

```json
{
  "minutes_ago": 43200,
  "max_records": 5
}
```

# Kết quả

- Org này không có failed system job nào trong 30 ngày (Test 6: default status=failed → 0, Success với echo `status`) — không có evidence cho detail failed job (message/friendlyMessage).
- List entries đủ: jobId, name, operationType, status/state, startedOn/completedOn, executionTime (format "94ms"/"8.4s"), correlationId, owner; `summary` phân loại (bulkDelete/other).
- Detail (Test 2) thêm createdOn, retryCount, depth; succeeded job không có message → Content text báo `Error: none. Message: none.`
- operation_type filter (Test 3) hoạt động, echo `operationType` ở root.
- Error paths (Test 4, 5) `IsError: true`, message liệt kê valid values.
- Description khớp source hiện tại (`GetSystemJobsTool.cs`).
