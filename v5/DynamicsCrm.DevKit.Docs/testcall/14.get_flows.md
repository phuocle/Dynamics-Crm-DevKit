# 14. get_flows

# Tool description AI đọc được

```
Name:        get_flows
Title:       List Power Automate cloud flows and run history
Idempotent:  true
Destructive: false
ReadOnly:    true

Description:
Power Automate cloud flows + run history. Modes: no flow_id = list (filtered); flow_id + action='list' = detail + last 5 runs; flow_id + action='runs' = extended run history. For classic (category=0) workflows use get_workflows.

WHEN TO USE:
- List flows by name/owner/status
- Inspect a specific flow + recent runs
- Drill into run history with status_filter (debug failures)

RELATED TOOLS:
- get_workflows → classic workflows (category=0)
- get_business_process_flows → BPF definitions + stages
- get_business_rules → client-side business rules

Fuzzy on name_filter / owner_filter: 0/multi → tool returns disambiguation list and stops; AI must ask user. 1 → auto.

Parameters:
  flow_id        (string, default: "")
    GUID. Empty = list. Set: action determines detail vs runs.
  action         (string, default: "list")
    'list' or 'runs'. 'runs' needs flow_id.
  name_filter    (string, default: "")
    list only. Name contains.
  owner_filter   (string, default: "")
    list only. Owner contains.
  status         (string, default: "active")
    'active' / 'draft' / 'suspended' / 'all'.
  status_filter  (string, default: "")
    runs only: succeeded/failed/running/cancelled/waiting/paused/skipped/suspended.
  minutes_ago    (int, default: 1440)
    runs only. Max 43200.
  max_records    (int, default: 50)
    1–250.
```

# Test calls

## 1. List mode — status=all, default filters

```
get_flows(status="all", max_records=10)
```

> Không truyền `flow_id` → list mode. `status=all` để liệt kê mọi cloud flow (active + draft + suspended). `max_records=10` giới hạn kết quả.

**Content (1 dòng):**

```
[Success] 3 flows found.
```

**Structured content:**

```json
{
  "totalCount": 3,
  "action": "list",
  "flows": [
    {
      "workflowId": "4ffa33c2-c12e-ed11-9db1-0022482aea7b",
      "name": "Integrated Search API trigger flow",
      "status": "Draft",
      "owner": "SYSTEM",
      "isManaged": true,
      "modifiedOn": "2025-10-09"
    },
    {
      "workflowId": "87023c69-962c-ec11-b6e6-000d3a574957",
      "name": "Search Dynamics 365 knowledge article flow",
      "status": "Draft",
      "owner": "SYSTEM",
      "isManaged": true,
      "modifiedOn": "2025-10-09"
    },
    {
      "workflowId": "ee2079d2-a93f-48b5-887a-c54ad830cbe5",
      "name": "SLAInstanceMonitoringWarningAndExpiryFlow",
      "status": "Draft",
      "owner": "SYSTEM",
      "isManaged": true,
      "modifiedOn": "2025-10-18"
    }
  ]
}
```

**IsError:** false

### Kết quả AI tổng hợp lại

- **Trạng thái:** Thành công. Org 🟢DEVKITV4 có 3 cloud flow (toàn Draft, managed, owner=SYSTEM).
- **totalCount:** 3 — tổng số flow trả về.
- **action:** `list` — chế độ danh sách.
- **flows[]:** mỗi entry chứa metadata tối thiểu cho list mode:
  - `workflowId` — GUID của flow.
  - `name` — tên flow.
  - `status` — `Draft` / `Active` / `Suspended`.
  - `owner` — tên owner (ẩn nếu null).
  - `isManaged` — `true` = managed solution, `false` = unmanaged.
  - `modifiedOn` — ngày sửa cuối (ẩn nếu null).
  - `description`, `uniqueName`, `createdOn`, `modifiedBy` — không trả trong list mode → tiết kiệm token.
- **Token tiết kiệm:** `description`, `uniqueName`, `createdOn`, `modifiedBy` ẩn trong list mode; `runs` và `runSummary` không trả trong list mode.
- **Cách dùng tiếp theo:** Truyền `flow_id` = một `workflowId` từ list + `action="list"` để xem detail đầy đủ, hoặc `action="runs"` để xem run history.

## 2. Detail mode — flow_id + action=list

```
get_flows(flow_id="ee2079d2-a93f-48b5-887a-c54ad830cbe5", action="list")
```

> Truyền `flow_id` + `action="list"` → detail mode: trả về đầy đủ thuộc tính flow + 5 runs gần nhất.

**Content (1 dòng):**

```
[Success] SLAInstanceMonitoringWarningAndExpiryFlow: detail + 0 recent runs.
```

**Structured content:**

```json
{
  "totalCount": 1,
  "action": "detail",
  "flows": [
    {
      "workflowId": "ee2079d2-a93f-48b5-887a-c54ad830cbe5",
      "name": "SLAInstanceMonitoringWarningAndExpiryFlow",
      "description": "It tracks and manage the SLA KPI instances and move them from InProgress to Warning/Failure time accordingly",
      "status": "Draft",
      "owner": "SYSTEM",
      "isManaged": true,
      "createdOn": "2025-10-09",
      "modifiedOn": "2025-10-18",
      "modifiedBy": "SYSTEM"
    }
  ]
}
```

**IsError:** false

### Kết quả AI tổng hợp lại

- **Trạng thái:** Thành công. Flow là SLA monitoring flow (managed, Draft, owner=SYSTEM).
- **totalCount:** 1 — chi tiết 1 flow.
- **action:** `detail` — chế độ chi tiết.
- **flows[0]:** đầy đủ thuộc tính:
  - `description` — mô tả flow (ẩn nếu null).
  - `createdOn` — ngày tạo (ẩn nếu null).
  - `modifiedBy` — người sửa cuối (ẩn nếu null).
  - `uniqueName` — ẩn vì null (flow managed không có unique name custom).
- **runs:** `null` (ẩn) — flow chưa có run nào.
- **Token tiết kiệm:** `uniqueName` ẩn khi null; `runs` ẩn khi 0 runs; `runSummary` không trả trong detail mode.
- **Cách dùng tiếp theo:** Dùng `action="runs"` với `flow_id` này để xem run history mở rộng (có filter status + time window).

## 3. Runs mode — flow_id + action=runs, 30 days

```
get_flows(flow_id="ee2079d2-a93f-48b5-887a-c54ad830cbe5", action="runs", minutes_ago=43200)
```

> Truyền `flow_id` + `action="runs"` → run history mode. `minutes_ago=43200` = 30 ngày. Không có `status_filter` → trả tất cả status.

**Content (1 dòng):**

```
[Success] SLAInstanceMonitoringWarningAndExpiryFlow (last 30d): 0 runs.
```

**Structured content:**

```json
{
  "totalCount": 0,
  "action": "runs",
  "runSummary": {
    "succeeded": 0,
    "failed": 0,
    "running": 0,
    "cancelled": 0,
    "waiting": 0,
    "paused": 0,
    "skipped": 0,
    "suspended": 0,
    "notSpecified": 0
  }
}
```

**IsError:** false

### Kết quả AI tổng hợp lại

- **Trạng thái:** Thành công. Flow không có run nào trong 30 ngày qua.
- **totalCount:** 0 — không có run.
- **action:** `runs` — chế độ run history.
- **runs:** `null` (ẩn) — 0 runs → ẩn hẳn thay vì `[]`.
- **runSummary:** tổng hợp theo status — toàn 0 vì không có run.
- **Token tiết kiệm:** `runs` ẩn khi 0 entries; `flows` không trả trong runs mode.
- **Cách dùng tiếp theo:** Nếu flow có runs, truyền `status_filter="failed"` để lọc chỉ runs thất bại để debug.
