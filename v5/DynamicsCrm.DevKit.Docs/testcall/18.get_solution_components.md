# 18. get_solution_components

# Tool description AI đọc được

```
Name:        get_solution_components
Title:        List all components inside a solution
Idempotent:  true
Destructive: false
ReadOnly:    true

Description:
List components in a Dataverse solution. Returns: solution info + count-per-type summary + detail (componentType, objectId, name). Full Entity components (rootComponentBehavior=0) listed as-is — use get_tables for sub-components.
WHEN TO USE:
- Audit solution contents before packaging/deploying
- Find objectIds for plugins, web resources, workflows
- Identify unmanaged customizations before importing managed solutions

FUZZY/AMBIGUITY:
- solution_name resolves Display Name contains first, then unique name contains. Ambiguity returns IsError=true with candidates.

RELATED TOOLS:
- get_tables → entity/attribute metadata for sub-components
- get_plugins → plugin assembly/type/step detail
- manage_webresource → web resource detail

Parameters:
  solution_name           (string, required)
    Solution unique/display name; multiple matches return choices.
  include_active_layers   (bool, default: false)
    Add ActiveLayer (Yes/No) via msdyn_componentlayer. Active = unmanaged customization exists.
  active_layers_only      (bool, default: false)
    Show only active-layer components; implies include_active_layers.
```

---

### Kết quả AI tổng hợp lại

- **Trạng thái:** Thành công. Solution `ALL-IN-ONE` (`all_in_one`) có 61 components trên org 🟢DEVKITV4.
- **solution:** thông tin solution: `solutionId`, `uniqueName`, `displayName`, `version`, `isManaged`, `publisherName`.
- **totalComponents:** 61 — tổng số component trong solution.
- **fullEntities:** 3 entity full (rootComponentBehavior=0): `all_in_one`, `all_in_one_clone`, `all_serversql`. Dùng `get_tables` để xem sub-components.
- **summary[i]:** mỗi entry có `type` (display name), `typeId` (componenttype int), `count` (số lượng).
- **components[i]:** mỗi entry có:
  - `type` — display name (Entity, Attribute, Web Resource, ...).
  - `typeId` — componenttype int value.
  - `objectId` — GUID của component.
  - `name` — tên resolved (hoặc `(unresolved)` nếu không resolve được).
  - `hasActiveLayer` — `Yes`/`No` (chỉ khi `include_active_layers=true`).
  - `isFullEntity` — `true` nếu entity full (rootComponentBehavior=0).
- **Token tiết kiệm:** `fullEntities`, `summary`, `components` ẩn khi rỗng. `activeLayerCount` ẩn khi không dùng active layers.
- **Cách dùng tiếp theo:** Dùng `get_tables(entity_name='all_in_one')` để xem sub-components của entity full.

## 4. Validation error — missing solution_name

```
get_solution_components(solution_name="")
```

> `solution_name` rỗng → validation error.

**Content:**

```
[Error] solution_name is required.
Hint: Provide the solution uniqueName (e.g. 'DevKit_Core') or displayName (e.g. 'DevKit Core').
```

**Structured content:**

```json
{
  "error": "solution_name is required.",
  "hint": "Provide the solution uniqueName (e.g. 'DevKit_Core') or displayName (e.g. 'DevKit Core')."
}
```

**IsError:** true

### Kết quả AI tổng hợp lại

- **Trạng thái:** Lỗi validation. `solution_name` bắt buộc.
- **Cách xử lý:** Re-call với `solution_name` = uniqueName hoặc displayName.
