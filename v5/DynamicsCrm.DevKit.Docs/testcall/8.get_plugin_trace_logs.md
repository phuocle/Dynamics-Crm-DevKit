# 8. get_plugin_trace_logs

# Tool description

```text
List recent plugin trace logs or inspect one trace with diagnostic details.

WHEN TO USE:
- Diagnose synchronous or asynchronous plugin execution
- Correlate traces by entity, message, plugin type, or request ID

RELATED TOOLS:
- get_plugins → plugin registrations and steps
- get_system_jobs → asynchronous job failures
```

# Kết quả

- List entries đầy đủ: typeName (full assembly-qualified), messageName, mode, durationMs, correlationId, pluginStepId, requestId, createdOn. Đủ để correlate (Test 4 dùng correlationId lọc đúng 1 trace).
- Detail mode (Test 3) thêm `messageBlock`/`exceptionDetails` khi có; Content text báo `Trace: available. Exception: none.` — messageBlock của plugin test này là blob nhiều KB nên không nhúng nguyên văn (đã verify trực tiếp).
- Filters entity+message (Test 2) hoạt động; echo `entityName` trong structured.
- 0 kết quả (Test 7) là Success với `timeScope` format `last 1d`; error paths (Test 5, 6) `IsError: true` đúng.
- Description khớp source hiện tại (`GetPluginTraceLogsTool.cs`).
