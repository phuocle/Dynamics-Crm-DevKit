# 28. manage_record

# Tool description AI đọc được

```text
Name:        manage_record
Title:       Manage a single record (CRUD)
Idempotent:  false
Destructive: true
ReadOnly:    false

Description:
CRUD a single Dataverse record. Actions: 'read' (read-only) | 'create', 'update', 'delete' (IRREVERSIBLE), 'associate', 'disassociate' (mutations). Record changes are live immediately — no publish needed.

WHEN TO USE:
- Create / read / update / delete a single record by GUID
- Partial-update specific fields without rewriting whole record
- Associate/disassociate two records via an N:N relationship
- Verify a record before destructive changes

RELATED TOOLS:
- get_tables → entity/attribute names before building fields_json
- execute_fetchxml → find lookup GUIDs and record_id
- create_records → bulk create multiple records
- execute_webapi → raw OData JSON/annotations
```
