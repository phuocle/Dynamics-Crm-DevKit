# 7. parse_record_url

# Tool description AI đọc được

```
Name:        parse_record_url
Title:       Parse a Dynamics 365 URL to entity and record ID
Idempotent:  true
Destructive: false
ReadOnly:    true

Description:
Parse a Dataverse/Power Platform URL or raw GUID → entity logical name + record ID.
Supports main.aspx, Web API, maker portal, legacy URLs.
EntityName='(unknown)' = GUID only; ask user for entity.
Call FIRST when user pastes a URL.

Parameters:
  input (string, required)
    URL, GUID, or text. URL-decoded automatically; first matching parser wins.
```

# Input tool call

```json
{
  "name": "parse_record_url",
  "arguments": {
    "input": "https://dynamics-crm-devkit-v4.crm.dynamics.com/main.aspx?appid=babc41e2-3271-f111-ab0e-0022480a530f&forceUCI=1&pagetype=entityrecord&etn=account&id=97f939f8-4e40-f111-bec6-70a8a59a451e"
  }
}
```

> URL là tab Account record trong model-driven app `Account: Green, King and Labadie` trên org DEVKITV4. Chứa cả `appid`, `forceUCI=1`, `pagetype=entityrecord`, `etn=account` và `id=` GUID. Các parser khác (`forceUCI`, `appid`) bị bỏ qua — priority 1 `main.aspx` thắng.

# Output tool call

**Content (1 line, plain text):**

```
[Success] account 97f939f8-4e40-f111-bec6-70a8a59a451e (main.aspx (etn+id)).
```

**Structured content (JSON):**

```json
{
  "entityName": "account",
  "recordId": "97f939f8-4e40-f111-bec6-70a8a59a451e",
  "source": "main.aspx (etn+id)"
}
```

**IsError:** `false`

# Kết quả AI tổng hợp lại

- **Trạng thái:** Thành công (`[Success]`, `IsError=false`).
- **Entity:** `account` — lấy từ query string `etn=account`, đã `ToLowerInvariant()` để thành logical name chuẩn.
- **Record ID:** `97f939f8-4e40-f111-bec6-70a8a59a451e` (chuẩn hoá thành lowercase, bỏ `{ }` nếu có).
- **Source:** `main.aspx (etn+id)` — parser priority 1 khớp vì URL chứa `main.aspx` + `pagetype=entityrecord` + cả `etn` lẫn `id`. Các key khác (`appid`, `forceUCI`) bị bỏ qua, không ảnh hưởng kết quả.
- **Chuỗi chain gợi ý:** dùng `entityName` + `recordId` ở trên làm input cho `manage_record(action='read', entity_name='account', record_id='97f939f8-4e40-f111-bec6-70a8a59a451e')` hoặc `execute_fetchxml` filter `accountid eq '97f939f8-4e40-f111-bec6-70a8a59a451e'`.
- **Token tiết kiệm:** property `environmentId`, `flowId`, `tip` đều `null` → bị `WhenWritingNull` ẩn khỏi JSON, không phình payload khi không cần.

## Ví dụ phụ: input rỗng → error path

**Input:**

```json
{
  "name": "parse_record_url",
  "arguments": { "input": "   " }
}
```

**Content:**

```
[Error] input is required.
Hint: Provide a Dynamics 365 URL, Web API URL, maker portal URL, or raw GUID.
```

**Structured content:**

```json
{
  "error": "[Error] input is required.",
  "hint": "Provide a Dynamics 365 URL, Web API URL, maker portal URL, or raw GUID."
}
```

**IsError:** `true`

> Convention: error prefix `[Error]` đối xứng với `[Success]` của happy path; `hint` được tách riêng (tham số thứ 2 của `Error()`) để AI client có thể đọc mà không cần parse text.
