# 7. parse_record_url

# Tool description AI đọc được

```
Name:        parse_record_url
Title:       Parse a Dynamics 365 URL to entity and record ID
Idempotent:  true
Destructive: false
ReadOnly:    true

Description:
Parse a Dataverse/Power Platform URL or raw GUID into record and environment identifiers.

WHEN TO USE:
- Call first when the user pastes a model-driven app, Web API, maker, admin, or legacy URL
- Extract a GUID while preserving its URL context

RELATED TOOLS:
- manage_record → read or change a parsed record
- get_tables → resolve or verify an unknown entity logical name

Parameters:
  input (string, required)
    URL, GUID, or text. URL-decoded automatically; first matching parser wins.
```

## Test 4 — Maker URL với ID malformed (regression case phase 4: `Guid.TryParse`)


# Kết quả AI tổng hợp lại

- **Build dưới test:** CLI `4.44.44.44` build `07.08.2026 17:09:27`, assembly SHA256 `D10BF74C…3C66`.
- **Test 1 (main.aspx):** parse đúng `etn` + `id` → `account` / record GUID; `appid` không lọt vào output (chỉ lấy entity + record).
- **Test 2 (Web API resolved):** `accounts` → `entityName=account`, `entitySetName=accounts` (cả hai cùng xuất hiện), source ghi rõ `(resolved)`.

- **Test 5 (raw GUID):** chấp nhận GUID trần, `entityName="(unknown)"` + tip gợi ý cung cấp entity.
- **Test 6 (no GUID):** error sạch với hint actionable, `IsError=true`.
