# ✅ TOOL DESCRIPTION

```text
Run a FetchXML query in single-page or bounded auto-paging mode.

WHEN TO USE:
- Query Dataverse records with deterministic columns, filters, joins, or aggregates
- Page through a bounded result after validating logical names

RELATED TOOLS:
- get_tables → discover entity and attribute logical names
- search_records → keyword relevance search
- schema://fetchxml → FetchXML syntax and examples
```

# PARAMETERS

```text
fetchxml    : string : FetchXML starting with <fetch>. Lowercase logical names.
max_records : int    : 1-5000. Default 5000. Use 10-100 for samples.
get_all     : bool   : true = auto-page until max_records. false = first page only.
```

# TEST 3

## INPUT

Paging attribute `top` on the opening `<fetch>` is rejected — the tool owns paging.

```json
{
  "fetchxml": "<fetch top='5'><entity name='account'><attribute name='name'/></entity></fetch>"
}
```

## OUTPUT

```text
[Error] Do not set top, count, page, or paging-cookie in <fetch>.
[Hint] Use max_records and get_all; the tool owns paging attributes.
```

## RESULT

```json
{ "IsError": true }
```

# RESULTS

- Test 1: single page returns 3 account records ordered by name, `hasMore=true`; each record carries `_entity`/`_id` metadata plus the requested columns.
- Test 2: malformed XML returns a clean validation error with a hint to `schema://fetchxml` — no raw `XmlException` bubbles up.
- Test 3: paging attributes (`top`, `count`, `page`, `paging-cookie`) on `<fetch>` are rejected with a hint to use `max_records`/`get_all`.
- Test 4: non-existent entity returns an error whose hint folds in the raw Dataverse `0x80041102` fault (the entity name checked plus MetadataCache diagnostics).
- Test 5: non-existent attribute returns an error whose hint points to `get_tables` and folds in the raw `0x80041103` fault naming the missing field.
- Test 6: unknown condition operator returns an error with a hint to the FetchXML `condition operator values` reference (`0x80041120` folded in).
- Test 7: empty `<fetch></fetch>` (no `<entity>`) returns an error with a hint to `schema://fetchxml` (`0x80040203` folded in).
- Test 8: empty `fetchxml` returns a required-parameter validation error with a hint to `schema://fetchxml`.
- Test 9: `max_records=0` returns a range validation error with a hint to pass 1-5000.
