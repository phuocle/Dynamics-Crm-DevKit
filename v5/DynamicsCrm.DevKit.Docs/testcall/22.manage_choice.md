# TOOL DESCRIPTION

```text
Manage GLOBAL option sets (choices). Actions: 'list', 'detail' (read-only) | 'create', 'update' (mutations). For local picklists → manage_column. solution_name is REQUIRED for create and label-only add_options — ask the user if missing, never guess. If needsWait=true, wait pollAfterSeconds before detail.

WHEN TO USE:
- Create a global choice with options, or update options (add/rename/remove/recolor), display name, description
- Inspect a global choice before binding it to a column

RELATED TOOLS:
- manage_column → local picklists; bind a global choice to a column
- get_tables → see which columns use a choice
- publish_customizations → batch publish after multiple metadata changes
```

# PARAMETERS

```text
action          : string : 'list', 'detail', 'create', 'update'.
optionset_name  : string : Logical or display name. Required: detail/update. Optional: create (auto-derived). Display Name matched first.
display_name    : string : Required: create. Optional: update (rename). For list, prefer filter=.
filter          : string : 'list' only. Contains filter on logical+display name.
description     : string : Optional: create/update. Localized description.
options         : string : 'create' only. 'Draft;Confirmed' (auto-value) or 'value:label'. solution_name required.
add_options     : string : 'update' only. 'NewLabel' (needs solution_name) or 'value:label'. Existing labels skipped.
update_options  : string : 'update' only. 'OldLabel:NewLabel;...' pairs.
remove_options  : string : 'update' only. 'Label1,Label2'. IRREVERSIBLE.
solution_name   : string : Required: create + label-only add_options. Solution unique/display name.
option_colors   : string : Optional: create/update. 'Label:#RRGGBB;...' or 'value:#RRGGBB;...'.
```
