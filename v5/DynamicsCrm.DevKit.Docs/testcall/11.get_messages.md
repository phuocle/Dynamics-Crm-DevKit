# 11. get_messages

# Tool description AI đọc được

```
Name:        get_messages
Title:       List SDK messages and custom actions
Idempotent:  true
Destructive: false
ReadOnly:    true

Description:
SDK messages + legacy Custom Actions (workflow-based, category=3). message_name empty = list; set = detail (params, plugin steps).
Modern Custom APIs excluded → get_custom_apis.
entity_name='none' = global messages.

WHEN TO USE:
- Discover available SDK messages for an entity before writing plugin registration
- Inspect a legacy Custom Action's input/output parameters from XAML
- Check plugin step count registered on a specific message

RELATED TOOLS:
- get_custom_apis → modern Custom API definitions (replaces Custom Actions)
- get_plugins → plugin assemblies/types/steps registered on these messages
- get_workflows → classic workflow definitions (background + realtime)

Parameters:
  entity_name             (string, default: "none")
    Entity Display/logical name. 'none'/empty = global. Ignored in detail mode.
  message_name            (string, default: "")
    Message/Action name → detail mode. Empty = list mode.
  include_custom_actions  (bool, default: true)
    List: include Custom Actions. false = SDK only. Ignored in detail mode.
```
