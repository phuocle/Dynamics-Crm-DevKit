# TOOL DESCRIPTION

```text
Dataverse entity metadata. entity_name empty = list; set = detail (attributes, relationships, alternate keys).

WHEN TO USE:
- Discover entity/attribute names before building FetchXML or calling other tools
- Find join columns, picklist options, required fields, primary key, lookup targets
- Clone or copy a column (detail_level='full' required — compact/standard lack clone metadata)
- AI MUST use get_tables for entity/attribute metadata — do NOT use execute_webapi with EntityDefinitions

RELATED TOOLS:
- manage_column → create/update columns (pass formula_definition unchanged from full mode)
- manage_table → create/update tables
- manage_relationship → create/update relationships
- execute_fetchxml → query data once you know attribute names
```

# PARAMETERS

```text
entity_name      : string : Logical name → detail mode. Empty = list mode.
filter           : string : LIST: keyword filter on entity. DETAIL: single value = prefix match on logical names; comma/pipe/semicolon-separated = word-boundary match on logical name + exact match on display name.
custom_only      : bool   : LIST: only custom entities.
include_intersect: bool   : LIST: include N:N intersect entities.
names            : string : LIST: comma-separated logical names. Overrides filter/custom_only.
detail_level     : string : DETAIL: 'compact' (default), 'standard', or 'full'.
max_records      : int    : LIST: maximum 1-500 entities. Default 100.
```
