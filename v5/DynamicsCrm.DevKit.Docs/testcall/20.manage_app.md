# Tool description AI đọc được

```text
Name:        manage_app
Title:       Manage model-driven apps
Idempotent:  true
Destructive: true
ReadOnly:    false

Description:
Model-driven app management. Actions: list, detail, create, update, update_navigation, validate, undo.

WHEN TO USE:
- List/inspect model-driven apps, create or update app metadata (name, description, icon)
- Apply app-scoped sitemap navigation operations (add_area/add_group/add_item), validate an app, or restore from a .app.json backup (undo)

RELATED TOOLS:
- get_solution_components → solution names for create
- publish_customizations → publish after create/update
- execute_webapi → blocked for appmodule/sitemap/appmodulecomponent; use this tool instead

Pass the current workspace directory to workspace_folder so backups land in the user's project. See docs://instructions_for_manage_app for the operation workflow and examples.

Parameters:
  action (string, default: "detail")
    'list', 'detail', 'create', 'update', 'update_navigation', 'validate', or 'undo'.
  app (string, default: "")
    App display name, unique name, or GUID. Required for detail/update/update_navigation/validate/undo.
  app_name (string, default: "")
    list only. App display/unique name contains filter.
  solution_name (string, default: "")
    Required for create. Used to resolve the solution publisher prefix.
  display_name (string, default: "")
    Required for create. Optional for update.
  unique_name (string, default: "")
    Optional for create. If empty, derived from display_name and solution publisher prefix.
  description (string, default: "")
    Optional for create/update.
  icon_webresource (string, default: "")
    Optional app icon web resource name or GUID.
  operations (string, default: "")
    JSON array for update_navigation, or backup file path for undo.
  backup (bool, default: true)
    Backup current app snapshot before update/update_navigation/undo when implemented.
  workspace_folder (string, default: "")
    Optional project/workspace folder path to save backups in.
  max_records (number, default: 100)
    list only. 1-500.
```
