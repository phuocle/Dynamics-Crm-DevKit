# TOOL DESCRIPTION

```text
List, inspect, create, update, and validate model-driven apps, edit app sitemap navigation, or restore an app from a .app.json backup.

WHEN TO USE:
- List/inspect model-driven apps, or create/update app metadata (name, description, icon)
- Apply app-scoped sitemap navigation operations (add_area/add_group/add_item), validate an app, or restore from a .app.json backup (undo)
- App is resolved by Display Name first, then unique name/GUID; ambiguous Display Names return the candidates

RELATED TOOLS:
- get_solution_components → solution names for create
- publish_customizations → publish other components (manage_app mutations auto-publish the app)
- execute_webapi → blocked for appmodule/sitemap/appmodulecomponent; use this tool instead
```

# PARAMETERS

```text
action            : string : 'list', 'detail', 'create', 'update', 'update_navigation', 'validate', or 'undo'. Default detail.
app               : string : App display name, unique name, or GUID. Required for detail/update/update_navigation/validate/undo.
app_name          : string : list only. App display/unique name contains filter.
solution_name     : string : Required for create. Used to resolve the solution publisher prefix.
display_name      : string : Required for create. Optional for update.
unique_name       : string : Optional for create. The solution publisher prefix is always prepended (e.g. 'MyApp' with solution all_in_one becomes 'all_MyApp'). If empty, derived from display_name.
description       : string : Optional for create/update.
icon_webresource  : string : Optional app icon web resource name or GUID.
operations        : string : JSON array for update_navigation, or backup file path for undo.
backup            : bool   : Backup current app snapshot before update/update_navigation/undo when implemented. Default true.
workspace_folder  : string : Optional project/workspace folder path to save backups in.
max_records       : int    : list only. 1-500. Default 100.
```
