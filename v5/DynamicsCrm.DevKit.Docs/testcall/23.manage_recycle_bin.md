# 23. manage_recycle_bin

# Tool description AI đọc được

```
Name:        manage_recycle_bin
Title:       List, preview and bulk-configure per-table soft-delete (Recycle Bin) settings
Idempotent:  false
Destructive: false
ReadOnly:    false

Description:
List / preview / set per-table soft-delete (Recycle Bin) configuration. Backed by the
recyclebinconfig entity — one row per (org, table) plus a special name='organization' row that
holds the org default cleanupintervalindays (1-30). isreadyforrecyclebin is the per-table
readiness flag. cleanupintervalindays=-1 means inherit from the org row.

ACTIONS:
  list_tables — paginated list of tables + their current soft-delete state (default 10/page, A-Z
                by recyclebinconfigid, supports entity_filter prefix match). When the result is
                truncated, the response text ends with '... còn N tables nữa. Nói show page 2
                để xem tiếp.' style note.
  preview     — interpret a free-form user intent (e.g. 'soft delete cho tất cả trừ Account,
                Contact') into a {enable, disable, skip} plan WITHOUT applying. Rule-based
                parser: tất cả trừ X → enable=ALL\skip=X; chỉ X → enable=X, disable=REST; tắt X
                → disable=X; bật X → enable=X.
  set         — enable/disable soft-delete for 1+ tables in parallel (Parallel.ForEachAsync +
                UpdateAsync, same pattern as create_records). Returns succeeded/failed counts +
                per-item status. dry_run=true by default.
  status      — org-level summary: org row cleanupintervalindays + isreadyforrecyclebin + per-
                table enabled count.

Parameters:
  action               (string, default: "list_tables")
    Action: 'list_tables' (default) | 'preview' | 'set' | 'status'.
  entity_filter        (string, default: "")
    list_tables: filter by name (contains, case-insensitive). preview: free-form intent. set:
    not used.
  include_system       (bool, default: false)
    list_tables: include system tables (default false; only_custom takes precedence).
  only_custom          (bool, default: false)
    list_tables: show only custom tables (default false).
  page                 (int, default: 1)
    list_tables: 1-based page number (default 1).
  page_size            (int, default: 10)
    list_tables: rows per page (default 10, max 100).
  enable               (string[], default: null)
    set: list of entity logical/display names to enable soft-delete.
  disable              (string[], default: null)
    set: list of entity logical/display names to disable soft-delete.
  cleanup_interval_days (int?, default: null)
    set: optional cleanupintervalindays (1-30). When set, also updates the org row. -1 = inherit.
  max_parallelism      (int, default: 0)
    set: 0 = server hint (RecommendedDegreesOfParallelism). Clamped 1-52.
  dry_run              (bool, default: true)
    set: false to actually apply. Default true (safe preview).

RELATED: manage_deleted_records (bin operations), manage_record (live CRUD), execute_webapi (raw).
```

# Ví dụ 1: list_tables (default page=1, page_size=10)

User: _"Cho tôi xem các table đang bật soft delete"_

```json
  "arguments": {
    "action": "list_tables"
  }
```

```json
    "action": "status"
  }
}
```

## Output (text)

```text
[Success] Soft-delete supported. Org interval: -1 day(s). Enabled tables: 381.
```

**IsError:** `false`

> `cleanupintervalindays=-1` cho org row nghĩa là "chưa override" → mỗi per-table dùng default 30 ngày từ Microsoft hard cap. `Enabled tables: 381` = `count(recyclebinconfig where statecode=0 AND isreadyforrecyclebin=true AND name!='organization')`. Trên org thật, tổng `382` rows trong table = 381 per-table + 1 org row.

# Lưu ý quan trọng

- **`recyclebinconfig.name` ≠ entity logical name** cho activity tables — Dataverse set tất cả activity rows có cùng `name='activityparty'`. Tool resolve qua `extensionofrecordid` (MetadataId) → `RetrieveEntityRequest by MetadataId` để lấy đúng logical name.
- **Microsoft không cho phép soft-delete trên system tables** (entity, organization, systemuser, businessunit, solution, plugin, workflow, v.v.). Tool sẽ trả error khi user cố `enable=['entity']`. Probe L trong `Dev.AllInOne.Console` skip 30 attempts trước khi từ bỏ.
- **Pagination bắt buộc** vì 1 org có thể có 5000+ tables. Default 10/page, max 100/page. Khi `truncated=true` → text kết thúc bằng "... còn N tables nữa. Nói show page 2 để xem tiếp."
- **Tool phụ trách config** (turn on/off + retention interval). **KHÔNG** phụ trách bin operations (list deleted records, restore, detail) — đó là scope của `manage_deleted_records` (action: list/detail/restore).
- **Không touch system tables mặc định**: `include_system=false` skip các tables thuộc danh sách Microsoft-blocked. Dùng `entity_filter` để narrow trước.
- **`Parallel.ForEachAsync` + UpdateAsync** pattern (giống `create_records`), không dùng `ExecuteMultiple`. Mỗi row update độc lập, fail 1 row không ảnh hưởng các row khác.
- **`dry_run=true` mặc định** cho action `set`. User phải explicit set `dry_run=false` để apply — an toàn cho thao tác trên nhiều tables.
- **Org row cleanup_interval_days**: nếu set, tool sẽ update cả org row. Nếu KHÔNG set, per-table rows giữ nguyên giá trị hiện tại, org row không bị touch.
