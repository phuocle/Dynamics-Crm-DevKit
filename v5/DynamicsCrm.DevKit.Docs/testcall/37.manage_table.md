# 37. manage_table

# Tool description AI đọc được

```
Create or update a Dataverse table. Auto-detects create vs update from the inputs (no entity_name param).
- UPDATE (entity exists): logical_name + optional display_name, display_collection_name, description, is_audit_enabled, is_quick_create_enabled, is_search_enabled.
- CREATE (new table): display_name + display_collection_name + solution_name (resolves publisher prefix). Auto-creates primary name attribute.
Technical names come from logical_name / schema_name or are auto-derived from display_name.

WHEN TO USE: create a new custom table, or update mutable metadata of an existing one. RELATED TOOLS: get_tables (discover entities), manage_column (add columns), manage_relationship (1:N / N:N), manage_form (forms), publish_customizations (batch publish).
```

Input schema params: `display_name`, `display_collection_name`, `solution_name`, `confirmed_prefix`, `description`, `primary_attribute_name`, `primary_attribute_display_name`, `ownership_type` (default "User"), `table_type` (default "Standard"), `is_activity`, `has_notes`, `is_quick_create_enabled`, `is_audit_enabled`, `is_search_enabled`, `primary_attribute_max_length` (default 100), `schema_name`, `logical_name`.

# Kết quả AI tổng hợp

- **Refactor refactor3**: 1 try-catch entry → `ThrowException(ex)`, helper `CreateNewEntity`/`UpdateExistingEntity` không try-catch. `ErrorResult` wrapper xóa, gọi thẳng `Error(msg, hint)` từ `McpToolBase`. `Success(...)` / `DryRun(...)` factory thay StringBuilder multi-line + raw `CallToolResult`. Tất cả `Tip:` → `hint` parameter (rule 18). Literal prefix `[Success]`/`[Error]`/`Hint:` xóa khỏi source (rule 10). `dry_run` check thêm trước `CreateEntityRequest`/`UpdateEntityRequest` (rule 11). Publish/RetrieveEntity swallow try-catch bỏ — fail lan ra entry catch (rule 16).
- **Anti-collision (Test 2)**: khi `logical_name` không được truyền và derived name đã tồn tại → Error block, không silent overwrite. Khi `logical_name` truyền explicit → resolve entity → UPDATE path, skip anti-collision (Test 17) — đúng semantic.
- **Prefix validation (Test 9, 14, 15)**: `confirmed_prefix` mismatch, `schema_name` sai prefix, `logical_name` sai prefix — tất cả block trước khi gọi Dataverse, error message rõ ràng + Hint.
- **Immutable warnings (Test 3–7)**: `ownership_type`, `table_type`, `is_activity`, `has_notes`, `primary_attribute_name`, `primary_attribute_display_name` — truyền trên UPDATE → warning, không crash, không change. Đúng behavior.
- **is_search_enabled toggle (Test 5–7)**: `SyncToExternalSearchIndex` toggle on/off hoạt động đúng khi `CanEnableSyncToExternalSearchIndex=true`. No-change khi giá trị trùng current. Quan sát quan trọng: Datverse tự động bật `SyncToExternalSearchIndex=true` cho table mới tạo bất kể create request set `false` — AI debug cần nhớ fact này.
- **Bug fix (Test 18)**: Trước fix, UPDATE trả `displayName=""`, `displayCollectionName=""`, `description=""` trong structured content do `new Label(string, int)` không set `UserLocalizedLabel` (chỉ server mới set field đó khi retrieve). Fix: track `effectiveDisplayName`/`effectiveDisplayCollectionName`/`effectiveDescription` local variables, dùng cho cả 3 structured blocks (updated, no-change, dry-run).
