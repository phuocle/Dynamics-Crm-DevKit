# TOOL DESCRIPTION

```text
List components in a Dataverse solution. Returns: solution info + count-per-type summary + detail (componentType, objectId, name). Full Entity components (rootComponentBehavior=0) listed as-is — use get_tables for sub-components. solution_name resolves Display Name contains first, then unique name contains; ambiguity returns IsError=true with candidates.

WHEN TO USE:
- Audit solution contents before packaging/deploying
- Find objectIds for plugins, web resources, workflows
- Identify unmanaged customizations before importing managed solutions

RELATED TOOLS:
- get_tables → entity/attribute metadata for sub-components
- get_plugins → plugin assembly/type/step detail
- manage_webresource → web resource detail
```

# PARAMETERS

```text
solution_name         : string : Solution unique/display name; multiple matches return choices.
include_active_layers : bool   : Add ActiveLayer (Yes/No) via msdyn_componentlayer. Active = unmanaged customization exists.
active_layers_only    : bool   : Show only active-layer components; implies include_active_layers.
```

# RESULTS

- Test 1: happy path returns solution info, count-per-type summary, and component detail.
- Test 2: include_active_layers=true adds activeLayerCount to summary, hasActiveLayer to components, and reports the count in the summary line.
- Test 3: active_layers_only=true implies include_active_layers and filters to active-layer components.
- Test 4: ambiguous solution_name returns IsError true; the candidate list travels only in the [Detail]/structured solutionMatches, keeping the text a clean 3-part single-line-per-part block.
- Test 5: an exact single display-name match auto-resolves (no ambiguity); full Entity components are flagged isFullEntity and listed in fullEntities; unknown component types resolve as (unresolved).
- Test 6: hidden solutions (isvisible=false) are not resolvable by design — returns NotFound, IsError true.
- Test 7: empty solution_name returns a validation error with a hint showing uniqueName/displayName examples, IsError true.
