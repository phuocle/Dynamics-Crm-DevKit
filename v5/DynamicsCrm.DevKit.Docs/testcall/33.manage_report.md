✅ # TOOL DESCRIPTION

```text
Manage Dataverse SSRS reports (report entity). Actions: 'list', 'detail', 'create', 'download', 'update', 'delete', 'add_dataset', 'update_dataset'.
- list/detail are read-only; create/download/update/delete are mutations
- create: provide file_path to an .rdl file, or omit it to use the embedded ReportTemplate.rdl (single source of truth); the embedded template is normalized for the connected organization and language defaults to the organization's base language
- create uploads the report, then downloads its bodytext to .devkit/manage_report/downloads/{languageCode}/ as {report}.rdl; existing Dataverse reports and local output files fail fast
- download writes bodytext to .devkit/manage_report/downloads/{languageCode}/ as {report}.rdl and returns the saved path and SHA-256
- update replaces bodytext (.rdl content) and/or description; reports need no publish after update
- add_dataset/update_dataset require file_path, modify only the local RDL, and create a pre-change backup under .devkit/manage_report/backups
- managed reports (isManaged=true) cannot be created/updated/deleted

WHEN TO USE:
- List or inspect reports of the organization or of a solution (solution component type 31)
- Create a new report from a local .rdl file or from the built-in template
- Download a report definition (.rdl) to local disk for editing
- Deploy an updated .rdl back to an existing report, or delete an unmanaged report
- Add or update a simple local RDL dataset before designing it in SSRS

RELATED TOOLS:
- get_solution_components → find valid solution names and report components
- execute_fetchxml → query report records directly
```

# PARAMETERS

```text
action         : string : 'list', 'detail', 'create', 'download', 'update', 'delete', 'add_dataset', 'update_dataset'.
report_id      : string : Report identifier: GUID, report name, or .rdl file name. Required for detail/download/update/delete.
file_path      : string : create/update: local .rdl file path. Relative paths resolve against the workspace folder (auto-resolved from MCP roots or server cwd). Omit on create to use the embedded ReportTemplate.rdl.
name           : string : create: report display name. Default: file name without extension, or 'Report Template' when using the embedded template.
description    : string : create/update: report description.
language       : string : create: language name (e.g. 'English') or LCID. Default: organization's base language.
solution_name  : string : list/create: solution unique or display name. list: filter reports by solution; create: add the new report to this solution.
name_filter    : string : list: case-insensitive contains filter on report name or file name.
max_records    : int    : list: max records, 1-500. Default 50.
dataset_name   : string : add_dataset/update_dataset: local RDL dataset name. Required for dataset actions.
fetchxml       : string : add_dataset/update_dataset: simple FetchXML or system view name. Required for dataset actions.
entity_name    : string : add_dataset/update_dataset: entity display/logical name when fetchxml is a system view name.
```

# RESULTS

- Test 1: list mode returns five reports with language names and language codes.
- Test 2: detail mode returns report metadata, English language 1033, data sources, and data sets.
- Test 3: download mode saves the report under `.devkit/manage_report/downloads/1033/` and applies a numeric suffix when the report file already exists.
- Test 4: create mode uses the organization's base language when language is omitted, creates the embedded template in Dataverse, and downloads it under `.devkit/manage_report/downloads/1033/DevKit Test Report 20260831-5.rdl`.
- Test 5: an existing Dataverse report fails fast before the create workflow continues.
- Test 6-7: invalid list bounds and missing action return actionable validation errors.
- Test 8: German resolves to LCID 4103 and fails fast with an actionable not-installed error before report creation.
- Test 9: embedded create normalizes the connected organization's URL, language, CRM URL, and user-specific defaults before upload/download.
