# TOOL DESCRIPTION

```text
Search Dataverse records or inspect Dataverse Search provisioning status.

WHEN TO USE:
- Find records by keywords across one or more searchable tables
- Diagnose whether Dataverse Search and entity indexes are ready

RELATED TOOLS:
- execute_fetchxml → deterministic field filters and joins
- get_tables → discover searchable entity logical names
```

# PARAMETERS

```text
action      : string : 'search' (default) or 'status'.
search_term : string : Required for search. 1-100 chars. Operators: + (AND), | (OR), - (NOT), * (wildcard), "phrase", () (group).
entities    : string : Comma-separated Display Names or logical names (e.g. 'Account,contact'). Empty = all searchable.
top         : int    : Max results to return. 1-100 (default 50).
filter      : string : OData filter applied after search. e.g. 'statecode eq 0'.
```
