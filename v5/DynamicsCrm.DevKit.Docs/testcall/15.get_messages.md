# 11. get_messages

# Tool description AI đọc được

```
Name:        get_messages
Title:       List SDK messages and custom actions
Idempotent:  true
Destructive: false
ReadOnly:    true

Description:
SDK messages + legacy Custom Actions (workflow-based, category=3). message_name empty = list; set = detail (params, plugin steps).
Modern Custom APIs excluded → get_custom_apis.
entity_name='none' = global messages.

WHEN TO USE:
- Discover available SDK messages for an entity before writing plugin registration
- Inspect a legacy Custom Action's input/output parameters from XAML
- Check plugin step count registered on a specific message

RELATED TOOLS:
- get_custom_apis → modern Custom API definitions (replaces Custom Actions)
- get_plugins → plugin assemblies/types/steps registered on these messages
- get_workflows → classic workflow definitions (background + realtime)

Parameters:
  entity_name             (string, default: "none")
    Entity Display/logical name. 'none'/empty = global. Ignored in detail mode.
  message_name            (string, default: "")
    Message/Action name → detail mode. Empty = list mode.
  include_custom_actions  (bool, default: true)
    List: include Custom Actions. false = SDK only. Ignored in detail mode.
```

# Input tool call

## 1. List global messages (entity_name=none, include_custom_actions=true)

```
get_messages(entity_name="none", include_custom_actions=true)
```

```
get_messages(entity_name="none", message_name="NonExistentMessage")
```

> `message_name` không match SDK message hay Custom Action nào → error kèm hint.

**Content:**

```
[Error] Message or Custom Action 'NonExistentMessage' not found.
Hint: Call get_messages without message_name to list all available messages for the entity.
```

**Structured content:**

```json
{
  "error": "Message or Custom Action 'NonExistentMessage' not found.",
  "hint": "Call get_messages without message_name to list all available messages for the entity."
}
```

**IsError:** true

### Kết quả AI tổng hợp lại

- **Trạng thái:** Validation error (expected, do tool raise).
- **Lý do:** Tool tìm `NonExistentMessage` trong sdkmessage (name) → không thấy; tìm trong workflow (name/uniquename, category=3) → không thấy.
- **Cách sửa:** Gọi `get_messages()` không truyền `message_name` để list tất cả, rồi dùng tên chính xác.

## 8. Validation error — entity_name không tồn tại

```
get_messages(entity_name="nonexistent_entity_xyz")
```

> `entity_name` không resolve được entity → error từ `DisplayNameFirstResolver`.

**Content:**

```
[Error] entity_name 'nonexistent_entity_xyz': [NotFoundEntity] 'nonexistent_entity_xyz' was not found by Display Name or Logical/Unique/Schema Name.
Tip: Use get_tables to list entities before calling get_messages.
```

**Structured content:**

```json
{
  "error": "entity_name 'nonexistent_entity_xyz': [NotFoundEntity] 'nonexistent_entity_xyz' was not found by Display Name or Logical/Unique/Schema Name.\r\nTip: Use get_tables to list entities before calling get_messages."
}
```

**IsError:** true

### Kết quả AI tổng hợp lại

- **Trạng thái:** Validation error (expected). `DisplayNameFirstResolver` không tìm thấy entity.
- **Cách sửa:** Dùng Display Name (vd `Account`) hoặc logical name (vd `account`) hợp lệ. Gọi `get_tables` để list entity nếu cần.

## 9. Validation error — message not found với entity_name hợp lệ

```
get_messages(entity_name="account", message_name="NonExistentMessage")
```

> `entity_name` hợp lệ nhưng `message_name` không tồn tại → error. `entity_name` bị ignore trong detail mode (chỉ dùng để resolve scope trước khi vào detail).

**Content:**

```
[Error] Message or Custom Action 'NonExistentMessage' not found.
Hint: Call get_messages without message_name to list all available messages for the entity.
```

**Structured content:**

```json
{
  "error": "Message or Custom Action 'NonExistentMessage' not found.",
  "hint": "Call get_messages without message_name to list all available messages for the entity."
}
```

**IsError:** true

### Kết quả AI tổng hợp lại

- **Trạng thái:** Validation error (expected). Detail mode tìm message global — `entity_name` không ảnh hưởng kết quả tìm.
- **Cách sửa:** Gọi `get_messages(entity_name="account")` không truyền `message_name` để list message cho account, rồi dùng tên chính xác.
