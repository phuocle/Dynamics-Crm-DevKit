# ✅ TOOL DESCRIPTION

```text
Dataverse column (attribute) — auto-detect create vs update. Types: string, memo, integer, bigint, decimal, money, float, boolean, datetime, lookup, customer, picklist, multipicklist, image, file.

Update (column exists): pass logical_name that matches an existing attribute. attribute_type ignored (immutable). picklist: use add/update/delete_options; use default_value to change the DefaultFormValue (single integer, e.g. 100000001) — omit to keep current; not supported on multipicklist. boolean: use default_value ('true'/'false' or '1'/'0') to flip the DefaultValue — omit to keep current. Omit params to keep current. Formula clone parameters are CREATE-only; if any are passed for an existing column, the tool returns an error and does not update the formula.

Create (no attribute): need attribute_type + display_name.
- schema_name: if provided, used AS-IS as SchemaName (skip auto-derive from display_name). Caller responsible for casing. Must start with the publisher prefix (e.g. 'devkit_InvoiceLineId'). Create only — ignored on update.
- logical_name: if provided, used AS-IS as the lowercase logical name. Must start with the publisher prefix and be the lowercase form of schema_name (e.g. 'devkit_invoicelineid'). Create only — ignored on update.
- If both omitted: SchemaName is auto-derived from display_name via DataverseNamer, logical name derives from schemaName.ToLowerInvariant().
- lookup: needs lookup_target (auto-creates 1:N)
- customer: polymorphic (account+contact), no lookup_target
- picklist/multipicklist: options JSON or global_optionset_name
- formula clone (PowerFx/Calculated/Rollup): pass only get_tables' `formulaDefinition` reference into formula_definition. Format: `source_table_logical_name:source_column_logical_name`. Pass it unchanged; never provide formula content directly.
- The server retrieves the raw source formula and kind directly from Dataverse, then rewrites entity/column/relationship references for the target. Supported underlying types: string/memo/integer/decimal/money/float/boolean/datetime.
- To intentionally create an empty formula column, omit formula_definition and pass formula_source_type as powerfx, calculated, or rollup.
- 5 create flags (so a column can be cloned in a SINGLE create call, no follow-up update): required_level (None/Recommended/Required — default None), is_audit_enabled (default true), is_valid_for_advanced_find (default true), is_secured (default false), is_sortable (default true when supported). On UPDATE, omit=null to keep current.

CREATE resolves the publisher prefix from solution_name (required for CREATE) and adds the column to that solution.
Statuscode (statuscode / StatusType): pass logical_name='statuscode' and use add_options/update_options/delete_options.
add_options: JSON array with optional 'state' field (linked statecode value, default 0): [{"label":"Under Review","value":100000001,"state":0}].
update_options: rename by value (no 'state' needed). delete_options: JSON array of integer values. statecode column is read-only.
Name resolution: entity_name resolves Display Name contains first, then logical/schema name contains — ambiguity returns candidates. logical_name (UPDATE) follows the same Display Name first rule. lookup_target, global_optionset_name, and solution_name use their shared resolvers.

WHEN TO USE:
- Create a new attribute on an existing table (need attribute_type + display_name)
- Clone a PowerFx, Calculated, or Rollup column read by get_tables (CREATE only)
- Update mutable metadata, format, required_level, and picklist options
- Add/rename/remove options on an existing picklist via add_options/update_options/delete_options

RELATED TOOLS:
- get_tables → discover entities and attribute logical names
- manage_table → create the table before its columns
- manage_relationship → 1:N / N:N
- manage_choice → global option sets
- manage_record_file → file/image column data
- execute_webapi → raw Web API for endpoints not covered here
```

# PARAMETERS

```text
entity_name                 : string : Logical name (e.g. 'account').
logical_name                : string : Logical name of the existing attribute to update (e.g. 'new_priority'). For CREATE: optional lowercase override of logical name; if omitted derives from schema_name/display_name. Must start with publisher prefix.
attribute_type              : string : string/memo/integer/bigint/decimal/money/float/boolean/datetime/lookup/customer/picklist/multipicklist/image/file. Required for CREATE. Ignored on UPDATE (immutable).
display_name                : string : Required for CREATE. Optional on UPDATE — pass only to rename the display label.
solution_name               : string : Required for CREATE. Resolves the publisher prefix and adds the attribute to the solution.
description                 : string : Optional column description.
required_level              : string : Required level for the column. CREATE: always applied (None when omitted — NOT a Dataverse default). UPDATE: omit=keep current.
max_length                  : int    : string 1-4000 (def 100); memo 1-1048576 (def 2000); file KB (def 32768).
min_value                   : double : Numeric types: minimum value.
max_value                   : double : Numeric types: maximum value.
precision                   : int    : decimal/money/float 0-10 (def 2; money max is 4). [update: omit=keep]
format                      : string : string: Text/Email/Url/Phone/TextArea/TickerSymbol/RichText. datetime: DateOnly/DateAndTime. integer: None/Duration/TimeZone/Language/Locale.
behavior                    : string : datetime: UserLocal (def)/DateOnly/TimeZoneIndependent. DateOnly forces DateOnly format.
precision_source            : int    : money: 0=Attribute (def), 1=Organization, 2=Currency.
options                     : string : picklist create: JSON array [{"label":"Low","value":100000000}]. Optional 'color' field: {"label":"Low","value":100000000,"color":"#808080"}.
global_optionset_name       : string : picklist create: existing global option set.
lookup_target               : string : lookup create: target entity. Comma-separated = polymorphic.
lookup_relationship_name    : string : lookup: schema name. Auto if empty.
true_label                  : string : boolean true label (def 'Yes'). [update: omit=keep]
false_label                 : string : boolean false label (def 'No'). [update: omit=keep]
add_options                 : string : picklist update: JSON array — options to add. Optional 'color' field: {"label":"New","value":100000003,"color":"#FF0000"}. StatusType (statuscode): include 'state' field (statecode value, default 0): {"label":"Under Review","value":100000001,"state":0}.
update_options              : string : picklist update: JSON array — options to rename. Optional 'color' field: {"label":"NewLabel","value":100000000,"color":"#FF0000"}.
delete_options              : string : picklist update: JSON array of integer values to remove.
is_audit_enabled            : bool   : Enable audit on this column. CREATE: pass to override Dataverse default (true). UPDATE: omit=null keeps current.
is_valid_for_advanced_find  : bool   : Show column in Advanced Find. CREATE: pass to override Dataverse default (true). UPDATE: omit=null keeps current.)
is_secured                  : bool   : Enable field-level security. CREATE: pass to override Dataverse default (false). UPDATE: omit=null keeps current.
is_sortable                 : bool   : Make column sortable in views. CREATE: pass to override Dataverse default (true, when supported by the attribute type). UPDATE: omit=null keeps current.
default_value               : string : picklist/boolean create: default option value. Picklist: single integer value (e.g. 100000002) — must match one of the options. Boolean: 'true'/'false' or '1'/'0'. Not supported on multipicklist.
schema_name                 : string : SchemaName for the new column (e.g. 'devkit_InvoiceLineId'). If provided, used AS-IS as SchemaName (skip auto-derive from display_name). Caller responsible for casing. Create only — ignored on update. Must start with the publisher prefix.
formula_definition          : string : Create-only formula clone reference returned by get_tables, exactly `source_table_logical_name:source_column_logical_name` (for example `account:new_total`). Pass it unchanged; the server retrieves and rewrites the source formula directly. Omit it and pass formula_source_type only to create an empty formula column.
formula_source_type         : string : Create only. Use powerfx, calculated, or rollup only when creating an empty formula column without formula_definition. Clone mode derives the kind from the referenced source column.
can_store_full_image        : bool   : image only. CREATE: true = store the full-sized image (default false). UPDATE: omit = keep current.
```
