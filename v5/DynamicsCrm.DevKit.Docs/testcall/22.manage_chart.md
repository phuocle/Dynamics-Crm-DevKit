# TOOL DESCRIPTION

```text
Manage Dataverse system charts (savedqueryvisualization). Actions: 'list', 'detail' (read-only) | 'create', 'update', 'rename', 'set_default', 'undo' (mutations). datadescription FetchXML is built from entity metadata — no view binding. Omitted chart_type on create defaults to Pie (category=statecode, legend=importsequencenumber/count). Pie create first returns needs_confirmation without creating; re-call with confirmed=true after user approval. Multi-series: measures='col:agg[:label]; ...' (agg: count/countcolumn/sum/avg/min/max) defaults chart_type to Column and is mutually exclusive with aggregate_column. filter='field op value; ...' (ops: =, !=, >, >=, <, <=, like, in, null, not-null) filters chart data. Create with measures or filter also requires confirmed=true.

WHEN TO USE:
- List or inspect system charts of an entity
- Create a chart from group-by/aggregate columns, update chart type or columns, rename, set the entity default chart
- Restore a chart from a .chart.json backup written by update (undo)

RELATED TOOLS:
- get_tables → column logical names for group_by_column/aggregate_column
- publish_customizations → batch publish after multiple metadata changes
- manage_view → views; execute_webapi → raw savedqueryvisualization access
```

# PARAMETERS

```text
action                  : string : 'list', 'detail', 'create', 'update', 'rename', 'set_default', 'undo'.
entity_name             : string : Entity Display Name or logical name (e.g. 'Account' or 'account'). Required for list/create.
chart_id                : string : Chart GUID. Required for detail/update/rename/set_default/undo (unless chart_name uniquely identifies chart).
chart_name              : string : Chart name. Used for detail/update/rename lookup or create. Required for create.
chart_type              : string : OOB Chart Type: Column, Bar, Line, Pie, Doughnut, Funnel, Area, Bubble, Radar. Default: Pie when omitted on create.
group_by_column         : string : Category / group-by attribute logical name or display name. Pie default: statecode.
aggregate_column        : string : Legend / measure attribute logical name or display name. Pie default: importsequencenumber.
aggregate_type          : string : Aggregation type: 'count' (default), 'sum', 'avg', 'min', 'max'.
measures                : string : Multi-measure series: 'column:aggregate_type[:label]; ...' (e.g. 'estimatedvalue:sum:Revenue; importsequencenumber:count'). Mutually exclusive with aggregate_column/aggregate_type. Optional label becomes the series legend name.
filter                  : string : Structured datadescription filter: 'field op value; ...'. Operators: =, !=, >, >=, <, <=, like, in (comma-separated list), null, not-null. Example: 'statecode=0; estimatedvalue>1000000'.
presentationdescription : string : Custom presentation Chart XML override (create/update). For undo: path to the .chart.json backup file.
description             : string : Chart description text.
solution_name           : string : Optional solution unique/display name. When provided and non-empty, chart is added to the solution after create/update.
validate                : bool   : Validate XML syntax and chart types before saving.
backup                  : bool   : Backup before overwrite.
publish                 : bool   : Publish entity after create/update/rename/set_default/undo so changes become visible. Default: true. Set false to batch-publish later via publish_customizations.
confirmed               : bool   : Pie create only: set true only after user approved the confirmation summary. Default false returns needs_confirmation without creating.
workspace_folder        : string : Optional project/workspace folder path to save backups in.
```
