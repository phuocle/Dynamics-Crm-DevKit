# 15. search_records

# Tool description

```text
Search Dataverse records or inspect Dataverse Search provisioning status.

WHEN TO USE:
- Find records by keywords across one or more searchable tables
- Diagnose whether Dataverse Search and entity indexes are ready

RELATED TOOLS:
- execute_fetchxml → deterministic field filters and joins
- get_tables → discover searchable entity logical names
```

# Input tool call

**Test 1 — Happy path: search một keyword trên 2 entities, giới hạn top**

```json
{
  "action": "search",
  "search_term": "devkit",
  "entities": "account,contact",
  "top": 3
}
```

**Test 2 — Validation error: thiếu search_term khi action='search'**

```json
{
  "action": "search",
  "search_term": ""
}
```

**Test 3 — Validation error: action không hợp lệ**

```json
{
  "action": "invalid",
  "search_term": "test"
}
```

**Test 4 — Happy path: search không có kết quả**

```json
{
  "action": "search",
  "search_term": "zzzqqq-nonexistent-term",
  "top": 5
}
```

# Kết quả

- Happy path trả `returnedCount`/`totalCount` + `records[]` với score, attributes (kèm FormattedValue annotations) và highlights `{crmhit}...{/crmhit}` — đúng như source mô tả.
- Zero-result search vẫn là Success (`returnedCount: 0`, `records: []`), không phải error — đúng contract.
- Validation errors: thiếu `search_term` → error rõ; `action` sai → error kèm `hint` liệt kê giá trị hợp lệ. Cả 2 đều `IsError: true`.
- Không có field nào bị rút gọn; output ghi nguyên văn từ MCP response.
- Note: `action='status'` đã được verify trực tiếp trên org (provisioned, 34 indexed entities, 1 MB / 2281 docs) nhưng full output ~64KB (danh sách indexed fields của 34 entities) quá lớn để nhúng nguyên văn vào file này.
- Description trên khớp source hiện tại (`SearchRecordsTool.cs`), bao gồm các tham số `action`, `search_term`, `entities`, `top`, `filter`.
