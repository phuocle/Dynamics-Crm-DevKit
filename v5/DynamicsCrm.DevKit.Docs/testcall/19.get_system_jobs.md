# 19. get_system_jobs

# Tool description AI đọc được

```
Name:        get_system_jobs
Title:       List and inspect system jobs
Idempotent:  true
Destructive: false
ReadOnly:    true

Description:
System jobs (asyncoperation) for async failures, workflow errors, bulk ops, imports, solutions. record_id empty = list (default: failed jobs last 24h); set = detail (error + stack trace).

WHEN TO USE:
- Debug async failures (list failed → detail for stack trace)
- Monitor bulk ops (operation_type='bulk_delete'/'import'/'solution')
- Trace one request (correlation_id across jobs)
- Async plugin failures: combine with get_plugin_trace_logs

RELATED TOOLS:
- get_plugin_trace_logs → plugin execution traces (sync + async)
- get_workflows → classic workflow definitions (background + realtime)
- get_flows → Power Automate cloud flows + run history

Parameters:
  record_id       (string, default: "")
    GUID → detail. Empty = list.
  entity_name     (string, default: "")
    Filter by entity Display Name or logical name (e.g. 'Account' or 'account').
  status          (string, default: "failed")
    failed/succeeded/waiting/in_progress/canceled/all.
  operation_type  (string, default: "")
    plugin/workflow/bulk_delete/import/goal_rollup/solution/all.
  name_filter     (string, default: "")
    Name contains.
  correlation_id  (string, default: "")
    GUID. Trace one request across jobs.
  minutes_ago     (int, default: 0)
    0 = 1440 (24h) default. Max 43200.
  max_records     (int, default: 50)
    Max 500.
```

- **Cách dùng tiếp theo:** Dùng `record_id` của job đầu tiên để xem chi tiết đầy đủ `createdOn` + `friendlyMessage` + `message`.

## 3. List mode — entity_name filter

```
get_system_jobs(entity_name="skillrolemapping", status="all", minutes_ago=10080, max_records=3)
```

> `entity_name="skillrolemapping"` filter theo entity. `minutes_ago=10080` = 7 ngày. Tool tự resolve ObjectTypeCode (11040) qua `RetrieveEntityRequest` rồi filter `primaryentitytype eq 11040`.

      "owner": "SYSTEM"
    }
  ],
  "summary": {
    "other": 1
  }

**IsError:** false

### Kết quả AI tổng hợp lại

- **Trạng thái:** Thành công. 1 system job cho entity `skillrolemapping` trong 7 ngày.
- **entityName:** `skillrolemapping` — echo lại filter (logical name sau khi resolve).
- **jobs[0]:**
  - `primaryEntity` = "skillrolemapping" (logical name, từ `GetAttributeValue<string>`).
  - `operationType` = "EntityKey Index Creation" (label từ FormattedValues).
  - `executionTime` = "2.9s" (format tự động: 1-60s → seconds).
- **Lưu ý:** `primaryentitytype` trong `asyncoperation` là `EntityName` type — lưu ObjectTypeCode (int), nhưng `GetAttributeValue<string>()` trả logical name. Filter phải dùng int ObjectTypeCode (tool tự resolve qua `RetrieveEntityRequest`).
- **Token tiết kiệm:** `status` ẩn vì `status="all"`. Các field null ẩn.
- **Cách dùng tiếp theo:** Dùng `record_id` để xem chi tiết, hoặc `correlation_id` để trace các job liên quan.

get_system_jobs(status="invalid_status")
```

```

{
  "error": "'invalid_status' is not a valid status. Valid values: failed, succeeded, waiting, in_progress, canceled, all."

### Kết quả AI tổng hợp lại

- **Trạng thái:** Lỗi validation. `status` không hợp lệ.
