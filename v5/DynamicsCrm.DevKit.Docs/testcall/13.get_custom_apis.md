# 13. get_custom_apis

# Tool description AI đọc được

```
Name:        get_custom_apis
Title:       List custom API definitions
Idempotent:  true
Destructive: false
ReadOnly:    true

Description:
Custom API definitions (modern replacement for Custom Actions). api_name empty = list; set = detail (params, plugin binding).
Managed APIs excluded by default (set include_microsoft=true to include them). isFunction=true → GET; false → POST.

WHEN TO USE:
- Inspect a Custom API's request/response parameters and plugin binding before registering or invoking it
- Discover Custom APIs bound to a specific entity
- Distinguish modern Custom APIs from legacy workflow Custom Actions

RELATED TOOLS:
- get_messages → legacy workflow Custom Actions (category=3) + SDK messages
- get_plugins → plugin assemblies/types/steps registered on these APIs
- get_workflows → classic workflow definitions

Parameters:
  api_name           (string, default: "")
    Display Name or unique name → detail. Empty = list.
  entity_name        (string, default: "")
    Bound entity Display/logical name. Empty = all.
  include_microsoft  (bool, default: false)
    Include managed APIs. Default false.
  status             (string, default: "active")
    'active' / 'inactive' / 'all'.
  max_records        (int, default: 100)
    1-500. Default 100.
```

# Test calls

## 1. List mode — default (active, unmanaged only)

```
get_custom_apis()
```

> Không truyền tham số → list mode mặc định: status=active, include_microsoft=false (chỉ custom API unmanaged).

**Content (1 dòng):**

```
[Success] active custom APIs: 2 found.
```

**Structured content:**

```json
{
  "totalCount": 2,
  "apis": [
    {
      "customApiId": "91cd8d8c-8f27-4932-956d-d593c526b88c",
      "uniqueName": "v4_AccountCustomApi",
      "displayName": "v4_AccountCustomApi",
      "bindingType": "Entity",
      "boundEntity": "account",
      "isFunction": false,
      "isPrivate": false,
      "processingType": "Sync and Async",
      "pluginType": "v4_AccountCustomApiRequest",
      "status": "Active"
    },
    {
      "customApiId": "249d55dc-a73d-4c83-bc8c-f4d13573f2d9",
      "uniqueName": "v4_CustomApi",
      "displayName": "v4_CustomApi",
      "bindingType": "Global",
      "isFunction": false,
      "isPrivate": false,
      "processingType": "Sync and Async",
      "pluginType": "v4_CustomApiRequest",
      "status": "Active"
    }
  ]
}
```

**IsError:** false

### Kết quả AI tổng hợp lại

- **Trạng thái:** Thành công. Org 🟢DEVKITV4 có 2 Custom API active unmanaged.
- **totalCount:** 2 — tổng số API trả về.
- **entityFilter:** `null` (ẩn) — không lọc theo entity.
- **apis[]:** mỗi entry chứa metadata tối thiểu cho list mode:
  - `customApiId` — GUID của Custom API.
  - `uniqueName` / `displayName` — tên định danh và tên hiển thị.
  - `bindingType` — `Global` / `Entity` / `EntityCollection`.
  - `boundEntity` — logical name entity bind (null nếu Global, ẩn khỏi JSON).
  - `isFunction` — `true` = GET, `false` = POST.
  - `isPrivate` — API private hay public.
  - `processingType` — `None` / `Async Only` / `Sync and Async`.
  - `pluginType` — tên plugin type bind (null nếu không có, ẩn).
  - `status` — `Active` / `Inactive`.
- **Token tiết kiệm:** `entityFilter` ẩn khi null; `description`, `owner`, `solutionId`, `createdOn`, `modifiedOn`, `pluginTypeFullName`, `pluginAssemblyName`, `pluginAssemblyVersion`, `pluginIsolationMode`, `requestParameters`, `responseProperties` không trả trong list mode → tiết kiệm đáng kể.
- **Cách dùng tiếp theo:** Truyền `api_name` = một `uniqueName` từ list để xem detail đầy đủ (params, response, plugin binding).

**IsError:** false

### Kết quả AI tổng hợp lại

- **Trạng thái:** Thành công. Custom API `v4_CustomApi` là global POST API, bind plugin `v4_CustomApiRequest`.
- **Trường detail thêm so với list:**
  - `description` — mô tả API.
  - `pluginTypeName` / `pluginTypeFullName` — tên friendly + full type name của plugin.
  - `pluginAssemblyName` / `pluginAssemblyVersion` — assembly chứa plugin.
  - `pluginIsolationMode` — `None` / `Sandbox` / `External` (ẩn khi null).
  - `owner` — tên user sở hữu.
  - `solutionId` — resolved từ GUID sang solution friendly name (`Active Solution`).
  - `createdOn` / `modifiedOn` — ngày (yyyy-MM-dd).
- **requestParameters[]:** danh sách input parameter:
  - `name` — unique name.
  - `type` — `String` / `Integer` / `Boolean` / `EntityReference` / ... (12 type).
  - `isOptional` — `true` = optional, `false` = required.
  - `logicalEntityName` — entity cho type `Entity`/`EntityReference` (ẩn khi null).
  - `description` — mô tả param (ẩn khi null).
- **responseProperties[]:** danh sách output property, cùng cấu trúc nhưng không có `isOptional`.
- **Token tiết kiệm:** `pluginIsolationMode` ẩn khi null; `boundEntity` ẩn vì Global; `entityFilter` ẩn.
- **Cách dùng tiếp theo:** Dùng `pluginTypeFullName` + `pluginAssemblyName` để tìm plugin step qua `get_plugins`; dùng `requestParameters` để build invoke payload qua `execute_webapi`.

## 5. Validation error — invalid status

```
get_custom_apis(status="xyz")
```

> `status` không thuộc `active` / `inactive` / `all` → error.

**Content:**

```
Invalid status 'xyz'. Use 'active', 'inactive', or 'all'.
```

**Structured content:**

```json
{
  "error": "Invalid status 'xyz'. Use 'active', 'inactive', or 'all'."
}
```

**IsError:** true

### Kết quả AI tổng hợp lại

- **Trạng thái:** Validation error (expected, do tool raise).
- **Lý do:** `status` chỉ chấp nhận `active`, `inactive`, `all`.
- **Cách sửa:** Dùng `status="all"` để xem cả active + inactive.

## 6. Validation error — api_name not found

```
get_custom_apis(api_name="nonexistent_api_xyz")
```

> `api_name` không match Custom API nào → error kèm hint.

**Content:**

```
api_name 'nonexistent_api_xyz': [NotFoundCustomApi] 'nonexistent_api_xyz' was not found by Display Name or Logical/Unique/Schema Name.
Tip: Use get_custom_apis with api_name empty to list available Custom APIs.
```

**Structured content:**

```json
{
  "error": "api_name 'nonexistent_api_xyz': [NotFoundCustomApi] 'nonexistent_api_xyz' was not found by Display Name or Logical/Unique/Schema Name.\r\nTip: Use get_custom_apis with api_name empty to list available Custom APIs."
}
```

**IsError:** true

### Kết quả AI tổng hợp lại

- **Trạng thái:** Validation error (expected). Resolver tìm theo Display Name → Unique Name → không match.
- **Cách sửa:** Gọi `get_custom_apis()` không truyền `api_name` để list tất cả, rồi dùng `uniqueName` chính xác.
