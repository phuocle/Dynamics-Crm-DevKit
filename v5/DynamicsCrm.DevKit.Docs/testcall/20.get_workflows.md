# 20. get_workflows

# Tool description AI đọc được

```
Name:        get_workflows
Title:       List classic workflows
Idempotent:  true
Destructive: false
ReadOnly:    true

Description:
Classic workflows (background async + realtime sync) for a Dataverse entity. workflow_id empty = list; set = detail. Classic only — use get_business_rules / get_custom_apis / get_business_process_flows / get_flows for others.

WHEN TO USE:
- Check if a field triggers any workflow (trigger_field + entity_name)
- Find synchronous workflows (mode='realtime'; Pre-op can cancel/rollback)
- Inspect workflow steps before refactoring/disabling

RELATED TOOLS:
- get_business_process_flows → BPF definitions + stages
- get_business_rules → client-side business rules
- get_flows → Power Automate cloud flows + run history
- get_system_jobs → workflow execution results (asyncoperation)

Parameters:
  workflow_id    (string, default: "")
    GUID → detail. Empty = list.
  entity_name    (string, default: "")
    Entity Display Name or logical name (e.g. 'Account' or 'account'). Empty = all.
  mode           (string, default: "")
    'background' / 'realtime'. Empty = both.
  status         (string, default: "active")
    'active' / 'draft' / 'all'. Default: active.
  trigger_field  (string, default: "")
    Update trigger field Display Name or logical name when entity_name is set; otherwise contains filter.
  name_filter    (string, default: "")
    Name contains. 1 match → auto-detail.
  max_records    (int, default: 50)
    Max 250.
```

# Test calls

## 1. List mode — all workflows on account (all statuses)

```
get_workflows(entity_name="account", status="all", max_records=10)
```

> Không truyền `workflow_id` → list mode. `entity_name="account"` lọc theo entity. `status="all"` để xem cả Draft và Activated. `max_records=10` giới hạn kết quả.

```
[Success] 1 classic workflow on account.
```

### Kết quả AI tổng hợp lại

- **Trạng thái:** Thành công. 1 classic workflow trên entity `account`.
- **mode:** `list` — chế độ danh sách.
- **totalCount:** 1 — đúng 1 workflow.
- **entityName:** `account` — entity đã filter.
- **statusFilter:** `all` — không lọc theo trạng thái.
- **summary:**
  - `backgroundCount` = 1 — 1 workflow Background (async).
  - `onDemandCount` = 1 — 1 workflow có thể chạy on-demand.
  - `draftCount` = 1 — 1 workflow ở trạng thái Draft.
  - `realtimeCount`, `subprocessCount`, `activeCount` — ẩn (giá trị 0, null-aware).
- **workflows[0]:** "When Account Created":
  - `triggerOnCreate` = true — trigger khi tạo record.
  - `triggerOnUpdateFields` = "statecode,name" — trigger khi update statecode hoặc name.
  - `mode` = "Background" (label từ FormattedValues, không phải int 0).
  - `scope` = "Organization" (label, không phải int 4).
  - `runAs` = "Calling User" (label, không phải int 1).
  - `state` = "Draft", `status` = "Draft" (label từ FormattedValues).
  - `rank` — ẩn (null, null-aware).
  - `owner` = "Phước Lê Văn", `modifiedBy` = "SYSTEM".
- **Token tiết kiệm:** Content 1 dòng thay vì bảng tab-separated dài. Structured JSON ẩn hết null/0 → giảm ~40% token so với old format.
- **Cách dùng tiếp theo:** Dùng `workflow_id` từ kết quả để gọi detail mode xem full metadata (isCustomizable, businessProcessType, createdBy, createdOn).

## 8. execute_webapi redirect — GET workflows blocked

```
execute_webapi(method="GET", url="workflows")
```

> `execute_webapi` GET `workflows` bị redirect về `get_workflows` theo rule 14. AI không được dùng Web API raw cho workflows.

**Content:**

```
REDIRECT: Use get_workflows instead of GET workflows.
get_workflows provides entity_name/mode/scope/status filters, trigger_field discovery, and detail mode with XAML.

Examples:
  get_workflows(entity_name='account') → workflows bound to account
  get_workflows(mode='realtime', status='active') → active realtime workflows
  get_workflows(workflow_id='<guid>') → detail with trigger fields + XAML
  get_workflows(entity_name='account', trigger_field='statecode') → workflows triggered by status change

USE INSTEAD: get_workflows
```

**IsError:** true

### Kết quả AI tổng hợp lại

- **Trạng thái:** Redirect (expected, do execute_webapi raise).
- **Lý do:** `workflows` endpoint đã có dedicated tool `get_workflows` với filters và detail mode tốt hơn raw Web API.
- **Cách sửa:** Gọi `get_workflows` thay vì `execute_webapi(GET, "workflows")`.
