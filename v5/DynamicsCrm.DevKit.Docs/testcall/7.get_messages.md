# 7. get_messages

# Tool description

```text
List SDK messages and legacy workflow Custom Actions, or inspect one message/action in detail.

WHEN TO USE:
- Discover available SDK messages for an entity before writing plugin registration
- Inspect a legacy Custom Action's input/output parameters from XAML
- Check plugin step count registered on a specific message

RELATED TOOLS:
- get_custom_apis → modern Custom API definitions (replaces Custom Actions)
- get_plugins → plugin assemblies/types/steps registered on these messages
- get_workflows → classic workflow definitions (background + realtime)
```

# Input tool call

**Test 1 — List mode: messages cho account (kèm custom actions)**

```json
{
  "entity_name": "account",
  "max_records": 10
}
```

**Test 2 — Detail: legacy Custom Action (input/output từ XAML, plugin steps)**

```json
{
  "message_name": "v4_AccountCustomAction"
}
```

**Test 3 — Error: message/action không tồn tại**

```json
{
  "message_name": "nonexistent_message_zzz"
}
```

**Test 4 — List mode: global scope (entity_name mặc định 'none')**

```json
{
  "max_records": 10
}
```

# Kết quả

- List mode phân tách rõ `sdkMessages` vs `customActions`, `max_records=10` áp dụng **per category** (Test 4: 10 SDK + 10 custom actions → totalCount 20) — đúng mô tả "maximum names per category".
- Detail custom action (Test 2) trả `isCustomAction: true`, `availability: Both`, `supportedEntities`, `pluginStepCount`. Custom action này không có input/output params (0/0).
- Detail của SDK message lớn như `Update` trả supportedEntities toàn bộ entities (~19KB) — hợp lệ nhưng quá lớn để nhúng nguyên văn; dùng custom action detail làm evidence.
- Error path (Test 3) `IsError: true` với hint đúng.
- Description khớp source hiện tại (`GetMessagesTool.cs`).
