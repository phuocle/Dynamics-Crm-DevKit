# TOOL DESCRIPTION

```text
Parse a Dataverse/Power Platform URL or raw GUID into record and environment identifiers.

WHEN TO USE:
- Call first when the user pastes a model-driven app, Web API, maker, admin, or legacy URL
- Extract a GUID while preserving its URL context

RELATED TOOLS:
- manage_record → read or change a parsed record
- get_tables → resolve or verify an unknown entity logical name
```

# PARAMETERS

```text
input : string : URL, GUID, or text. URL-decoded automatically; first matching parser wins.
```

# RESULTS

- Test 1: main.aspx record URL parses `etn` + `id` to `account` and the record GUID; `appid` is ignored.
- Test 2: main.aspx with `etc=1` resolves the entity type code to `account` via org metadata (source `etc+id, resolved`).
- Test 3: main.aspx `entitylist` + `viewid` (braces URL-decoded) returns the savedquery GUID with entity `(unknown)`.
- Test 4: Web API URL resolves entity set `accounts` to logical name `account`; both `entityName` and `entitySetName` are returned.
- Test 5: unresolvable entity set `totallyunknownsets` keeps `entityName` null (set name not borrowed), stores it in `entitySetName`, and adds a `tip` pointing to get_tables — a success, not an error.
- Test 6: maker flow-run URL returns the run GUID as a `flowsession` record plus `environmentId` and `flowId`.
- Test 7: maker solution URL with a unique-name id keeps it verbatim in `recordId` and marks the source as not a record GUID.
- Test 8: admin portal environment URL parses as `environment` with the environment GUID as record id.
- Test 9: legacy `sfa/workflow/edit.aspx` URL parses as a `workflow` record.
- Test 10: bare GUID is accepted as a raw GUID with `entityName` `(unknown)` and a tip to provide the entity name.
- Test 11: empty input returns a validation error with a hint.
- Test 12: text without any GUID falls through all five parsers and returns the no-GUID error with a hint.
- Test 13: maker URL with non-GUID ids is rejected by `Guid.TryParse` (no garbage identifiers) and returns the same no-GUID error with a hint.
