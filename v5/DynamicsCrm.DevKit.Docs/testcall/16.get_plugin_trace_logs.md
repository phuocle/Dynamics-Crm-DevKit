# 16. get_plugin_trace_logs

# Tool description AI đọc được

```
Name:        get_plugin_trace_logs
Title:       List and inspect plugin trace logs
Idempotent:  true
Destructive: false
ReadOnly:    true

Description:
Plugin trace logs (plugintracelog). record_id empty = list (newest first, default 60min); set = detail (messageBlock+exceptionDetails). Requires Plugin Trace Log enabled. type_name = plugin class (NOT table); entity_name = primaryentity. For async failures → get_system_jobs.

WHEN TO USE:
- Debug failing plugin (list first → detail with record_id for full trace)
- Trace one request across logs (correlation_id)
- Async plugin failures: combine with get_system_jobs

RELATED TOOLS:
- get_plugins → plugin assemblies/types/steps registered on these messages
- get_system_jobs → async failures (asyncoperation)
- get_messages → SDK messages + legacy Custom Actions

Parameters:
  record_id      (string, default: "")
    plugintracelog GUID → detail. Empty = list.
  type_name       (string, default: "")
    Plugin type name (contains). NOT table name.
  entity_name     (string, default: "")
    Primary entity Display/logical name.
  message_name    (string, default: "")
    SDK message: Create, Update, Delete, etc.
  mode            (string, default: "")
    'sync' / 'async'. Empty = both.
  correlation_id  (string, default: "")
    GUID. Trace one request across logs.
  minutes_ago     (int, default: 0)
    0 = 60 min default. Max 43200 (30d).
  max_records     (int, default: 50)
    Max 200.
```

# Test calls


### Kết quả AI tổng hợp lại

- **Trạng thái:** Thành công. 2 plugin trace logs trong 24h qua, cả 2 đều là plugin async trên Account Create.
- **mode:** `list` — chế độ danh sách.
- **totalCount:** 2 — tổng số log trả về.
- **timeScope:** `last 1d` — phạm vi thời gian (1440 min = 1d).
- **traces[0]:** log mới nhất:
  - `typeName` — tên class plugin đầy đủ (assembly-qualified).
  - `messageName` — SDK message (`Create`).
  - `primaryEntity` — entity bị plugin trigger (`account`).
  - `mode` — `Asynchronous` (từ FormattedValues, không phải int).
  - `operationType` — `Plug-in` (từ FormattedValues).
  - `depth` — 1 (plugin chạy ở execution depth 1).
  - `durationMs` — 312ms (thời gian thực thi).
  - `correlationId` — GUID để trace 1 request qua nhiều logs.
  - `pluginStepId` — GUID của step đăng ký plugin.
  - `requestId` — GUID unique cho request này.
  - `isSystemCreated` — `Yes` (từ FormattedValues, plugin trace do system tạo).
  - `createdOn` — timestamp log.
- **Token tiết kiệm:** `entityName` ẩn vì không filter; `messageBlock`/`exceptionDetails` ẩn trong list mode.
- **Cách dùng tiếp theo:** Dùng `record_id` của trace đầu tiên để xem chi tiết `messageBlock` + `exceptionDetails`.

### Kết quả AI tổng hợp lại

- **Trạng thái:** Thành công. Chi tiết 1 plugin trace log.
- **mode:** `detail` — chế độ chi tiết.
- **totalCount:** 1 — đúng 1 log.

- **Token tiết kiệm:** `timeScope`/`entityName` ẩn trong detail mode; `exceptionDetails` ẩn vì null.
- **Cách dùng tiếp theo:** Nếu `exceptionDetails` có nội dung → đọc để debug lỗi. Dùng `correlationId` để tìm các log khác cùng request.
