# 25. manage_deleted_records

# Tool description AI đọc được

```text
Name:        manage_deleted_records
Title:       List/detail/restore/check-status of soft-deleted Dataverse records
Idempotent:  false
Destructive: false
ReadOnly:    false

Description:
Manage soft-deleted (recycle bin) records. Actions: 'list', 'detail', 'status' (read-only) | 'restore', 'turn' (mutations). Soft-deleted records stay recoverable up to the retention period (1-30 days, default 30), then are auto-purged. Bin exposes record attributes only (no deletedon/deletedby; use modifiedOn as delete-time proxy).

WHEN TO USE:
- List or inspect records in the recycle bin before restoring
- Restore one or many deleted records back to the live table
- Check (status) or toggle (turn on/off) the org-level 'Keep deleted Dataverse records' setting

RELATED TOOLS:
- manage_record → live CRUD; delete becomes soft-delete when the bin is ON
- get_audit_history → who deleted a record and when
- execute_webapi → raw access (Restore action is redirected here)

Parameters:
  action (string, default: "list")
    Action: 'list' (default) | 'detail' | 'restore' | 'status' | 'turn'.
  entity_name (string, default: "")
    Entity Display/logical name. list: required. detail: required. restore: required if record_ids span multiple entities. status: not used. turn: not used.
  record_id (string, default: "")
    Single GUID. detail: required. list: not used. restore: optional if record_ids set.
  record_ids (string[], default: null)
    Array of GUIDs (preferred for restore). detail/list: not used. restore: alternative to record_id.
  name_filter (string, default: "")
    Search by primary attribute value (contains, case-insensitive). list only. Empty = all deleted records of entity.
  max_records (int, default: 100)
    Max records. list: default 100, max 5000. detail/restore/status/turn: not used.
  turn (string, default: "")
    Toggle direction for action='turn': 'on' to enable soft-delete, 'off' to disable. Required when action='turn'.
  retention_days (int, default: 30)
    Retention days for action='turn' turn='on'. Integer 1..30 inclusive. Default 30. Ignored for turn='off' or other actions.
```

## Key behaviors observed

1. **Tool's `status.softDeleteSupported=false` is conservative**: The tool reads `recyclebinconfig[organization].isreadyforrecyclebin=False` and reports `softDeleteSupported=false` even though the actual bin DOES accept soft-deletes. This is a Dataverse platform quirk where the `isreadyforrecyclebin` flag flips asynchronously after provisioning completes.

2. **Restore has a known issue**: Late-bound `OrganizationRequest("Restore")` with `Target = new Entity(logicalName, Guid)` fails with `Attribute 'statecode' cannot be NULL`. The tool should use `RestoreRequest` from `Microsoft.Crm.Sdk.Messages` with `Target = EntityReference`, or explicitly set `statecode = 0` (Active) on the Target entity. **Recommended fix: import `Microsoft.Crm.Sdk.Messages.RestoreRequest` and set `Target = new EntityReference(logicalName, guid)`.**

3. **Idempotent turn detection**: `turn='on'` when already Active+ready returns "already ON" error. `turn='off'` when statecode=Active but isreadyforrecyclebin=False returns "already OFF" — tool's conservative definition.

4. **Bin attributes are full**: `detail` returns all entity attributes from the bin (including `statecode`, `ownerid`, etc.), not just the primary key + name.

5. **execute_webapi Restore is blocked**: Tool-level enforcement prevents AI from bypassing safety via raw Web API. Redirect message includes reason and recommended replacement.
