# TOOL DESCRIPTION

```text
Business rules (client-side logic) for an entity. rule_id empty = list; set = detail (conditions+actions from XAML). Rules run BEFORE form JS. Scope 'Entity' = all forms.

WHEN TO USE:
- Inspect a business rule's conditions and actions before refactoring or disabling it
- Find business rules bound to an entity (entity_name filter)
- Check if a field is referenced in any client-side rule logic

RELATED TOOLS:
- get_workflows → classic workflow definitions (background async + realtime sync)
- get_messages → legacy workflow Custom Actions (category=3) + SDK messages
- get_custom_apis → modern Custom API definitions
- get_business_process_flows → BPF definitions + stages
- manage_record(action='read', columns='xaml') → raw XAML when parse is incomplete
```

# PARAMETERS

```text
entity_name : string : Entity display name, logical name, or schema name.
rule_id     : string : GUID. Empty = list mode; set with entity_name = detail mode.
status      : string : Lifecycle filter. Empty = all.
max_records : int    : Default 50. <=0 falls back to 50. Ignored in detail mode.
```
