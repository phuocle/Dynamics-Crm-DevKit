# 1. execute_fetchxml

# Tool description AI đọc được

```
Name:        execute_fetchxml
Title:       Run a FetchXML query
Idempotent:  true
Destructive: false
ReadOnly:    true

Description:
Run a FetchXML query in single-page or bounded auto-paging mode.

WHEN TO USE:
- Query Dataverse records with deterministic columns, filters, joins, or aggregates
- Page through a bounded result after validating logical names

RELATED TOOLS:
- get_tables → discover entity and attribute logical names
- search_records → keyword relevance search
- schema://fetchxml → FetchXML syntax and examples

Parameters:
  fetchxml (string, required)
    FetchXML starting with <fetch>. Lowercase logical names.
  max_records (integer, default: 5000)
    1-5000. Default 5000. Use 10-100 for samples.
  get_all (boolean, default: false)
    true = auto-page until max_records. false = first page only.
```

# Input tool call

## Test 1 — Happy path (single page, max_records=3)

```json
{
  "name": "execute_fetchxml",
  "arguments": {
    "fetchxml": "<fetch><entity name='account'><attribute name='name'/><attribute name='accountid'/><order attribute='name'/></entity></fetch>",
    "max_records": 3,
    "get_all": false
  }
}
```

## Test 2 — Malformed XML ở giữa chuỗi (regression case phase 4)

```json
{
  "name": "execute_fetchxml",
  "arguments": {
    "fetchxml": "<fetch><entity name='account'><attribute name='name'><broken</entity></fetch>"
  }
}
```

> Chuỗi bắt đầu bằng `<fetch` và kết thúc bằng `</fetch>` nhưng XML ở giữa sai cấu trúc (`<broken` không đóng). Trước phase 4 case này bubble `XmlException` từ `FetchXmlPagingHelper`; giờ phải trả validation `Error` sạch.

## Test 3 — Paging attribute bị cấm (`top`)

```json
{
  "name": "execute_fetchxml",
  "arguments": {
    "fetchxml": "<fetch top='5'><entity name='account'><attribute name='name'/></entity></fetch>"
  }
}
```

> `top`, `count`, `page`, `paging-cookie` ở opening `<fetch>` bị reject vì tool sở hữu paging.

## Test 4 — Entity không tồn tại (Dataverse error path)

```json
{
  "name": "execute_fetchxml",
  "arguments": {
    "fetchxml": "<fetch><entity name='nonexistent_entity_xyz'><attribute name='name'/></entity></fetch>"
  }
}
```
