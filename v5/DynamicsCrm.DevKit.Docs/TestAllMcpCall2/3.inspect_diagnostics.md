# TOOL DESCRIPTION

```text
Inspect Dataverse runtime diagnostics, execution traces, and audit history.

RESOURCES:
- 'audit': browse recent audit events or inspect field-level changes for one record (record_id + entity_name)
- 'plugin_traces': list recent plugin trace logs or inspect one trace by record_id
- 'system_jobs': list asynchronous system jobs (default status='failed') or inspect one job by record_id
```

# PARAMETERS

```text
resource       : string : Required: 'audit', 'plugin_traces', or 'system_jobs'.
record_id      : string : GUID → detail mode (audit record GUID [requires entity_name], plugintracelog GUID, or asyncoperation GUID). Empty = list.
entity_name    : string : Entity Display/logical name filter (required with record_id for audit).
minutes_ago    : int    : Lookback minutes (max 43200). Defaults: audit=1440, plugin_traces=60, system_jobs=1440.
max_records    : int    : List cap (default 50; max: audit/system_jobs=500, plugin_traces=200).
correlation_id : string : GUID to trace one request across plugin_traces or system_jobs.
options        : object : Resource-specific filters. audit: {user_filter, operation, attribute_name, from_date, to_date}. plugin_traces: {type_name, message_name, mode ('sync'|'async')}. system_jobs: {status ('failed'|'succeeded'|'waiting'|'in_progress'|'canceled'|'all'), operation_type, name_filter}.
env            : string : Optional .env connection group: numeric id ("1"), alias ("prod"), or "default". Omit for startup connection. Call get_context(action='connections') to list groups.
```

# TEST 4

## INPUT

```json
{
  "resource": "audit",
  "record_id": "11111111-1111-1111-1111-111111111111"
}
```

## OUTPUT

```text
[Error] entity_name is required when record_id is provided.
[Hint] Pass entity_name (Display Name or logical name, e.g. 'Account' or 'account') + record_id GUID.
```

```json
{ "IsError": true }
```
