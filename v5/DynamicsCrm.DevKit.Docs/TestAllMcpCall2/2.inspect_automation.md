# TOOL DESCRIPTION

```text
Inspect Dataverse server-side logic and automation definitions. Read docs://server_logic_guide for filtering and list/detail modes.

RESOURCES:
- 'plugins': assemblies, types, steps, images, or download DLL/.nupkg (options.download=true)
- 'workflows': classic background/realtime workflows (id set = detail with decompiled XAML)
- 'flows': Power Automate cloud flows and run history (options.action='runs' with id)
- 'bpfs': Business Process Flows and stages
- 'business_rules': client-side business rules for entity_name (decompiled DSL steps in detail)
- 'messages': SDK messages and legacy workflow Custom Actions (MIGRATION RULE: inspect/convert ONE custom action at a time in detail mode)
```

# PARAMETERS

```text
resource    : string : Required: 'plugins', 'workflows', 'flows', 'bpfs', 'business_rules', or 'messages'.
entity_name : string : Entity Display/logical name filter (required for business_rules; 'none'/empty = global for messages).
id          : string : GUID for detail mode (workflow_id, flow_id, bpf_id, rule_id; or assembly_id for plugins download).
name        : string : Name filter/selector (plugins: assembly_name; workflows/flows: name_filter; bpfs: bpf_name; messages: message_name → detail).
status      : string : State filter. Defaults: workflows='active', flows='active', bpfs='all', business_rules='' (all).
max_records : int    : List cap. Defaults: plugins/messages=100, others=50.
options     : object : Resource-specific options. plugins: {message_name, type_name, stage, mode, active_only, include_images, include_config, download, assembly_id, package_id, package_name}. workflows: {mode, trigger_field}. flows: {action ('list'|'runs'), owner_filter, status_filter, minutes_ago}. bpfs: {include_stages}. messages: {include_custom_actions}.
env         : string : Optional .env connection group: numeric id ("1"), alias ("prod"), or "default". Omit for startup connection. Call get_context(action='connections') to list groups.
```
