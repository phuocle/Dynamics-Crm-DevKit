# TOOL DESCRIPTION

```text
Inspect Dataverse static metadata catalogs. Always use resource='tables' for entity/attribute metadata (do NOT call execute_webapi with EntityDefinitions).

RESOURCES:
- 'tables' (default): list tables (name empty) or inspect entity attributes, relationships, alternate keys, and formula clone metadata (name set; detail_level='full' for formulas/cascades)
- 'solution_components': list components in a named solution with optional ActiveLayer (unmanaged) checks
- 'custom_controls': discover installed field or dataset PCF controls and manifest properties

Read docs://schema_tools_guide for schema rules before modifying metadata.
```

# PARAMETERS

```text
resource     : string : 'tables' (default), 'solution_components', or 'custom_controls'.
name         : string : tables: entity logical/display name (empty = list). solution_components: required solution unique/display name. custom_controls: optional PCF name filter.
filter       : string : tables only: list keyword filter, or detail attribute prefix/word-boundary filter.
detail_level : string : tables detail only: 'compact' (default), 'standard', or 'full'.
max_records  : int    : tables list only: 1-500 (default 100).
options      : object : Resource-specific options. tables: {custom_only, include_intersect, names}. solution_components: {include_active_layers, active_layers_only}. custom_controls: {name_match ('contains'|'prefix'|'exact'), kind ('field'|'dataset'), data_type}.
env          : string : Optional .env connection group: numeric id ("1"), alias ("prod"), or "default". Omit for startup connection. Call get_context(action='connections') to list groups.
```
