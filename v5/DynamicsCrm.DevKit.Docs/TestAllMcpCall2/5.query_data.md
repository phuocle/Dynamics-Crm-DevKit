# TOOL DESCRIPTION

```text
Read-only Dataverse data queries via FetchXML, SQL SELECT, or Dataverse Relevance Search.

MODES:
- 'fetchxml': deterministic FetchXML query (single-page or bounded auto-paging)
- 'sql': Dataverse Web API SQL SELECT subset (JOINs, aggregates, WHERE, ORDER BY; no SELECT *)
- 'search': keyword relevance search across searchable tables (detail_level='full' saves raw payload under .devkit/search_records/)
- 'search_status': diagnose Dataverse Search provisioning and entity index readiness

Read docs://data_operations_guide, docs://instructions_for_sql, or schema://fetchxml before complex queries.
```

# PARAMETERS

```text
mode         : string : Required: 'fetchxml', 'sql', 'search', or 'search_status'.
query        : string : Required for fetchxml (<fetch>...), sql (SELECT ...), or search (1-100 chars keyword query). Omit for search_status.
max_records  : int    : Max rows. Defaults: fetchxml 5000 (1-5000), sql 5000 (1-50000), search 50 (1-100).
get_all      : bool   : fetchxml/sql only: true = auto-page until max_records; false (default) = first page only.
entities     : string : search only: comma-separated Display Names or logical names (e.g. 'Account,contact'). Empty = all searchable.
filter       : string : search only: OData filter applied after search, e.g. 'statecode eq 0'.
detail_level : string : search/search_status only: 'compact' (default) or 'full' (saves raw API payload under .devkit/search_records/).
env          : string : Optional .env connection group: numeric id ("1"), alias ("prod"), or "default". Omit for startup connection. Call get_context(action='connections') to list groups.
```
