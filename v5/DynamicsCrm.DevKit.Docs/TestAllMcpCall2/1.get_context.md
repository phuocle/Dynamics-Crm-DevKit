# TOOL DESCRIPTION

```text
Inspect the active Dataverse identity/runtime, list configured .env connection groups offline, or parse a Dynamics 365/Power Platform URL or GUID.

ACTIONS:
- 'whoami' (default): verify live user, org, direct roles, dry-run policy, and DevKit process version/build/SHA
- 'connections': list .env connection groups, aliases, startup selection, and per-group policy without connecting
- 'parse_url': parse a main.aspx, Web API, maker/admin portal, or legacy URL (or raw GUID) into entity + recordId
```

# PARAMETERS

```text
action : string : 'whoami' (default), 'connections' (offline), or 'parse_url'.
input  : string : Required for action='parse_url': Dynamics 365 URL, Web API URL, maker portal URL, or raw GUID.
env    : string : Optional .env connection group: numeric id ("1"), alias ("prod"), or "default". Omit for startup connection. Call get_context(action='connections') to list groups.
```
