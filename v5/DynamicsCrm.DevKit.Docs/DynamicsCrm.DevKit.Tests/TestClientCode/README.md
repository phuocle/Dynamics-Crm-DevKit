# TestClientCode

This directory contains 6 isolated project environments used for testing, validation, and verification of the DynamicsCrm.DevKit templates and generators. They simulate different user scenarios (JS vs TS, Unit Testing vs AI Code vs VSIX Templates).

## Quick Start

```powershell
# From TestClientCode folder, run scripts in order:
.\01.Clean-All.ps1      # Clean all generated files
.\02.Install-All.ps1    # Install npm packages
.\03.Generate-All.ps1   # Generate entity files from CRM
.\04.Sync-All.ps1       # Sync source of truth files
.\05.Build-All.ps1      # Build TypeScript projects
.\06.Test-All.ps1       # Run all tests
```

## PowerShell Scripts

| # | Script | Purpose |
|---|--------|---------|
| 01 | `01.Clean-All.ps1` | Clean all generated files (node_modules, build, coverage, etc.) |
| 02 | `02.Install-All.ps1` | Install npm packages for all 6 folders |
| 03 | `03.Generate-All.ps1` | Run CLI to generate entity form/webapi files from CRM |
| 04 | `04.Sync-All.ps1` | Sync all source of truth files from Shared resources |
| 05 | `05.Build-All.ps1` | Build TypeScript projects in release mode |
| 06 | `06.Test-All.ps1` | Run all unit tests with code coverage |

## Folder Structure

### 01.DevKitJs-UnitTest
- **Purpose**: Validates JavaScript unit testing capabilities.
- **Tech Stack**: JavaScript, Jest, xrm-mock.
- **Key Scripts**: `npm run test`, `npm run coverage`.

### 02.DevKitTs-UnitTest
- **Purpose**: Validates TypeScript unit testing capabilities.
- **Tech Stack**: TypeScript, Jest, ts-jest, xrm-mock.
- **Key Scripts**: `npm run devkit-test`, `npm run check`.

### 03.DevKitJs-AICode
- **Purpose**: Sandbox for testing code generated by AI assistants (Copilot/Gemini) in JavaScript.
- **Use Case**: Verifying AI-generated snippets with `devkit.d.ts` definitions.

### 04.DevKitTs-AICode
- **Purpose**: Sandbox for testing code generated by AI assistants in TypeScript.
- **Use Case**: Ensuring type safety and correct compilation of AI-suggested code.

### 05.DevKitJs-Vsix
- **Purpose**: Represents the output structure of a JavaScript project created via VSIX template.
- **Use Case**: Verifying scaffolding, file structure, and default configurations.

### 06.DevKitTs-Vsix
- **Purpose**: Represents the output structure of a TypeScript project created via VSIX template.
- **Use Case**: Verifying TS scaffolding, `tsconfig`, and build scripts.

## Source of Truth

Files are synced from `DynamicsCrm.DevKit.Shared\Resources\`:

| Type | Source | Destination |
|------|--------|-------------|
| JS | `js\devkit.js` | `lib\devkit.js` |
| JS | `js\devkit.d.ts` | `entities\devkit.d.ts` |
| TS | `ts\devkit.ts` | `lib\devkit.ts` |
| TS | `ts\devkit.ts` | `lib\devkit.d.ts` |
| TS | `ts\build.js` | `build.js` |
