# Connection Type Implementation Plans

This directory contains detailed implementation plans for each connection type in priority order.

## Plan Files

1. **PLAN_01_OAuth_Enhancement.md** - Priority 1 - OAuth enhancements
2. **PLAN_02_ClientSecret_Enhancement.md** - Priority 2 - ClientSecret enhancements  
3. **PLAN_03_Interactive.md** - Priority 3 - Interactive browser OAuth
4. **PLAN_04_DeviceCode.md** - Priority 4 - Device code flow
5. **PLAN_05_ClientCertificate.md** - Priority 5 - Certificate authentication
6. **PLAN_06_ManagedIdentity.md** - Priority 6 - Azure managed identity
7. **PLAN_07_DefaultAzureCredential.md** - Priority 7 - Azure credential chain
8. **PLAN_08_FromPac.md** - Priority 8 - PAC CLI integration
9. **PLAN_09_AD.md** - Priority 9 - Active Directory (maintain)

## Plan Structure

Each plan includes:
- Overview and goals
- Reference implementation from Rnwood.Dataverse.Data.PowerShell
- Detailed implementation steps
- Code examples
- Testing strategy
- Success criteria

## Usage

These plans are designed to be used during implementation to ensure consistency and completeness. Each plan can be used independently for future development.
